Git 사용 시 Studio Pro 버전 9.24.28 이상에서 다양한 클론 유형을 사용할 수 있습니다.
{{% /alert %}}

## 소개

Git 버전 관리 시스템은 기본적으로 서버에서 리포지토리의 전체 사본을 다운로드합니다. Studio Pro에서는 오프라인 작업이나 대용량 리포지토리 작업 등 필요에 따라 최적화할 수 있도록 다른 클론 방식을 선택할 수 있습니다.

## 클론 유형

현재 Studio Pro는 두 가지 클론 유형을 지원합니다. 클론 유형은 리포지토리가 로컬 장치에 저장되는 방식에만 영향을 미치며 앱 자체에는 영향을 주지 않습니다.

기본적으로 Mendix는 전체 클론 사용을 권장합니다. 초기 다운로드가 약간 더 길어지지만 작업 중에 더 원활한 경험을 제공합니다.

시간이 지남에 따라 [대용량 리포지토리¹](/refguide/troubleshoot-repository-size/)가 축적된 경우, 부분 클론을 사용하여 초기 다운로드를 단축하고 개발 속도를 높일 수 있습니다.

*¹이 링크는 Mendix 10 문서로 연결되지만 Git을 사용하는 Mendix 9 앱에도 적용됩니다.*

### 전체 클론(Full Clone)

전체 클론은 Git의 기본 클론 유형으로, 서버에 있는 리포지토리의 전체 사본을 다운로드합니다.

이 클론 유형에는 다음과 같은 장점이 있습니다:

* 전체 사본이 있으면 서버에 연결하지 않고도 명령줄에서 일부 작업을 수행할 수 있습니다. 그러나 `detached head`와 같은 Git 작업은 Studio Pro에서 지원되지 않으므로 이점이 제한적입니다.
* 전체 클론으로 작업할 때 [변경 사항 결합](/refguide9/new-merge-algorithm/)과 같은 작업이 훨씬 빠를 수 있습니다. 최신 변경 사항은 서버에서 다운로드해야 하지만, 로컬 리포지토리에 이미 일부가 포함되어 있어 시간이 절약됩니다.

이 클론 유형의 단점은 전체 클론을 다운로드하는 데 상당히 오래 걸릴 수 있다는 것입니다. 2GB 리포지토리의 경우 로컬에 보관된 전체 히스토리를 제한적으로 사용하더라도 완전히 다운로드하고 압축을 해제해야 합니다.

### 부분 클론(Partial Clone)

"부분 클론"이라는 용어는 다양한 유형의 클론에 사용됩니다. Studio Pro에서는 `blobless clone`이 사용됩니다. Blobless clone을 수행하면 실제 파일 내용 없이 전체 커밋 히스토리가 포함된 메타데이터가 다운로드됩니다.

{{% alert color="info" %}}
이 경우 Studio Pro는 이미지가 여러 커밋에서 변경되었다는 것을 확인할 수 있지만, 전체 클론과 달리 인터넷 연결 없이는 이전 버전의 이미지를 로드할 수 없습니다.
{{% /alert %}}

이 클론 유형에는 다음과 같은 장점이 있습니다:

* 클론이 더 빠릅니다. 관련 데이터만 다운로드되므로 매우 빠르게 시작할 수 있습니다.
* 디스크 공간 사용이 제한됩니다. 로컬 리포지토리의 크기가 전체 클론에 비해 훨씬 작습니다.

이 클론 유형의 단점은 추가 다운로드가 필요할 수 있다는 것입니다. 예를 들어 이전 브랜치에서 [변경 사항을 결합](/refguide9/new-merge-algorithm/)할 때 전체 클론에 비해 더 많은 데이터를 다운로드해야 합니다. 이로 인해 약간 더 오래 걸릴 수 있습니다. 히스토리와 상호 작용할 때도 동일하게 적용됩니다.

## 환경 설정

향후 앱 다운로드 또는 이미 다운로드한 앱의 다른 브랜치 체크아웃과 같은 클론 작업에 대해 [클론 유형](/refguide9/preferences-dialog/#clone)을 변경할 수 있습니다. 이 설정을 변경해도 이미 다운로드한 앱에는 영향을 미치지 않습니다.

## 부분 클론을 전체 클론으로 변환

Mendix Studio Pro에서는 다운로드한 부분 클론을 전체 클론으로 변환할 수 있습니다. Git이 누락된 모든 데이터를 다운로드하도록 지시하여 최종적으로 전체 클론 상태가 됩니다.

부분 클론을 전체 클론으로 변환하려면 **Help** > **Support** > **Convert to full clone...**을 클릭하십시오. 앱이 이미 전체 클론인 경우 이 옵션은 비활성화됩니다.

열리는 대화 상자에서 변환을 시작할 수 있으며, 이는 차단 작업이므로 변환 중에는 Studio Pro를 사용할 수 없습니다. 이 프로세스의 소요 시간은 리포지토리 크기, 인터넷 연결 속도 및 컴퓨터 성능에 따라 달라집니다.
