## Catalog용 API

Mendix는 [Catalog](/catalog/)를 위해 다음과 같은 API를 제공합니다:

* [Search API](/apidocs-mxsdk/apidocs/search-api/)
  
  앱 개발에 사용할 수 있는 등록된 자산에 대한 정보를 검색하고 조회합니다.

* [Registration API](/apidocs-mxsdk/apidocs/registration-api/)
  
  조직의 Catalog에 서비스를 등록하고 업데이트합니다.

* [Transform API](/apidocs-mxsdk/apidocs/registration-api/#transform-api)
  
  Mendix Cloud 외부에 Mendix 애플리케이션을 배포하는 사용자를 위해, Registration API를 사용하여 서비스를 등록하기 위한 요청 본문을 생성합니다. Transform API의 v5 호환성은 엔드포인트 섹션의 Registration API를 통해 접근할 수 있습니다.
