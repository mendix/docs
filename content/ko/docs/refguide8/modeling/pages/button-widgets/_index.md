## 소개

버튼 위젯은 클릭 시 액션을 수행합니다. 버튼 또는 하이퍼링크로 렌더링할 수 있습니다. 버튼 위젯은 다음과 같이 나눌 수 있습니다:

* **Action Button** – 특정 액션을 수행하는 버튼의 일반적인 이름입니다. 액션을 직접 지정하거나 미리 구성된 액션이 있는 버튼을 선택할 수 있습니다. 예를 들어:
    * Microflow 호출 버튼
    * Nanoflow 호출 버튼
    * 페이지 열기 버튼
    * 저장 버튼
    * 취소 버튼
    * 링크 버튼
    * 페이지 닫기 버튼
    * 삭제 버튼
    * 동기화 버튼
    {{< figure src="/attachments/refguide8/modeling/pages/button-widgets/preconfigured-action-button.png" alt="Preconfigured Buttons" class="no-border" >}}

* **Drop-Down Button** – 항목 목록을 표시하며, 항목 중 하나를 클릭하면 액션이 수행됩니다. 최종 사용자가 드롭다운 버튼을 클릭하면 가능한 액션 목록이 포함된 팝업 창이 나타납니다:

    {{< figure src="/attachments/refguide8/modeling/pages/button-widgets/drop-down-example.png" alt="Drop-Down Button Example" class="no-border" >}}

    각 항목은 서로 다른 액션을 수행할 수 있습니다. 항목 및 할당할 수 있는 액션에 대한 자세한 내용은 *버튼 속성*의 [Item 섹션](/refguide8/button-properties/#items)을 참조하세요.
