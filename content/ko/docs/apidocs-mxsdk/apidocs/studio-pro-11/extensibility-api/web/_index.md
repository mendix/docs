## 소개

확장은 여기에 설명된 TypeScript 또는 기타 웹 언어로 작성하거나, [C# 개발자를 위한 Extensibility API](/apidocs-mxsdk/apidocs/csharp-extensibility-api-11/)에 문서화된 C# API를 사용하여 작성할 수 있습니다.

{{% alert color="info" %}}
확장 개발은 `--enable-extension-development` 기능 플래그를 사용해야만 가능합니다.
{{% /alert %}}

Web API에 대한 자세한 내용은 [Mendix Studio Pro Web Extensibility API 레퍼런스 문서](http://apidocs.rnd.mendix.com/11/extensions-api/index.html)를 참조하세요.

## 전제 조건

Web Extensibility API를 사용하려면 다음이 필요합니다:

* Mendix 플랫폼에 대한 기본적인 이해
* Mendix 모델에 대한 어느 정도의 이해
* TypeScript 개발 경험

## 시작하기

확장을 시작하는 방법에 대한 자세한 내용은 다음을 참조하세요: [Get Started with the Web Extensibility API](/apidocs-mxsdk/apidocs/web-extensibility-api-11/getting-started/).
