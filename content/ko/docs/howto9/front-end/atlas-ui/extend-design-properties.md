## 소개

디자인 속성을 사용하면 Widget의 외관을 간단하게 변경할 수 있습니다. 이러한 변경에는 색상, 테두리 및 간격과 같은 속성이 포함될 수 있습니다. Atlas 프레임워크에는 확장할 수 있는 기본 디자인 속성 세트가 기본 제공됩니다.

디자인 속성은 웹 앱과 네이티브 모바일 앱 모두의 스타일링에 있는 클래스를 기반으로 합니다. 기본적으로 디자인 속성은 클래스를 토글합니다.

디자인 속성은 Widget 속성의 일부로 표시됩니다:

{{< figure src="/attachments/howto9/front-end/atlas-ui/extend-design-properties/studio-pro-design-properties.png" alt="Design Properties in Studio Pro"   width="350"  class="no-border" >}}

디자인 속성 추가 방법에 대한 자세한 내용은 [Design Properties API 문서](/apidocs-mxsdk/apidocs/design-properties/)를 참조하세요.

개발자는 모듈의 일부로 추가 디자인 속성을 추가할 수도 있습니다. 자세한 내용은 *스타일링 커스터마이징 방법*의 [파일 및 폴더 구조](/howto9/front-end/customize-styling-new/#file-and-folder) 섹션을 참조하세요.
