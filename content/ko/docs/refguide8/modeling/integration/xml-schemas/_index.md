## 개요

XML 스키마는 XML Schema Definition (XSD) 파일에 정의되며 모델에 가져올 수 있습니다. 이는 특정 XML 문서가 어떤 형태여야 하는지 설명합니다. 예시는 **그림 1**에 표시되어 있습니다. 스키마는 [Import Mappings](/refguide8/import-mappings/) 및 [Export Mappings](/refguide8/export-mappings/)에서 사용할 수 있습니다.
