## Introduction

[Maia Spec](https://plan.home.mendix.com/index.html) (formerly Maia Plan) helps you create a project scope and a set of specifications, based on which you can then generate your app with [Maia Make](/refguide/maia-make/). The pages in this category describe how to provide project context, review and refine the generated project scope, and review the specifications to start app development.

Maia Spec covers the planning stage of the application lifecycle. You can use the specifications as input when building your app in Studio Pro with Maia Make, or have external AI agents read them through [Maia Spec as MCP Server](/developerportal/maia-plan-mcp/). For an overview of how Maia supports each stage, see [Maia Across the Development Lifecycle](/refguide/maia-development-lifecycle/).
