{{% alert color="info" %}}
최신 버전의 Native Template 5.2는 Android 11(API 레벨 30)을 대상으로 합니다. 

Android 13(API 레벨 33 이상)을 대상으로 하려면, **build.gradle** 파일에서 `compileSdkVersion`과 `targetSdkVersion`을 33으로 업데이트하고 종속성을 업데이트할 수 있습니다([이 블로그](https://www.mendix.com/blog/update-needed-for-android-native-mobile-apps/)의 *Build a new version of your native mobile app* 섹션 참조). 
{{% /alert %}}

## 5.2.18

**릴리스 날짜: 2023년 5월 24일**

### 수정 사항

* 원격 또는 로컬 알림이 활성화된 상태에서 앱을 빌드할 때 발생하는 문제를 수정했습니다. (티켓 185505, 186171)

## 5.2.17

**릴리스 날짜: 2023년 5월 16일**

### 수정 사항

* App Center 구성을 업데이트했습니다.
  
## 5.2.16

**릴리스 날짜: 2023년 1월 20일**

### 수정 사항

* AndroidX 라이브러리 버전을 고정하여 Android 빌드에 영향을 미치는 컴파일 오류 문제를 수정했습니다.

## 5.2.15

**릴리스 날짜: 2022년 12월 27일**

### 수정 사항

* jitpack.io 관련 문제를 해결하기 위해 Android 빌드의 리포지토리 순서를 변경했습니다.

## 5.2.14

**릴리스 날짜: 2022년 11월 9일**

### 수정 사항

* 최근 React Native 릴리스로 인해 Android 빌드 실패가 발생하는 문제를 수정했습니다. (티켓 170385, 170396, 170398, 170469)
* Apple M1 머신을 사용하여 로컬로 빌드된 Android 앱에 영향을 미치는 문제를 수정했습니다.

## 5.2.13

**릴리스 날짜: 2022년 6월 15일**

### 수정 사항

* 다크 모드에서 날짜 선택기가 보이지 않는 문제를 수정했습니다. (티켓 120143, 122791, 122843)

## 5.2.12

**릴리스 날짜: 2022년 5월 11일**

### 수정 사항

* CocoaPods 서비스가 일시적으로 사용 불가능할 때 빌드가 실패하는 iOS의 CocoaPods 문제를 수정했습니다.

## 5.2.11

**릴리스 날짜: 2022년 5월 10일**

### 수정 사항

* 빌드 실패를 일으키는 Android의 JCenter 문제를 수정했습니다. JCenter가 불안정해지고 더 이상 지원되지 않으므로, 이제 Android 종속성을 자체 호스팅합니다. (티켓 148798, 148819, 148830, 148840)

## 5.2.9

**릴리스 날짜: 2022년 3월 29일** 

### 개선 사항

* Native Template 5.2는 이제 Android 전체 화면 비디오를 지원합니다. 컨트롤 표시 속성이 `true`로 설정된 경우 비디오 상단에 전체 화면 아이콘이 있습니다. 아이콘을 누르면 비디오가 오버레이 모달에서 계속 재생됩니다. (티켓 135581)

## 5.2.8

**릴리스 날짜: 2022년 1월 25일** 

### 수정 사항

* Android v11 이상에서 **Navigate To** 액션이 Google Maps를 실행하지 못하는 문제를 식별하고 수정했습니다.

## 5.2.7

**릴리스 날짜: 2021년 11월 5일** 

### 수정 사항

* Android 11 이상을 사용하는 기기에서 `OpenURL` 및 `CallPhoneNumber` JavaScript 액션이 실패하는 누락된 구성을 추가했습니다. 이 구성이 없으면 액션이 실패합니다.

## 5.2.6

**릴리스 날짜: 2021년 11월 2일**

### 수정 사항

* 첫 번째 로그인 후 앱이 올바르게 다시 로드되지 않는 Android 버그를 수정했습니다.

## 5.2.5

**릴리스 날짜: 2021년 10월 25일**

### 개선 사항

* Android에서 SQLite 데이터베이스 수명 주기를 개선했습니다. 이를 통해 OTA 업데이트 후 앱이 재시작될 때 교착 상태가 발생할 가능성이 제거됩니다.

## 5.2.4

**릴리스 날짜: 2021년 9월 29일**

### 개선 사항

* iOS 15에서는 Xcode 13으로 앱을 재컴파일해야 합니다. 이 릴리스는 App Center의 구성을 Xcode 13을 사용하도록 업데이트합니다.

## 5.2.3

**릴리스 날짜: 2021년 9월 7일**

### 수정 사항

* Android의 종속성 해석 문제를 수정했습니다.

## 5.2.2

**릴리스 날짜: 2021년 8월 9일**

### 개선 사항

* 이 릴리스는 Firebase Crashlytics 지원을 도입하고 더 이상 사용되지 않는 Fabric.io 종속성에 대한 이전 참조를 제거합니다.

## 5.2.1

**릴리스 날짜: 2021년 7월 28일**

이 릴리스는 Native Template [5.2.0](#520)의 재릴리스입니다.

## 5.2.0 {#520}

**릴리스 날짜: 2021년 7월 26일**

### 개선 사항

* 기능 구성을 개선했습니다. `appCenterOTA` 기능에 대한 구현을 추가했습니다. 이로 인해 Native Mobile App Builder를 통해 OTA 지원이 활성화되지 않은 경우에도 모든 애플리케이션에 `Codepush`를 번들로 포함해야 하는 이전의 필요성이 제거되었습니다.
* Android 11 기기에 대한 지원을 구현했습니다.
* 이전 버전의 보안 문제로 인해 `react-native-codepush` 종속성을 `6.4.1`로 업데이트했습니다.

### 호환성을 깨뜨리는 변경 사항

* `react-native-image` 내부 종속성을 버전 `4.0.3`으로 업데이트하고 `react-native-permissions` 종속성을 도입했습니다. 개발자는 예기치 않은 동작을 피하기 위해 App Store에서 `NativeMobileResources` 모듈을 최신 버전으로 업데이트해야 합니다. 이 변경으로 인해 이전에 OTA 업데이트에 의존하던 개발자는 앱 스토어에 새 애플리케이션을 릴리스해야 합니다.
