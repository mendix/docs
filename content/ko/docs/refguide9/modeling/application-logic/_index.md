## 소개

위젯을 사용하여 페이지에서 간단한 Mendix 앱을 만들 수 있지만, 애플리케이션 로직을 추가하면 Mendix의 강력한 기능을 활용할 수 있습니다.

Mendix의 애플리케이션 로직은 [Microflow](/refguide9/microflows/), [Nanoflow](/refguide9/nanoflows/), [Workflow](/refguide9/workflows/)를 통해 구현할 수 있습니다. Expression을 사용하여 함수 또는 함수 조합에 기반하여 값을 변경할 수 있습니다.

Microflow와 Nanoflow를 사용하면 애플리케이션의 로직을 표현할 수 있습니다. 객체 생성 및 업데이트, 페이지 표시, 선택 수행 등의 작업을 수행할 수 있습니다. 이는 전통적으로 텍스트 프로그램 코드로 작성되던 것을 시각적으로 표현하는 방법입니다.

Workflow는 장기 실행 프로세스를 나타냅니다. Microflow 및 Nanoflow와의 주요 차이점은 대기 측면입니다. Workflow는 최종 사용자로부터 입력을 받을 때까지 일시 중지됩니다. 예를 들어, 직원이 출장 요청을 보내면(Workflow 시작을 트리거) 관리자가 버튼을 클릭하여 요청을 승인할 때까지 Workflow가 일시 중지됩니다.
