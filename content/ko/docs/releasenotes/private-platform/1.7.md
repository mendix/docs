이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.7에 적용된 변경 사항을 다루고 있습니다.

## 1.7.1

### 릴리스 날짜: 2024년 3월 19일

Private Mendix Platform 버전 1.7.1은 여러 버그 수정을 포함하는 패치 릴리스입니다.

#### 수정 사항

다음 수정 사항을 제공합니다:

* (Marketplace) 인증 헤더 없이 작동하도록 Bulk Importer를 수정하였습니다.
* (CI/CD) 자체 서명 인증서에 대한 핫픽스를 추가하였습니다.

## 1.7.0

### 릴리스 날짜: 2024년 2월 26일

Private Mendix Platform 버전 1.7.0에서는 Marketplace, 플랫폼 경험 및 Build 및 Deploy(CI/CD) 기능에 대한 여러 주요 기능이 도입되었습니다.

#### 새로운 기능

##### 플랫폼 사용량 통계 대시보드

이 대시보드를 통해 Company Admin은 플랫폼 사용 통계를 확인하고 프로젝트 생성, 협업 활동 등의 메트릭을 통해 진행 중인 플랫폼 활동을 빠르게 그래픽으로 확인할 수 있습니다.

##### 플랫폼 알림

새로 도입된 알림 기능을 통해 사용자 간의 상호작용이 향상되고 최신 정보를 더 잘 파악할 수 있습니다. 앱 초대가 이제 플랫폼 상단 바에 알림으로 표시되며, 추가 정보 및 관련 프로젝트나 페이지로의 링크가 포함된 알림 센터가 펼쳐집니다.

#### 개선 사항

##### Marketplace 업로드 승인 정책

Private Mendix Platform Marketplace에서 사용자가 업로드한 콘텐츠에 대한 승인 정책을 설정하기 위한 보다 세분화된 거버넌스 제어 기능이 추가되었습니다. 다음에 대해 승인을 구성할 수 있습니다:

* 일반적인 Marketplace 컴포넌트
* 개별 Marketplace 컴포넌트 버전

또한 게시 후 버전이 수정되지 않도록 컴포넌트 버전을 변경 불가능하게 설정할 수 있습니다.

##### CI/CD 경험 개선

Private Mendix Platform 1.7에는 Build 및 Deploy 기능 설정과 관련 서비스 통합 및 리소스 사용 구성에 관련된 다양한 UI 및 UX 개선 사항이 포함되어 있습니다.

##### 엔지니어링 개선

###### 환경 생성 시 임의 이름

보다 사용자 친화적인 환경 생성 프로세스를 위해, 각 환경에 대한 고유한 임의 이름이 식별자로 생성됩니다. 환경 이름은 사람이 읽을 수 있는 레이블로 설정되어 플랫폼에서 관련 위치에 표시됩니다. 환경의 기술적 이름(또는 식별자)은 이제 사용자 친화적 레이블과 분리되었습니다.

##### 기타 개선 사항

###### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.16](/releasenotes/studio-pro/9.24/#92416)으로 업데이트되었습니다
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.3](/releasenotes/studio-pro/10.6/#1063)으로 업데이트되었습니다

#### 수정 사항

다음 수정 사항을 제공합니다:

* (일반) SSO 로그인 시 오류가 발생하던 문제를 수정하였습니다.
* (Admin) **First-Time Setup** 과정의 두 번째 단계에서 발생하던 문제를 수정하였습니다.
* (플랫폼) 플랫폼 로드 시 브라우저 로그에 404 오류가 나타나던 문제를 수정하였습니다.
* (플랫폼) 특정 경우에 앱을 다른 사용자에게 이전할 수 없던 문제를 수정하였습니다.
* (플랫폼) 특정 경우에 사용자가 다른 사용자의 앱 요청을 수락할 수 없던 문제를 수정하였습니다.
* (Developer) 템플릿 선택기에서 선택한 버전이 유지되지 않던 문제를 수정하였습니다.
* (Developer) Studio Pro 10.6.1에서 임의의 Git 오류 팝업이 발생하던 문제를 수정하였습니다.
* (Marketplace) Marketplace 항목의 일부 카드 텍스트에 대한 시각적 정렬 문제를 수정하였습니다.
* (Marketplace) 새 버전이 추가된 후 컴포넌트 날짜가 변경되던 문제를 수정하였습니다.
* (CI/CD) 이전 Mendix 버전의 패키지 자동 감지 관련 문제를 수정하였습니다.
* (CI/CD) EKS 노드가 알 수 없는 경우의 오토스케일링 문제를 수정하였습니다.
* (CI/CD) **Keep Build pod** 체크를 해제하면 Pipeline 작업의 로그를 확인할 수 없던 문제를 수정하였습니다.
* (CI/CD) Studio Pro 10.6.1에서 빌드 패키지를 생성할 때 오류가 표시되던 문제를 수정하였습니다.
* (Download Portal) 관리자가 접근을 취소했지만 사용자가 로그인 상태로 유지되던 문제를 수정하였습니다.
