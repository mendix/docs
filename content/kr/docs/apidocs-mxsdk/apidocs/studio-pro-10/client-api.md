## 소개

강력한 API를 사용하여 필요한 JavaScript 액션을 빌드하십시오.

## Client API

Client API는 React 및 Dojo 클라이언트 모두와 호환되며 전역 mx 객체를 기반으로 하던 이전 API를 대체합니다. 이 공식 문서 사이트에는 예제, 모듈 등이 포함되어 있습니다:

* [Mendix 10 Client API](https://apidocs.rnd.mendix.com/10/client-mx-api/index.html)

{{% alert color="info" %}}
Mendix 10 Client API는 Studio Pro 10.20.0 이상에서 사용할 수 있습니다. 이전 버전의 Studio Pro의 경우 [Legacy Client API(#legacy)](#legacy)에 나열된 API를 사용하십시오.
{{% /alert %}}

{{% alert color="warning" %}}
Client API는 위젯에서 지원되지 않습니다. 위젯 개발의 경우 [Pluggable Widgets API](/apidocs-mxsdk/apidocs/pluggable-widgets/)를 사용하십시오.
{{% /alert %}}

## Legacy Client API {#legacy}

이 API는 Mendix 11에서 더 이상 사용되지 않으며 Mendix 12에서 완전히 제거될 예정입니다.

* [Mendix 10 Client API (React)](https://apidocs.rnd.mendix.com/10/client-react/index.html)
* [Mendix 10 Client API (Dojo)](https://apidocs.rnd.mendix.com/10/client/index.html)
