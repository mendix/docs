## 소개

*Mendix Studio Pro 9 가이드*는 [Studio Pro](/refguide9/modeling/), [Mendix Runtime](/refguide9/runtime/) 및 Mendix Platform의 기타 구성 요소에 관한 중요한 주제를 다룹니다.

Studio Pro 9를 설치하기 전에 [시스템 요구 사항](/refguide9/system-requirements/)을 확인하십시오. Studio Pro 설치 방법에 대한 정보는 [Mendix Studio Pro 설치](/refguide9/install/)를 참조하십시오.

Studio Pro 8을 사용해 오셨다면 [Mendix Studio Pro 8에서 9로 전환하기](/refguide9/moving-from-8-to-9/)를 읽어보시기 바랍니다.

다양한 Mendix 작업을 수행하는 단계별 가이드를 찾고 계시다면 [Studio Pro 9 사용 가이드](/howto9/)를 참조하십시오.

## Studio Pro 기능

Studio Pro를 사용하면 앱을 생성, 테스트 및 실행할 수 있습니다.

### 모델링

앱 모델링은 앱을 생성하는 과정으로, 페이지 생성, 로직 추가, 보안 구성 등을 포함합니다. 앱 모델링에 사용할 수 있는 기능에 대한 자세한 내용은 [앱 모델링](/refguide9/modeling/)을 참조하십시오.

### 테스트

애플리케이션 테스트와 관련하여, 먼저 무엇을 테스트할 것인지 결정해야 합니다: 외부 서비스와의 통합, 앱 로직(Microflow) 등. 애플리케이션 테스트 방법에 대한 자세한 내용은 [테스트](/howto9/testing/)를 참조하십시오.

### 배포

Studio Pro를 사용하면 앱을 로컬 또는 기본 환경에서 실행하고 확인할 수 있습니다.

앱 배포 옵션에 대한 자세한 내용은 [앱 배포](/deployment/)를 참조하십시오.

## 버전 관리

[버전 관리](/refguide9/version-control/)를 통해 앱 개발을 관리하고 여러 개발 라인에서 작업할 수 있습니다. Studio Pro가 앱 버전 관리를 처리하는 방법에 대한 정보는 *Studio Pro에서 버전 관리 사용하기*의 [클라우드에 배포된 앱 버전 관리](/refguide9/using-version-control-in-studio-pro/#versioning-app) 섹션을 참조하십시오.

## Mendix Runtime

[Mendix Runtime](/refguide9/runtime/)은 Studio Pro에서 생성된 애플리케이션 모델을 실행합니다. 동일한 버전 번호 체계를 사용하므로 Studio Pro 9 가이드에 포함되어 있습니다.

## 모바일

모바일 앱 개발을 통해 네이티브 모바일 및 하이브리드 앱을 만들 수 있으며, 이는 Studio Pro의 중요한 부분입니다. 자세한 내용은 [모바일](/refguide9/mobile/)을 참조하십시오.
