## 소개

**개요** 탭에서는 배포된 모든 앱과 해당 환경(해당되는 경우)의 목록을 볼 수 있습니다. [점수 기준](/control-center/scoring-criteria-tab/) 탭에서 구성한 각 심각도 수준에 대한 발견 사항의 수도 확인할 수 있습니다.

## 인사이트

**인사이트** 카드는 모든 환경에 걸친 발견 사항의 수를 심각도 수준별로 표시합니다. 예를 들어, 빌드 패키지에 하나의 심각한 발견 사항이 포함되어 있고 테스트 및 프로덕션 환경에 배포된 경우 **인사이트**에 두 개의 발견 사항이 추가됩니다.

각 카드에는 지난 30일 동안 발견 사항 수가 어떻게 변화했는지에 대한 이동 평균도 백분율로 표시됩니다.

다음은 2025년 1월 1일에 **심각** 발견 사항의 변화 추세를 계산하는 예시입니다:

* 1월 1일 이동 평균(12월 1일~1월 1일 사이의 **심각** 발견 사항 평균) = 5
* 12월 1일 이동 평균(11월 1일~12월 1일 사이의 **심각** 발견 사항 평균) = 10
* 변화 추세 = (5 - 10)/10, 결과적으로 **심각** 발견 사항이 50% 감소

계산은 하루에 한 번 새로 고침됩니다.
점수 기준을 변경하면 추세가 재설정됩니다.

심각도 수준에 대한 자세한 내용은 [점수 기준](/control-center/scoring-criteria-tab/)을 참조하십시오.

## 애플리케이션 환경 목록

애플리케이션 환경 목록 위에는 다음 옵션을 사용할 수 있습니다:

* 목록 내 정보를 검색하는 검색 상자.
* 클라우드 유형별로 앱을 표시하는 필터.
* 목록의 모든 정보를 Excel 파일로 내보내는 {{% icon name="office-sheet" %}}**모두 내보내기** 옵션.

앱 목록은 발견 사항 수와 심각도에 따라 높은 것부터 낮은 순으로 정렬됩니다. 다음 정보가 포함됩니다:

* **앱 이름** — 앱의 이름입니다.
* **환경** — 환경의 이름입니다.
* **런타임** — Mendix Runtime 버전입니다.
* **발견 사항** — 심각도 수준에 따라 색상으로 구분된 각 유형의 발견 사항 수입니다.
* **기술 담당자** — 앱의 기술 담당자입니다.
* **대상 클라우드** — 배포 패키지가 배포된 클라우드 유형입니다. 현재 다음 유형의 클라우드가 지원됩니다:
    * Mendix Free Cloud
    * Mendix Cloud(Mendix Cloud Dedicated 포함)
    * Mendix on Kubernetes(connected)
* 열 맞춤 설정({{% icon name="view" %}}) — {{% icon name="view" %}} 아이콘을 클릭하고 옵션을 선택 또는 해제하여 목록의 열을 맞춤 설정할 수 있습니다.
* **세부 정보 보기** — 이를 클릭하면 사용 가능한 경우 [애플리케이션 환경 요약](#app-env-summary) 페이지가 열립니다. 선택한 애플리케이션 환경에 SBOM을 사용할 수 없는 경우 **세부 정보 보기** 버튼이 회색으로 표시됩니다. 여기에서 컴포넌트를 표시하려면 호환되는 런타임 버전을 사용하고 새 배포 패키지를 생성해야 합니다.

목록에서 선택한 항목에 해당하는 정보를 Excel 파일로 내보내려면 목록에서 항목의 체크박스를 선택한 다음 페이지 하단에 나타나는 **선택 항목 내보내기**를 클릭하십시오.

## 애플리케이션 환경 요약 {#app-env-summary}

**개요** 탭의 목록에서 앱에 대해 **세부 정보 보기**를 클릭하면 **애플리케이션 환경 요약** 페이지가 열립니다. 이 페이지에는 선택한 앱이 사용하는 모든 컴포넌트에서 식별된 발견 사항에 대한 세부 정보가 표시됩니다.

페이지 상단에서 다음 정보를 찾을 수 있습니다:

* 앱 이름
* 색상으로 구분된 발견 사항 요약
* 환경 이름
* Mendix Runtime 버전
* 기술 담당자
* 배포 패키지가 배포된 클라우드 유형

페이지 오른쪽 상단에서 {{% icon name="download-bottom" %}}**SBOM**을 클릭하여 소프트웨어 자재 명세서(SBOM)를 다운로드할 수 있습니다.

소프트웨어 자재 명세서(SBOM)는 CycloneDX 형식의 *.json* 파일입니다. Mendix 앱과 그 안에 포함된 컴포넌트(종속성)에 대한 설명이 포함되어 있습니다. 자세한 내용은 [SBOM 생성](/refguide/sbom-generation/)을 참조하십시오.

Studio Pro 버전에 따라 다른 컴포넌트 종속성을 지원합니다. 버전별 지원되는 컴포넌트 종속성에 대한 자세한 내용은 *SBOM 생성*의 [지원되는 기능](/refguide/sbom-generation/#supported-features) 섹션을 참조하십시오.

페이지는 두 개의 탭으로 나뉩니다: **발견 사항** 및 **컴포넌트 사용**.

### 발견 사항 {#overview-findings}

**발견 사항** 탭에는 해당 특정 앱 환경에 영향을 미치는 모든 발견 사항이 나열됩니다.

{{< figure src="/attachments/control-center/security/software-composition/findings.png" >}}

목록 위에 다음 옵션을 사용할 수 있습니다:

* 목록 내 정보를 검색하는 검색 상자.
* 발견 사항 유형별로 목록 항목을 표시하는 필터.
* 목록의 모든 정보를 Excel 파일로 내보내는 {{% icon name="office-sheet" %}}**모두 내보내기** 옵션.

발견 사항 목록에는 다음 정보가 포함됩니다:

* **심각도** — 해당 컴포넌트와 관련된 발견 사항의 심각도 수준입니다.
* **발견 사항 유형** — **오래됨** 또는 **더 이상 사용되지 않음**일 수 있는 발견 사항의 유형입니다.
* **컴포넌트** — 앱에서 사용되는 컴포넌트의 이름입니다. 이를 클릭하면 해당 Mendix Marketplace 페이지로 이동합니다.
* **버전** — 앱에서 사용되는 컴포넌트의 버전입니다.
* **유형** — 컴포넌트의 유형입니다.
* **지원 유형** — Marketplace 컴포넌트의 지원 유형을 표시합니다. **Mendix**, **Partner** 또는 **Community**일 수 있습니다. 자세한 내용은 [콘텐츠 지원 카테고리](/appstore/marketplace-content-support/#category)를 참조하십시오.
* **기간** — 발견 사항이 적용된 일수로, 다음과 같이 계산됩니다:

    * 더 이상 사용되지 않는 컴포넌트: 현재 날짜 - 컴포넌트가 더 이상 사용되지 않게 된 날짜
    * 오래된 컴포넌트: 현재 날짜 - 첫 번째 상위 런타임 호환 버전의 게시 날짜

* **오래됨 이후 버전** — 현재 사용 중인 버전이 오래되게 만든 버전입니다. 오래된 컴포넌트에만 적용됩니다.
* **오래됨 이후 버전 게시 날짜** — 현재 사용 중인 버전이 오래되게 만든 버전의 릴리스 날짜입니다. 오래된 컴포넌트에만 적용됩니다.
* **더 이상 사용되지 않음 이후 버전** — 컴포넌트가 더 이상 사용되지 않게 된 버전입니다.
* **더 이상 사용되지 않음 이후 버전 게시 날짜** — 컴포넌트가 더 이상 사용되지 않게 된 버전의 릴리스 날짜입니다.
* 열 맞춤 설정({{% icon name="view" %}}) — {{% icon name="view" %}} 아이콘을 클릭하고 옵션을 선택 또는 해제하여 목록의 열을 맞춤 설정할 수 있습니다.

### 컴포넌트 사용 {#overviw-component-usage}

**컴포넌트 사용** 탭은 앱 내에서 사용되는 모든 컴포넌트의 상세 뷰를 표시합니다.

{{< figure src="/attachments/control-center/security/software-composition/component_usage.png" >}}

목록 위에 다음 옵션을 사용할 수 있습니다:

* 목록 내 정보를 검색하는 검색 상자.
* 클라우드 유형별로 앱을 표시하는 필터.
* 목록의 모든 정보를 Excel 파일로 내보내는 {{% icon name="office-sheet" %}}**모두 내보내기** 옵션.

컴포넌트 사용 목록에는 다음 정보가 포함됩니다:

* **컴포넌트** — 컴포넌트의 이름입니다.
* **버전** – 사용 중인 컴포넌트의 버전입니다.
* **유형** — 다음 중 하나일 수 있는 컴포넌트의 유형입니다:
  
    * **Module** — [Community Commons](https://marketplace.mendix.com/link/component/170)와 같이 Marketplace에서 가져온 표준 Marketplace 모듈입니다.
    * **Widget** — [Charts](https://marketplace.mendix.com/link/component/105695)와 같이 Marketplace에서 다운로드한 사용자 인터페이스 요소입니다.
    * **Framework** — Mendix Runtime 버전, 예: 10.12.0
    * **Jar** — [관리 종속성](/refguide/managed-dependencies/)을 사용하여 앱에 가져오거나 사용된 Studio Pro 버전에 따라 **userlib** 폴더에 수동으로 추가된 Java 라이브러리, 예: `org.apache.commons.io`.
    * **npms** — [JavaScript 액션](/refguide/javascript-actions/)에서 사용되는 `npm` 라이브러리입니다.
    * **Unknown** — 컴포넌트 유형이 위의 항목에 해당하지 않아 확인할 수 없는 경우입니다.
    
* **지원 유형** – Marketplace 컴포넌트의 지원 유형입니다. **Mendix**, **Partner** 또는 **Community**일 수 있습니다.
  자세한 내용은 [콘텐츠 지원 카테고리](/appstore/marketplace-content-support/#category)를 참조하십시오.
* **라이선스** – Mendix Marketplace에서 파생된 컴포넌트의 경우 최종 사용자 라이선스입니다.
* **최신 버전** – 컴포넌트의 최신 버전입니다.
* **Marketplace** – 컴포넌트가 **Public**인지 **Private**인지 여부입니다. 퍼블릭 컴포넌트는 Marketplace에서 전체 Mendix 커뮤니티에 사용할 수 있고, 프라이빗 컴포넌트는 [회사 콘텐츠](/appstore/home-page/#company-content) 페이지를 통해서만 사용할 수 있습니다.
* **최신 런타임 호환 버전** — 컴포넌트가 호환되는 가장 최근 런타임 버전입니다.
* **게시자** – 컴포넌트를 게시한 조직의 이름입니다.
* 열 맞춤 설정({{% icon name="view" %}}) – {{% icon name="view" %}} 아이콘을 클릭하고 옵션을 선택 또는 해제하여 목록의 열을 맞춤 설정할 수 있습니다.

목록에서 선택한 항목에 해당하는 정보를 Excel 파일로 내보내려면 목록에서 항목의 체크박스를 선택한 다음 페이지 하단에 나타나는 **선택 항목 내보내기**를 클릭하십시오.
