이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.18에 적용된 변경 사항을 다루고 있습니다.

## 1.18.0

### 릴리스 날짜: 2025년 1월 23일

Private Mendix Platform 버전 1.18.0에서는 다수의 개선 사항 및 버그 수정이 도입되었습니다.

#### 개선 사항

##### 환경 리소스 패키지 사용자 정의 가능

이제 [새 환경을 생성](/developerportal/deploy/private-cloud-deploy/#create-environment)할 때 선택하는 환경 리소스 패키지(소형, 중형, 대형)를 사용자 정의할 수 있습니다.

##### 관리자 설정의 중국어, 일본어, 한국어 현지화

Private Mendix Platform의 다양한 관리자 설정 및 메뉴를 이제 중국어, 일본어, 한국어로 사용할 수 있습니다.

##### 로깅 개선

버전 1.18.0에서는 로깅 및 감사에 대한 여러 개선 사항이 도입되었습니다. 여기에는 다음이 포함됩니다:

* 일부 작업에 대해 로깅되는 세부 수준 구성
* 감사 작업 정렬 및 필터링
* 외부 데이터베이스에 로그 작성
* 감사 로깅 실패 시 이메일 알림 수신

##### UX 개선

**Refresh**를 클릭한 후 화면이 **My Apps** 페이지로 돌아가지 않고 현재 페이지에 유지되도록 하였습니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.31](/releasenotes/studio-pro/9.24/#92431)로 업데이트되었습니다 (프로덕션 지원)
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.18](/releasenotes/studio-pro/10.6/#10618)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)
* Studio Pro 10.12 MTS 최신 패치 버전이 [10.12.11](/releasenotes/studio-pro/10.12/#101211)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)

#### 수정 사항

다음 수정 사항을 제공합니다:

* (Marketplace) Marketplace 콘텐츠 이름이 고유해야 하는 요구 사항을 추가하였습니다.
* (플랫폼) S3 버킷에서 파일 다운로드 시 발생하던 문제를 수정하였습니다.
* (플랫폼) Build Pipeline에 Webhook을 추가할 때 발생하던 문제를 수정하였습니다.
* (플랫폼) Kubernetes용 MDA 패키지 및 OCI 이미지 관련 필드가 표시되지 않던 문제를 수정하였습니다.
* (UI) 사용할 수 없는 빌드 메서드에서 **Build Steps** 옵션이 회색으로 표시되도록 하였습니다.
* (UI) 일부 페이지 간 이동 시 URL이 변경되지 않던 문제를 해결하였습니다.

#### 알려진 문제

* Private Mendix Platform은 AWS ECR 및 Azure ACR 마이그레이션을 위한 수동 프로덕션 배포 클러스터를 지원하지 않습니다.
* 진행 중인 Git 호환성 문제로 인해 이번 릴리스에서는 Private Mendix Platform에서 Studio Pro 10.18 MTS를 사용할 수 없습니다.
