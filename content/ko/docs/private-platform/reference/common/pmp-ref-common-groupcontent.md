## 소개

**My Content** 페이지는 사용자가 속한 그룹이 소유한 모든 콘텐츠 목록을 표시합니다. 관련 그룹과 공유된 항목만 여기에 표시됩니다. 콘텐츠의 초안 버전은 페이지에 표시되지 않습니다.

{{< figure src="/attachments/private-platform/pmp-refguide-mygroupcontent.png" class="no-border" >}}

**Add Content**를 클릭하여 새 콘텐츠 항목을 추가할 수 있습니다. 자세한 내용은 [Marketplace 콘텐츠 공유](/private-mendix-platform/user-guide/#sharing-content-with-groups)를 참조하십시오.

콘텐츠 항목을 클릭하여 Private Platform Marketplace에서 보거나 다운로드할 수도 있습니다.

{{< figure src="/attachments/private-platform/pmp-group-content-details.png" class="no-border" >}}
