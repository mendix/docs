## 소개

관계 Expression을 사용하면 사용자가 값을 비교하고 해당 정보를 기반으로 변경 및 작업을 수행할 수 있습니다. 이러한 Expression의 반환 유형은 항상 Boolean입니다.

## 보다 작음 ( < )

이 Expression은 첫 번째 값이 두 번째 값보다 작은지 확인합니다.

### 입력 매개변수

가능한 값은 아래 표에 설명되어 있습니다:

| 값      | 유형                            |
| ---------- | ------------------------------- |
| 두 개의 값 | String                          |
| 두 개의 값 | Numeric (Integer/Long, Decimal) |
| 두 개의 값 | Date and time                   |

{{% alert color="info" %}}
두 값은 같은 범주에 있어야 합니다(예: 하나가 숫자이면 다른 하나도 숫자여야 합니다).
{{% /alert %}}

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값              | 유형    |
| ------------------ | ------- |
| `True` 또는 `False`. | Boolean |

### 예제

다음 입력을 사용하는 경우:

```java
4<3
```

출력은 다음과 같습니다:

```java
False
```

## 같음 ( = )

이 Expression은 두 값이 같은지 확인합니다.

### 입력 매개변수

가능한 값은 아래 표에 설명되어 있습니다:

| 값      | 유형                                                         |
| ---------- | ------------------------------------------------------------ |
| 두 개의 값 | String                                                       |
| 두 개의 값 | Numeric (Integer/Long, Decimal)                              |
| 두 개의 값 | Date and time                                                |
| 두 개의 값 | Domain Entity; 동등성은 객체의 ID를 기반으로 확인됩니다 |

{{% alert color="info" %}}
두 값은 같은 범주에 있어야 합니다(예: 하나가 숫자이면 다른 하나도 숫자여야 합니다).
{{% /alert %}}
{{% alert color="info" %}}
빈 값과의 비교는 다른 값이 `empty`이거나 빈 목록인 경우에만 `true`로 평가됩니다.
{{% /alert %}}

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값              | 유형    |
| ------------------ | ------- |
| `True` 또는 `False`. | Boolean |

### 예제

아래 예제는 Expression이 반환하는 값을 보여줍니다:

* 다음 입력을 사용하는 경우:

    ```java
    "mystring" = "myotherstring"
    ```

    출력은 다음과 같습니다:

    ```java
    False
    ```

* 다음 입력을 사용하는 경우:

    ```java
    dateTime(2007) = dateTime(2007)
    ```

    출력은 다음과 같습니다:

    ```java
    True
    ```

## 같지 않음 ( != )

두 값이 같지 않은지 확인합니다.

### 입력 매개변수

값은 다음 유형 중 하나일 수 있지만, 두 값은 같은 범주에 있어야 합니다(예: 둘 다 숫자):

가능한 값은 아래 표에 설명되어 있습니다:

| 값      | 유형                                                      |
| ---------- | --------------------------------------------------------- |
| 두 개의 값 | String                                                    |
| 두 개의 값 | Numeric (Integer/Long, Decimal)                           |
| 두 개의 값 | Date and time                                             |
| 두 개의 값 | Object; 동등성은 객체의 ID를 기반으로 확인됩니다 |

{{% alert color="info" %}}
두 값은 같은 범주에 있어야 합니다(예: 하나가 숫자이면 다른 하나도 숫자여야 합니다).
{{% /alert %}}
{{% alert color="info" %}}
빈 값과의 비교는 다른 값이 `empty`이거나 빈 목록인 경우에만 `true`로 평가됩니다.
{{% /alert %}}

### 출력 

출력은 아래 표에 설명되어 있습니다:

| 값              | 유형    |
| ------------------ | ------- |
| `True` 또는 `False`. | Boolean |

### 예제

다음 입력을 사용하는 경우:

```java
"mystring" != "mystring"
```

출력은 다음과 같습니다:

```java
False
```
