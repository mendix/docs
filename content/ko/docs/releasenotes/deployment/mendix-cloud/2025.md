## December 2025

### December 23, 2025

#### New Features

* Dynatrace 통합에 로깅 지원을 추가했습니다.

### December 14, 2025

#### Improvements

* 내부 데이터 객체에 대한 더 강력한 접근 제어를 통해 보안 인프라를 강화했습니다.

### December 06, 2025

#### Improvements

* 계약 만료 배너를 지원하도록 Mendix Dock를 업그레이드했습니다. Mendix Cloud는 이제 계약이 만료일에 가까워질 때 적시에 정보를 제공할 수 있습니다.

## November 2025

### November 23, 2025

#### New Features

* 고객 환경 간의 일관성을 보장하고 예기치 않은 배포 동작을 방지하기 위해 Kubernetes의 배포 컴포넌트에 대한 [Version Pinning](/developerportal/deploy/version-pinning/)을 도입했습니다. 애플리케이션을 한 환경에서 상위 환경으로 프로모션하여 이 기능을 사용할 수 있습니다.

* 이제 특정 경우에 서비스 중단 없이 [Zero-Downtime](/developerportal/deploy/zero-downtime/)으로 Mendix 애플리케이션을 배포할 수 있습니다. [Deploy Wizard](/developerportal/deploy/environments/#deploy-wizard)의 **Options Tab**에서 **Deploy without downtime** 옵션을 선택하여 활성화할 수 있습니다. 이 기능은 앱 패키지를 다시 빌드하거나 교체하지 않는 변경에 적용됩니다.

### November 9, 2025

#### New Features

* **Cloud Settings** 페이지에 [IP Restriction Profiles](/developerportal/deploy/access-restrictions/#ip-restriction-profiles)라는 새 기능을 추가하여, 애플리케이션 URL의 루트 수준에서 IP 주소를 차단할 수 있습니다. 구성된 프로파일은 **Networks** 탭의 [IP Access Restriction](/developerportal/deploy/environments-details/#ip-access-restrictions) 섹션에서 적용할 수 있습니다.

#### Bug Fixes

* 사용자 정의 도메인 경로가 애플리케이션에서 삭제되었음에도 완전히 제거되지 않던 문제를 수정했습니다.

## October 2025
  
### October 29, 2025

#### New Features

* Kubernetes에 배포된 앱이 이제 New Relic을 지원하여, Cloud Foundry에서 Kubernetes로 마이그레이션할 수 있습니다.

* New Relic을 사용하는 Kubernetes 배포의 경우, 메타데이터 내에서 `instance_index` 태그가 더 이상 제공되지 않습니다. 대신 `pod_name` 태그를 사용하세요.

### October 19, 2025

#### New Features

* Flexible environments를 위한 **Environment Details** 페이지에 새 기능을 추가했습니다. 사용자는 이제 환경의 표시 이름에 비라틴 문자를 사용할 수 있습니다. 환경의 표시 이름은 환경의 서브도메인과 독립적으로 변경할 수 있습니다.

* 이메일 국제화 지원을 추가했습니다. Developer Portal에서 발송하는 이메일이 이제 사용자 프로필에 설정된 언어로 번역됩니다.

#### Bug Fixes

* 누락된 패키지 메타데이터로 인해 앱이 정상적으로 실패하지 않고 "starting" 상태에서 멈추던 문제를 수정했습니다.

### October 12, 2025

#### Bug Fixes

* 환경 배포 활동이 [Activity 탭](/developerportal/deploy/environments/#activity-tab)에 표시되지 않던 문제를 수정했습니다.

### October 5, 2025

#### New Features

* Kubernetes에 배포된 앱에 대해 **Access Restriction Profile**에서 IP 차단 목록 지원을 추가하여, 구성된 프로파일과 일치하는 특정 IP에서의 수신 요청을 차단할 수 있습니다.

#### Bug Fixes

* **Path Based Access Restriction**에서 중복 경로가 추가되어 Kubernetes 앱의 배포 실패를 유발하던 문제를 수정했습니다. 이 수정으로 새로운 중복은 방지되지만, 기존 중복은 수동으로 제거해야 합니다.

### October 1, 2025

#### Announcement – 2026년 2월 1일부터 HTTPS SSL/TLS 취약 암호 지원 중단

Mendix Cloud v4의 애플리케이션에 대한 HTTPS 연결 보안을 강화하기 위해, 취약한 것으로 간주되는 다음 블록 암호에 대한 지원을 중단합니다:

* `TLS_DHE_RSA_WITH_AES_128_GCM_SHA256`
* `TLS_DHE_RSA_WITH_AES_256_GCM_SHA384`

**Mendix 애플리케이션에 미치는 영향**

RSA 키 교환을 사용하는 DHE(Diffie-Hellman Ephemeral) 암호만 지원하는 클라이언트는 더 이상 Mendix 애플리케이션에 연결할 수 없게 됩니다.

**계속 지원하는 항목**

또한 새로운 권장 SSL/TLS 암호를 도입할 예정입니다. 이러한 추가 사항으로 2026년 2월 1일 이후 HTTPS 연결에 대해 계속 지원되는 암호 목록이 확정됩니다:

**TLSv1.3**

* `TLS_AES_128_GCM_SHA256`
* `TLS_AES_256_GCM_SHA384`
* `TLS_CHACHA20_POLY1305_SHA256`

**TLSv1.2**

* `TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256`
* `TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384`
* `TLS_ECDHE_RSA_WITH_CHACHA20_POLY1305_SHA256`
* `TLS_ECDHE_ECDSA_WITH_AES_128_GCM_SHA256`
* `TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384`
* `TLS_ECDHE_ECDSA_WITH_CHACHA20_POLY1305_SHA256`
* `TLS_ECDHE_PSK_WITH_CHACHA20_POLY1305_SHA256`

## September 2025

### September 21, 2025

#### Improvements

* **Environments** 페이지의 **Request Overview** 탭 이름을 **Change Requests**로 변경했습니다.

### September 9, 2025

#### New Features

* Kubernetes에 배포된 앱에 대한 Splunk 로그 전송 지원을 추가했습니다. 이를 통해 Splunk를 사용하는 앱을 Cloud Foundry에서 Kubernetes로 마이그레이션할 수 있습니다.

#### Improvements

* Kubernetes 배포의 경우 `SPLUNK_LOGS_REDACTION` 환경 변수를 사용할 수 없습니다. 대신 `LOGS_REDACTION` 변수를 사용하세요.

## August 2025

### August 17, 2025

#### New Features

**Environment Details** 창의 [Plan Details](/developerportal/deploy/environments-details/#plan-details) 섹션에서 플랜을 변경할 수 있습니다. 플랜 이름 옆의 **Change Plan**을 클릭하세요.

## July 2025

### July 27, 2025

#### New Features

* 상태 아이콘의 안정성을 향상시켰습니다. 이 업데이트의 일환으로, 애플리케이션 로그의 위험 또는 경고 수준 [알림](/developerportal/operate/monitoring-application-health/)을 나타내는 새로운 **Alerts** 레이블을 도입했습니다. 상태 아이콘은 이제 환경의 실행 상태만을 반영합니다.

#### Bug Fixes

* 사용자가 Sandbox 앱의 백업을 볼 수 없던 문제를 수정했습니다. (Ticket 252022)
* [Model Options](/developerportal/deploy/environments-details/#model-options) 탭의 **Export to Excel** 옵션을 개선했습니다. 내보낸 파일이 이제 세미콜론 대신 쉼표 구분자를 사용합니다. (Feedback #1460)
* **Permissions** 페이지의 정렬 동작을 개선했습니다. 항목이 이제 이름순으로 정렬되고 유형별(역할 기반 / 비역할 기반)로 그룹화됩니다. (Feedback #1458)

### July 13, 2025

#### Bug Fixes

* [Upload Package API](/apidocs-mxsdk/apidocs/deploy-api-2/#upload-package)에 엄격한 유효성 검사를 구현했습니다. 요청 매개변수 키는 이제 특히 file 키에 대해 정확한 이름 일치가 필요합니다.
* **Resource Mismatch** 레이블이 잘못 표시되던 문제를 수정했습니다. 이 레이블은 이제 UI 스케일 설정이 백엔드 클라우드 리소스 설정과 다를 때만 표시됩니다.

## June 2025

### June 12, 2025

#### New Features

* [환경 UI](/developerportal/deploy/environments/)에 새로운 베타 기능을 추가했습니다. 이 기능을 통해 Technical Contact가 앱의 [환경 플랜을 변경](/developerportal/deploy/change-plan/)하여 더 높은 리소스 플랜으로 변경할 수 있습니다.
    * 또한 Technical Contact가 플랜 변경 요청을 보고 관리하고 [Control Center](/control-center/approval-requests/)에서 Mendix Admin 검토를 기다리는 대기 중인 요청의 상태를 추적할 수 있는 새 탭([Change Requests](/developerportal/deploy/environments/#change-requests))이 도입되었습니다.

## May 2025

### May 25, 2025

#### New Features

* 백업 복원을 시작하기 전에 필요한 오버헤드(데이터베이스 디스크 공간)에 대한 새로운 경고 메시지를 추가했습니다.
  
#### Improvements

* 사용자 정의 도메인 이름 생성을 위한 유효성 검사 규칙을 업데이트했습니다. DNS 표준에 따라 53자 제한 대신 63자 제한으로 변경되었습니다.
* Old UI가 더 이상 사용되지 않으며 6월 1일에 제거됩니다. 이전에 전환하지 않은 사용자는 자동으로 새 UI로 전환됩니다.

#### Bug Fixes

* 사용자가 프로덕션 환경의 권한 탭을 열 때 오류가 발생하던 버그를 수정했습니다 (Ticket 241675).

#### Temporary Deprecations

* Basic 플랜 제공이 일시적으로 중단됩니다.

## April 2025

### April 17, 2025

#### Improvements

* Splunk 및 New Relic용 Fluentbit 에이전트의 버퍼 크기와 버퍼 메모리를 제어할 수 있는 새로운 환경 변수를 추가했습니다.

## February 2025

### February 20, 2025

#### Improvements

* 사용자 정의 JMX 메트릭 접두사를 `jmx`에서 `mx`로 업데이트했습니다. 이 변경으로 이러한 메트릭이 Datadog에서 `custom metrics`로 인덱싱되지 않습니다.

### February 2, 2025

#### New Features

* [새 UI](/developerportal/deploy/environments/)의 일부로 제공되는 여러 새 기능을 추가했습니다:

    * 기능 및 사용자 경험을 개선하기 위해 **Environment Details** 페이지를 재설계했습니다.
    * Deploy wizard에 스테이징 지원을 추가했습니다.
    * 환경 간 모델 옵션을 비교하고 편집하는 기능을 추가했습니다.
    * Free App의 **Environments** 페이지를 재설계했습니다.

#### Improvements

* 사용자 피드백을 기반으로, [새 UI](/developerportal/deploy/environments/)에 유료 앱의 **Environments Overview** 페이지에 대한 UX 개선 사항도 포함되었습니다.
