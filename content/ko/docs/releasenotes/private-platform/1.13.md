이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.13에 적용된 변경 사항을 다루고 있습니다.

{{% alert color="info" %}}
이것은 [MTS](/releasenotes/studio-pro/lts-mts/#mts) 버전 릴리스입니다. LTS 버전 [1.24](/releasenotes/private-platform/1-24/)가 릴리스됨에 따라 이 MTS 버전은 더 이상 지원되지 않습니다.
{{% /alert %}}

## 1.13.4

### 릴리스 날짜: 2025년 2월 20일

Private Mendix Platform 버전 1.13.4는 취약점 수정을 위한 패치 릴리스입니다.

#### 개선 사항

MTS 버전의 취약점을 수정하고 Private Mendix Platform 런타임 버전을 10.6에서 10.12로 업그레이드하였습니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24.31 LTS (프로덕션 등급 지원)
* Studio Pro 10.6.18 MTS (이노베이션 트랙 전용, 제한적 지원)
* Studio Pro 10.12.11 MTS (이노베이션 트랙 전용, 제한적 지원)

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전 [2.20.1](/releasenotes/developer-portal/mendix-for-private-cloud/#2.20.1)
* Private Cloud License Manager (PCLM) 버전 [0.9.0](/releasenotes/developer-portal/mendix-for-private-cloud/#september-13th-2024)

## 1.13.2

### 릴리스 날짜: 2024년 9월 18일

Private Mendix Platform 버전 1.13.2는 Private Cloud License Manager와 Mendix Operator 간 연결을 암호화하기 위해 사용자 정의 자체 서명 root-CA 인증서를 사용하는 것을 지원하는 패치 릴리스입니다.

#### 개선 사항

PCLM에서 구성된 사용자 정의 자체 서명 root-CA 인증서를 사용하여 암호화된 경우, Mendix Operator가 Private Cloud License Manager(PCLM)로의 TLS 연결을 신뢰하지 않던 문제를 수정하였습니다.

이 릴리스에서는 Operator 배포에서 로그 레벨을 설정하여 고객이 로그 가시성을 조정할 수 있도록 하고, 라이선스 없이 PCLM이 구성된 경우의 애플리케이션 스케일링 문제를 해결하며, JSON 형식의 로그를 생성하는 등 Mendix Operator에 대한 다양한 개선 사항도 제공합니다. 자세한 내용은 [Operator 릴리스 노트](/releasenotes/developer-portal/mendix-for-private-cloud/#2.19.0)를 참조하십시오.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24.26 LTS (프로덕션 등급 지원)
* Studio Pro 10.6.12 MTS (이노베이션 트랙 전용, 제한적 지원)

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전을 2.19.0으로 업그레이드하였습니다
* Private Cloud License Manager 버전을 0.9.0으로 업그레이드하였습니다

#### 수정 사항

* Build 또는 Deploy Steps(Pipeline 템플릿) 편집기에서 Pipeline의 마지막 Webhook 단계에 대한 편집 또는 삭제 등의 변경 사항이 유지되지 않던 문제를 수정하였습니다.
* **Share with groups** 창의 드롭다운 목록이 올바르게 작동하지 않던 문제를 수정하였습니다.
* Build 또는 Deploy Steps(Pipeline 템플릿) 편집기에서 **Edit** 창을 닫을 때 Webhook 페이로드에 대한 사용자 정의가 올바르게 저장되지 않던 문제를 수정하였습니다.
* 권한 누락으로 인해 Mendix 10.6.9 앱의 Build 패키지가 실패하던 문제를 수정하였습니다.
* Bitbucket을 버전 관리 호스트로 사용할 때 사용자가 앱 프로젝트를 떠날 때 저장소에서 사용자를 제거하는 것과 관련된 [알려진 문제](/releasenotes/private-platform/1-13/#issue131a)를 수정하였습니다.
* 할당된 그룹 관리자가 다른 그룹의 멤버이기도 한 경우 새 사용자 그룹 생성 시 예기치 않은 유효성 검사 오류가 발생하던 [알려진 문제](/releasenotes/private-platform/1-13/#issue131b)를 수정하였습니다.
* 앱 프로젝트가 다른 소유자에게 이전되고 이전 소유자가 떠났을 때 409 오류가 나타나던 [알려진 문제](/releasenotes/private-platform/1-13/#issue131c)를 수정하였습니다.
* Company Admin이 한 사용자에서 다른 사용자로 앱 프로젝트 소유권을 이전하려 할 때 발생하던 [알려진 문제](/releasenotes/private-platform/1-13/#issue131d)를 수정하였습니다.
* 앱 프로젝트 이름이 변경될 때 저장소 URL 오류가 발생하던 [알려진 문제](/releasenotes/private-platform/1-13/#issue131e)를 수정하였습니다.

## 1.13.1

### 릴리스 날짜: 2024년 9월 6일

Private Mendix Platform 버전 1.13.1은 여러 개선 사항 및 버그 수정을 포함하는 패치 릴리스입니다.

#### 개선 사항

* 사용자가 로그아웃할 때 사용자가 생성한 Personal Access Token(PAT)이 삭제되던 문제를 수정하였습니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24.26 LTS (프로덕션 등급 지원)
* Studio Pro 10.6.12 MTS (이노베이션 트랙 전용, 제한적 지원)

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전을 2.18.1로 업그레이드하였습니다

#### 알려진 문제

##### Bitbucket 호스트에서 사용자 제거 관련 문제 {#issue131a}

Bitbucket을 버전 관리 호스트로 사용할 때, 사용자가 앱 프로젝트를 떠날 때 저장소에서 사용자를 제거하는 데 문제가 있습니다.

###### 원인

사용자가 Mendix 앱 프로젝트를 떠날 때 해당 Bitbucket 사용자를 저장소에서 제거하지 못하는 Bitbucket 통합 문제입니다.

###### 해결 방법

Company Admin이 앱 프로젝트에서 해당 사용자를 제거해야 합니다.

##### 사용자 그룹 생성 시 유효성 검사 오류 {#issue131b}

할당된 그룹 관리자가 다른 그룹의 멤버이기도 한 경우 새 사용자 그룹 생성 시 예기치 않은 유효성 검사 오류가 발생합니다.

###### 원인

이 문제는 그룹 관리 로직의 버그로 인해 발생합니다.

###### 해결 방법

Company Admin은 다음 단계를 수행해야 합니다:

1. 새 그룹을 생성합니다.
2. 즉시 저장합니다.
3. **Group Detail** 페이지에서 그룹 관리자를 할당합니다.

##### 사용자에 의한 앱 소유권 이전 시 409 오류 {#issue131c}

앱 프로젝트가 다른 소유자에게 이전되고 이전 소유자가 떠났을 때 409 오류가 나타납니다.

###### 원인

이 문제는 앱 소유권 로직의 버그로 인해 발생합니다.

###### 해결 방법

소유권 이전 후 이전 소유자는 떠나지 말아야 합니다. 대신 새 소유자가 이전 소유자를 제거해야 합니다.

##### Admin에 의한 앱 소유권 이전 시 데이터 충돌 문제 {#issue131d}

Company Admin이 한 사용자에서 다른 사용자로 앱 프로젝트 소유권을 이전하려 할 때 데이터 충돌 문제가 발생합니다. 소유권 상태는 업데이트되지만 해당 사용자의 프로젝트 역할은 이전과 동일하게 유지됩니다.

###### 원인

이 문제는 소유권 이전 로직의 버그로 인해 발생합니다.

###### 해결 방법

사용자 간에 앱 프로젝트를 이전한 후 Company Admin이 각 프로젝트 역할을 수동으로 설정해야 합니다.

##### 앱 프로젝트 이름 변경 관련 문제 {#issue131e}

앱 프로젝트 이름이 변경될 때 저장소 URL 오류가 발생합니다.

###### 원인

앱 이름 변경 로직의 버그로 인해 앱 이름이 업데이트된 후 저장소 URL이 빈 값으로 설정됩니다. 이로 인해 사용자가 Studio Pro에서 앱을 올바르게 사용하지 못할 수 있습니다.

###### 해결 방법

이 버그는 향후 릴리스에서 수정될 예정입니다. 이 문제가 해결될 때까지 앱 프로젝트 이름을 변경하지 않는 것을 권장합니다.

## 1.13.0

### 릴리스 날짜: 2024년 8월 30일

Private Mendix Platform 버전 1.13.0에서는 다수의 버그 수정 및 개선 사항이 도입되었습니다.

#### 개선 사항

##### Build 및 Deploy 개선

Build 및 Deploy 프로세스를 이제 API 호출을 통해 트리거할 수 있습니다.

Kubernetes의 Build 및 Deploy에 대해 동적 역할 관리가 가능합니다. 역할 관리가 세분화되어, 모든 용도에 대한 하나의 권한 목록 대신 각 멤버가 각 DTAP 용도에 대해 별도의 역할을 가지며 각각 다른 용도에 대해 다른 역할이나 권한을 부여받을 수 있습니다.

##### Webhook 개선

이제 Webhook의 페이로드를 사용자 정의할 수 있습니다. 정적 텍스트와 변수를 모두 입력할 수 있습니다.

##### 엔지니어링 개선

* Kubernetes 빌드 출력에 Azure Blob이 지원됩니다.
* Deployment Pipeline이 트리거될 때 로그가 생성됩니다.

###### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.26](/releasenotes/studio-pro/9.24/#92426)으로 업데이트되었습니다
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.12](/releasenotes/studio-pro/10.6/#10612)로 업데이트되었습니다

#### 수정 사항

다음 수정 사항을 제공합니다:

* (플랫폼) 새 사용자 양식에 이메일 유효성 검사를 추가하였습니다.
* (플랫폼) Build Pipeline과 관련된 일부 문제를 수정하였습니다.
* (플랫폼) 결정 트리가 있는 CI/CD Pipeline에서 발생하던 병합 오류를 해결하였습니다.
* (플랫폼) 거버넌스 이유로, 비관리자 사용자가 사용자 이름을 편집할 수 없도록 제한하였습니다.
* (UI) 일부 UI 관련 문제를 수정하였습니다.

#### 알려진 문제

##### 업그레이드 후 Cluster Manager 멤버 제거

Private Mendix Platform을 ver. 1.13으로 업그레이드한 후 Cluster Manager 설정에 이전에 정의된 멤버가 제거됩니다.

###### 원인

동적 역할 관리 구현으로 인해 이전에 생성된 멤버가 새로운 옵션과 호환되지 않아 다시 생성해야 합니다. Private Mendix Platform의 이전 릴리스에서는 모든 DTAP 용도에 대해 하나의 전역 역할만 있었기 때문에 모든 멤버가 모든 용도에 대한 하나의 권한 목록으로 생성되었습니다. ver. 1.13부터는 배포 환경의 지정된 용도에 해당하는 네 가지 배포 목적(DTAP) 각각에 대해 세 가지 역할 옵션(*Cluster Member*, *Cluster Admin*, *Custom*)이 있습니다. 이로 인해 릴리스 간에 멤버 역할을 매핑하거나 상속할 수 없었습니다.

###### 해결 방법

업그레이드 후 Cluster Manager 설정의 각 네임스페이스에서 제거된 멤버를 수동으로 추가하십시오.
