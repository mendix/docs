## 소개

<i>Window</i>는 페이지가 팝업으로 열릴 때 렌더링됩니다.

<i>ConfirmationDialog</i>는 삭제 또는 Microflow Action에 확인이 필요할 때 표시됩니다. Microflow의 메시지 표시 Action은 <i>DialogMessage</i> Widget을 생성합니다.
