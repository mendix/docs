## 소개

이 문서에서는 [문자열](/refguide9/data-types/)을 변환하고 검사하는 데 사용되는 함수를 설명합니다. 이 함수들은 문자열 자체를 변경하지 않으며, 새 값만 반환합니다.

문자열은 따옴표로 둘러싸여 있습니다. 문자열에 따옴표가 포함된 경우 다른 따옴표로 이스케이프해야 합니다. 예: `'this isn''t funny'`.

문자열 함수 호출에 대한 자세한 심층 분석을 보려면 이 비디오를 확인하십시오:

## toLowerCase

문자열의 모든 문자를 소문자로 변환합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값             | 유형   |
| ----------------- | ------ |
| 변환할 문자열 | String |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                               | 유형   |
| ----------------------------------- | ------ |
| 동일한 문자열이지만 모두 소문자입니다. | String |

### 예제

다음 입력을 사용하는 경우:

```java
toLowerCase('thisISmyString')
```

출력은 다음과 같습니다:

```java
'thisismystring'
```

## substring

문자열의 하위 문자열을 검색합니다. 문자열의 첫 번째 문자는 위치 `0`에 있고, 마지막 문자는 위치 `length(string)-1`에 있습니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                                       | 유형    |
| ------------------------------------------- | ------- |
| 대상                                     | String  |
| 하위 문자열의 시작 위치             | Integer |
| 결과의 원하는 길이 **(선택 사항)** | Integer |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형   |
| ------------------------------------------------------------ | ------ |
| 시작 위치에서 시작하여 원하는 길이와 같은 길이를 가진 원래 문자열의 일부입니다. 원하는 길이가 지정되지 않으면 시작 위치에서 시작하여 문자열 끝까지의 하위 문자열을 반환합니다. | String |

{{% alert color="warning" %}}
이 함수는 다음의 경우 오류를 출력합니다:

* 하위 문자열의 시작 위치가 문자열의 마지막 문자 뒤인 경우
* 결과의 원하는 길이가 하위 문자열보다 긴 경우
{{% /alert %}}

### 예제

다음 입력을 사용하는 경우:

```java
substring('thisismystring', 6)
```

출력은 다음과 같습니다:

```java
'mystring'
```

세 번째 매개변수를 사용하여 출력의 원하는 길이를 지정하는 경우:

```java
substring('thisismystring', 6, 2)
```

출력은 다음과 같습니다:

```java
'my'
```

세 번째 매개변수의 값이 범위를 벗어나지 않도록 하려면 예를 들어 `min` 및 `length` 함수를 사용하여 세 번째 매개변수에 제한을 설정할 수 있습니다:

```java
substring('thisismystring', 0, min(length('thisismystring'), 20))
```

## find

문자열에서 하위 문자열의 첫 번째 발생 위치를 찾습니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                                                  | 유형    |
| ------------------------------------------------------ | ------- |
| 검색할 원래 문자열 | String  |
| 검색할 하위 문자열                  | String  |
| 검색을 시작할 시작 위치 **(선택 사항)** | Integer |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형    |
| ------------------------------------------------------------ | ------- |
| 원래 문자열에서 하위 문자열의 첫 번째 위치입니다. 하위 문자열이 원래 문자열에 전혀 발생하지 않으면 `-1`을 반환합니다. | Integer |

### 예제

다음 입력을 사용하는 경우:

```java
find('thisismystring', 'my')
```

출력은 다음과 같습니다:

```java
6
```

원래 문자열에 발생하지 않는 하위 문자열:

```java
find('thisismystring', 'yourstring')
```

반환값:

```java
-1
```

다른 입력 예제는 다음과 같습니다:

```java
find('thisismystring', 'i', 5)
```

출력은 다음과 같습니다:

```java
11
```

## findLast

원래 문자열에서 하위 문자열의 마지막 발생 위치를 찾습니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                                                  | 유형    |
| ------------------------------------------------------ | ------- |
| 검색할 원래 문자열 | String  |
| 검색할 하위 문자열                  | String  |
| 검색할 마지막 위치 **(선택 사항)**            | Integer |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형    |
| ------------------------------------------------------------ | ------- |
| 원래 문자열에서 하위 문자열의 마지막 위치입니다. 하위 문자열이 원래 문자열에 전혀 발생하지 않으면 `-1`을 반환합니다. | Integer |

### 예제

다음 입력을 사용하는 경우:

```java
findLast('thisismystring', 't')
```

출력은 다음과 같습니다:

```java
9
```

원래 문자열에서 하위 문자열이 발생하지 않는 다른 입력 예제:

```java
findLast('thisismystring', 'yourstring')
```

출력은 다음과 같습니다:

```java
-1
```

세 번째 매개변수를 사용하는 입력 예제:

```java
findLast('thisismystring', 'i', 5)
```

출력은 다음과 같습니다:

```java
4
```

선택적 매개변수가 `5`이므로 위치 `5`까지(포함) 문자열을 검색합니다. 이는 하위 문자열 `'thisis'`를 검색하는 것을 의미합니다. 해당 하위 문자열에서 `'i'`의 마지막 인스턴스는 위치 `4`에 있습니다.

## contains

원래 문자열(첫 번째 매개변수)에 하위 문자열(두 번째 매개변수)이 포함되어 있는지 확인합니다.

예를 들어, 다음 Expression:

```java
contains('stringtosearchin', 'stringtosearchfor')
```

은 다음 Expression과 동일합니다:

```java
find('stringtosearchin', 'stringtosearchfor') != -1
```

아래 예제는 빈 변수 또는 빈 문자열을 검색하는 것으로, `$param = ''`인 경우:

```java
contains('stringtosearchin', $param)
```

위의 입력은 `true`를 반환합니다.

{{% alert color="warning" %}}
이 함수는 대소문자를 구분합니다.
{{% /alert %}}

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                                                  | 유형   |
| ------------------------------------------------------ | ------ |
| 검색할 원래 문자열 | String |
| 검색할 하위 문자열                  | String |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                               | 유형    |
| --------------------------------------------------- | ------- |
| 원래 문자열에 하위 문자열이 포함되어 있는지 여부입니다. | Boolean |

### 예제

다음 입력을 사용하는 경우:

```java
contains('thisismystring', 'my')
```

출력은 다음과 같습니다:

```java
true
```

## isMatch

문자열이 주어진 정규 표현식과 일치하는지 확인합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                       | 유형   |
| --------------------------- | ------ |
| 일치를 시도할 문자열     | String |
| 일치할 정규 표현식 | String |

{{% alert color="info" %}}
정규 표현식은 문자열로 제공해야 합니다. 정규 표현식과 동일한 형식을 사용하지만 이 함수에서 [정규 표현식](/refguide9/regular-expressions/) 리소스 문서를 사용할 수는 없습니다.
{{% /alert %}}

{{% alert color="warning" %}}

이 함수 호출은 현재 플랫폼에서 제공하는 정규 표현식 언어를 사용합니다:

* [Microflow](/refguide9/microflow/) 내에서 사용되는 경우 – Java의 정규 표현식(자세한 내용은 [Class Pattern 문서](https://docs.oracle.com/javase/8/docs/api/java/util/regex/Pattern.html) 참조)
* 클라이언트에서 사용되는 경우 – JavaScript의 정규 표현식(자세한 내용은 [정규 표현식 문서](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_Expressions) 참조)

{{% /alert %}}

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                              | 유형    |
| ---------------------------------- | ------- |
| 문자열이 일치하는지 여부입니다. | Boolean |

### 예제

아래 입력은 문자열이 숫자만 포함하는지 테스트합니다:

```java
isMatch('234hello6432', '^([0-9]+)$')
```

출력은 다음과 같습니다:

```java
False
```

`isMatch()`에서 정규 표현식은 암시적으로 `^`와 `$`에 앵커됩니다.

**다른 예제**

* `isMatch('NLG 123.45', '[0-9]')`은 `false`를 반환합니다
* `isMatch('NLG 123.45', '.*[0-9].*')`은 `true`를 반환합니다

빈 문자열 검색:

* `isMatch('', '.*[0-9].*')`은 `false`를 반환합니다

## replaceAll

정규 표현식의 모든 발생을 다른 문자열로 대체합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                                                        | 유형   |
| ------------------------------------------------------------ | ------ |
| 검색할 문자열                                      | String |
| 일치할 정규 표현식; 리터럴 문자열을 검색하려면 `\Q`와 `\E` 사이에 넣으십시오(예: `\QPaul S. Mueller\E`는 점을 와일드카드로 해석하지 않고 문자열 `Paul S. Mueller`를 검색합니다) | String |
| 각 일치에 대해 대체할 문자열(역참조, 대체 또는 캡처를 지원하지 않습니다) | String |

{{% alert color="info" %}}
정규 표현식은 문자열로 제공해야 합니다. 정규 표현식과 동일한 형식을 사용하지만 이 함수에서 [정규 표현식](/refguide9/regular-expressions/) 리소스 문서를 사용할 수는 없습니다.
{{% /alert %}}

{{% alert color="warning" %}}

이 함수 호출은 현재 플랫폼에서 제공하는 정규 표현식 언어를 사용합니다:

* [Microflow](/refguide9/microflows/) 내에서 사용되는 경우 – Java의 정규 표현식(자세한 내용은 [Class Pattern](https://docs.oracle.com/javase/8/docs/api/java/util/regex/Pattern.html) 참조)
* 클라이언트에서 사용되는 경우 – JavaScript의 정규 표현식(자세한 내용은 [정규 표현식](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_Expressions) 참조)

{{% /alert %}}

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형   |
| ------------------------------------------------------------ | ------ |
| 정규 표현식의 모든 발생이 대체 문자열로 대체된 원래 문자열입니다. 정규 표현식이 문자열에 발생하지 않으면 원래 문자열이 반환됩니다. | String |

### 예제

다음 입력을 사용하는 경우:

```java
replaceAll('this is a string with 75 some numbers 234 thrown in', '([0-9])', 'NUMBER')
```

출력은 다음과 같습니다:

```java
'this is a string with NUMBERNUMBER some numbers NUMBERNUMBERNUMBER thrown in'
```

다음과 같은 다른 입력 예제:

```java
replaceAll('this is a string with no numbers thrown in', '([0-9])', 'NUMBER')
```

입력에 대한 일치가 없으므로 출력은 다음과 같습니다:

```java
'this is a string with no numbers thrown in'
```

## replaceFirst

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                                                        | 유형   |
| ------------------------------------------------------------ | ------ |
| 검색할 문자열                                      | String |
| 일치할 정규 표현식; 리터럴 문자열을 검색하려면 `\Q`와 `\E` 사이에 넣으십시오(예: `\QPaul S. Mueller\E`는 점을 와일드카드로 해석하지 않고 문자열 `Paul S. Mueller`를 검색합니다) | String |
| 첫 번째 일치에 대해 대체할 문자열(역참조, 대체 또는 캡처를 지원하지 않습니다) | String |

{{% alert color="info" %}}
정규 표현식은 문자열로 제공해야 합니다. 정규 표현식과 동일한 형식을 사용하지만 이 함수에서 [정규 표현식](/refguide9/regular-expressions/) 리소스 문서를 사용할 수는 없습니다.
{{% /alert %}}

{{% alert color="warning" %}}

이 함수 호출은 현재 플랫폼에서 제공하는 정규 표현식 언어를 사용합니다:

* [Microflow](/refguide9/microflow/) 내에서 사용되는 경우 – Java의 정규 표현식(자세한 내용은 [Class Pattern 문서](https://docs.oracle.com/javase/8/docs/api/java/util/regex/Pattern.html) 참조)
* 클라이언트에서 사용되는 경우 – JavaScript의 정규 표현식(자세한 내용은 [정규 표현식 문서](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_Expressions) 참조)

{{% /alert %}}

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형   |
| ------------------------------------------------------------ | ------ |
| 정규 표현식의 첫 번째 발생이 대체 문자열로 대체된 원래 문자열입니다. 정규 표현식이 문자열에 발생하지 않으면 원래 문자열이 반환됩니다. | String |

### 예제

다음 입력을 사용하는 경우:

```java
replaceFirst('this is a string with 75 some numbers 234 thrown in', '([0-9])', 'NUMBER')
```

출력은 다음과 같습니다:

```java
'this is a string with NUMBER5 some numbers 234 thrown in'
```

## 문자열 연결 ( + )

`+` 연산자를 사용하여 두 개의 문자열 또는 문자열과 숫자를 연결할 수 있습니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값            | 유형                          |
| ---------------- | ----------------------------- |
| 첫 번째 매개변수  | String, integer/long, decimal |
| 두 번째 매개변수 | String, integer/long, decimal |

{{% alert color="info" %}}

매개변수 중 하나 이상은 string 유형이어야 합니다.

{{% /alert %}}

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형   |
| ------------------------------------------------------------ | ------ |
| 두 입력 매개변수의 리터럴 연결인 새 문자열입니다. | String |

### 예제

두 문자열을 결합하는 입력 예제는 다음과 같습니다:

```java
'foo' + 'bar'
```

출력은 다음과 같습니다:

```java
'foobar'
```

문자열과 숫자를 결합하는 입력 예제는 다음과 같습니다:

```java
4.73 + ' kilometers'
```

출력은 다음과 같습니다:

```java
'4.73 kilometers'
```

## urlEncode {#urlEncode}

문자열을 URL에서 사용할 수 있도록 변환합니다. 이 함수는 문자열을 URL의 일부로 사용하려는 경우에 유용합니다.

예:

```java
'http://google.com/search?q=' + urlEncode($myQuery)
```

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값             | 유형   |
| ----------------- | ------ |
| 변환할 문자열 | String |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                    | 유형   |
| ------------------------ | ------ |
| URL 인코딩된 문자열입니다. | String |

### 예제

다음 입력을 사용하는 경우:

```java
urlEncode('Hello, world!')
```

출력은 다음과 같습니다:

```java
'Hello%2C+world%21'
```

## urlDecode

URL에서 문자열을 다시 변환합니다. [urlEncode](#urlEncode)의 반대입니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                           | 유형   |
| ------------------------------- | ------ |
| 변환할 URL 인코딩된 문자열 | String |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                    | 유형   |
| ------------------------ | ------ |
| URL 디코딩된 문자열입니다. | String |

### 예제

다음 입력을 사용하는 경우:

```java
urlDecode('Hello%2C+world%21')
```

출력은 다음과 같습니다:

```java
'Hello, world!'
```
