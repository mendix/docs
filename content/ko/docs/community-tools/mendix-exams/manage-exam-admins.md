## 소개

조직은 Mendix 인증 시험 좌석을 대량 주문할 수 있습니다. Mendix가 주문을 처리하면 각 주문에 시험 관리자가 지정됩니다.

시험 관리자는 시험 주문에 시험 관리자를 추가하거나 제거할 수 있습니다.

## 전제 조건

모든 시험 관리자는 Mendix 계정을 보유하고 있어야 합니다.

시험 관리자를 관리하려면 본인도 시험 관리자여야 합니다. 시험 좌석 주문과 연결된 이름이 있으면 주문 처리 과정에서 시험 관리자로 지정됩니다.

## 시험 관리자 추가하기

시험 관리자를 추가하려면 다음을 수행하세요:

1. [Mendix Academy](https://academy.mendix.com/)에서 **Access Management** 페이지로 이동하세요. 시험 관리자의 전체 목록을 확인할 수 있습니다.

     {{< figure src="/attachments/community-tools/order-exams-in-bulk/manage-exam-admins/access-management.png" >}}

2. 페이지 오른쪽 상단 모서리에 있는 **Add Exam Admin**을 클릭하세요. **Add Exam Admin** 대화 상자가 열립니다.

3. **User** 필드에 추가하려는 시험 관리자의 이메일 주소를 입력하세요. 여러 이메일 주소를 입력하는 경우 쉼표로 구분하세요.

    {{< figure src="/attachments/community-tools/order-exams-in-bulk/manage-exam-admins/add-exam-admin.png" max-width=70% >}}

4. 새 시험 관리자에게 할당하려는 **Exam Orders**를 선택하세요.

5. **Add**를 클릭하세요.

추가된 시험 관리자는 시험 관리를 위한 [Overview](https://academy.mendix.com/link/examadmin) 페이지로 이동하는 링크가 포함된 이메일을 받습니다.

## 시험 관리자 제거하기

{{% alert color="info" %}}
주문의 유일한 관리자인 경우 시험 관리자를 제거할 수 없습니다.    
자기 자신을 시험 관리자에서 제거할 수 없습니다.
{{% /alert %}}

시험 관리자를 제거하려면 다음을 수행하세요:

1. [Mendix Academy](https://academy.mendix.com/)에서 **Access Management** 페이지로 이동하세요. 시험 관리자의 전체 목록을 확인할 수 있습니다.

2. 제거하려는 시험 관리자의 제거({{% icon name="trash-can" %}}) 아이콘을 클릭하세요.
