## December 2023

### December 28, 2023

#### New Features

* Mendix Cloud에서 [regional fallback](/developerportal/deploy/mendix-cloud-deploy/#regional-fallback)을 지원합니다. Regional fallback을 사용하면 애플리케이션의 데이터베이스와 파일 스토리지가 다른 Mendix Cloud 리전으로 복제됩니다. 장애로 인해 애플리케이션의 기본 리전이 다운되면, 폴백 리전으로 전환합니다. 그러면 폴백 리전에서 요청을 처리할 수 있습니다. Regional fallback 없이는 기본 리전이 다시 사용 가능해질 때까지 기다려야 합니다. Regional fallback은 Premium Plus 클라우드 리소스 팩의 일부입니다.
    * Regional fallback은 도쿄를 제외한 모든 Mendix Cloud 리전에서 사용할 수 있습니다. 도쿄에서의 regional fallback은 2024년 1분기에 제공할 예정입니다.

### December 21, 2023

#### Improvements

* 사용자가 최대 크기인 1GB를 초과하는 MDA 파일을 업로드하거나 전송하려고 하면, MDA 파일이 너무 크다는 경고 오류 메시지가 표시됩니다.

### December 14, 2023

#### Improvements

* Metrics 페이지의 애플리케이션 디스크 사용량 및 CPU 사용량 그래프가 이제 동적으로 스케일링되는 y축을 가지며, 최소값은 0이고 최대값은 요청에 포함된 최대 데이터 포인트로 설정됩니다.
* Deploy API v4에서 `/apps/{appId}/environments`에 대한 최대 limit 값을 20에서 100으로 증가시켰습니다. 100은 새로운 기본 limit 값이기도 합니다. 자세한 내용은 [Deploy API – Version 4](/apidocs-mxsdk/apidocs/deploy-api-4/)를 참조하세요.

## November 2023

### November 22, 2023

#### Improvements

* Metrics 페이지의 레이아웃과 표시를 개선했습니다. 이제 그래프의 시간 기간(day, week, month, quarter) 및 그룹(application, database, all)을 설정하는 드롭다운 메뉴를 통해 메트릭을 필터링할 수 있습니다. 그래프의 시각적 스타일도 업데이트했습니다. 자세한 내용은 [Metrics](/developerportal/operate/metrics/)를 참조하세요.
* Logs 페이지의 레이아웃과 기능을 개선했습니다. 로그 아카이브에 앱 및 접근 로그의 파일 크기가 표시되며, 날짜별 로그 필터링 옵션이 포함되었습니다. 자세한 내용은 [Logs](/developerportal/operate/logs/)를 참조하세요.
* Logs 페이지에 활동 로그가 추가되어, 로그를 조회하거나 다운로드한 사용자에 대한 데이터를 보고합니다. 활동 로그는 팀 구성원과 Mendix Support 구성원의 접근을 기록합니다. Mendix Support는 열려 있는 지원 티켓과 관련하여 앱의 로그를 보거나 다운로드할 수 있습니다. 

### November 16, 2023

#### Improvements

* [New Relic](/developerportal/operate/newrelic-metrics/)으로 애플리케이션 런타임 로그와 메트릭을 전송하는 지원을 추가했습니다.
* `SPLUNK_LOGS_REDACTION` 및 `DATADOG_LOGS_REDACTION` 환경 변수를 더 이상 사용하지 않습니다.
* [Splunk](/developerportal/operate/splunk-metrics/), [Datadog](/developerportal/operate/datadog-metrics/), [New Relic](/developerportal/operate/newrelic-metrics/)과 호환되는 `LOGS_REDACTION` 변수를 도입했습니다.

## October 2023

### October 26, 2023

#### Improvements

* Developer Portal에서 `Origin-Trials` HTTP 헤더 지원을 추가했습니다. 이 헤더를 사용하려면 고객이 10월 26일 12:00 PM 이후에 앱을 먼저 배포(또는 재배포)해야 합니다. 해당 날짜 이후 배포한 경우, 헤더를 설정하고 앱을 재시작하면 헤더를 사용할 수 있습니다. 자세한 내용은 [HTTP Headers](/developerportal/deploy/environments-details/#http-headers)를 참조하세요.

### October 25, 2023

#### Improvements

* 데이터베이스에 대한 gp3 스토리지 인스턴스 지원을 추가했습니다. gp2에 비해 더 높은 기본 스토리지 성능을 제공합니다. IOPS 및 처리량 성능은 아래 표에 따라 업그레이드됩니다.

    * 10월 25일부터 고객이 새 DB 인스턴스를 생성하면, 스토리지 크기가 최소 20GiB인 경우(아래 표에 지정됨) gp3 스토리지 인스턴스로 프로비저닝됩니다. 고객의 데이터베이스가 재생성되는 경우에도 마찬가지입니다.
    | Storage Size           | Storage Instance Type | Baseline Storage Performance      | Provisioned IOPS Range | Provisioned Throughput Range |
    | ---------------------- | --------------------- | --------------------------------- | ---------------------- | ---------------------------- |
    | Less than 20 GiB       | gp2                   | 100 IOPS (3000 Burst) / 125 MiB/s | 100 - 1197 IOPS        | 128-250 MiB/s                |
    | Between 20 and 400 GiB | gp3                   | 3000 IOPS / 125 MiB/s             | N/A                    | N/A                          |
    | 400 GiB and higher     | gp3                   | 12000 IOPS / 500 MiB/s            | 12000 - 64000 IOPS     | 500 - 4000 MiB/s             |

    * 이 업그레이드 대상인 기존 데이터베이스는 나중에 마이그레이션됩니다. 자세한 내용은 추후 안내할 예정입니다.

    * 자세한 내용은 *Metrics* 문서의 [Database IOPS Burst Balance](/developerportal/operate/metrics/#Trends-dbmxdatabaseburstbalance)를 참조하세요.

### October 12, 2023

#### Portal Enhancements

* **Running Now** 인터페이스를 **Metrics** 페이지에서 [Environment Details](/developerportal/deploy/environments-details/) 페이지로 이동했습니다. 이 인터페이스는 이제 환경이 실행 중일 때 **Show Running Now** 작업 버튼을 클릭하여 접근하는 대화 상자로 표시됩니다.

#### Fixes

* MDA 패키지 업로드 중 UI에 나타나던 일부 불일치를 수정했습니다.

## July 2023

### July 3, 2023

#### Improvements

* Mendix Cloud의 Cloud Foundry 스택을 `cflinuxfs4`로 업그레이드했습니다. 이 스택은 Mendix Cloud 퍼블릭 또는 전용 클러스터에서 Mendix 앱을 다시 배포할 때 자동으로 사용됩니다.

## June 2023

### June 15, 2023

#### Portal Enhancements

* 웹훅 기능이 GA로 릴리스되었습니다. 웹훅은 Team Server Git 저장소에 변경 사항이 커밋되거나 Mendix Cloud에 배포할 새 배포 패키지가 사용 가능할 때 엔드포인트를 트리거할 수 있습니다. 자세한 내용은 [Webhooks](/developerportal/deploy/webhooks/)를 참조하세요.

#### Improvements

* Mendix 런타임 메트릭을 APM 벤더에 전송하기 위한 필터링 기능을 도입했습니다.

## May 2023

### May 4, 2023

#### Improvements

* Build 및 Deploy API에서 Developer Portal에서 패키지를 다운로드하는 링크를 추가했습니다. 이는 다음 API 호출의 매개변수로 제어됩니다:
    * Build API의 [Retrieve Package](/apidocs-mxsdk/apidocs/build-api/#retrieve-package)
    * Deploy API의 [Retrieve Environment Package](/apidocs-mxsdk/apidocs/deploy-api/#retrieve-environment-package)
* Build API의 [Download Package](/apidocs-mxsdk/apidocs/build-api/#download-package) 호출을 더 이상 사용하지 않습니다.

## February 2023

### February 23, 2023

#### Improvements

* Mendix Cloud에서 [Dynatrace](/developerportal/operate/dynatrace-metrics/) 모니터링을 위한 OneAgent 지원을 추가했습니다.
* Dynatrace 통합에 `DT_TENANT` 환경 변수가 이제 필수입니다.

* `cname.mendix.net`에 대한 DNS 조회를 인증하기 위해 DNSSEC를 활성화했습니다.
    * 이는 Mendix Cloud의 애플리케이션에 대한 사용자 정의 도메인이 DNSSEC를 사용하여 검증됨을 의미하며, 사용자 정의 도메인에서도 활성화된 경우에 해당합니다.

### February 21, 2023

#### Improvements

* 인증된 Client Certificate의 SHA1 Fingerprint 및 Serial number에 대한 HTTP 헤더를 반환합니다. 자세한 내용은 [Mendix Cloud HTTP Request Headers](/developerportal/deploy/mendix-cloud-request-headers/)를 참조하세요.

### February 16, 2023

#### Improvements

* 고객이 이제 애플리케이션의 접근 로그를 다운로드할 수 있습니다. Deploy API도 이 기능으로 업데이트되었습니다. 자세한 내용은 *Deploy API*의 [Download Access Logs](/apidocs-mxsdk/apidocs/deploy-api/#download-logs)를 참조하세요.
