## 소개

Row는 Table의 일부입니다. 셀을 포함하며, 셀은 다시 다른 위젯을 포함할 수 있습니다.

## 컴포넌트

### Cell

행의 셀입니다. 자세한 정보는 [Cell (Document Template)](/refguide8/cell-document-template/)을 참조하십시오.

## 외관 속성

### 표시 조건

표시 조건은 이름에서 알 수 있듯이 최종 사용자에게 행이 표시되는 조건을 설정할 수 있는 속성입니다. 이러한 조건은 Data View Entity의 Enumeration 또는 Boolean 속성(Attribute)일 수 있습니다.
