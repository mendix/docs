이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.15에 적용된 변경 사항을 다루고 있습니다.

## 1.15.0

### 릴리스 날짜: 2024년 10월 31일

Private Mendix Platform 버전 1.15.0에서는 다수의 버그 수정 및 개선 사항이 도입되었습니다.

#### 새로운 기능

##### 배포된 앱 시작 및 중지

환경 관리 메뉴에서 새로운 옵션을 사용하여 배포된 애플리케이션을 쉽게 시작하고 중지할 수 있게 되었습니다. 자세한 내용은 [Private Mendix Platform 사용자 가이드: 앱 배포](/private-mendix-platform/user-guide/#deploy)를 참조하십시오.

##### 시스템 관리자 계정 일괄 비활성화

계정 제어 관련 컴플라이언스 요구 사항을 충족하기 위해, Private Mendix Platform은 이제 배포 시 기본 MxAdmin 계정을 비활성화하는 것을 지원합니다. 이 설정은 기본 시스템 관리자 계정을 사용한 앱 접근 기능을 효과적으로 제거하며, 잠김을 방지하기 위해 SSO 모듈의 기본 사용과 함께 사용하는 것을 권장합니다. 관리자는 관리자 메뉴의 **Settings** > **Integrations** > **Security** 섹션에서 이 설정을 활성화하거나 비활성화할 수 있습니다.

##### 설치 프로그램에서 PCLM 구성 요소 업그레이드 처리

Private Mendix Platform 설치 마법사가 이제 PCLM 구성 요소 업그레이드를 지원합니다. 자세한 내용은 [Private Mendix Platform 업그레이드](/private-mendix-platform/quickstart/#upgrade)를 참조하십시오.

#### 개선 사항

##### Grafana Metrics 사용 가능

Private Mendix Platform은 이제 Grafana 메트릭을 통합하여 향상된 모니터링 기능을 제공합니다.

###### 새 인스턴스에서만 데이터 가져오기 가능

플랫폼 설정 가져오기 및 내보내기 기능이 복원되었습니다. 데이터 무결성과 플랫폼 안정성을 보호하기 위해, 플랫폼 설정 가져오기는 이제 새 인스턴스에서만 가능합니다. 초기 구성 마법사를 실행하는 과정에서 구성 설정이 포함된 JSON 파일을 가져올 수 있습니다. 초기 구성 후에는 나중에 설정을 가져올 수 없습니다.

##### Webhook 개선

###### 사용자 정의 Webhook 메시지 템플릿에 모든 기본 필드 표시

사용자 정의 Webhook 메시지 템플릿이 이제 모든 기본 필드를 표시합니다. 여기에는 메시지 페이로드에 항상 포함되는 네 가지 기본 필드(*eventId*, *eventType*, *eventTime*, *operator*)가 포함됩니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.29](/releasenotes/studio-pro/9.24/#92429)로 업데이트되었습니다 (프로덕션 지원)
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.17](/releasenotes/studio-pro/10.6/#10617)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)
* Studio Pro 10.12 MTS는 [10.12.8](/releasenotes/studio-pro/10.12/#10128) 버전부터 호환됩니다 (이노베이션 트랙, 제한적 지원)

#### 수정 사항

다음 수정 사항을 제공합니다:

* (플랫폼) PDF 형식으로 다운로드한 플랫폼 로그 파일의 형식 문제를 수정하였습니다.
* (플랫폼) 빌드 패키지 생성 및 다운로드 관련 일부 문제를 해결하였습니다.
* (플랫폼) Azure Blob에 대한 MDA Storage 설정이 저장되지 않던 문제를 수정하였습니다.
* (플랫폼) Studio Pro 버전 10.12.1로 앱을 다시 열었을 때 발생하던 Git 자격 증명 관련 문제를 해결하였습니다.
