## 소개

Java Action을 사용하면 Microflow로 구현하기 어려운 상황에서 애플리케이션의 기능을 확장할 수 있습니다.

Studio Pro의 Java Action에 대한 정보는 [Java Actions](/refguide9/java-actions/)를 참조하십시오.

## Java Action의 .java 파일에 코드 작성

Java Action의 *.java* 파일에서 Java Action이 실행될 때 Mendix Runtime이 `executeAction` 메서드를 호출합니다. 이 메서드는 발생하는 모든 예외를 throw합니다. 이는 이 Java Action을 호출하는 Microflow에서 오류 처리를 수행할 수 있음을 의미합니다. Action 내에서 자체적으로 오류 처리를 하려면 `try` / `catch` 문을 사용하십시오.

`// BEGIN USER CODE`와 `// END USER CODE` 줄 사이에 Action 실행 시 항상 호출되는 사용자 정의 코드를 작성할 수 있습니다. `// BEGIN EXTRA CODE`와 `// END EXTRA CODE` 사이의 섹션에서 다른 메서드를 호출할 수 있습니다.

블록 외부의 코드는 모델을 배포할 때마다 재생성되므로, 해당 영역에 가한 모든 수정은 덮어쓰여집니다. 그러나 import는 보존됩니다.

```java
// This file was generated by Mendix Studio Pro.
//
// WARNING: Only the following code will be retained when actions are regenerated:
// - the import list
// - the code between BEGIN USER CODE and END USER CODE
// - the code between BEGIN EXTRA CODE and END EXTRA CODE
// Other code you write will be lost the next time you deploy the app.
// Special characters, for example, é, ö, à, etc. are supported in comments.

package myfirstmodule.actions;

import com.mendix.systemwideinterfaces.core.IContext;
import com.mendix.webui.CustomJavaAction;

public class JavaAction_1 extends CustomJavaAction<java.lang.Void>
{
	public JavaAction_1(IContext context)
	{
		super(context);
	}
	@java.lang.Override
	public java.lang.Void executeAction() throws Exception
	{
		// BEGIN USER CODE
		return true;
		// END USER CODE
	}
	/**
	 * Returns a string representation of this action
	 */
	@java.lang.Override
	public java.lang.String toString()
	{
		return "JavaAction_1";
	}

	// BEGIN EXTRA CODE
	// END EXTRA CODE
}
```

## Mendix Java 라이브러리 사용

Java Action에 작성하는 Java 코드에서 Mendix Java 라이브러리를 사용할 수 있습니다.

{{% alert color="info" %}}
Javadoc은 [Mendix Runtime API](/apidocs-mxsdk/apidocs/runtime-api-9/) 또는 Studio Pro가 설치된 디렉터리(예: *C:\Program Files\Mendix\9.0.0\runtime\javadoc*)에서 찾을 수 있습니다.
{{% /alert %}}

이 라이브러리는 앱을 Eclipse에 가져올 때 자동으로 라이브러리에 추가되며, *mxruntime.jar*이라고 합니다.

사용법 및 예제에 대한 자세한 내용은 [Java API 사용하기](/refguide9/java-api-tutorial/)를 참조하십시오.

## HTTP 연결 열기

대부분의 클라우드 인프라 서비스(Mendix Cloud에서 사용하는 서비스 포함)는 트래픽이 없으면 몇 분 후에 HTTP 연결을 자동으로 닫습니다. Activity가 여전히 응답을 기다리고 있더라도 마찬가지입니다. 이는 Activity가 응답에 오랜 시간이 걸리는 웹 서비스를 호출하는 경우 Activity가 이를 인식하지 못한 채 연결이 닫힐 수 있으며, Activity는 응답을 받지 못하고 데이터 도착을 무한정 기다리게 됨을 의미합니다.

따라서 사용자 정의 Java 코드에서 만드는 모든 연결에 항상 타임아웃을 설정해야 합니다.
