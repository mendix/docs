## 소개

보안은 배포에서 가장 중요한 측면 중 하나입니다. 잘못된 구성이나 보안 실패는 큰 영향을 미칠 수 있기 때문입니다. Mendix Workstation은 배포의 보안에 영향을 줄 수 있는 권한에 대한 다양한 구성 옵션을 제공합니다.

이 문서에서는 Mendix Workstation을 프로덕션 환경에 배포할 때 고려해야 할 보안 측면을 설명합니다.

## 워크스페이스 역할 할당 {#workspace-roles}

워크스페이스 역할은 최소 권한 원칙에 따라 할당해야 합니다. 항상 사용자가 작업을 성공적으로 완료하는 데 필요한 최소한의 권한만 부여하십시오. 책임이 변경되면 언제든지 역할을 재할당할 수 있습니다. 안전한 배포를 유지하려면 다음 가이드라인을 고려하십시오:

* 신뢰할 수 없는 사용자에게는 View Only 역할을 할당하십시오.
* Workspace Admin 역할을 부여할 때는 주의하십시오.
    * Workspace Admin은 실수로 프로덕션을 중단시킬 수 있습니다. 예를 들어, 앱을 삭제하거나 공개 키를 수정할 수 있습니다.
    * Workspace Admin은 Workstation Client가 악성 앱에 접근하도록 허용할 수 있습니다.
* 정기적인 권한 감사를 수행하여 임시 권한 상승이 더 이상 필요하지 않을 때 원래대로 되돌려졌는지 확인하십시오.

## 스테이션 설정 {#setup-stations}

스테이션 설정에는 보안에 중요한 영향을 미치는 다양한 옵션이 있습니다. 안전한 배포를 보장하려면 다음 모범 사례를 따르십시오:

* 사용하지 않는 앱을 비활성화하고 사용하지 않는 장치를 삭제하여 스테이션을 간결하게 유지하십시오.
    * 사용하지 않는 모든 장치는 잠재적 공격 표면을 나타냅니다(예: 토큰을 유출하는 잊혀진 카드 리더기 또는 네트워크의 장치를 노출하는 TCP 장치).
    * 활성화되었지만 사용하지 않는 모든 앱은 의도하지 않은 장치 접근 권한을 얻을 수 있습니다.
* 스테이션에 구성된 모든 장치가 활성화된 모든 애플리케이션에 대해 안전한지 확인하십시오.
    * 장치는 스테이션의 모든 애플리케이션에서 공유됩니다. 특정 앱에서 접근해서는 안 되는 장치는 해당 스테이션에 존재해서는 안 됩니다.
* 파일 장치(File Device)를 신중하게 구성하십시오.
    * 파일 장치는 강력하며, 잘못 구성하면 보안 위험을 초래할 수 있습니다.
    * 허용 폴더와 권한을 최대한 제한하십시오. Workstation Client는 허용 폴더와 하위 폴더 내에서 이러한 제한을 적용합니다.

## Microsoft Windows에서 구성 폴더에 대한 접근 제한 {#config-access}

기본적으로 Workstation Client의 Windows 글로벌 설치 프로그램은 **BUILTIN\Users** Windows 사용자 그룹에 *ProgramData/Mendix Workstation* 폴더에 대한 읽기 및 쓰기 접근 권한을 부여합니다. 이 구성은 대부분의 경우 안전합니다. 그러나 매우 민감한 환경에서는 기본 제공 Users 그룹의 쓰기 접근을 제한하고 대신 다른 그룹에 권한을 위임할 수 있습니다.

### Users 그룹을 제한하는 이유

**BUILTIN\Users** 그룹에는 시스템의 모든 표준 사용자 계정이 포함됩니다. 쓰기 접근을 제한하면 다음을 방지할 수 있습니다:

* 손상된 계정이 구성 파일을 수정하는 것
* 권한이 없는 사용자가 스테이션 등록을 해제하여 일시적으로 프로덕션을 중단시키는 것

더 엄격하게 제어되는 그룹에 권한을 위임하면, 승인된 계정만 구성을 수정하고 Workstation Client를 사용할 수 있도록 보장할 수 있습니다.

사용자 정의 그룹에 권한을 위임하려면, 새 Windows 사용자 그룹을 생성하고 현재 Users 그룹이 보유한 것과 동일한 *C:\ProgramData\Mendix Workstation* 폴더에 대한 권한을 부여하십시오. 그런 다음 Users 그룹을 제거하거나 필요에 따라 권한을 조정할 수 있습니다. 그룹 및 권한 관리에 대한 자세한 내용은 Microsoft Windows 문서를 참조하십시오.
