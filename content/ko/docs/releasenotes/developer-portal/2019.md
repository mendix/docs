## December 2019

### December 23, 2019

#### Improvements

* 새 앱 생성 프로세스에 소규모 개선을 적용했습니다.

#### Fixes

* **Stories** 페이지에서 **Comments** 페이지로 리다이렉트되던 문제를 수정했습니다.

### December 18, 2019

#### Improvements

* Stories 베타 버전의 스타일을 약간 개선했습니다. 이번 릴리스에서는 일괄 작업 관련 문제가 수정되었습니다.

### December 13, 2019

#### Improvements

* 완전히 새로운 UI와 향상된 안정성으로 **Stories** 페이지를 재설계했습니다. 새 UI는 **Enable new UI**를 클릭하여 사용할 수 있습니다. 이 기능은 [베타 버전](/releasenotes/release-status/)입니다.

### December 5, 2019

#### Improvements

* [Buzz](/developerportal/general/overview/)에 소규모 스타일 개선을 적용했습니다.

## November 2019

### November 21, 2019

#### Fixes

* Developer Portal의 **Edit in Studio Pro** 기능이 Studio Pro를 열지 못하던 문제를 수정했습니다.

### November 1, 2019

#### Improvements

* **My Apps** 페이지에서 앱을 [즐겨찾기](/developerportal/#my-apps)에 추가하고 즐겨찾기 앱으로 필터링하는 기능을 도입했습니다. 이 기능은 Mendix 앱이 많은 경우 유용합니다.

## September 2019

### September 24, 2019

#### Improvements

* 대문자가 포함된 이메일 주소로 초대할 수 없던 문제를 수정했습니다.
* 가입 중 간헐적으로 오류 메시지가 발생하던 문제를 수정했습니다.
* Developer Portal에 다양한 소규모 성능 개선을 적용했습니다.

### September 19, 2019

#### Launchpad Removal and App User Management Update

* 새로운 SSO 아키텍처로 전환함에 따라 기존 런치패드 페이지를 제거했습니다. 기존 URL `launchpad.mendix.com`은 이제 [My Apps](/developerportal/#my-apps) 페이지로 연결됩니다.
* 런치패드의 앱 사용자 관리 기능을 Developer Portal의 **General** 앱 설정으로 이동했습니다. 자세한 내용은 *How to Manage General App Settings*의 [Managing App Users](/developerportal/general-settings/#managing-app-users) 섹션을 참조하세요.

## August 2019

### August 9, 2019

#### App User Management Improvements

* 앱 사용자 관리를 위한 UI를 재설계하고, 관리 가능한 앱 환경 및 사용자 로딩 성능을 개선했습니다.

## July 2019

### July 25, 2019

#### Fixes

* Developer Portal에서 소수점 상수 업데이트가 소수점 이하 2자리로 제한되던 문제를 수정했습니다. 이제 소수점 이하 8자리까지 사용할 수 있습니다. (Ticket 85507)

## May 2019

### May 2, 2019

#### UI Improvements

* Mendix Studio 및 Mendix Studio Pro (Mendix 8)의 베타 릴리스와 함께 Developer Portal 전체에서 *Web Modeler*를 *Mendix Studio*로, *Desktop Modeler*를 *Mendix Studio Pro*로 명칭을 변경했습니다.

## April 2019

### April 8, 2019

#### Webhooks Available

* 앱의 스토리 및 Sprint에 대한 Webhook 생성 기능을 추가했습니다. 이 Webhook은 Sprint 변경 및/또는 스토리 변경 시 정보를 전송하도록 구성할 수 있습니다.

### April 5, 2019

#### Fixes

* Developer Portal의 메모리 활용이 최적화되지 않아 시스템 불안정을 유발할 수 있던 문제를 수정했습니다. 이 변경 사항은 고객 앱의 메모리 활용에는 영향을 미치지 않습니다.

## March 2019

### March 15, 2019

#### Fixes

* **Password Has Expired** 페이지에서 비밀번호를 변경할 수 없던 문제를 수정했습니다. (Tickets 80828, 80882, 80884, 80888, 80997, 81005)
* Desktop Modeler에서 스토리를 가져올 때 발생하던 문제를 수정했습니다. (Tickets 80618, 80623, 80636, 80665, 80685, 80705, 80726, 80738, 80780, 80833, 80834, 80854, 80866, 80935, 81008)
* 특정 상황에서 Excel로 스토리를 가져올 때 발생하던 오류를 수정했습니다.
* Mendix Platform에 추천인을 초대할 수 없던 문제를 수정했습니다.

### March 14, 2019

#### Fixes

* Developer Portal 앱의 *General* 페이지에서 Technical Contact 정보가 간헐적으로 숨겨지던 문제를 수정했습니다. (Tickets 70285, 77387, 80269, 80929)

### March 7, 2019

#### Fix

* 새 프로젝트용 모바일 애플리케이션 패키지를 빌드할 때 권한의 기본값이 이제 *비활성화*로 설정됩니다. 이는 모바일(Phonegap) 앱에 필요한 권한 세트이며, 이전에는 새 프로젝트에 대해 모든 권한이 기본적으로 활성화되어 있었습니다. 이로 인해 추가 구성 없이는 Push Notifications가 실패했습니다.

### March 6, 2019

#### Feedback and Support

* Developer Portal에서 [Mendix Feedback](/appstore/modules/mendix-feedback/) 위젯을 제거했습니다. 문제를 보고하거나 질문하려면 [Mendix Support](https://support.mendix.com)에 티켓을 제출하세요.

## January 2019

### January 3, 2019

#### Fixes

* Mendix 환영 이메일의 튜토리얼 링크를 업데이트하여 새 사용자가 더 나은 안내를 받을 수 있도록 했습니다. (Ticket 77158)
* 애플리케이션 멤버를 관리하는 동안 일부 Developer Portal 사용자에게 영향을 미치던 통합 문제를 수정했습니다. (Ticket 77386)
