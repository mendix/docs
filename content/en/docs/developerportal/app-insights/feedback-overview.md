## Introduction

The **Feedback Overview** page shows the feedback submitted for all of your projects in one table. You can use it to keep track of incoming feedback without opening each project separately. 

This page is available via the Mendix Portal home page global navigation, by clicking **Projects**, then **Feedback Overview**.

## Feedback Table

The table lists each piece of feedback in a separate row. It contains the following columns:

* **ID** – The unique number that is assigned to the feedback.
* **Subject** – The title of the feedback given by the reporter.
* **Read** – This column displays an **UNREAD** label for feedback that has not been opened yet.
* **Status** – The status that your team has set for the feedback.
* **Date** – The date when the feedback was submitted.
* **Project** – The project the feedback was submitted for.
* **Stories** – The stories that the feedback is linked to.
* **Priority** – The priority of the feedback.
* **View in Project** – Open the project to view the feedback details page in context.

You can sort table columns, and find feedback by entering keywords in the search bar above the table.

## Filtering Feedback 

To narrow down the feedback in the table, click **Filters**. The **Filter** side panel opens with the following options:

* **Watched Feedback** – Choose whether to only show feedback for that you are watching.
* **Read State** – Show only feedback which is read, unread or both.
* **Projects** – Show only feedback for the selected projects.
* **Environment** – Show only feedback submitted from the selected environment.
* **Assigned to** – Show only feedback assigned to the selected team member.
* **Priority** – Show only feedback with the selected priority.
* **Status** – Show only feedback with the selected status.
* **Tags** – Show only feedback with the selected tags.
* **Submission Date** – Show only feedback submitted within a specific date range.

To close the side panel without applying changes, click **Close**.     
To remove all selected filters, click **Clear Filters**.    
To save the selected filters, click **Save Filters**.
