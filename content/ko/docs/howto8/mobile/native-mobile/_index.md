## 소개

Mendix 8부터 완전한 Native Mobile 앱을 빌드할 수 있습니다. Native Mobile 앱은 웹 뷰 내에서 렌더링되지 않는다는 점에서 하이브리드 앱과 다릅니다. 대신 네이티브 UI 요소를 사용합니다. 이를 통해 빠른 성능, 스와이프 제스처와 같은 부드러운 애니메이션, 그리고 모든 네이티브 디바이스 기능에 대한 향상된 접근이 가능합니다.

Mendix Native Mobile 앱은 웹 또는 하이브리드 앱을 빌드하는 것과 동일한 방법으로 빌드합니다. Page, Widget, Nanoflow, JavaScript Action, Microflow와 같은 익숙한 요소를 사용하여 앱을 구성할 수 있습니다. 그러나 네이티브 앱과 하이브리드 앱을 빌드하는 데는 몇 가지 차이점이 있습니다. 예를 들어, 사용 가능한 Widget 세트(및 해당 속성)가 약간 다릅니다. 또한 네이티브 스타일링은 SASS/CSS 대신 JavaScript를 기반으로 합니다.
