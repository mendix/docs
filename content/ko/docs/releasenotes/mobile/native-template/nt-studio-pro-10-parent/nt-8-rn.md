## 8.2.10 {#830}

**릴리스 날짜: 2025년 1월 15일**

* 커스텀 빌드된 Mendix Native Developer App에서 원격 JavaScript 디버깅이 실패하여 "Remote JS Debugging"을 활성화할 때 충돌이 발생하는 문제를 해결했습니다. 이 문제는 빌드 과정에서 Firebase 서비스가 올바르게 초기화되지 않아 발생했습니다. 이제 Firebase 종속성은 애플리케이션에서 명시적으로 필요한 경우에만 포함됩니다.

### 수정 사항

## 8.2.3 {#812}

**릴리스 날짜: 2024년 6월 7일**

### 개선 사항

* `@mendix/native` 종속성을 최신 호환 버전으로 업그레이드했습니다.

### 알려진 문제

* 기존 메커니즘과 호환되지 않는 것으로 판명된 쿠키 암호화 문제를 해결했습니다. 이로 인해 앱 로드 시 다음 예외가 발생합니다: `java.security.InvalidAlgorithmParameterException Unsupported IV length: 16 bytes. Only 12 bytes long IV supported`
    * [Native Template 8.2.5](#fix-cookie-encryption)에서 수정되었습니다.
