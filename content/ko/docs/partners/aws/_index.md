## 소개

Mendix는 AWS와 전략적 제휴를 맺고 Mendix를 AWS에서 앱을 구축하는 가장 빠르고 쉬운 방법으로 만들고 있습니다.

## 이 카테고리의 참고 문서

* [플랫폼 평가 가이드의 AWS](https://www.mendix.com/evaluation-guide/strategic-partners/aws/) – AWS-Mendix 제휴에 대한 개요를 제공합니다
* [Mendix Marketplace의 AWS 커넥터](https://marketplace.mendix.com/link/category/205) – 사용 가능한 커넥터에 대한 개요를 제공합니다
* [Mendix 문서의 AWS 커넥터](/appstore/aws-modules/) - 모든 플랫폼 지원 AWS 커넥터에 대한 문서를 제공합니다
* [Amazon EKS—Terraform 모듈](https://registry.terraform.io/modules/aws-ia/mendix-private-cloud/aws/latest) - 프라이빗 클라우드 환경을 자동으로 프로비저닝하여 AWS 계정에서 앱 배포를 간소화하는 방법을 제공합니다
