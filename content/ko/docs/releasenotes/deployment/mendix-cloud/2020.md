## December 2020

### December 17, 2020

* 특정 허용된 사용자 정의 환경 변수를 추가하여 고객이 베타 기능을 테스트할 수 있도록 하는 기능을 추가했습니다. 이 변수는 Mendix Cloud v4 환경에서 기존 드롭다운 옆의 텍스트 필드를 사용하여 사용자 정의 환경 변수처럼 추가할 수 있습니다.

    사용자 정의 환경 변수에 대한 자세한 내용은 *Environment Details* 문서의 [Runtime Tab](/developerportal/deploy/environments-details/#custom-environment-variables)을 참조하세요.

* Developer Portal 정리의 일환으로, Mendix Cloud의 환경을 확인할 때 Developer Portal 메뉴의 DEVELOP 섹션에서 Model 옵션을 제거했습니다. 이 페이지의 기능은 환경 페이지의 **Edit in Studio Pro** 버튼을 통해 계속 사용할 수 있습니다.

### December 8, 2020

* Mendix Cloud v4에서 Log Levels를 설정하는 방식을 변경했습니다.
    * 단일 인스턴스 앱의 경우, 앱이 실행 중인 동안 로그 수준을 변경할 수 있습니다.
    * 다중 인스턴스 앱의 경우, 새 로그 수준은 재시작 후에만 적용됩니다.

    이것은 [12월 3일](#20201203) 릴리스 이후 요청된 개선 사항입니다. 해당 날짜에 발표된 대로 로그 수준 변경은 여전히 영구적입니다.

### December 3, 2020 {#20201203}

* Mendix Cloud v4에서 앱의 Log Levels를 영구적으로 변경하여 재시작 간에 유지되는 기능을 추가했습니다. 이는 고객 요청에 대한 응답입니다. (Ticket 101413)<br/>Log Levels는 앱의 다음 재시작 후에만 영구적이 되므로, 한 번 더 설정해야 할 수 있습니다.<br/>로그 수준에 대한 자세한 내용은 *Environment Details* 문서의 [Log Levels Tab](/developerportal/deploy/environments-details/#log-levels)을 참조하세요.
* 이제 Deploy API [Retrieve Environment](/apidocs-mxsdk/apidocs/deploy-api/#retrieve-environment) 호출을 통해 배포에 사용된 빌드팩 버전을 조회할 수 있습니다. 버전은 `RuntimeLayer`로 반환됩니다. API 응답에서 이를 반환하려면 앱을 다시 배포해야 합니다.

### September 14, 2020

#### Announcement - **2020년 12월 1일**부터 HTTPS SSL/TLS 취약 암호 지원 중단

Mendix Cloud v4의 앱에 대한 HTTPS 연결의 보안을 강화하기 위해, [올해 2월에 TLSv1.3을 활성화했습니다](#tls-v1_3). 이후 Cloud v4 앱에 대한 요청의 50% 이상이 TLSv1.3을 통해 처리되었습니다.

Mendix Cloud v4의 앱에 대한 HTTPS 연결 보안을 더욱 강화하기 위해, 블록 암호에 대한 지원을 중단합니다. 블록 암호는 취약한 것으로 간주됩니다.

**2020년 12월 1일**에 Mendix **Cloud v4**의 앱에 대한 HTTPS 연결에 대해 **TLSv1.2 Block ciphers (CBC)** 기술 지원을 중단합니다.

**Mendix 앱에 미치는 영향**

TLSv1.2 Block ciphers (CBC) 지원 중단은 오래된 클라이언트가 더 이상 Mendix 앱에 연결할 수 없게 됨을 의미합니다.

더 이상 지원되지 않는 클라이언트의 예:

* Java 7 (Mendix 5)
* Windows 7의 Internet Explorer 버전 11
* Windows 8.1의 Internet Explorer 버전 11
* OS X 10.11의 Safari 버전 9 이전
* iOS 9의 Safari 버전 9 이전

**계속 지원하는 항목 (전문가 세부 사항)**

2020년 12월 1일 이후 HTTPS 연결에 대해 계속 지원되는 SSL/TLS 암호:

**TLSv1.3**

* `TLS_AES_128_GCM_SHA256`
* `TLS_AES_256_GCM_SHA384`
* `TLS_CHACHA20_POLY1305_SHA256`

**TLSv1.2**

* `TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384`
* `TLS_ECDHE_RSA_WITH_AES_128_GCM_SHA256`
* `TLS_ECDHE_RSA_WITH_CHACHA20_POLY1305_SHA256`
* `TLS_DHE_RSA_WITH_AES_256_GCM_SHA384`
* `TLS_DHE_RSA_WITH_AES_128_GCM_SHA256`

### July 2, 2020

#### Improvements and Fixes

* 데이터를 더 정확하게 만들기 위해 *unused java heap* 메트릭 계산 방식을 변경했습니다.
    * 이 메트릭이 음수 값을 가질 수 있었던 문제도 수정합니다(tickets: 92998, 93241, 93725, 94560, 99308, 99979, 100086, 101004, 101429, 102260, and 103225).

이 값은 Mendix Cloud v4용 Metrics의 다음 그래프에 표시됩니다:

* [JVM Object Heap](/developerportal/operate/metrics/#Trends-appmxruntimejvmheap)에서 **unused**로 표시
* [JVM Process Memory Usage](/developerportal/operate/metrics/#Trends-appmxruntimejvmprocessmemory)에서 **unused java heap**으로 표시

{{% alert color="info" %}}이 변경 사항은 다음에 애플리케이션을 배포할 때 적용됩니다.{{% /alert %}}

{{% alert color="warning" %}}이 변경이 적용되면 unused Java heap 메트릭의 크기가 크게 증가할 수 있습니다. 이는 새로운 계산의 결과이며 앱의 메모리 사용량 변경이 아닙니다.{{% /alert %}}

* Mendix Cloud에서의 데이터 복원이 이제 비동기적으로 수행됩니다. 이는 다음을 의미합니다:
    * 백업이 복원되는 동안 Developer Portal에서 계속 작업할 수 있습니다
    * 백업이 복원되는 동안 앱을 중지하거나 시작할 수 없습니다
    * 백업이 복원되는 동안 환경 세부 정보 페이지에 메시지가 표시됩니다
    * 복원이 완료되면 환경 활동 로그에 표시됩니다
* 새로운 Deploy API 호출이 추가되었습니다. 이는 곧 [Deploy API](/apidocs-mxsdk/apidocs/deploy-api/) 문서에 추가될 예정입니다.
* 파일 전용 백업을 Mendix Cloud에 복원할 수 없다는 경고가 표시됩니다. 데이터베이스가 포함된 백업만 복원할 수 있습니다.
