## TypeScript란 무엇인가요?

Mendix Platform을 사용하는 개발자라면 Java를 사용하여 사용자 정의 사용자 액션을 구현하는 것에 익숙할 수 있습니다.

그러나 Mendix Platform 및 Model SDK는 완전히 다른 언어, 즉 [TypeScript](https://www.typescriptlang.org/)로 구현되어 있습니다. TypeScript는 JavaScript와 유사합니다—사실, TypeScript 소스는 실행되기 전에 JavaScript로 "트랜스파일"됩니다. TypeScript가 JavaScript와 다른 주요 차이점은 명시적 타이핑이 추가된다는 것입니다. 이는 Java 배경을 가진 개발자들에게 좋은 소식입니다. 컴파일러가 실수로 Integer를 String으로 처리하려 할 때 경고해 줄 것이기 때문입니다. 동시에, 이미 존재하는 JavaScript 라이브러리의 풍부한 생태계를 여전히 활용할 수 있습니다.

이 새롭고 흥미로운 TypeScript 세계에서 길을 찾을 수 있도록, TypeScript와 JavaScript 라이브러리를 사용하여 개발하는 데 유용한 몇 가지 리소스를 모았습니다.

추가 유용한 리소스가 있으면 아래 댓글란에 자유롭게 언급해 주십시오.
