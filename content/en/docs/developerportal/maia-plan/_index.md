## Introduction

Maia Spec helps you create a detailed project plan, based on which you can then generate your app with [Maia Make](/refguide/maia-make/). The pages in this category describe how to provide project context, review and refine the generated project scope, and approve the solution proposal to start app development.

{{< figure src="/attachments/developerportal/maia/maia-create-app.png" alt="Plan and build with Maia entry point" max-width=50% >}}

{{% alert color="info" %}}
If you are not the owner of a project, but are invited to collaborate on it, you can only view the generated specs. If a planning tool has already been set up for the project, you can also [send the project to Studio Pro and start the development](/developerportal/maia-spec/start-development/).
{{% /alert %}}

Maia Spec covers the planning stage of the application lifecycle. You can use the stories from the plan as input when building your app in Studio Pro with Maia Make, or have external AI agents read the plan through [Maia Spec as MCP Server](/developerportal/maia-spec-mcp/). For an overview of how Maia supports each stage, refer to [Maia Across the Development Lifecycle](/refguide/maia-development-lifecycle/).
