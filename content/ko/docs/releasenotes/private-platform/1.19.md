이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.19에 적용된 변경 사항을 다루고 있습니다.

## 1.19.1

### 릴리스 날짜: 2025년 3월 13일

Private Mendix Platform 버전 1.19.1은 다수의 버그 수정이 포함된 패치 릴리스입니다.

#### 업데이트

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전 [2.21.1](/releasenotes/developer-portal/mendix-for-private-cloud/#2.21.1)
* Private Cloud License Manager (PCLM) 버전 [0.10.1](/releasenotes/developer-portal/mendix-for-private-cloud/#license-manage-cli-v0101)

#### 수정 사항

다음 수정 사항을 제공합니다:

* (플랫폼) CVE-2024-45337 및 CVE-2024-45338에 대해 거짓 양성 알림을 유발하던 라이브러리를 업데이트하였습니다.

{{% alert color="info" %}}
Private Mendix Platform은 해당 취약점의 영향을 받지 않았습니다.
{{% /alert %}}

## 1.19.0

### 릴리스 날짜: 2025년 2월 27일

Private Mendix Platform 버전 1.19.0에서는 다수의 새로운 기능, 개선 사항 및 버그 수정이 도입되었습니다.

#### 새로운 기능

##### Build 타임아웃 설정 추가

빌드 프로세스가 자동으로 타임아웃되는 시간을 사용자 정의할 수 있게 되었습니다. 이 타임아웃 기간은 빌드 이미지 설정에서 구성할 수 있습니다.

#### 개선 사항

##### 사용자 정의 리소스 프리셋 내보내기

내보내기 및 가져오기 기능에 이제 **CIAdmin.ResourceSettings** 엔티티가 포함되어, 사용자 정의 리소스 설정을 내보내고 가져올 수 있습니다.

##### UX 개선

새로운 배포 Pipeline을 트리거할 때 Pipeline ID가 자동으로 업데이트됩니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.33](/releasenotes/studio-pro/9.24/#92433)으로 업데이트되었습니다 (프로덕션 지원)
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.21](/releasenotes/studio-pro/10.6/#10621)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)
* Studio Pro 10.12 MTS 최신 패치 버전이 [10.12.14](/releasenotes/studio-pro/10.12/#101214)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전 [2.20.1](/releasenotes/developer-portal/mendix-for-private-cloud/#2.20.1)
* Private Cloud License Manager (PCLM) 버전 [0.10.0](/releasenotes/developer-portal/mendix-for-private-cloud/#license-manage-cli-v0100)
* SVIX webhooks 서비스 버전 1.42.0

#### 수정 사항

다음 수정 사항을 제공합니다:

* (플랫폼) *pmp-pipeline-tools* 이미지의 일부 취약점을 해결하였습니다.
* (플랫폼) Private Mendix Platform API 서버에 접근할 때 오류 500이 발생하던 문제를 해결하였습니다.
* (플랫폼) Studio Pro의 Blank Web App 템플릿 버전이 Private Mendix Platform의 최신 버전 대신 항상 10.6.18이던 문제를 수정하였습니다.
* (플랫폼) 환경의 사용자 정의 리소스 설정이 일부 경우에 기본 Mendix Operator 설정으로 덮어쓰여지던 문제를 해결하였습니다.
* (플랫폼) 일부 Webhook이 각 Pipeline 실행마다 여러 번 트리거되던 문제를 수정하였습니다.
* (플랫폼) MTS 버전에서 스타터 앱 템플릿이 Studio Pro에 표시되지 않던 문제를 수정하였습니다.
* (플랫폼) 여러 수신자에게 알림을 보낼 때 실제로는 성공적으로 전송되었음에도 로그에 오류가 표시되던 문제를 수정하였습니다.
* (플랫폼) 새 사용자 생성과 관련된 문제를 해결하였습니다.
* (UI) 중국어 및 한국어 현지화의 일부 누락된 번역을 수정하였습니다.
* (UI) 로그오프 후 다시 로그인했을 때 동일한 페이지로 돌아가던 문제를 해결하였습니다.
