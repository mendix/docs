## 소개

강력한 API를 사용하여 필요한 JavaScript 액션을 빌드하십시오.

## Client API

Client API는 React 및 Dojo 클라이언트 모두와 호환됩니다. 이 공식 문서 사이트에는 예제, 모듈 등이 포함되어 있습니다:

* [Mendix 11 Client API 문서](https://apidocs.rnd.mendix.com/11/client-mx-api/index.html)

{{% alert color="warning" %}}
Client API는 위젯에서 지원되지 않습니다. 위젯 개발의 경우 [Pluggable Widgets API](/apidocs-mxsdk/apidocs/pluggable-widgets/)를 사용하십시오.
{{% /alert %}}
