## 소개

Private Mendix Platform은 프라이빗 인프라에서 엔드투엔드 Mendix 개발자 경험을 필요로 하는 고객에게 이를 제공합니다. 자체 엔터프라이즈 보안 경계 내에서 애플리케이션을 개발하고 배포할 수 있는 환경을 제공하여 최고 수준의 데이터 보안 및 규정 준수를 보장합니다. Private Mendix Platform을 기존 IT 인프라와 통합하고 특정 비즈니스 요구사항에 맞게 조정할 수 있습니다.

## Private Mendix Platform 사용의 이점

Private Mendix Platform은 개발 환경, 인프라 및 배포 옵션을 필요에 맞게 구성하고 기존 시스템 및 워크플로와 원활하게 통합되는 애플리케이션을 만들 수 있는 기능을 제공합니다. 정밀한 접근 제어를 정의하고, 기존 시스템과 원활하게 통합하며, 대규모로 고성능 애플리케이션을 구축할 수 있으며, 이 모든 것이 자체 조직 인프라 내에서 완전히 이루어집니다.

## Private Mendix Platform의 기능

Private Mendix Platform은 다음과 같은 기능을 제공합니다.

{{% alert color="info" %}}
정확한 기능 지원 여부는 선택한 구성에 따라 다릅니다. 자세한 내용은 기능별 문서를 참조하십시오.
{{% /alert %}}

* 퍼블릭 인터넷에 접속하지 않아도 Mendix Studio Pro 통합 및 원클릭 앱 배포 지원
* 모든 가상 프라이빗 클라우드 내에서 완전히 호스팅되는 Mendix 개발자 경험
* 자체 ID 공급자(IdP)를 통한 Private Mendix Platform 및 Studio Pro의 SSO 인증 지원
* Private Mendix Platform 내에서 완전히 호스팅되는 모든 콘텐츠가 포함된 프라이빗 버전의 Mendix Marketplace, 브라우저 및 Studio Pro에서 직접 접근 가능
* 프로젝트의 소스 코드 리포지토리로 사용할 수 있는 GitLab, GitHub, Bitbucket 및 Azure DevOps에 대한 SCM 리포지토리 지원
* Jenkins, Kubernetes 및 Azure DevOps와의 통합을 추가로 지원하는 기본 제공 CI/CD 기능. 사전 정의된 템플릿을 활용하거나 자체 맞춤 템플릿을 구현할 수 있습니다.
* Loki 및 Grafana와의 통합을 통한 기본 로그 검색 및 메트릭과 같은 운영 기능
* 애플리케이션 환경 관리, Marketplace 관리, 사용자 그룹 관리, 다양한 개발자 플랫폼 기능 설정 및 활동 로그와 같은 거버넌스 기능
