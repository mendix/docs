## 소개

이 문서에서는 객체가 비어 있는지, 새 객체인지, 동기화되었는지 확인하는 등 Expression의 특수 검사를 설명합니다.

## 빈 객체 확인

객체가 비어 있는지 확인합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값     | 유형               |
| --------- | ------------------ |
| 객체 | 모든 유형의 객체 |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값    | 유형    |
| ---------- | ------- |
| 객체가 비어 있는지 반환합니다 | Boolean |

### 예제

다음 입력을 사용하는 경우:

```java
$object1 = empty
```

$object1이 Domain Entity이고 현재 존재하는 경우 출력은 `False`입니다.

객체가 현재 존재하지 않는 경우(존재하지 않는 객체를 조회하려는 경우 가능) 출력은 `True`입니다.

$object1이 변수(예: Integer, String 등)인 경우에도 동일합니다.

## 빈 객체 멤버 확인

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                                            | 유형               |
| ------------------------------------------------ | ------------------ |
| 객체의 멤버(Attribute 또는 Association) | 모든 유형의 멤버 |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                   | 유형    |
| --------------------------------------- | ------- |
| Attribute가 비어 있는지 반환합니다 | Boolean |

### 예제

예를 들어, 다음과 같은 입력이 있습니다:

```java
$object1/member1 = empty
```

$object1이 'member1'이라는 멤버를 가진 Domain Entity라고 가정하면, 아래 표에 출력이 표시됩니다:

|   | member1에 값이 있음 | member1에 값이 없음 |
| --- | --- | --- |
| $object1에 값이 있음 | false | true |
| $object1에 값이 없음 | N/A | true |

## 객체가 새 객체인지 확인 {#new}

객체가 새 객체인지 확인합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값     | 유형               |
| --------- | ------------------ |
| 객체 | 모든 유형의 객체 |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형    |
| ------------------------------------------------------------ | ------- |
| 출력은 객체가 새 객체인지(생성되었지만 아직 커밋되지 않은) 여부에 따라 달라집니다. 이 함수는 생성된 객체에서 호출될 때만 유효합니다. 데이터베이스에서 객체를 조회한 경우 `isNew`는 항상 `false`입니다. | Boolean |

### 예제

입력 예제는 다음과 같습니다:

```java
isNew($object1)
```

## 객체가 동기화되었는지 확인 {#synced}

이 함수는 [조건부 가시성 또는 편집 가능성](/refguide9/common-widget-properties/) 및 [Nanoflow](/refguide9/nanoflows/)의 Expression에서만 사용할 수 있으며, 클라이언트 측에서만 평가됩니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값     | 유형               |
| --------- | ------------------ |
| 객체 | 모든 유형의 객체 |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형    |
| ------------------------------------------------------------ | ------- |
| [오프라인](/refguide9/offline-first/)에서 객체에 대한 변경 사항이 런타임 데이터베이스에 동기화되었는지 반환합니다. 웹 프로필 및 오프라인 지원이 없는 [하이브리드 프로필](/refguide9/navigation/#hybrid-profiles)에서는 항상 `true`를 반환합니다. | Boolean |

### 예제

입력 예제는 다음과 같습니다:

```java
isSynced($currentObject)
```

## 동기화가 실행 중인지 확인 {#is-syncing}

이 함수는 클라이언트 측 Expression([Nanoflow](/refguide9/nanoflows/) 및 [페이지](/refguide9/pages/)의 Expression)에서만 사용할 수 있습니다.

### 입력 매개변수

이 확인에는 입력 매개변수가 필요하지 않습니다.

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형    |
| ------------------------------------------------------------ | ------- |
| [동기화](/refguide9/synchronize/) 프로세스가 실행 중이면 `true`를 반환하고, 그렇지 않으면 `false`를 반환합니다.| Boolean |

### 예제

입력 예제는 다음과 같습니다:

```java
isSyncing()
```
