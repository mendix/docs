## 소개

Mendix SDK 문서는 아래에 설명된 섹션으로 나뉘어 있습니다.

{{% alert color="info" %}}

* Mendix Platform SDK 5.0 미만 버전에 대한 사용 방법은 [이전 SDK 버전 (5.0 미만)](/apidocs-mxsdk/mxsdk/sdk-howtos/)을 참조하십시오.
* Mendix SDK 릴리스에 대한 자세한 내용은 [Mendix Platform SDK 릴리스 노트](/releasenotes/sdk/platform-sdk/) 및 [Mendix Model SDK 릴리스 노트](/releasenotes/sdk/model-sdk/)를 확인하십시오.
{{% /alert %}}

## SDK 소개

Mendix SDK는 [Mendix Platform SDK](https://apidocs.rnd.mendix.com/platformsdk/latest/index.html)와 [Mendix Model SDK](https://apidocs.rnd.mendix.com/modelsdk/latest/index.html)로 구성됩니다. SDK의 세부 사항을 바로 살펴보기 전에 [SDK 소개](/apidocs-mxsdk/mxsdk/sdk-intro/)부터 시작할 수 있습니다.

## SDK 사용 사례

[사용 사례 예제](/apidocs-mxsdk/mxsdk/sdk-use-cases/)는 Mendix SDK로 수행할 수 있는 네 가지 기본 범주의 작업(분석, 내보내기, 수정, 가져오기)에 대한 예제를 제공합니다.

## SDK FAQ 및 문제 해결

이 문서에서는 일반적인 오류 메시지에 대한 FAQ 및 문제 해결 정보를 제공합니다.

SDK에 대한 도움이 필요하면 [SDK FAQ](/apidocs-mxsdk/mxsdk/sdk-faq/)에서 질문에 대한 답변이 있는지 확인하십시오. 그렇지 않으면 [Mendix 커뮤니티](https://community.mendix.com/)에서 질문하십시오.

## SDK 참조 가이드

Mendix Metamodel에 대한 아래 참조 문서를 살펴보십시오:

* [Mendix Metamodel](/apidocs-mxsdk/mxsdk/mendix-metamodel/) – Mendix Metamodel의 기본 구성 요소와 도메인 모델(Domain Model), 마이크로플로우(Microflow), 페이지(Page), 앱에 대해 설명합니다
* [JavaScript & TypeScript 리소스](/apidocs-mxsdk/mxsdk/javascript-typescript-resources/) – TypeScript를 요약하고 더 자세히 학습하기 위한 유용한 리소스 링크를 제공합니다

## SDK 사용 방법

아래의 단계별 가이드를 따라 SDK 사용에 필요한 모든 것을 학습하십시오:

* [개발 환경 설정](/apidocs-mxsdk/mxsdk/setting-up-your-development-environment/) – Mendix Platform SDK로 작업을 시작하는 데 필요한 모든 것을 설정하는 과정을 안내합니다
* [개인 액세스 토큰 설정](/apidocs-mxsdk/mxsdk/set-up-your-pat/) – 스크립트 인증에 필요한 개인 액세스 토큰을 생성하고 저장하는 과정을 안내합니다
* [첫 번째 스크립트 만들기](/apidocs-mxsdk/mxsdk/creating-your-first-script/) – Mendix Platform SDK를 사용하는 스크립트를 작성하는 방법을 알려드립니다
* [Mendix Platform SDK 사용하기](/apidocs-mxsdk/mxsdk/using-platform-sdk/) – Platform SDK를 사용하여 Mendix 앱을 생성, 열기, 삭제하고 앱을 변경하는 방법을 안내합니다
* [도메인 모델 만들기](/apidocs-mxsdk/mxsdk/creating-the-domain-model/) – 더 광범위한 도메인 모델(Domain Model)을 만드는 과정을 안내합니다
* [기존 모델 조작하기](/apidocs-mxsdk/mxsdk/manipulating-existing-models/) – 모델에서 사항을 변경하고, 서버 연결을 닫고, 유닛과 엘리먼트를 찾고 로드하는 방법을 알려드립니다
* [모델에서 코드 생성하기](/apidocs-mxsdk/mxsdk/generating-code-from-the-model/) – 모델을 변경하기 위한 코드를 작성하는 방법을 설명합니다
