이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.22에 적용된 변경 사항을 다루고 있습니다.

## 1.22.1

### 릴리스 날짜: 2025년 6월 17일

Private Mendix Platform 버전 1.22.1은 일부 라이선스 문제를 수정하는 패치 릴리스입니다.

#### 업데이트

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전 [2.21.3](/releasenotes/developer-portal/mendix-for-private-cloud/#2.21.3)
* Private Cloud License Manager (PCLM) 버전 [0.10.3](/releasenotes/developer-portal/mendix-for-private-cloud/#license-manage-cli-v0103)

#### 수정 사항

다음 수정 사항을 제공합니다:

* Mendix Operator 및 PCLM의 새로운 릴리스를 Private Mendix Platform에 통합하여 라이선스 문제를 해결하였습니다.

## 1.22.0

### 릴리스 날짜: 2025년 5월 29일

Private Mendix Platform 버전 1.22.0에서는 다수의 새로운 기능, 개선 사항 및 버그 수정이 도입되었습니다.

#### 새로운 기능

##### Global Operator 활성화

Private Mendix Platform은 이제 Mendix Operator를 [Global](/developerportal/deploy/global-operator/) 모드로 사용할 수 있습니다. 이 옵션을 활성화하는 방법에 대한 자세한 내용은 [빠른 시작 가이드](/private-mendix-platform/quickstart/#install-operator)를 참조하십시오.

#### 개선 사항

##### Build Settings UI 개선

사용자 경험을 향상시키기 위해 **Build Settings** 페이지를 개선하였습니다.

##### Svix 설치 프로그램 개선

Svix 설치 시 AWS Secret Manager를 지원하게 되었습니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.34](/releasenotes/studio-pro/9.24/#92434)로 업데이트되었습니다 (프로덕션 지원)
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.23](/releasenotes/studio-pro/10.6/#10623)으로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)
* Studio Pro 10.12 MTS 최신 패치 버전이 [10.12.16](/releasenotes/studio-pro/10.12/#101216)으로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)
* Studio Pro 10.18 MTS 지원은 호환성 문제로 인해 연기되었습니다

#### 수정 사항

다음 수정 사항을 제공합니다:

* (플랫폼) CVE-2024-56406 패키지 취약점을 해결하기 위해 Svix 버전을 1.62.0에서 1.65.0으로 업그레이드하였습니다.
* (플랫폼) 가져오기 및 내보내기 기능 관련 문제를 해결하였습니다.
* (플랫폼) 화면 잠금 해제 후 로그아웃할 수 없던 문제를 수정하였습니다.
* (UI) 기타 사소한 UI 개선 및 수정을 진행하였습니다.
