## 소개

{{% alert color="warning" %}}
Mendix는 더 이상 APD의 신규 라이선스를 판매하지 않습니다. 기존 계약이 유효한 고객에게는 여전히 지원되는 제품입니다.
{{% /alert %}}

이 섹션에는 Application Performance Monitor(APM) 버전 1 및 2와 Application Performance Diagnostics(APD) 버전 3의 모든 문서가 포함되어 있습니다.

{{% alert color="info" %}}
버전 3에서 제품 이름이 **Mendix Application Performance Monitor (APM)**에서 **Mendix Application Performance Diagnostics (APD)**로 변경되었습니다.
{{% /alert %}}

{{% alert color="info" %}}
구매한 라이선스를 획득하거나 갱신하려면 [이 양식](https://addon.mendix.com/index.html)으로 이동하십시오.
{{% /alert %}}
