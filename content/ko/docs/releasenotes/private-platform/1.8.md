이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.8에 적용된 변경 사항을 다루고 있습니다.

## 1.8.0

### 릴리스 날짜: 2024년 3월 31일

Private Mendix Platform 버전 1.8.0에서는 앱 프로젝트 관리, 개발(Studio Pro) 및 Marketplace 영역과 관련된 다수의 개선 사항 및 수정 사항이 도입되었습니다.

#### 새로운 기능

##### Marketplace 콘텐츠에 대한 Save and Get Notified 옵션

새로운 **Save and get notified** 옵션을 통해 Marketplace 콘텐츠의 새 버전이 준비되면 사용자에게 알림이 전송됩니다.

##### Contributor 및 Operator 프로젝트 역할

프로젝트에 새로운 역할이 제공됩니다.

###### Contributor 역할

Contributor 역할은 다음과 같은 권한 및 제한이 있습니다:

* Git 저장소에 초대되어야 합니다
* Git 서버 페이지에 접근할 수 있습니다
* Studio Pro에서 앱을 열고 코드를 커밋할 수 있습니다
* 패키지를 빌드할 수 있습니다
* 프로젝트에 멤버를 초대할 수 없습니다
* 환경을 생성하거나 환경에 배포할 수 없습니다
* 이 역할에 대해 Studio Pro의 **Publish** 버튼이 비활성화됩니다

###### Operator 역할

Operator 역할은 다음과 같은 권한 및 제한이 있습니다:

* Git 저장소에 초대되지 않습니다
* Git 서버 페이지에 접근할 수 없습니다
* Studio Pro에서 앱을 열 수 없습니다 (Studio Pro의 프로젝트 목록에 앱이 표시되지 않습니다)
* 패키지를 빌드할 수 없습니다
* 멤버를 초대할 수 없습니다
* 환경 생성 및 배포만 가능합니다

#### 개선 사항

##### 개발자 경험 개선

###### 거부된 콘텐츠에 대한 툴팁

업로드된 콘텐츠를 거부할 때 관리자가 이제 이유를 명시해야 합니다. 이유는 콘텐츠를 업로드한 사용자에게 표시됩니다.

###### 서비스 자격 증명에 구성된 Git 호스트 표시

서비스 자격 증명 드롭다운 목록이 이제 구성된 Git 호스트를 강조 표시합니다.

##### 엔지니어링 개선

###### 초대된 사용자를 위한 경험 개선

새 프로젝트에 초대된 후 로그인하는 사용자의 경험을 개선하였습니다.

###### Mendix 프로젝트 저장소 구조와의 호환성 개선

이제 Bitbucket 저장소의 기본 브랜치를 *main*으로 설정할 수 있습니다. 이를 통해 Mendix 프로젝트에서 사용하는 저장소 구조와의 호환성이 향상됩니다.

##### 기타 개선 사항

###### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.16](/releasenotes/studio-pro/9.24/#92416)으로 업데이트되었습니다
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.3](/releasenotes/studio-pro/10.6/#1063)으로 업데이트되었습니다

#### 수정 사항

다음 수정 사항을 제공합니다:

* (일반) Studio Pro와 Private Mendix Platform 간의 앱 이름 형식을 표준화하였습니다.
* (포털) 앱 생성 중 지정된 GitLab 사용자 ID가 잘못된 경우 UI 및 로그에 오류 메시지가 표시되지 않던 문제를 수정하였습니다.
* (포털) 일부 오류 팝업을 수정하였습니다.
* (포털) GitLab에 대해 잘못된 PAT ID를 입력했을 때 표시되던 오류 팝업을 수정하였습니다.
* (일반) *mxdevtools* 파일에 대한 *ERROR - Connector: 404 - file not found* 오류를 수정하였습니다.
* (포털) *Feedback no response* 오류를 수정하였습니다.
* (Marketplace) 승인 후 Marketplace 콘텐츠가 Company Content 및 Content Management 페이지에서 사라지던 문제를 수정하였습니다.
* (Studio Pro) 프로필 이미지가 너무 클 때 OIDC를 사용한 Studio Pro 로그인이 실패하던 문제를 수정하였습니다.
* (Studio Pro) GitLab OIDC 로그인으로 Studio Pro에 로그인한 후 앱을 생성할 수 없던 문제를 수정하였습니다.
