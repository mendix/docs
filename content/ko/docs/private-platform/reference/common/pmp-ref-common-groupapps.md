## 소개

**My Group Apps** 페이지는 사용자가 속한 그룹이 소유한 모든 앱의 개요를 표시합니다.

{{< figure src="/attachments/private-platform/pmp-refguide-groupapps.png" class="no-border" >}}

다음 요소가 포함되어 있습니다:

* 검색 바 - 검색 바를 사용하여 이름 또는 설명으로 앱을 검색하십시오.
* 모든 사용자 그룹이 소유한 각 앱에 대한 카드.

    * 이 앱의 프로젝트 팀 멤버인 경우 카드를 클릭하면 앱 세부 정보를 볼 수 있습니다.
    * 프로젝트 멤버가 아닌 경우 카드를 클릭하면 이 앱에 대한 기본 정보가 포함된 대화 상자가 열립니다. 거기에서 **Request Access**를 클릭하여 앱 팀에 참가하고 싶다는 것을 앱 소유자에게 알릴 수 있습니다. 앱이 배포된 경우 **Launch App**을 클릭하여 이 앱의 가장 최근에 배포된 환경의 URL을 열 수도 있습니다.
