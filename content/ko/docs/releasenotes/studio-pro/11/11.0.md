## 11.0.0 정식 출시(General Availability)

**릴리스 날짜: 2025년 6월 26일**

{{% button color="info" href="https://marketplace.mendix.com/link/studiopro/11.0.0" text="Go to Marketplace" title="Download version 11.0.0 from the Marketplace" %}}

### 새로운 기능

* Studio Pro에 새로운 시작점인 **Start with Maia**를 도입했습니다. 이 기능은 앱 개발 프로세스를 빠르게 시작하는 데 도움을 줍니다. 필수 텍스트 설명과 선택적 이미지 또는 PDF를 기반으로 Domain Model, 데이터 관리 개요 페이지, 테스트 데이터 및 맞춤형 홈페이지를 포함하는 앱을 생성합니다. 자세한 내용은 [Start with Maia](/refguide/start-with-maia/)를 참조하세요.
* 사용자가 텍스트 및 이미지 프롬프트로 Workflow를 생성할 수 있는 **Maia for Workflows**를 추가했습니다.
* Maia 생성 세션에 대한 새 메시지를 도입했습니다. 이를 통해 세션과 관련된 문서로 다시 이동하거나 현재 활성 문서에 대한 새 **Generate** 세션을 만들 수 있습니다.
* **Go to...** 대화 상자의 필터 버튼을 업데이트하여 활성 필터가 있는 경우 표시하도록 했습니다.
* 로직 편집기에서 **App Explorer**, **Toolbox** 또는 도구 모음에서 객체를 드래그할 때 <kbd>Shift</kbd>를 누르면 다른 객체에 대한 스냅이 비활성화됩니다.
* Workflow 중단 [Boundary Event](/refguide/workflow-boundary-events/)를 정식 출시(GA)했습니다. 이 새로운 유형의 Boundary Event를 통해 타이머가 만료되면 Workflow가 모델링된 흐름을 중단하고 대체 흐름을 시작할 수 있습니다.
* 이제 비중단 Boundary Event에서 반복을 지원합니다. 초기 실행 시간을 설정하고, Boundary Event가 반복되어야 하는 횟수를 지정하며, 분에서 월까지의 실행 간격을 정의할 수 있습니다.
* 오프라인 앱에서 온라인 데이터에 접근하는 기능이 이제 정식으로 사용 가능합니다. 자세한 내용은 [Offline-First Data](/refguide/mobile/building-efficient-mobile-apps/offlinefirst-data/#intro)를 참조하세요.
* 사용자 친화적인 인터페이스로 View Entity를 나타내고 OQL 쿼리를 정의하고 관리할 수 있는 OQL Query를 도입했습니다.
* PMP 고객을 위한 네이티브 모바일 빌드를 활성화했습니다.
* Mendix 11.0.0 이상에서 열 수 있는 Mendix 앱 버전을 업데이트했습니다. 이제 Mendix 11.0.0 이상에서 앱을 열려면(필요시 변환) 앱이 Mendix 버전 10.21.0 이상이어야 합니다.
* 이제 마우스에 <kbd>Back</kbd> 및 <kbd>Forward</kbd> 버튼이 있는 경우 Studio Pro에서 활성 편집기의 히스토리를 탐색할 수 있습니다.
* 새 클라이언트 API를 사용하여 CSRF 토큰을 가져오는 지원을 추가했습니다. 이제 `mx-api/session`의 `getCSRFToken`을 사용하여 보안 REST 서비스를 호출할 때 필요한 토큰을 가져올 수 있습니다.
* **Edit view entity** 대화 상자에 선택기를 추가하여 라이브 미리보기를 볼 사용자를 지정할 수 있습니다. 이를 통해 `[%CurrentUser%]` 토큰을 사용하는 쿼리를 미리 볼 수 있습니다.
* React 클라이언트가 이제 Studio Pro에서 새 애플리케이션을 만들 때 기본 클라이언트로 설정됩니다.
* Published REST 서비스에 대한 **OpenAPI Documentation** 패인을 활성화했습니다. Published OData 서비스 경험과 유사하게, 이 패인은 결과 OpenAPI 문서를 미리 보며 REST 서비스 구축을 지원합니다.
* External Database Connector가 이제 이 기능을 허용하는 데이터베이스에서 익명 블록 실행을 지원합니다.
* 이제 **mx tool**을 사용하여 Studio Pro가 로컬 앱 데이터에 저장한 비공개 값을 확인하고 삭제할 수 있습니다.
* `mx.exe`에 **Security Overview**를 JSON 및 XLSX 형식으로 내보내는 CLI 명령을 추가했습니다. `mx export-security-overview  --export-format [json|xlsx] [--exclude-appstore] [--output-file OUTPUT_FILE_PATH] PROJECT`를 사용할 수 있습니다. `--export-format` 옵션은 `json` 또는 `xlsx` 내보내기 형식을 지정합니다. 선택적 `--exclude-appstore` 플래그는 Marketplace 모듈을 내보내기에서 제외하는 데 사용할 수 있습니다. `--output-file` 옵션은 내보내기가 기록될 파일을 지정합니다. JSON으로 내보내는 경우 이 옵션을 생략할 수 있으며, 이 경우 출력이 콘솔에 인쇄됩니다. `PROJECT` 자리 표시자에는 프로젝트의 *.mpr* 파일 경로가 포함되어야 합니다.
* **Help** > **Support Tools** 메뉴에 새로운 **Contact Support** 옵션을 추가했습니다. 이를 통해 사용자가 Studio Pro에서 직접 Mendix 지원 웹사이트에 접근할 수 있습니다.
* 히스토리 탐색에서 기본적으로 화살표 키를 사용하도록 설정하고, 탐색 설정을 **Work Environment** 탭으로 이동했습니다.
* Studio Pro에서 기존 앱을 열 때 이제 자동으로 MPRV2 저장 형식으로 변환됩니다. 자세한 내용은 *Version Control*의 [Mendix MPR 저장소](/refguide/version-control/#mpr-format) 섹션을 참조하세요.
    * MPRv1 앱은 250MB보다 큰 *.mpr* 파일에 대해 커밋할 수 있으려면 MPRv2로 변환해야 합니다. 기본적으로 MPRv2로의 변환은 자동으로 수행됩니다.

* Git과 더 일치하도록 **port fix**를 **cherry pick**으로 변경하고, 상단 바에 cherry pick 및 revert 작업 인식을 추가했습니다.
* View Entity를 나타내고 사용자가 OQL 쿼리를 보다 직관적으로 정의하고 관리할 수 있는 사용자 친화적 기능인 OQL Query 인터페이스를 도입했습니다. 또한 이 인터페이스에는 플랫폼 내에서 직접 OQL 쿼리를 더 쉽게 작성, 미리보기 및 유지관리할 수 있는 새로운 AI 기능인 Maia for OQL이 탑재되어 있습니다. 자세한 내용은 [View Entities](/refguide/view-entities/) 및 [Maia for OQL](/refguide/maia-for-oql/)을 참조하세요.
* 웹 확장에서 모달 대화 상자를 표시하기 위한 새 API를 도입했습니다. Web Extensibility API의 `studioPro.ui.dialogs`에서 사용할 수 있습니다.
* 사용자가 앱 폴더를 Microsoft Defender 제외 목록에 추가할 수 있는 새 기능을 도입했습니다.
* 웹 확장에서 사용자 기본 설정에 접근하기 위한 새 API를 도입했으며, 사용자가 선택한 테마 기본 설정(라이트 또는 다크)과 언어 설정(예: `en-US`)을 가져옵니다. Web Extensibility API의 `studioPro.ui.preferences`에서 사용할 수 있습니다.
* 웹 확장에서 알림 팝업을 표시하기 위한 새 API를 도입했습니다. Web Extensibility API의 `studioPro.ui.notifications`에서 사용할 수 있습니다.
* 이제 Consumed REST 서비스에서 OpenAPI 계약의 content-type 헤더 하나만 가져옵니다. 이 기능은 베타입니다.

### 개선 사항

* Studio Pro에서 AutoNumber 속성의 기본값 검증을 개선했습니다. 이제 2,147,483,647보다 큰 값을 허용합니다. (Ticket 240734)
* 페이지를 찾을 수 없을 때 표시되는 대화 상자의 텍스트가 이제 번역 가능합니다. (Ticket 242035)
* 많은 중첩된 결과 기반 Activity가 있는 Workflow에 대한 Workflow 버전 관리 충돌 분석 성능을 개선했습니다. (Ticket 242615)
* React 클라이언트에서 페이지로 이동할 때 페이지 로드에 실패하면 오류 로깅을 추가했습니다. 이는 손상된 번들이 있는 위젯이 페이지에 포함된 경우 발생할 수 있습니다. (Ticket 245516)
* 모든 Maia 관련 기본 설정을 **New Features** 탭에서 **Maia** 탭의 새로운 **Generative AI** 섹션으로 이동했습니다.
* 작업 큐의 시작 성능을 개선했습니다. 대기 중인 작업은 이제 시작 시가 아닌 실행될 때 검증됩니다.
* OQL 문법에 추가 키워드를 추가했습니다. 이러한 용어는 따옴표 없이 식별자로 사용할 수 없습니다. 새 키워드는 `DELETE`, `INSERT`, `REPLACE`, `UPDATE`, `UPSERT`, `INTO`, `SET`, `VALUES`, `IGNORE`, `MATCHED`, `DUPLICATE`, `KEY`, `CONFLICT`, `MERGE`, `USING`, `SOURCE`, `TARGET` 및 `WITH`입니다.
* 현대화된 접근 규칙 편집기를 Entity **Properties** 패인에 통합했습니다.
* **Keep active document selected the App Explorer** 기본 설정이 활성화되면 현대화된 App Explorer가 현재 활성 문서를 선택된 상태로 유지합니다.
* Studio Pro가 **Stories** 뷰가 열릴 때만 현재 스프린트의 데이터를 다운로드하도록 업데이트했습니다.
* Studio Pro에 브라질 포르투갈어 지원을 추가했습니다.
* View Entity에서 OQL 쿼리를 실행할 때 Studio Pro가 표시하는 메시지를 개선했습니다. 이제 앱이 아직 완전히 시작되지 않은 경우와 쿼리가 사용자를 지정하지 않고 `[%CurrentUser%]`를 참조하는 경우에 대해 보다 명확한 메시지가 표시됩니다.
* 온라인 동기화 모드가 있는 Entity가 오프라인 동기화 모드가 있는 Entity를 참조할 수 없는 제한을 완화했습니다. 이제 온라인 및 오프라인 동기화 모드가 있는 Entity를 혼합하는 페이지 및 Nanoflow의 XPath 제약 조건만 방지하여 더 많은 모델링 가능성을 허용합니다.
* [추적](/refguide/tracing-in-runtime/)이 활성화되면 추적에 이제 모든 Microflow Activity에 대한 span이 포함됩니다.
* OpenTelemetry 에이전트 jar를 Studio Pro에 번들로 포함했습니다. `runtime/agents/opentelemetry-javaagent.jar`에서 찾을 수 있습니다.
* Studio Pro에서 런타임 추적을 활성화하는 **Enable Tracing** 옵션을 제공했습니다. **App Settings**를 통해 접근할 수 있습니다. 자세한 내용은 *Tracing*의 [최소 구성](/refguide/tracing-in-runtime/#min-configuration) 섹션을 참조하세요.
* 비동기 요청이 시작된 경우 사용자 정의 요청 핸들러의 응답 라이터를 더 이상 닫지 않습니다. 이 변경으로 비동기 요청 핸들러를 구현할 수 있습니다.
* 기본 설정을 제공하는 OpenTelemetry 에이전트 확장을 구현했습니다. `runtime/agents/mendix-opentelemetry-agent-extension.jar`에서 찾을 수 있습니다.
* 이제 앱에 동일한 Java 종속성의 여러 버전이 있는 경우 일관성 경고를 추가합니다.
* OData HTTP 상태 코드 422의 이유 구문을 https://www.rfc-editor.org/rfc/rfc9110.html#name-422-unprocessable-content에 정의된 대로 *Unprocessable Content*로 변경했습니다.
* 모듈, 위젯, 솔루션 패키지를 가져오거나 템플릿에서 새 앱을 시작할 때, 이제 패키지가 원하지 않는 디렉토리에 콘텐츠를 풀지 못하도록 방지합니다. 사용자는 여전히 나머지 패키지를 추출하도록 선택할 수 있습니다.
* 이제 현대화된 Entity 접근 규칙 편집기에서 **Changes** 또는 **Error** 패인에서 열린 접근 규칙을 직접 열지 않고 강조 표시합니다.
* 모듈에서 CSP를 구현하기 위한 Java API를 개선했습니다. 구성 API가 사용자 정의 헤더와 상호 작용하기 위한 `getHeader` 및 `getCustomHeaders` 메서드로 확장되었으며 `getTemplate`, `getNonce`, `hasNonce` 및 `addHeader` 메서드를 포함하는 CSP API를 `Core` 클래스에 추가했습니다. 자세한 내용은 Java API 문서를 참조하세요.
* React 클라이언트의 오류 보고를 개선했습니다. 이제 애플리케이션 로그를 열지 않고도 Studio Pro에서 직접 JS 액션 및 위젯 관련 오류를 확인할 수 있습니다.
* 구조 모드와 디자인 모드 간의 페이지 및 스니펫 변수의 미리보기 값을 정렬했습니다.
* **Call a Microflow** 및 **Call a Nanoflow** 액션에 대한 매개변수 매핑을 구성할 때 위젯 액션 변수를 더 쉽게 사용할 수 있도록 했습니다.
* **Properties**의 **Accessibility** 섹션에서 기본 **Role Type**을 **Link Button**에서 **Link**로 변경했습니다. 이 **Role Type**은 기능적으로 링크이지만 기본적으로 **Link Button**으로 설정되어 있었습니다.
* Consumed REST Service에서 이제 다양한 방식으로 본문 콘텐츠를 정의할 수 있습니다. **Create Entity (JSON)**를 선택하여 JSON 파일을 Entity로 변환하고 **Send REST Request** Activity의 입력으로 사용할 수 있습니다. 또한 텍스트 콘텐츠를 전송하려면 **Use as template**를 선택할 수 있습니다. 텍스트의 매개변수는 중괄호로 둘러싸서 지원됩니다(예: `{my_param}`).
* Consumed REST 서비스 문서의 응답 및 본문 구조에서 **Create entity** 버튼에 진행 표시기를 추가했습니다.
* System 모듈에 **WorkflowEndedUserTask**라는 새 Entity를 추가했습니다. Workflow 사용자 작업이 종료될 때마다(**Finished** 및 **Aborted** 모두 포함) 작업에 대한 데이터가 이 새 Entity에 저장됩니다.
* 여러 매개변수가 있는 페이지를 열 수 있도록 `FeedbackHelper.OpenFormFeedback` Java API를 확장했습니다.
* [입력 요소](/refguide/input-widgets/), 플러그형 위젯 [속성 속성](/apidocs-mxsdk/apidocs/pluggable-widgets-property-types/#attribute) 및 [스니펫 호출](/refguide/snippet-call/#snippet-settings)을 구성할 때 페이지 매개변수를 사용하는 데 더 이상 Data View가 필요하지 않습니다.
* 비활성화된 도구 모음 버튼 아이콘에 투명도를 추가하여 가시성을 개선했습니다.
* Studio Pro와 함께 설치되는 dotnet 런타임 버전을 업데이트했습니다.
* 처리되지 않은 예외가 발생할 때 오류 팝업 창 대신 메인 창의 오른쪽 상단 모서리에 알림을 표시하도록 Studio Pro를 업데이트했습니다.
* Starter 앱 템플릿의 이미지를 다운로드하고 처리하는 프로세스의 효율성을 개선하여 Studio Pro 시작 속도를 높이고 메모리 소비를 줄였습니다.
* **Create New App** 페이지에 다크 모드 지원을 추가했습니다.
* **OpenAPI Documentation** 패인의 레이아웃을 개선했습니다. 이제 보다 간결한 레이아웃을 제공하여 서비스가 게시할 모든 작업을 더 쉽게 볼 수 있습니다.
* Published OData 서비스의 OpenAPI 문서가 이제 OpenAPI 버전 3.0.1 대신 OpenAPI 버전 3.0.4를 사용합니다.
* Maia for pages가 이제 기존 페이지에서 작동합니다. 페이지의 콘텐츠를 이해하므로 필요에 따라 위젯을 추가, 변경 또는 제거하도록 쉽게 요청할 수 있습니다.
* [디자인 속성](/apidocs-mxsdk/apidocs/design-properties/#common-fields)에 `category`를 도입하여 사용자가 스타일링 패인 내에서 디자인 속성을 선택적으로 그룹화할 수 있습니다.
* Micrometer Prometheus 레지스트리 종속성을 업그레이드했습니다.
* 공개 API에 `com.mendix.core.conf.LicenseInfo#validateCustomerID(String)` 메서드를 추가했습니다. 이 메서드는 고객 ID가 실행 중인 애플리케이션의 라이선스에 있는 것과 일치하는지 확인하는 데 사용할 수 있습니다. `LicenseInfo` 인스턴스는 `Core.getLicenseInformation()`을 통해 사용할 수 있습니다.
* Studio Pro **Preferences**에서 Gradle 프로세스에 [추가 인수](/refguide/preferences-dialog/#extra-arguments)를 추가하는 옵션을 추가했습니다.
    * MxBuild에 `extra-gradle-arguments` 옵션도 추가했습니다. 이 옵션을 사용하여 Gradle 프로세스에 추가 인수를 전달할 수 있습니다.
* 푸시할 것이 없으면 서버에 커밋 푸시가 더 이상 불가능합니다.
* 현대화된 Entity Access Rules 편집기에서 Entity 및 멤버 접근 권한 검증을 개선했습니다. 이제 특정 권한을 부여할 수 없는 이유를 표시하고 멤버 접근 권한 기능을 사전에 확인합니다.
* Nanoflow 간 변환 시 표시되는 경고 팝업 창을 개선했습니다: **Find Usages** 버튼이 **Show Usages**로 이름이 변경되었으며 이제 대체할 수 없는 사용만 표시합니다.
* 현대화된 Entity Access Rules 편집기가 이제 System Entity와 같은 편집할 수 없는 Entity의 접근 규칙 보기를 지원합니다.
* Microsoft SQL Server용 JDBC 드라이버를 버전 12.10.0으로 업그레이드했습니다. [Database Connector](https://marketplace.mendix.com/link/component/2888)와 같은 모듈에서 통합 보안을 사용하여 SQL Server에 연결하는 경우 `userlib`의 JDBC 드라이버도 업데이트해야 할 수 있습니다.
* Consumed REST Service에 대한 **Open API request** 선택 대화 상자의 체크/해제 동작을 개선했습니다.
* 페이지 및 스니펫의 변수가 이제 XPath 제약 조건에서 사용할 수 있습니다.
* OQL 쿼리에서 이제 빈 값을 `DATETIME`, `DECIMAL`, `INTEGER`, `LONG` 또는 `STRING`으로 캐스트하려는 경우 `CAST` 표현식에서 `NULL`을 사용할 수 있습니다. 이는 Java 액션의 OQL 실행에서 이미 지원되었지만, Studio Pro에서 View Entity 또는 데이터 세트에서 사용할 때 오류를 추가했었습니다.
* Studio Pro에서 View Entity의 라이브 미리보기를 개선했습니다. Association을 나타내는 열이 이제 헤더에 Entity 이름을 표시하고, 연관된 객체가 없으면 셀이 비어 있습니다.
* 이제 Studio Pro의 [View Entity](/refguide/view-entities/)에서 **Run Query** 테이블에서 복사할 수 있습니다.
* OpenAPI **Documentation** 패인의 레이아웃을 개선했습니다. 이제 보다 간결한 레이아웃을 제공하여 서비스가 게시할 모든 작업을 더 쉽게 볼 수 있습니다.
* 로직 편집기에서 다양한 개선을 했습니다:
    * 요소를 루프 내부로 드래그할 때 루프 테두리를 강조 표시합니다.
    * 연결점과 크기 조정 핸들이 선택된 요소에서만 보이도록 했습니다. <kbd>Shift</kbd> 키를 눌러 호버 시 연결점을 표시합니다.
    * 요소 크기를 조정할 때 연결된 요소를 이동합니다.
    * 첨부된 어노테이션이 있는 요소를 플로우에 삽입할 때, 불필요하게 긴 플로우를 방지하기 위해 삽입된 요소의 길이만큼만 공간을 확보합니다.
    * 요소를 작게 만들면 시퀀스 플로우 간의 너비를 유지하기 위해 연결된 요소가 자동으로 재배치됩니다.
    * 요소를 플로우에 삽입할 때, 연결된 요소와 같은 컨테이너의 연결되지 않은 요소가 이제 공간을 확보하기 위해 이동됩니다.
* React 관련 다양한 개선을 했습니다:
    * `react-native-reanimated`를 최신 버전으로 업데이트했습니다.
    * `@react-navigation`을 최신 버전으로 업데이트했습니다.
* `mx create-module-package` 명령이 이제 모듈의 관리 종속성을 동기화하여 내보낸 모듈 패키지에 포함합니다. 이를 통해 Gradle 동기화가 비활성화된 Studio Pro에서 모듈을 사용할 수 있습니다. `exclude-managed-dependencies` 플래그를 사용하여 이 동작을 비활성화할 수 있습니다.
* 인증 토큰이 이제 회전되어 세션 만료 시 보안을 개선하기 위해 새 토큰이 생성됩니다.
* **Security Overview** 및 현대화된 Entity Access Rules 편집기에서 Entity의 일반화에서 상속된 속성 및 Association이 이제 고유한 상속 아이콘으로 표시됩니다.
* 탐색 메뉴 버튼이 이제 보이는 경우 접근할 수 있습니다.
* 탐색 트리 메뉴가 여전히 보이는 경우 더 이상 *aria-hidden*으로 태그되지 않습니다.
* 관련 위치의 탐색 트리에 *aria-expanded*, *aria-haspopup* 및 *aria-controls* 속성을 추가했습니다.
* 페이지 및 스니펫의 변수를 더 쉽게 사용할 수 있도록 했습니다. 이제 조건부 가시성, 조건부 편집 가능성 및 텍스트 템플릿의 값 선택기에서 변수를 사용할 수 있습니다.
* **Connector** 패인이 이제 페이지 및 스니펫 변수를 제공합니다.
* External Database Connector에서 주석 내부의 매개변수를 올바르게 무시하도록 SQL 파싱을 개선했습니다.
* 페이지 및 Microflow 편집기의 컨텍스트 메뉴를 화살표 키를 사용한 탐색을 지원하도록 개선했습니다.
* **Integration** 패인에서 Business Event 기능의 툴팁을 개선했습니다.

### 수정 사항

* Studio Pro에 모듈을 가져오는 것과 관련된 보안 문제를 수정했습니다. (6.1 – CVSS:3.1/AV:N/AC:H/PR:N/UI:R/S:C/C:N/I:H/A:N – 자세한 내용은 [보안 권고](/releasenotes/security-advisories/#40592)를 참조하세요)
* Consumed Web Service가 로컬로 가져온 WSDL 파일에 대해 런타임에 유효성 검사 실패를 일으키는 문제를 수정했습니다. (Ticket 146066)
* 로직 편집기에서 Microflow가 애플리케이션에서 사용되고 있음에도 접근 불가능하다는 경고가 표시되는 문제를 수정했습니다. (Tickets 184859, 186059, 215091, 216988)
* 위젯 간 리스닝에 영향을 미치는 문제에 대한 수정을 재적용했습니다. (Ticket 206642)
* **Message** 정의에서 노드 확장 시 사용자 정의 이름이 초기화되는 문제를 수정했습니다. (Tickets 222597, 227958, 236152, 232930, 240806, 241561, 244349)
* **Call a microflow**가 선택되고 **Map entity** 대화 상자에서 **Select** 버튼을 클릭했을 때 앱이 충돌하는 문제를 수정했습니다. (Ticket 225433)
* Export Mapping에서 XML 스키마 또는 Consumed Web Service를 체크 해제할 수 없는 필드가 문서 스키마 소스를 처음 선택할 때 기본적으로 체크되고 확장되지 않는 문제를 수정했습니다. (Ticket 232274)
* 숨겨진 플러그형 위젯 속성이 올바르게 재설정되지 않는 문제를 수정했습니다. 이로 인해 위젯 업데이트 알림을 일으키는 번역, Data Grid 2의 누락된 번역, **File Uploader**에서 일관성 오류를 생성하는 미사용 속성이 발생했습니다. 이 수정으로 이러한 속성은 숨겨질 때 기본값으로 재설정되고, 사용될 때만 적용됩니다. (Tickets 233401, 248682)
* 현대화된 **Toolbox**에서 앱 디렉토리를 동기화하여 새 위젯을 로드한 후 **Toolbox**가 새로 고쳐지지 않는 문제를 수정했습니다. (Ticket 237560)
* **Multiple sessions per user** 설정을 비활성화하면 현재 유효한 토큰을 포함하여 기존의 모든 사용자 세션을 잘못 종료하고 모든 관련 토큰을 삭제하는 문제를 수정했습니다. (Ticket 238657)
* Nanoflow에서 사용할 때 `Substract`, `Union` 및 `Intersect` 리스트 작업이 항상 고유한 값이 있는 리스트를 반환하지 않는 문제를 수정했습니다. (Ticket 240695)
* 로직 편집기에서 추출할 선택에서 매개변수 또는 변수가 두 번 이상 사용된 경우 동일한 매개변수가 여러 개 생성되는 문제를 수정했습니다. (Ticket 242517)
* Java 액션에서 문자열 리스트를 로깅할 때 Studio Pro가 충돌하는 문제를 수정했습니다. (Ticket 243124)
* Microflow에 비활성화되고 분리된 Activity가 있으면 Microflow가 메인 플로우를 실행하지 않는 문제를 수정했습니다. (Ticket 243133)
* <kbd>F9</kbd> **View App** 단축키를 수정했습니다. 현재 실행 중인 앱을 브라우저에서 보는 데 사용됩니다. (Ticket 243743)
* Microflow에 잘못된 비활성화된 Activity가 포함된 경우 `NullPointerException`으로 런타임 시작에 실패하는 문제를 수정했습니다. (Ticket 243931)
* Published REST 및 OData 서비스에서 만료된 CSRF 토큰으로 JavaScript를 사용하여 활성 세션 인증으로 서비스를 호출할 때 브라우저가 **Username**/**Password** 팝업 창을 표시하는 문제를 수정했습니다. (Ticket 243407)
* 오류 팝업 창을 일으키는 Microflow 매개변수 매핑 문제를 수정했습니다. (Ticket 244852)
* 로직 편집기에서 크로스 모듈 일대일 Association의 표시 데이터 유형을 수정했습니다. (Ticket 245052)
* Entity에서 자체 특수화로의 Association을 특수화 인스턴스에서 업데이트할 때 Association이 반대 방향으로 설정되는 문제를 수정했습니다. (Ticket 245140)
* React 클라이언트에서 시작 시 문서 제목이 애플리케이션에 구성된 제목 대신 *Mendix*였던 문제를 수정했습니다. (Ticket 245280)
* 클라이언트에서 `urlEncode` 및 `urlDecode` 함수의 동작을 런타임과 일치하도록 수정했습니다. 이제 공백이 `+` 대신 `%20`으로 올바르게 인코딩됩니다. `urlDecode`는 이전 버전에서 인코딩된 문자열과의 하위 호환성을 보장하기 위해 `+`가 포함된 문자열의 디코딩을 여전히 지원합니다. (Ticket 245510)
* 텍스트 템플릿을 사용하는 위젯과 관련된 배포 중 성능 문제를 해결했습니다. (Ticket 245543)
* Safari 확장이 Dojo 클라이언트를 손상시키는 문제를 수정했습니다. (Ticket 246247)
* 로그아웃 작업 후 오프라인 데이터베이스 크기가 제대로 줄어들지 않는 문제를 수정했습니다. (Ticket 247029)
* 사용자가 로그인한 후 Studio Pro가 닫히는 문제를 수정했습니다. (Ticket 248086)
* 앱에서 언어가 제거된 후 대화 상자에 잘못된 텍스트가 표시되는 문제를 수정했습니다. (Ticket 248967)

### Breaking Changes

* 각 앱에 자동으로 포함되는 **System** 모듈의 **ShowHomePage** Microflow에서 Entity 접근을 활성화했습니다. 이를 통해 안전한 기본값을 제공하여 보안 우려를 줄입니다. 자세한 내용은 *Mendix Studio Pro 10에서 11로 업그레이드*의 [System 모듈에서 ShowHomePage Microflow 사용](/refguide/upgrading-from-10-to-11/#apply-entity-access) 섹션을 참조하세요. (Ticket 92564)
* `XPathQueryBase` Java API 및 확장에 새 메서드 `allowMathOperators`를 추가했습니다. XPath 쿼리에서 수학 연산자를 활성화하는 데 사용할 수 있습니다.
* Java API `Core.createXPathQuery`로 생성된 XPath는 더 이상 기본적으로 수학 연산자를 허용하지 않습니다. 수학 연산자를 사용하려면 새 `allowMathOperators` 메서드를 사용하여 쿼리에 대해 활성화해야 합니다. 예:

    ```
    core.createXPathQuery("//Module.Entity[attr1 + attr2 = 42]")
        .allowMathOperators(true)
        .execute(context);
    ```

* **App Settings**에서 **Automatically encode parameter values in Send REST request microflow activities** 옵션을 제거했습니다. 이를 통해 사용자가 URL 매개변수의 자동 인코딩을 활성화할 수 있었습니다. 이제 **Send REST request** Microflow Activity에서 URL 매개변수를 자동으로 인코딩하지 않으며, 이는 Consumed REST Service 문서에서 매개변수를 처리하는 방식과 일치합니다.
* WSDL의 다차원 배열을 **Import Mapping** 및 **Export Mapping** 문서에서 선택할 수 없도록 했습니다. 이전에는 일반 배열로 잘못 감지되었지만, 런타임은 이 입력을 파싱할 수 없었습니다.
* `com.mendix.core.actionmanagement.internal.InternalCoreAction#getMetaInfo()` 메서드를 제거했습니다. 이 메서드는 내부 사용 전용이었으므로 대체품이 없습니다.
* `com.mendix.modules.email.EmailModule` 지원을 제거했습니다. 대신 [Email Connector](https://marketplace.mendix.com/link/component/120739) 모듈을 사용하는 것을 권장합니다.
