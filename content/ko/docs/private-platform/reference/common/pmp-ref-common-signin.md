## 소개

초기 로그인 화면은 관리자 접근 권한 보유 여부에 관계없이 모든 사용자에게 동일합니다. 다음과 같은 로그인 방법을 사용할 수 있습니다:

* 사용자 이름과 비밀번호를 사용한 로컬 사용자 로그인
* 선택적으로 SSO 공급자로 리디렉션하는 SSO 로그인

{{< figure src="/attachments/private-platform/pmp-ref-signin.png" class="no-border" >}}

로그인 후 역할에 관계없이 모든 사용자는 처음에 **My Apps** 페이지로 이동됩니다. 관리자 역할을 가진 사용자는 오른쪽 상단의 사용자 아이콘을 클릭한 다음 **Switch to Admin Mode**를 선택하여 관리자 보기로 전환할 수 있습니다.
