## 설명

지정된 열 및 행 캡션으로 찾은 체크박스의 값을 반전합니다.

## 지원 Widget

* Grid Selector

## 사용법

토글하려는 체크박스의 Widget 이름, 열 캡션, 행 캡션을 전달하세요.

## 입력 파라미터

Name | Datatype | Required | Description
---- | -------- | -------- | ---------------
Widget Name | String | Yes | Grid Selector Widget의 이름입니다.
Column Caption | String | Yes | 토글하려는 체크박스 셀의 열 캡션입니다.
Row Caption | String | Yes | 토글하려는 체크박스 셀의 행 캡션입니다.
