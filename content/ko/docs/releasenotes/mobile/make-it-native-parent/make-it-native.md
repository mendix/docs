앱이 개발된 Mendix 버전과 실행하려는 기기에 따라 다른 Make It Native 앱이 필요합니다. 올바른 버전을 다운로드하는 방법에 대한 자세한 내용은 *네이티브 앱 사전 요구 사항 및 문제 해결*의 [Make It Native 앱 다운로드](/refguide/mobile/getting-started-with-mobile/prerequisites/#get-min-app) 섹션을 참조하세요.

**릴리스 날짜: 2025년 11월 11일**

## iOS 2.0.0 / Android 2.0.0{#upgraded-react-min}

**릴리스 날짜: 2023년 12월 21일**

### 개선 사항

* React Native를 0.72.7로 업그레이드했습니다. 이 중요한 업데이트는 성능을 개선하고 React Native의 최신 기능과의 호환성을 높입니다.

### 호환성 공지

* **10.6~10.10과 호환** – 이 버전의 MIN 앱은 **Mendix Studio Pro 10.6~10.10**에서만 작동하도록 설계되었습니다. Mendix Studio Pro 10.6 미만 버전의 사용자는 앱 개발 및 테스트 목적으로 Make It Native 9를 계속 사용해야 합니다. 어떤 MIN 버전이 Studio Pro 버전과 작동하는지에 대한 정확한 목록은 [Make It Native 앱 다운로드](/refguide/mobile/getting-started-with-mobile/prerequisites/#get-min-app)를 참조하세요.
* **필수 업데이트** – React Native 0.72.7로의 업그레이드로 모든 사용자가 앱을 이 최신 버전으로 업데이트해야 합니다. 이전 버전의 MIN 앱은 이 업데이트 후 더 이상 작동하지 않습니다. 중단 없이 앱을 계속 사용하려면 모든 사용자가 이 업데이트를 즉시 설치하는 것을 강력히 권장합니다.

### 알려진 문제 {#known-issues-200}

* **증강 현실(AR) 기능** - MIN 앱에서 AR 기능이 예상대로 작동하지 않는 문제를 현재 인지하고 있습니다. 해결책을 적극적으로 찾고 있으며 후속 업데이트에서 이 문제를 수정할 계획입니다.

## iOS 1.0.3

**iOS 릴리스 날짜: 2023년 7월 22일**

### 개선 사항

* **Launch App** 화면이 이전에 사용한 URL을 일관되게 기억하도록 했습니다.

## Android 1.0.0

**Android 릴리스 날짜: 2023년 7월 7일**

Mendix Studio Pro 10.0을 지원하는 Android 버전의 Make It Native 10 앱의 공식 릴리스입니다.

Android 및 iOS 버전 모두 지원되는 모든 모바일 플랫폼에서 로컬로 실행 중인 네이티브 앱을 미리 보고 디버그할 수 있습니다.

### 개선 사항

* 기본 언어를 `- en-US`로 설정했습니다.
* 더 깔끔하고 직관적인 레이아웃으로 앱 디자인을 새롭게 했습니다.
* 더 세련되고 현대적인 룩을 위해 시각적 요소와 아이콘을 개선했습니다.

## iOS 1.0.0

**iOS 릴리스 날짜: 2023년 6월 27일**

Mendix Studio Pro 10.0을 지원하는 iOS 버전의 Make It Native 10 앱의 공식 릴리스입니다.

Android 및 iOS 버전 모두 지원되는 모든 모바일 플랫폼에서 로컬로 실행 중인 네이티브 앱을 미리 보고 디버그할 수 있습니다.

### 새로운 기능

* **History** 탭을 도입하여 자주 방문하는 URL을 다시 입력하지 않고도 접근할 수 있습니다.
