## 소개

Mendix의 강점 중 하나는 Mendix 애플리케이션을 다른 시스템에 쉽게 연결할 수 있다는 것입니다. [Mendix Marketplace](https://marketplace.mendix.com/)에는 다양한 종류의 커넥터와 어댑터가 준비되어 있습니다. 또한 Widget(위젯)을 사용하고 직접 만들어 앱을 확장할 수도 있습니다.

관련하여, Studio Pro의 강점 중 하나는 커스터마이징이 가능하다는 것입니다. Studio Pro에 첫 번째 커스텀 확장 기능을 추가하는 방법에 대한 자세한 내용은 API 문서의 [Get Started with the Web Extensibility API](/apidocs-mxsdk/apidocs/web-extensibility-api-11/getting-started/) 또는 [Get Started with the C# Extensibility API](/apidocs-mxsdk/apidocs/csharp-extensibility-api-11/get-started/)를 참조하세요.
