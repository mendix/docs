## 소개

이 문서에서는 Expression에서 지원되는 산술 연산자를 설명합니다. 이들은 모두 숫자 데이터 유형(Integer/Long 및 Decimal)에서 작동합니다.

## 곱셈

두 숫자를 곱합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값         | 유형                  |
| ------------- | --------------------- |
| 첫 번째 숫자  | Integer/Long, Decimal |
| 두 번째 숫자 | Integer/Long, Decimal |

### 출력

두 입력이 모두 Integer/Long 유형인 경우, 결과도 Integer/Long 유형입니다.

두 입력 중 하나가 Decimal 유형인 경우, 결과는 Decimal 유형입니다.

### 예제

다음 입력을 사용하는 경우:

```java
2*3
```

출력은 다음과 같습니다:

```java
6
```

## 나눗셈

두 숫자를 나눕니다. 아래 예제에서 볼 수 있듯이 `div` 또는 콜론( ``:`` ) 구문을 사용할 수 있습니다. 콜론( ``:`` ) 구문은 나누기 기호 `÷`에서 영감을 받았습니다. 슬래시( / )는 객체와 멤버를 구분하는 데 사용되므로 더 일반적인 슬래시 구문을 사용할 수 없습니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값         | 유형                  |
| ------------- | --------------------- |
| 첫 번째 숫자  | Integer/Long, Decimal |
| 두 번째 숫자 | Integer/Long, Decimal |

### 출력

입력 유형에 관계없이 결과는 항상 Decimal 유형입니다.

### 예제

아래에서 사용 예를 확인하십시오:

* `div` 구문 예제: 다음 입력을 사용하는 경우:

    ```java
    3 div 5
    ```

    출력은 다음과 같습니다:

    ```java
    0.6
    ```

* `:` 구문 예제: 다음 입력을 사용하는 경우:

    ```java
    12 : 3
    ```

    출력은 다음과 같습니다:

    ```java
    4.0
    ```

### 참고 사항

나눗셈의 결과가 무한 소수 확장을 갖는 경우 근사값만 제공됩니다. 아래 두 예제는 이 근사값을 보여줍니다:

* 다음 입력을 사용하는 경우:

    ```java
    3 : 7
    ```

    출력은 다음과 같습니다:

    ```java
    0.4285714285714285714285714285714286
    ```

    나눗셈 결과로 계산을 계속하면 예상치 못한 결과가 나올 수 있습니다. 다음 입력:

    ```java
    (3 : 7) * 7
    ```

    은 아래와 같은 출력을 생성합니다:

    ```java
    3.0000000000000000000000000000000002
    ```

* 다음 입력을 사용하는 경우:

    ```java
    ceil((3 : 7) * 7)
    ```

    출력은 다음과 같습니다:

    ```java
    4
    ```

따라서 나눗셈 연산은 마지막에 수행하는 것이 좋습니다.

## 나머지(Modulo)

한 숫자를 다른 숫자로 나눈 나머지를 계산합니다. 즉, `m` modulo `n`은 다음에 해당합니다: `m = p + k*n`, 여기서 `p`는 `m` modulo `n` 연산의 결과입니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값         | 유형                  |
| ------------- | --------------------- |
| 첫 번째 숫자  | Integer/Long, Decimal |
| 두 번째 숫자 | Integer/Long, Decimal |

### 출력

두 입력이 모두 Integer/Long 유형인 경우, 결과도 Integer/Long 유형입니다.

두 입력 중 하나가 Decimal 유형인 경우, 결과는 Decimal 유형입니다.

### 예제

다음 입력을 사용하는 경우:

```java
23 mod 5
```

출력은 다음과 같습니다:

```java
3
```
