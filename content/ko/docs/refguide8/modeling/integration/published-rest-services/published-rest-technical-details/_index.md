## 소개

Published REST 문서의 이 섹션에서는 Mendix의 Published REST 기능에 대한 기술적 측면을 설명합니다.

여기의 세부 사항을 모르더라도 Published REST를 사용할 수 있습니다. 이러한 문서를 통해 Mendix Published REST Service를 추가로 사용자 정의하고 문제를 해결할 수 있습니다.

## Mendix Published REST 기술 문서

### [Published REST Routing](/refguide8/published-rest-routing/)

이 페이지에서는 수신 HTTP 요청이 처리되는 방법과 주어진 요청에 대해 어떤 작업이 실행되는지 보여줍니다.

문제 해결과 Published REST Service 설계를 지원하는 데 모두 사용할 수 있습니다.

### [JSON Schema](/refguide8/published-rest-service-json-schema/)

OpenApi (Swagger) 문서 페이지에서 Import 및 Export Mapping을 지원하기 위해 생성되는 JSON Schema의 기술 세부 사항입니다.

### [OpenAPI 2.0 문서](/refguide8/open-api/)

OpenApi (Swagger) 문서 페이지에서 Published REST Service를 설명하기 위해 생성되는 *swagger.json* 파일의 기술 세부 사항입니다.

### [사용자 정의 인증 Microflow의 매개변수](/refguide8/published-rest-authentication-parameter/)

Published REST Service에 대한 사용자 정의 인증을 수행하는 Microflow에 전달되는 매개변수를 설명합니다.
