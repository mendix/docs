## December 2018

### December 12, 2018

#### Improvements

* 다수의 팀에 소속된 사용자의 **My Apps** 페이지 성능을 개선했습니다.
* **My Company's Apps** 페이지의 디자인을 **My Apps** 페이지와 일관되도록 업데이트했습니다.
* Developer Portal에서 발송되는 이메일의 디자인을 개선했습니다.

#### Fixes

* **Stories** 페이지로의 딥 링크가 깨지던 문제를 수정했습니다.

### December 1, 2018

#### Fixes

* Technical Contact 역할을 가진 팀 멤버가 **Security** 페이지의 **Node Permissions** 탭에서 간헐적으로 숨겨지던 문제를 수정했습니다. (Tickets 69085, 69150, 69419, 69440, 69458, 69585, 69592, 69783, 69884,70131,70228, 70285, 76152)

## November 2018

### November 1, 2018

#### Improvements

* Web Modeler와 Developer Portal 간의 통신을 개선했습니다.

## October 2018

### October 17, 2018

#### Fixes

* Developer Portal의 응답 시간이 길어지는 메모리 누수 문제를 수정했습니다.
* 일부 Developer Portal 사용자에게 오류 메시지 대신 빈 대화 상자가 표시되던 문제를 해결했습니다. (Tickets 67626, 69363)

### October 16, 2018

#### Fixes

* 이제 [Buzz](/developerportal/general/overview/) 및 **People** 페이지에서 Mendix 커뮤니티 멤버의 새로운 [Mendix Profile](/portal/mendix-profile/)로 직접 이동할 수 있습니다. (Ticket 69702)

### October 11, 2018

#### Improvements

* Developer Portal 페이지에 여러 UX 업데이트가 적용되었습니다:
    * [My Apps](https://sprintr.home.mendix.com/link/myapps) 페이지가 재설계되었으며, 앱 목록 보기를 전환할 수 있습니다.
    * **App** > **General** 페이지가 재설계되었습니다.

### October 1, 2018

#### Web Modeler Improvements

이제 모든 유형의 앱에 대해 Web Modeler를 활성화할 수 있습니다. 이 설정은 앱의 **Settings** > **General** 페이지에서 할 수 있습니다. 라이선스가 있는 앱의 경우, [배포](/deployment/) 환경도 선택해야 합니다.

#### Fixes

* 회사 **Buzz** 페이지의 **Show activity for** 필터 버튼이 한동안 작동하지 않아 아무 것도 표시되지 않던 문제를 수정했습니다. 이제 다시 정상적으로 작동합니다.

## September 2018

### September 10, 2018

#### Improvements

* API를 통해 생성된 애플리케이션이 Web Modeler에 적합한 템플릿을 기반으로 한 경우, Web Modeler가 자동으로 활성화됩니다.

#### Fixes

* 가입 시 이메일 도메인에 대한 불필요하게 엄격한 제약을 완화했습니다. 이제 단일 문자 서브도메인이 포함된 이메일 도메인으로 가입할 수 있습니다. (Tickets 68210, 68386)

## June 2018

### June 26, 2018

#### Improvement

* 새로운 Mendix 헤더를 적용했습니다.

## May 2018

### May 23, 2018

#### Improvements

* Company Admin이 활성 사용자, 활성 사용자의 앱 권한, 앱 등 세 가지 보고서를 Excel로 내보낼 수 있습니다. 이를 통해 사용자와 권한을 대규모로 관리할 수 있습니다.

#### Fixes

* **Story Details** 페이지의 **Revisions** 탭에 앱 아바타 대신 커미터의 아바타가 표시되도록 수정했습니다.

### May 8, 2018

#### Improvements

* **Stories** 페이지에서 라벨에 색상을 지정할 수 있습니다: Mendix Blue, Firetruck Red, Goldfish Orange, Tulip Green.
* **Story Details** 페이지에 스토리와 관련된 리비전을 표시하는 새 탭이 추가되었습니다.

#### Fixes

* **Feedback Details** 페이지에서 **Move to app** 드롭다운 메뉴가 다시 표시됩니다.
* `&`와 같은 특수 문자가 **Buzz** 알림 이메일 제목에 올바르게 표시됩니다.
* Buzz 알림 이메일의 녹색 행동 유도 버튼이 이제 Windows용 Outlook에서도 작동합니다. (Ticket 63452)
* Buzz 스레드에 활동이 많을 경우, 각 알림 이메일에 올바른 스레드 기록이 표시되며, 이전처럼 모든 이메일에 동일한 댓글이 포함되지 않습니다.
* 두 개의 문서 링크를 수정했습니다.

## April 2018

### April 9, 2018

#### Fixes

* 문자열 데이터 유형의 애플리케이션 상수에 빈 값을 할당할 수 있도록 수정했습니다.
* 브랜치 조회 중 표시되는 로딩 팝업 창 텍스트를 수정했습니다.
* 일부 사용자가 애플리케이션의 실행 중인 요청 목록을 볼 수 없던 버그를 수정했습니다.
* 사용자가 프로젝트를 비활성화할 수 없던 버그를 수정했습니다.

## March 2018

### March 16, 2018

#### Improvements

* 브라우저 제목을 "Mendix App Platform"에서 **Mendix Platform**으로 변경하여 메시지 및 문서와 일관성을 유지하도록 했습니다.
* 하이브리드 모바일 개선 사항: 이제 아이콘 및 스플래시 스크린 생성, 사용자 정의 로더 및 오류 이미지 추가, 사용자 정의 HTML 및 CSS 추가가 가능합니다. 또한 간단한 색상 조정을 위한 새로운 테마 섹션이 추가되었습니다.

#### Fixes

* 모니터링 액세스가 없는 사용자 그룹의 **Security** 메뉴에서 **Deploy** 및 **Operate** 딥 링크를 사용할 수 없던 문제를 수정했습니다.

## February 2018

### February 15, 2018

#### Improvements

* **Buzz** 게시물에 대한 답장 시 수신되는 알림 이메일에 아름다운 새로운 디자인을 적용했습니다.

#### Fixes

* **Daily Digest** 이메일이 발송되지 않던 문제를 해결했습니다.

## January 2018

### January 25, 2018

#### Improvement

* 이제 애플리케이션의 Technical Contact를 직접 변경할 수 있습니다.
