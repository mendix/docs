## 소개

활성화되면 머리글이 모든 페이지 상단에 삽입됩니다. 머리글에 다른 위젯을 배치할 수 있습니다.

{{% alert color="info" %}}

{{< figure src="/attachments/refguide9/modeling/resources/document-templates/header-document-template/918236.png" class="no-border" >}}

머리글입니다.

{{% /alert %}}

Document Template 자체의 속성에서 머리글을 활성화하는 방법에 대한 자세한 내용은 *Document Template*의 [외관 속성](/refguide9/document-template/#appearance-properties) 섹션을 참조하십시오.

페이지 번호 삽입에 대한 자세한 내용은 [Static Label](/refguide9/static-label-document-template/)을 참조하십시오.

## 외관

### 상단 여백

페이지 상단과 머리글 사이의 간격(인치)입니다.
