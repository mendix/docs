## 소개

Studio Pro 상단 바에는 다음과 같은 메뉴가 포함되어 있습니다:

{{< figure src="/attachments/refguide8/modeling/menus/menu-bar.png" alt="Menu-bar" class="no-border" >}}

* [File](#file) – 문서와 프로젝트를 관리할 수 있습니다
* [Edit](#edit) – Studio Pro 내에서 검색 또는 복사와 같은 편집 기능을 수행할 수 있습니다
* [View](#view) – Studio Pro와 Studio Pro 내의 도킹 가능한 창 표시 방법을 선택할 수 있습니다
* [Project](#project) – 프로젝트 전체 설정을 포함합니다
* [Run](#run) – 앱 배포 및 모니터링을 위한 작업을 포함합니다
* [Version Control](#version-control) – 버전 관리 설정을 포함합니다
* [Language](#language) – 언어 및 번역 설정을 포함합니다
* [Help](#help) – 문서를 조회하거나 [Mendix Community](https://community.mendix.com/p/questions)를 열거나 로그 파일 디렉터리를 열거나 Studio Pro의 현재 정보를 확인할 수 있습니다

## File 메뉴 {#file}

**File** 메뉴를 통해 문서와 프로젝트를 관리할 수 있습니다. **File** 메뉴에 대한 자세한 내용은 [File Menu](/refguide8/file-menu/)를 참조하십시오.

## Edit 메뉴 {#edit}

**Edit** 메뉴를 통해 잘라내기/복사/붙여넣기 등의 편집 기능을 수행할 수 있습니다. 이 메뉴를 통해 [환경설정](/refguide8/preferences-dialog/)을 지정할 수도 있습니다. **Edit** 메뉴에 대한 자세한 내용은 [Edit Menu](/refguide8/edit-menu/)를 참조하십시오.

## View 메뉴 {#view}

**View** 메뉴를 통해 도킹 가능한 창을 보거나, 전체 화면 모드를 활성화하거나, 프로젝트 레이아웃을 초기화할 수 있습니다. **View** 메뉴와 해당 항목에 대한 자세한 내용은 [View Menu](/refguide8/view-menu/)를 참조하십시오.

## Project 메뉴 {#project}

**Project** 메뉴에서는 프로젝트 및 배포와 관련된 설정을 보거나 조작할 수 있습니다. **Project** 메뉴에 대한 자세한 내용은 [Project Menu](/refguide8/project-menu/)를 참조하십시오.

## Run 메뉴 {#run}

**Run** 메뉴에는 **Run**, **Run Locally**, **Debugger** 등 앱 배포 및 모니터링을 위한 작업이 포함되어 있습니다. **Run** 메뉴에 대한 자세한 내용은 [Run Menu](/refguide8/run-menu/)를 참조하십시오.

## Version Control 메뉴 {#version-control}

**Version Control** 메뉴에서는 버전 관리 설정을 보거나 조작할 수 있습니다. **Version Control** 메뉴에 대한 자세한 내용은 [Version Control Menu](/refguide8/version-control-menu/)를 참조하십시오.

## Language 메뉴 {#language}

**Language** 메뉴에서는 최종 사용자가 선호하는 언어로 앱을 볼 수 있도록 대체 언어를 추가할 수 있습니다. 하나의 언어만 사용하는 경우에도 동일한 텍스트를 일괄 변경할 수 있습니다. **Language** 메뉴에 대한 자세한 내용은 [Language Menu](/refguide8/translatable-texts/)를 참조하십시오.

## Help 메뉴 {#help}

| 메뉴 항목 | 설명 | 단축키 |
| --- | --- | --- |
| **Help** | 현재 선택된 요소에 대한 문서 페이지를 엽니다. 예를 들어, Entity를 선택한 경우 Entity에 대한 문서가 표시됩니다. | <kbd>F1</kbd> |
| **Help Contents** | 기본 웹 브라우저에서 문서 홈 페이지를 엽니다. |   |
| **Ask a Question** | 기본 웹 브라우저에서 [Mendix Community](https://community.mendix.com/p/questions)를 엽니다. |   |
| **Open Log File Directory** | 앱의 로컬 로그 파일을 엽니다. |   |
| **About Mendix Studio Pro** | 현재 Mendix Studio Pro 버전에 대한 정보를 표시합니다. |   |
