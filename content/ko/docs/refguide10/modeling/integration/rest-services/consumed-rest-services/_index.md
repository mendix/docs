## Consumed REST Services

Mendix는 모든 REST API와 상호 작용할 수 있는 다양한 기능을 제공합니다. 이러한 기능을 사용하여 REST 요청을 작성 및 테스트하거나 프로젝트에 데이터 구조를 생성할 수 있습니다.
