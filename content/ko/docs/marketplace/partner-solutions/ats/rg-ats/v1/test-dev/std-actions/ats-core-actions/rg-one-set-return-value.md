## 설명

지정된 값을 해당 Action이 사용되는 곳의 반환 값으로 설정합니다.

## 사용법

이 Action을 사용하여 사용자 정의 Action의 반환 값을 설정하세요.
반환 값으로 설정하려는 값을 파라미터로 전달하세요.

## 입력 파라미터

Name | Datatype | Required | Description
---- | -------- | ------- |---------------
Value | any | yes | 반환 값으로 설정하려는 값입니다.
