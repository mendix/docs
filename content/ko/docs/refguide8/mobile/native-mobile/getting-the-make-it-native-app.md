## 소개

Make It Native 앱을 사용하면 개발자가 Mendix Studio Pro와 연동하여 네이티브 모바일 앱을 미리보기, 테스트 및 디버그할 수 있습니다. Android 및 iOS 디바이스 모두에서 사용할 수 있습니다.

Make It Native 앱을 사용하여 앱을 테스트하는 방법에 대한 자세한 내용은 [네이티브 모바일 시작하기](/howto8/mobile/getting-started-with-native-mobile/)를 참조하십시오. Make It Native 앱을 사용한 고급 디버깅 정보는 [네이티브 모바일 앱 디버그(고급)](/howto8/mobile/native-debug/)를 참조하십시오. 앱에 커스텀 종속성(예: 커스텀 위젯 또는 폰트)이 필요한 경우 [커스텀 개발자 앱 생성 방법](/howto8/mobile/how-to-devapps/)을 참조하십시오.

Make It Native 앱이 지원하는 모바일 운영 체제에 대한 정보는 *시스템 요구 사항*의 [모바일 운영 체제](/refguide8/system-requirements/#mobileos) 섹션을 참조하십시오.

Make It Native 앱을 다운로드하려면 디바이스의 앱 스토어에서 *Make It Native 8*을 검색하거나 아래 다운로드 링크 중 하나를 선택하십시오:

* [Android용 다운로드](https://play.google.com/store/apps/details?id=com.mendix.developerapp)
* [iOS용 다운로드](https://apps.apple.com/app/make-it-native/id1334081181)
