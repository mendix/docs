이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.14에 적용된 변경 사항을 다루고 있습니다.

## 1.14.0

### 릴리스 날짜: 2024년 9월 30일

Private Mendix Platform 버전 1.14.0에서는 다수의 버그 수정 및 개선 사항이 도입되었습니다.

#### 새로운 기능

##### 내장 Pipeline을 위한 자동 SBOM 생성

플랫폼에서 제공하는 내장 Kubernetes 기반 빌드 Pipeline을 사용하는 고객의 경우, 앱 배포 아티팩트를 빌드할 때 메타데이터가 포함된 SBOM이 자동으로 생성됩니다. 거버넌스 목적으로 SBOM을 다운로드할 수 있습니다.

#### 개선 사항

##### 인증된 배포 아티팩트 다운로드

애플리케이션이 MDA(배포 패키지)로 빌드된 후, 이제 인증을 통해 배포 목적의 MDA 패키지 다운로드를 보안 처리할 수 있습니다. 이를 통해 배포 패키지의 스토리지 버킷에 대한 익명 접근을 방지하여 보다 안전한 프로세스를 제공합니다.

##### Webhook 개선

###### 설치 프로그램에서 Webhook을 위한 Redis 불필요

Private Mendix Platform에는 내장된 Webhook 기능이 있습니다. 이전 릴리스에서는 이 기능을 위해 Webhook 서버 구성 요소인 Svix를 설치하려면 Redis 데이터베이스를 프로비저닝해야 했습니다. 이번 변경으로 Redis는 더 이상 필수 요구 사항이 아니며, 설치 프로그램은 이를 선택적 구성으로 처리합니다.

즉, 새로운 플랫폼 배포에서는 Webhook을 위해 Redis를 사용하지 않아도 되지만, 대량의 Webhook 호출이 구성된 고트래픽 플랫폼에서 Webhook 서버(Svix)를 사용할 때는 여전히 권장됩니다. 자세한 내용은 [Private Mendix Platform 빠른 시작 가이드: 사전 요구 사항](/private-mendix-platform/quickstart/#prerequisites)을 참조하십시오.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.27](/releasenotes/studio-pro/9.24/#92427)로 업데이트되었습니다 (프로덕션 지원)
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.14](/releasenotes/studio-pro/10.6/#10614)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전이 [2.19.0](/releasenotes/developer-portal/mendix-for-private-cloud/#september-13th-2024)으로 업데이트되었습니다
* Private Cloud License Manager (PCLM) 버전이 [0.9.0](/releasenotes/developer-portal/mendix-for-private-cloud/#september-13th-2024)으로 업데이트되었습니다
* SVIX webhooks 서비스 버전이 1.25.0으로 업데이트되었습니다
* Prometheus 호환성이 2.34.0으로 업데이트되었습니다
* Grafana 호환성이 10.3.3으로 업데이트되었습니다

#### 수정 사항

다음 수정 사항을 제공합니다:

* (플랫폼) Mendix Studio Pro 버전 10.6.1에서 배포 패키지를 생성할 때 빌드가 실패하던 문제를 수정하였습니다.
* (플랫폼) Webhook 단계가 있는 Deploy Pipeline에서 여러 이벤트를 전송할 때 발생하던 문제를 해결하였습니다.
* (플랫폼) Pipeline 템플릿에서 Webhook을 제거한 후에도 Svix 서버에서 Webhook 구성이 삭제되지 않던 문제를 수정하였습니다.
* (UI) 일부 UI 관련 문제를 수정하였습니다.
