APM Tool(버전 1.6.0 이상)은 Mendix 6.2 이상 및 Java 8에서 사용할 수 있습니다.

APM Tool은 앱 내에 모듈로 추가됩니다.

설치 후 Java 권한 문제가 발생하면 필요한 권한에 대해 [Java 보안 설정](/appstore/partner-solutions/apd/ig-one-java-security-settings/)을 참조하십시오.

크기 영향에 대해서는 [크기 영향](/appstore/partner-solutions/apd/ig-one-sizing-impact/)을 참조하십시오.
