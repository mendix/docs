Application Performance Monitor(APM) 대시보드는 APM의 홈 화면입니다:

{{< figure src="/attachments/appstore/partner-solutions/apd/rg-apd/rg-one-apm/rg-one-dashboard/Dashboard.png" class="no-border" >}}

대시보드는 Statistics Tool, Measurements Tool, Trap Tool 및 Log Tool의 최신 정보를 표시합니다.

페이지 왼쪽의 메뉴에서 개별 도구를 선택할 수 있습니다.

이러한 도구는 별도의 장에서 설명합니다.
