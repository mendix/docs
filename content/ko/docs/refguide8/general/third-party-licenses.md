## 소개

Mendix는 자체 라이선스가 있는 다양한 서드파티 라이브러리를 사용합니다. 사용 가능한 [Mendix Studio Pro](https://marketplace.mendix.com/link/studiopro/)를 다운로드하면 모든 라이선스를 확인할 수 있습니다. 아래에 설명된 **Mendix** 설치 폴더의 다양한 하위 폴더에서 찾을 수 있습니다:

| 라이브러리 및 라이선스 | 위치 |
| ------------------------ | ------------------------------------------------------------ |
| Runtime Server 라이브러리 | **runtime\bundles** |
| Studio Pro 라이브러리 | **modeler\Licenses** |
| Client 라이선스 | Client 라이선스는 다음 위치에서 찾을 수 있습니다: <ul><li>**modeler\deployment.mxz** – 이것은 ZIP 파일로 **web\lib\bootstrap\css\bootstrap.css** 및 **web\lib\rbootstrap\css\rbootstrap.css**로 이동하여 Bootstrap 라이선스를 확인할 수 있습니다(앱을 배포하면 배포 폴더에서도 이 모든 파일을 찾을 수 있습니다)</li><li>**runtime\mxclientsystem\mxui.mxui.js** – Dojo 라이선스</li></ul> |
