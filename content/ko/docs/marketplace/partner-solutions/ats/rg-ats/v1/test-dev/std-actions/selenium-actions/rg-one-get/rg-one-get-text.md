## 설명

WebElement 내부의 텍스트 값을 반환합니다.

## 사용법

텍스트 값을 가져오려는 WebElement를 전달하세요.

## 입력 파라미터

Name | Datatype | Required | Description
---- | -------- | ------- |---------------
Web Element | WebElement | yes | 텍스트 값을 가져오려는 WebElement입니다.

## 반환 값

Name | Datatype | Description
---- | --------- | ---------------
Value | String | WebElement의 현재 값입니다.
