## 소개

If Expression은 Expression에서 조건부 동작을 정의하는 데 사용할 수 있습니다. 올바른 구문은 다음과 같습니다:

if `<condition>` then `<a value>` else `<other value>`

## 예제

문자열 값에 대한 변수 변경 Activity의 Expression으로 다음 문을 사용하는 경우:

```java
if 7 > 6 then 'correct' else 'incorrect'
```

변수의 값이 `correct`로 설정됩니다.
