## 설명

제공된 WebElement에 텍스트 입력을 시뮬레이션합니다.

## 사용법

텍스트와 텍스트를 삽입하려는 WebElement를 이 Action의 파라미터로 전달하세요. WebElement를 가져오려면 WebElement를 반환하는 Find/Assert Widget과 같은 Action을 사용하세요.

## 입력 파라미터

Name | Datatype | Required | Description
---- | -------- | ------- |---------------
Element | WebElement | yes | 실행하려는 JavaScript 소스 코드입니다.
Text | String | yes | 스크립트 완료까지의 시간(밀리초)입니다.
