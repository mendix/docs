## Mobile Development Libraries Compatibility Guide

This page outlines the compatibility between Mendix mobile development libraries and Mendix Studio Pro versions.

### Native Mobile Resources

[GitHub Repository](https://github.com/mendix/native-widgets)

| Module Version  | Compatible Studio Pro Versions |
| --------------- | ------------------------------ |
| 9.*             | 10.17 and above                |
| 8.*             | 10.13 - 10.16                  |
| 7.*             | 10.12                          |
| 6.*             | 10.6 - 10.11                   |
| 5.*             | 10 - 10.5                      |
| 4.0.4 - 4.99.99 | 9.24.1 - 9.24.99               |
| 4.0.0 - 4.0.3   | 9.24                           |
