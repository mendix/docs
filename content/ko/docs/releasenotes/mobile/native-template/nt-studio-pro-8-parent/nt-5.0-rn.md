{{% alert color="warning" %}}
Native Template [5.0](/releasenotes/mobile/nt-5.0-rn/) 및 [5.1](/releasenotes/mobile/nt-5.1-rn/) 버전은 더 이상 업데이트를 받지 않습니다. 또한, Native Template은 8.18.9 미만 버전에서는 작동하지 않습니다. 

최신 Studio Pro [8.18.x](/releasenotes/studio-pro/8.18/) 패치 릴리스와 [호환되는](/releasenotes/mobile/nt-studio-pro-8-parent/) Native Template 버전을 사용하세요.
{{% /alert %}}

## 5.0.14

**릴리스 날짜: 2022년 5월 17일**

### 수정 사항

* 빌드 실패를 일으키는 Android의 JCenter 문제를 수정했습니다. JCenter가 불안정해지고 더 이상 지원되지 않으므로, 이제 Android 종속성을 자체 호스팅합니다. (티켓 148798, 148819, 148830, 148840)

## 5.0.12

**릴리스 날짜: 2021년 3월 31일**

### 수정 사항

* 디버그 모드를 활성화할 때 Firebase가 커스텀 개발자 앱을 충돌시킬 수 있는 또 다른 경우를 수정했습니다.

## 5.0.12 {#5012}

**릴리스 날짜: 2021년 3월 17일**

* JavaScript 디버깅이 활성화된 경우 커스텀 개발자 앱이 충돌할 수 있는 문제를 수정했습니다.

## 5.0.11

**릴리스 날짜: 2021년 3월 12일**

### 수정 사항

* JavaScript 디버깅이 활성화된 경우 커스텀 개발자 앱이 충돌할 수 있는 문제를 수정했습니다.

## 5.0.10

**릴리스 날짜: 2021년 2월 15일**

### 수정 사항

* **react-native-image-picker** 종속성을 업데이트했습니다.
* **react-native-image-picker** 패치가 이제 Windows에서 올바르게 적용됩니다.
* iOS에서 **PRODUCT_NAME** 변수를 각 타겟의 XCConfig 파일을 통해 설정할 수 있습니다.

## 5.0.9

**릴리스 날짜: 2021년 2월 4일**

### 수정 사항

* 스크롤 가능한 뷰의 입력에 대한 Android 키보드 동작을 수정했습니다.
* 보안 문제를 해결하기 위해 React Native Device Info 라이브러리를 업데이트했습니다.

## 5.0.8

**릴리스 날짜: 2020년 12월 22일**

### 수정 사항

* 푸시 알림을 열 때 iOS 앱이 충돌할 수 있는 문제를 수정했습니다.

## 5.0.7

**릴리스 날짜: 2020년 11월 27일**

### 개선 사항

* iOS 피어 종속성을 업데이트했습니다.

### 수정 사항

* iOS 14의 버그를 수정하기 위해 기본 DatePicker 라이브러리를 업데이트했습니다.

## 5.0.6

**릴리스 날짜: 2020년 11월 2일**

### 고지 사항

* Native Template v5.0.5는 Studio Pro 8.12.1 - 8.14.x로 빌드된 앱에 적용됩니다.

### 개선 사항

* 이 릴리스는 Mendix 네이티브 모바일 앱을 Xcode 12의 빌드 시스템과 완전히 호환되도록 합니다.

### 수정 사항

* Xcode 12를 사용하여 완료된 빌드에서 Base64 인코딩 이미지가 이제 완전히 지원됩니다.

## 5.0.5

**릴리스 날짜: 2020년 10월 19일**

### 개선 사항

* Android v10 이상에 추가된 새로운 파일 시스템 보안 규칙에 대한 지원을 추가했습니다. 

### 수정 사항

* Android v10 이하를 지원하기 위해 레거시 외부 저장소 플래그를 설정했습니다.
* 누락된 iPad 아이콘에 대한 지원을 추가했습니다.

## 5.0.4 및 5.0.3 

**릴리스 날짜: 2020년 10월 9일**

### 개선 사항 

* Xcode 12 지원을 보장하기 위해 여러 종속성을 업데이트했습니다. App Center 구성도 Xcode 12 및 Node LTS를 사용하도록 업데이트했습니다.

## 5.0.2

**릴리스 날짜: 2020년 9월 2일**

### 수정 사항

* iOS에서 충돌을 유발할 수 있는 스레딩 관련 예외를 수정했습니다.

## 5.0.1

**릴리스 날짜: 2020년 8월 26일**

2020년 8월부터 Google Play는 SDK 29를 대상으로 빌드된 앱을 요구합니다. 이 버전의 Native Template은 이러한 요구 사항을 준수합니다. 자세한 내용은 [Play Console의 Target API 레벨 요구 사항](https://support.google.com/googleplay/android-developer/answer/113469#targetsdk)을 참조하세요.

## 5.0.0

**릴리스 날짜: 2020년 8월 7일**

Mendix Studio Pro [8.12.1](/releasenotes/studio-pro/8.12/#8121)은 네이티브 모바일 앱에 대한 더 나은 스플래시 화면 지원을 도입합니다. 새로운 기능에는 새로운 네이티브 종속성이 필요하므로, 이전 Mendix Studio 버전과는 호환되지 않습니다. 

첫 번째 구현에서 스플래시 화면은 앱의 네이티브 쪽에서 제어하는 정적 리소스였습니다. 간단한 경우에는 충분했지만, 스플래시 화면이 너무 빨리 꺼질 수 있는 긴 동기화 세션에는 부적합했습니다.

새로운 구현에서 스플래시 화면은 클라이언트를 통해 완전히 토글 가능합니다. 이는 클라이언트가 스플래시 화면을 완전히 제어할 수 있음을 의미합니다. 이로 인해 더 나은 켜기/끄기 타이밍과 긴 동기화 세션에서의 프레임 누락 감소로 이어집니다.
