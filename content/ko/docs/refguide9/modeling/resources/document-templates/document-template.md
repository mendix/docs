## 소개

이 문서에서는 Document Template의 속성을 설명합니다. Document Template의 용도와 배치할 수 있는 위젯의 종류를 확인하려면 [Document Template](/refguide9/document-templates/) 개요 문서를 참조하십시오.

## 외관 속성 {#appearance-properties}

### 페이지 형식

페이지 형식은 Document Template으로 대상으로 하는 페이지의 크기를 결정합니다. 예를 들어 A4(세로) 및 A5(가로)가 있습니다. 사용자 정의 페이지 형식을 선택하고 아래의 [페이지 너비](#width) 및 [페이지 높이](#height) 속성을 사용할 수도 있습니다.

### 페이지 너비 (인치) {#width}

Document Template으로 대상으로 하는 페이지의 너비입니다. 페이지 형식을 선택하면 자동으로 설정됩니다. 변경하면 페이지 형식이 'Custom'으로 설정됩니다.

### 페이지 높이 (인치) {#height}

Document Template으로 대상으로 하는 페이지의 높이입니다. 페이지 형식을 선택하면 자동으로 설정됩니다. 변경하면 페이지 형식이 'Custom'으로 설정됩니다.

### PPI (Pixels per Inch)

픽셀 밀도는 픽셀 값을 기반으로 이미지 크기를 계산하는 데 사용됩니다.

### 왼쪽/오른쪽/위/아래 여백 (인치)

여백은 용지 테두리와 모든 면의 내용 사이의 거리를 지정합니다.

### 첫 페이지에 머리글/바닥글 표시

첫 페이지에도 머리글 및/또는 바닥글이 표시되는지 여부를 나타냅니다.

{{% alert color="warning" %}}
더 이상 첫 페이지가 아님을 나타내려면 페이지 나누기 위젯을 사용해야 합니다. 이는 콘텐츠를 생성하는 동안 계산할 수 없습니다.
{{% /alert %}}

기본값: *True.*

### 머리글 활성화

페이지에 각 페이지(선택적으로 첫 번째 페이지 제외)에 표시되는 머리글이 있는지 여부를 나타냅니다.

### 바닥글 활성화

페이지에 각 페이지(선택적으로 첫 번째 페이지 제외)에 표시되는 바닥글이 있는지 여부를 나타냅니다.

## 디자인 속성

### 캔버스 너비

캔버스 너비는 Studio Pro에서 Document Template을 구축하는 캔버스의 너비를 결정합니다. 이 속성은 애플리케이션에 어떠한 영향도 미치지 않습니다.
