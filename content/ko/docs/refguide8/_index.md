{{% alert color="warning" %}}
2025년 6월 Mendix 11.0.0 릴리스와 함께 Mendix 8은 지원이 종료되었습니다. 이는 Mendix 8이 더 이상 지원, 유지보수 또는 업데이트를 받지 않음을 의미합니다. 최신 기능과 보안 향상에 지속적으로 접근하려면 플랫폼의 최신 버전으로 업그레이드를 계획하시기 바랍니다.
{{% /alert %}}

## 소개

*Mendix Studio Pro 8 가이드*는 [Studio Pro](/refguide8/modeling/), [Mendix Runtime](/refguide8/runtime/) 및 Mendix 플랫폼의 기타 구성 요소에 관한 중요한 주제를 다룹니다.

Studio Pro 8을 설치하기 전에 [시스템 요구 사항](/refguide8/system-requirements/)을 읽어 주십시오. Studio Pro 설치 방법에 대한 정보는 [Mendix Studio Pro 설치 방법](/howto8/general/install/)을 참조하십시오.

Desktop Modeler 버전 7을 사용해 오셨다면 [Desktop Modeler 7에서 Studio Pro 8로 이전](/refguide8/moving-from-7-to-8/)을 읽어 보시기 바랍니다.

다양한 Mendix 작업에 대한 단계별 가이드를 찾고 계시다면 [Studio Pro 8 How-to](/howto8/)를 참조하십시오.

## Studio Pro 기능

Studio Pro를 사용하여 앱을 생성, 테스트 및 실행할 수 있습니다.

### 모델링

앱을 모델링하는 것은 앱을 생성하는 과정으로, 페이지 생성, 로직 추가, 보안 구성 등을 포함합니다. 앱을 모델링하는 데 사용할 수 있는 기능에 대한 자세한 내용은 [앱 모델링](/refguide8/modeling/)을 참조하십시오.

### 테스트

애플리케이션 테스트 시 먼저 무엇을 테스트할지 결정해야 합니다: 외부 서비스와의 통합, 앱 로직(Microflow) 등. 애플리케이션 테스트 방법에 대한 자세한 내용은 [테스트](/howto8/testing/)를 참조하십시오.

### 배포

Studio Pro를 사용하면 앱을 로컬 또는 기본 환경에서 실행하고 확인할 수 있습니다.

앱 배포 옵션에 대한 자세한 내용은 [앱 배포](/deployment/)를 참조하십시오.

## 버전 관리

[버전 관리](/refguide8/version-control/)를 통해 앱 개발을 관리하고 여러 개발 라인에서 작업할 수 있습니다. Studio Pro가 앱의 버전 관리를 처리하는 방법에 대한 정보는 *Studio Pro에서 버전 관리 사용*의 [클라우드에 배포된 프로젝트의 버전 관리](/refguide8/using-version-control-in-studio-pro/#versioning-project) 섹션을 참조하십시오.

## Mendix Runtime

[Mendix Runtime](/refguide8/runtime/)은 Studio Pro에서 생성된 애플리케이션 모델을 실행합니다. 동일한 버전 번호 체계를 사용하므로 Studio Pro 8 가이드에 포함되어 있습니다.

## 모바일

모바일 앱 개발을 통해 네이티브 모바일 및 하이브리드 앱을 생성할 수 있으며, 이는 Studio Pro의 중요한 부분입니다. 자세한 내용은 [모바일](/refguide8/mobile/)을 참조하십시오.
