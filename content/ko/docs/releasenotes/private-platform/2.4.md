이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 2.4에 적용된 변경 사항을 다루고 있습니다.

## 2.4

### 릴리스 날짜: 2025년 1월 28일

Private Mendix Platform 버전 2.4에서는 다수의 새로운 기능, 업데이트 및 수정 사항이 도입되었습니다.

#### 새로운 기능

##### Maia 통합

Private Mendix Platform은 이제 [Maia 지원 앱 생성](/refguide/start-with-maia/)을 지원합니다. Maia Chat 등 기타 Maia 기능은 이번 릴리스에 포함되어 있지 않습니다.

{{% alert color="info" %}}
이 기능은 베타 릴리스로 제공되며, 선별된 고객에게만 제공됩니다. 베타 릴리스에 대한 자세한 내용은 [릴리스 상태](/releasenotes/release-status/)를 참조하십시오.
{{% /alert %}}

##### Environment Overview

**Environment Overview** 페이지는 배포된 모든 환경의 개요를 표시하여 손쉽게 모니터링하고 관리할 수 있도록 도와줍니다. 환경의 상태, 용도, 실행 중인 레플리카 수 등의 정보를 확인할 수 있습니다. 또한 개별적으로 또는 일괄적으로 환경을 중지하거나 확장할 수 있습니다.

#### 개선 사항

##### Pipeline 개선

Deploy Pipeline에서 Manual Approve 단계의 승인자로 그룹을 선택할 수 있게 되었습니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.40](/releasenotes/studio-pro/9.24/#92440)으로 업데이트되었습니다
* Studio Pro 10.24 LTS 최신 패치 버전이 [10.24.13](/releasenotes/studio-pro/10.24/#102413)으로 업데이트되었습니다
* Studio Pro 11.6 MTS 최신 패치 버전이 [11.6.2](/releasenotes/studio-pro/11.6/#1162)로 업데이트되었습니다

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전 [2.25.1](/releasenotes/developer-portal/mendix-for-private-cloud/#2.25.1)
* Private Cloud License Manager (PCLM) 버전 [0.10.5](/releasenotes/developer-portal/mendix-for-private-cloud/#license-manage-cli-v0105)

#### 수정 사항

* (일반) IRSA 없이 S3가 구성된 경우 발생하던 S3 스토리지 문제를 수정하였습니다.
* (일반) 필요한 권한이 없는 사용자가 **Environment Details** 페이지에 접근할 수 있던 문제를 해결하였습니다.
* (일반) 필요한 권한이 없는 사용자가 **Metrics and Logs** 페이지에 접근할 수 있던 문제를 해결하였습니다.
* (일반) Azure 외부 시크릿 저장소의 구성이 올바르게 검색되지 않던 문제를 수정하였습니다.
* (UI) 일부 UI 관련 문제를 수정하였습니다.
