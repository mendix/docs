## Android 4.7.1 / iOS 4.7.1

**릴리스 날짜: 2018년 3월 26일**

### 수정 사항

* 하이브리드 앱이 오프라인 또는 온라인 모드에 고정되는 문제를 수정했습니다.

### 제한 사항

* Mendix 피드백 위젯이 iOS에서 항상 올바르게 로드되지 않습니다.
* Mendix 하이브리드 앱(예: QR 스캐너 또는 수동 앱 로딩 화면을 사용하여 로드된 앱)은 바코드 스캐닝 위젯을 사용할 수 없습니다. 앱별 하이브리드 앱(Mendix Developer Portal의 모바일 앱 플로우를 사용하여 빌드된 앱)에서 바코드 스캐닝 기능을 사용하는 것은 문제가 없습니다.

## Android 4.7.0 / iOS 4.7.0

**릴리스 날짜: 2018년 3월 23일**

### 새로운 기능

* 오프라인 지원 하이브리드 앱 열기 지원을 추가했습니다. QR 스캐너를 통해 오프라인 지원 앱을 열려면 Modeler의 `View App` 대화 상자에서 `offline` 토글을 활성화하세요. URL을 수동으로 입력하여 오프라인 지원 앱을 열려면 앱 내에서 `offline` 토글을 활성화하세요.

### 개선 사항

* 하이브리드 앱이 이제 새롭게 스타일링된 로딩 화면, 로그인 화면 및 오류 화면을 사용합니다.

### 수정 사항

* Mendix Mobile 앱을 사용하여 열린 딥 링크(예: Mendix 앱으로의 링크)가 이제 올바르게 정제됩니다.

### 제한 사항

* Mendix 피드백 위젯이 iOS에서 항상 올바르게 로드되지 않습니다.
* Mendix 하이브리드 앱(예: QR 스캐너 또는 수동 앱 로딩 화면을 사용하여 로드된 앱)은 바코드 스캐닝 위젯을 사용할 수 없습니다. 앱별 하이브리드 앱(Mendix Developer Portal의 모바일 앱 플로우를 사용하여 빌드된 앱)에서 바코드 스캐닝 기능을 사용하는 것은 문제가 없습니다.

## Android 4.5.0 / iOS 4.5.0

**릴리스 날짜: 2017년 10월 24일**

### 새로운 기능

* 이제 앱에서 `mxapps.io` 및 `mendixcloud.com` URL을 자동으로 열 수 있습니다
* 이메일, WhatsApp 등을 통해 Mendix 앱을 공유할 수 있습니다
* 앱의 Buzz에 직접 새 메시지를 게시할 수 있습니다
* 앱에서 Mendix 계정 생성을 시작할 수 있습니다

### 지원 중단 및 제거

* Mendix 7.4에서 더 이상 사용되지 않는 커스텀 프로필에 대한 지원을 제거했습니다.

### 제한 사항

* Mendix 하이브리드 앱(예: QR 스캐너 또는 수동 앱 로딩 화면을 사용하여 로드된 앱)은 바코드 스캐닝 위젯을 사용할 수 없습니다. 앱별 하이브리드 앱(Mendix Developer Portal의 모바일 앱 플로우를 사용하여 빌드된 앱)에서 바코드 스캐닝 기능을 사용하는 것은 문제가 없습니다.

## iOS 4.4.1 {#RN441}

**릴리스 날짜: 2017년 10월 2일**

### 버그 수정

* iOS 11 지원을 수정했습니다: Mendix 하이브리드 앱을 로드할 때(예: QR 스캐너를 사용하거나 **Apps** 페이지에서) Mendix Mobile 앱이 충돌하는 문제가 해결되었습니다.

### 제한 사항

* Mendix 하이브리드 앱(예: QR 스캐너 또는 수동 앱 로딩 화면을 사용하여 로드된 앱)은 바코드 스캐닝 위젯을 사용할 수 없습니다. 앱별 하이브리드 앱(Mendix Developer Portal의 모바일 앱 플로우를 사용하여 빌드된 앱)에서 바코드 스캐닝 기능을 사용하는 것은 문제가 없습니다.

## Android 4.4.0 / iOS 4.4.0

**릴리스 날짜: 2017년 7월 21일**

### 새로운 기능

* 앱을 처음 사용할 때 몇 가지 소개 슬라이드가 표시됩니다.
* **Apps** 페이지에 이제 최근 열었던 하이브리드 앱의 개요가 포함됩니다.

### 개선 사항

* 메뉴 항목 중 하나를 누르면 사이드바가 자동으로 닫힙니다.
* 더 쉽게 누를 수 있도록 뒤로 버튼의 터치 영역을 늘렸습니다.

### 버그 수정

* 하이브리드 앱의 웹 URL이 이제 예상대로 작동합니다.

### 알려진 문제

* iOS 11에서 샘플 앱 중 하나를 로드하거나 QR 스캐너를 사용하여 앱을 로드하면 애플리케이션이 충돌합니다. 
    * [4.4.1](#RN441)에서 수정되었습니다.

## Android 4.3.0

**릴리스 날짜: 2017년 7월 10일**

### 새로운 기능

앱 전달 프로젝트를 가속화하기 위해 두 가지 새로운 기능을 추가했습니다:

* Mendix Mobile 앱의 편의성으로 Mendix Modeler에 표시된 QR 코드를 스캔하여 하이브리드 모바일 Mendix 앱을 휴대폰에서 쉽게 테스트하세요.
* Mendix Mobile 앱을 통해 접근 가능한 쇼케이스를 통해 Atlas UI 및 Mendix Platform의 역량을 확인하세요. 위 기능은 로그인 없이 사용할 수 있습니다. 하지만 **Buzz**를 사용하려면 로그인해야 합니다.

## Android 4.1.0 / iOS 4.3.0

**릴리스 날짜: 2017년 4월 7일**

이 릴리스에서는 Mendix Mobile 앱의 사용자 경험을 크게 개선했습니다.

### 새로운 기능

* 인터넷 연결 없이 **Buzz**를 읽을 수 있습니다.
* 앱의 전체 성능과 앱 시작 시간을 크게 개선했습니다.
* **Buzz** 및 **Post Details**에 당겨서 새로고침을 추가했습니다.
* 새 메시지 로딩 시 진행률 표시기를 추가했습니다.
* **Buzz**에 무한 스크롤을 추가했습니다.
* 최근 메시지가 이제 기기에 캐시됩니다.
* **Buzz**에 새 메시지 알림을 추가했습니다.
* 전송에 실패한 메시지를 편집하는 옵션을 추가했습니다.
