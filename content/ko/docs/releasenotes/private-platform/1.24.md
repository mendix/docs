이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.24에 적용된 변경 사항을 다루고 있습니다.

{{% alert color="info" %}}
이것은 [LTS](/releasenotes/studio-pro/lts-mts/#lts) 버전 릴리스입니다. 이 버전으로 업그레이드하는 것을 권장합니다. Private Mendix Platform의 [이전 MTS 버전](/releasenotes/private-platform/1-13/)은 더 이상 지원되지 않습니다.
{{% /alert %}}

## 1.24.3

### 릴리스 날짜: 2025년 12월 22일

#### 개선 사항

##### Pipeline 개선

Deploy Pipeline에서 Manual Approve 단계의 승인자로 그룹을 선택할 수 있게 되었습니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.40](/releasenotes/studio-pro/9.24/#92440)으로 업데이트되었습니다
* Studio Pro 10.24 LTS 최신 패치 버전이 [10.24.13](/releasenotes/studio-pro/10.24/#102413)으로 업데이트되었습니다

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전 [v.2.24.1](/releasenotes/developer-portal/mendix-for-private-cloud/#2.24.1)
* Private Cloud License Manager (PCLM) 버전 [0.10.5](/releasenotes/developer-portal/mendix-for-private-cloud/#license-manage-cli-v0105)

#### 수정 사항

다음 수정 사항을 제공합니다:

* (일반) 만료일이 2038년 이후인 라이선스가 업로드 후 올바르게 처리되지 않던 문제를 수정하였습니다.
* (일반) 디버거 URL 관련 문제를 수정하였습니다.
* (일반) 환경 URL 관련 문제를 수정하였습니다.
* (일반) 접근 그룹이 허용하지 않는 경우에도 사용자가 App Metrics 및 Logs를 볼 수 있던 문제를 수정하였습니다.

## 1.24.2

### 릴리스 날짜: 2025년 11월 21일

#### 새로운 기능

##### Hashicorp Vault를 통한 Secret 관리

Private Mendix Platform은 이제 기존 데이터베이스 저장 옵션과 함께 외부 시크릿 관리 솔루션으로 [Hashicorp Vault](https://www.hashicorp.com/en/products/vault)를 지원합니다. 자세한 내용은 [HashiCorp Vault를 사용한 외부 Secret 관리 구성](/private-mendix-platform/configure-hashicorp-vault/)을 참조하십시오.

#### 개선 사항

##### 설치 프로그램 개선

설치 프로그램이 이제 설치 과정에서 Azure Key Vault를 외부 시크릿 관리자로 선택하는 것을 지원합니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.40](/releasenotes/studio-pro/9.24/#92440)으로 업데이트되었습니다
* Studio Pro 10.24 LTS 최신 패치 버전이 [10.24.11](/releasenotes/studio-pro/10.24/#102411)으로 업데이트되었습니다

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전 [v.2.24.1](/releasenotes/developer-portal/mendix-for-private-cloud/#2.24.1)
* Private Cloud License Manager (PCLM) 버전 [0.10.5](/releasenotes/developer-portal/mendix-for-private-cloud/#license-manage-cli-v0105)

#### 알려진 문제

##### 영구 라이선스 문제

Private Mendix Platform의 영구 라이선스 지원에 관한 문제가 확인되었습니다.

###### 원인

만료일이 2038년 이후인 라이선스가 Private Mendix Platform 포털 및 런타임에서 업로드 후 올바르게 처리되지 않습니다. 이 문제는 현재 해결 중입니다.

###### 해결 방법

이 문제는 현재 해결 중이며 향후 릴리스에서 수정될 예정입니다. 긴급한 경우 CSM, Mendix 파트너 또는 Mendix 지원팀에 연락하여 임시 라이선스를 요청하십시오.

## 1.24.1

### 릴리스 날짜: 2025년 10월 24일

Private Mendix Platform 버전 1.24.1에서는 다수의 업데이트 및 수정 사항이 도입되었습니다.

#### 새로운 기능

##### Azure Key Vault를 통한 Secret 관리

Private Mendix Platform은 이제 기존 데이터베이스 저장 옵션과 함께 외부 시크릿 관리 솔루션으로 [Azure Key Vault](https://azure.microsoft.com/en-us/products/key-vault)를 지원합니다. 자세한 내용은 [Azure Key Vault를 사용한 외부 Secret 관리 구성](/private-mendix-platform/configure-azure-key-vault/)을 참조하십시오.

#### 개선 사항

##### Pipeline 개선

Jenkins 및 Azure DevOps Pipelines CI/CD 도구에 Pipeline을 프로비저닝하는 템플릿을 업데이트하여 SBOM 생성 기능을 포함하고, [Software Composition](/developerportal/deploy/software-composition/) 분석을 위해 MDA와 동일한 폴더에 파일을 저장하도록 하였습니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.40](/releasenotes/studio-pro/9.24/#92440)으로 업데이트되었습니다
* Studio Pro 10.24 LTS 최신 패치 버전이 [10.24.9](/releasenotes/studio-pro/10.24/#10249)로 업데이트되었습니다

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전 [2.23.0](/releasenotes/developer-portal/mendix-for-private-cloud/#2.23.0)
* Private Cloud License Manager (PCLM) 버전 0.10.4

#### 수정 사항

다음 수정 사항을 제공합니다:

* (일반) Azure Key Vault에서 시크릿을 검색할 수 없던 문제를 수정하였습니다
* (일반) Azure DevOps를 CI/CD 도구로 사용할 때 패키지를 빌드할 수 없던 문제를 수정하였습니다.
* (일반) 다음과 관련된 취약점을 수정하였습니다:

    * CVE-2025-8885
    * CVE-2025-8916
    * CVE-2024-25710
    * CVE-2022-23437
    * CVE-2020-14338
    * CVE-2019-12415

#### 알려진 문제

* 영구 라이선스는 라이선스 업로드 기능에서 지원되지 않습니다.
