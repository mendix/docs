## 소개

이 메뉴 옵션 대화 상자는 버전이 지정된 배포 패키지를 생성하고 Mendix Cloud 환경에 배포합니다.

## Development Line

배포 패키지를 생성할 **Development line**을 선택하세요. 메인 라인 또는 브랜치 라인을 선택할 수 있습니다. 예를 들어, 메인터넌스 브랜치 라인에서 구현한 수정 사항을 온라인에 배포하려는 경우 해당 브랜치 라인에서 패키지를 생성할 수 있습니다. 또는 다음 주요 버전의 애플리케이션을 배포할 준비가 되었다면 메인 라인에서 배포 패키지를 생성할 수 있습니다.

## Revision

배포 패키지를 생성할 선택된 development line의 **Revision**을 선택하세요. 일반적으로 최신 리비전을 선택하지만, 필요한 경우 이전 리비전을 선택할 수도 있습니다. 예를 들어, 최근에 개발한 기능을 제외하려는 경우 이전 버전을 사용할 수 있습니다.

## New Version

배포 패키지의 **New version**을 선택하세요. 버전은 메이저 버전, 마이너 버전, 패치, 리비전의 4개 숫자로 구성됩니다. 리비전은 **Revision**에서 선택한 리비전에 의해 고정되고 결정됩니다.

다른 숫자는 자유롭게 선택할 수 있지만, 번호 매기기 규칙을 사용하는 것이 좋습니다. 메이저 버전은 일반적으로 하나 이상의 주요 새 기능이나 기존 기능의 재작성을 포함합니다. 마이너 버전은 소규모 새 기능과 수정 사항을 포함합니다. 패치는 사소한 문제를 해결하며 애플리케이션의 데이터 모델을 변경하지 않습니다. 패치 릴리스는 데이터 변경 없이 다른 패치 릴리스와 교환 가능합니다.

Studio Pro는 패키지를 생성한 최신 버전(있는 경우)을 표시합니다. 사용하는 규칙에 따라 메이저, 마이너 또는 패치 번호를 증가시킬 수 있습니다.

## Description

이 배포 패키지에 대한 사용자 정의 **Description**을 입력할 수 있습니다. 이는 패키지를 빠르게 식별할 수 있도록 순전히 참조용입니다. Mendix Portal에서는 버전 번호와 함께 이 설명이 표시됩니다.

## App

배포 패키지가 배포될 Mendix Cloud의 **App**을 표시합니다. 이는 정보 제공 전용이며 여기서 대상을 변경할 수 없습니다.

## Licensee

이 라이선스가 부여된 노드의 **Licensee**를 표시합니다.
