These release notes cover changes to On-premises deployments based on Virtual Machine (Windows and Linux), and important customer-facing changes to the buildpacks. For full release notes for the buildpacks, see the [Cloud Foundry](https://github.com/mendix/cf-mendix-buildpack/releases) and [Docker](https://github.com/mendix/docker-mendix-buildpack/releases) buildpack release notes on GitHub. For [Mendix Service Console](https://marketplace.mendix.com/link/component/223425), the release notes can be found in the Marketplace module page.

There are separate release notes for other deployment targets; for more information, see the [Deployment](/releasenotes/developer-portal/deployment/) release notes page.

For information on the current status of Mendix deployment, see [Mendix Status](https://status.mendix.com/).
