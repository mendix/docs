## Introduction

The **Activity Logs** page provides an audit trail of cluster operations and management activities.

## Accessing Activity Logs

To access activity logs, perform the following steps:

1. Navigate to the **Cluster Overview** page.
2. Click **Activity** in the top navigation bar.

{{< figure src="/attachments/deployment/mx-azure/cluster-activity-logs.png" alt="Cluster Overview page with Activity button" max-width="100%" >}}

The activity log displays recent cluster activities with timestamps. The Activity log tracks cluster operations such as initialization, updates, failures, and role assignments. You can filter activities by keyword or date using the filter fields.
