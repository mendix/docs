이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.20에 적용된 변경 사항을 다루고 있습니다.

## 1.20.0

### 릴리스 날짜: 2025년 3월 27일

Private Mendix Platform 버전 1.20.0에서는 다수의 새로운 기능, 개선 사항 및 버그 수정이 도입되었습니다.

#### 새로운 기능

##### 설치 시 AWS Secret Manager 지원

설치 중 데이터베이스 및 스토리지 플랜을 수동으로 구성하는 대신, AWS Secret Manager에 저장된 정보를 사용할 수 있게 되었습니다. 자세한 내용은 [Private Mendix Platform 빠른 시작 가이드](/private-mendix-platform/quickstart/)를 참조하십시오.

#### 개선 사항

##### Build Pipeline에서 Build 타임아웃 구성

**Build Timeout** 구성을 **Build Image Settings** 페이지에서 Build Pipeline 구성으로 이동하여 더 쉽게 접근할 수 있도록 하였습니다.

##### 사용자 정의 IdP 클레임 매핑을 위한 OIDC 모듈 지원

Private Mendix Platform은 이제 [SAML 모듈](/appstore/modules/saml/)과 동일한 Just-in-Time 프로비저닝 기능을 사용자 정의 IdP 클레임 매핑에 제공합니다.

##### UX 개선

**Deployment Steps** 페이지의 **MDA/OCI source URL** 필드가 이제 선택 사항으로 표시됩니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.33](/releasenotes/studio-pro/9.24/#92433)으로 업데이트되었습니다 (프로덕션 지원)
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.21](/releasenotes/studio-pro/10.6/#10621)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)
* Studio Pro 10.12 MTS 최신 패치 버전이 [10.12.15](/releasenotes/studio-pro/10.12/#101215)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)

#### 수정 사항

다음 수정 사항을 제공합니다:

* (플랫폼) 수동 단계를 제거한 후 빌드 템플릿이 간헐적으로 비어 있게 되던 문제를 해결하였습니다.
* (UI) 로그오프 후 다른 사용자 계정으로 로그인했을 때 동일한 페이지로 돌아가던 문제를 해결하였습니다.
