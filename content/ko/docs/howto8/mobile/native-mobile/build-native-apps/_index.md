이 단계별 가이드에서는 Native Mobile 애플리케이션을 빌드하는 방법 등을 설명합니다. 이 가이드의 대부분은 Mendix Studio Pro 8.15 이상에 포함된 Native Builder UI 도구를 사용합니다:

* [클라우드에서 Mendix Native App 빌드](/howto8/mobile/deploying-native-app/) – 빈 상태에서 디바이스에서 실행되는 앱까지 만들어 보십시오.
* [로컬에서 Mendix Native App 빌드](/howto8/mobile/native-build-locally/) – Mendix Native Mobile Builder를 사용하여 로컬에서 앱을 빌드하려면 이 가이드를 따르십시오.
* [수동으로 로컬에서 Mendix Native App 빌드](/howto8/mobile/native-build-locally-manually/) – 인터넷 연결 없이 로컬에서 앱을 빌드하려면 이 가이드를 따르십시오.
* [Native Mobile 앱 디버그 (고급)](/howto8/mobile/native-debug/) – Make It Native 앱을 사용하여 Native Mobile 앱을 디버그하십시오.
* [사용자 정의 Developer App 만들기](/howto8/mobile/how-to-devapps/) – 네이티브 Widget이나 폰트와 같은 사용자 정의 종속성을 수용하는 Make It Native 앱의 대체물인 사용자 정의 Developer App을 만드십시오.
* [Native App에 폰트 추가](/howto8/mobile/native-custom-fonts/) - Native Mobile 앱에 사용자 정의 폰트를 추가하십시오.

Mendix는 앱을 빌드할 때 Native Builder UI 클라이언트를 사용하는 것을 권장합니다. 그러나 Native Builder CLI 도구를 사용해야 하는 경우 다음 문서 모음을 참조하십시오:

* [Native Builder CLI를 사용하여 앱 빌드하는 방법](/howto8/mobile/use-cli-docs/)
