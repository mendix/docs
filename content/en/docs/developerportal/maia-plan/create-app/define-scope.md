## Introduction

Work with Maia to review and refine the project scope, including the goal, success criteria, target users, and requirements.

1. After you click **Create Scope**, the **Scope** window is displayed, and Maia starts populating it with the proposed project scope.     
   The app plan becomes available on the **Projects** page as soon as you click **Generate Scope** at the beginning of the workflow. You can return to the plan at any time after you leave it, and you can add team members to the app.
    
    After the **Scope** window is populated, you can see the following information generated by Maia:
    
    * **Goal** – A description of what you want to achieve with the app.     
        You can edit this description.
       
    * **Success Metrics** – A list of metrics to measure the success of the app. You can perform the following actions:  
        
        * Edit metrics inline.
        * Remove metrics by hovering over them, then clicking the trash can icon.    
        * Add new metrics by clicking **+Add New Success Metric**.

    * **Target Users** – Cards for the app's target users and each user's goal. You can perform the following actions:   
        
        * Edit user details inline.
        * Remove users or their goals by hovering over them, then clicking the trash can icon.    
        * Add users by clicking **+Add New User**.    
        * Add user goals by clicking **+Add New User Goal**.

    * **Requirements** – The features that the app must have. You can perform the following actions:

        * Edit requirements inline.
        * Remove features by hovering over them, then clicking the trash can icon.    
        * Add new features by clicking **+Add New Requirement**.

    You can use the pane on the right to chat with Maia about your requirements for the new app.

2. After you review the project scope and make any necessary changes, click **Create Specs**. This prompts Maia to start turning your input into a detailed set of specs, with each spec mapping to each distinct capability.

For details on the next steps, refer to [Generating the Spec](/developerportal/maia-spec/generate-spec/).
