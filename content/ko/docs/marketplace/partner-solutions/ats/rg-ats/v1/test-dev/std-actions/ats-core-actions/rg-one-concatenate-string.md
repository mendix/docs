## 설명

문자열을 연결합니다.

## 사용법

연결하려는 문자열을 최대 5개까지 전달하세요.

## 입력 파라미터

Name | Datatype | Required | Description
---- | -------- | ------- |---------------
String 1 | String | no | 체인의 첫 번째 문자열입니다.
String 2 | String | no | String 1 뒤에 추가됩니다.
String 3 | String | no | String 2 뒤에 추가됩니다.
String 4 | String | no | String 3 뒤에 추가됩니다.
String 5 | String | no | String 4 뒤에 추가됩니다.
