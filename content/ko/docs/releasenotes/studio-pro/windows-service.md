[Mendix Service Console](https://marketplace.mendix.com/link/component/223425) 버전 4.7.4부터 이 모듈은 Mendix Marketplace를 통해 릴리스되며, 릴리스 노트도 해당 위치에서 확인할 수 있습니다.

## 4.7

### 4.7.3

**릴리스 날짜: 2023년 12월 18일**

* 이제 메인 실행 파일과 설치 파일 외에도 모든 Mendix Service Console 실행 파일과 라이브러리에 서명합니다(타사 라이브러리 제외).
* Service Console의 기본 설치 디렉토리를 32비트 디렉토리(일반적으로 *C:\Program Files (x86)*)에서 64비트 프로그램 파일 디렉토리(일반적으로 *C:\Program Files*)로 변경했습니다. 이는 Service Console이 OS가 지원하는 경우 실제로 64비트로 실행되기 때문입니다.
* `Start-MxApp` cmdlet에 `NoService` 매개변수를 추가하여 앱을 서비스가 아닌 로컬 프로세스로 시작할 수 있게 했습니다.
* `Stop-MxApp` cmdlet은 이제 로컬 프로세스로 시작된 앱과 서비스로 시작된 앱 모두를 중지합니다.

### 4.7.2

**릴리스 날짜: 2023년 9월 21일**

* `Update-MxApp` cmdlet을 통해 앱을 업데이트할 때 새로 추가되거나 삭제된 애플리케이션 상수가 올바르게 감지되지 않는 문제를 수정했습니다. (Ticket 185938)
* **Advanced Settings** 창의 **Jetty Configuration** 섹션에 폼 포스트의 최대값(바이트)을 지정하는 새 필드를 추가했습니다.

### 4.7.1

**릴리스 날짜: 2023년 2월 24일**

* *Settings.yaml* 파일에 추가 `logsubscribers`를 추가할 수 있는 기능이 도입되었습니다(자세한 내용은 [full-documented-m2ee.yaml](https://github.com/mendix/m2ee-tools/blob/v7.2.3/examples/full-documented-m2ee.yaml#L392)을 참조하세요). 해당 정보와 비교하여, `Logging` 속성은 대문자로 시작해야 합니다(즉, `logging:` 대신 `Logging:`). 설명된 `loglevel` 설정은 Windows Service에서 지원되지 않습니다.
* 수정된 YAML 파서 YamlSerializer 0.9.0.2를 YamlDotNet 12.3.1로 교체했습니다.
* Newtonsoft Json.NET 라이브러리를 버전 13.0.1에서 13.0.2로 업데이트했습니다.
* 실행 파일의 버전 정보와 MSI 설치 파일의 제목 필드에 빌드 번호 정보를 추가했습니다.

* Newtonsoft Json.NET 라이브러리를 버전 12.0.2에서 13.0.1로 업데이트했습니다.
* Tulpep.ActiveDirectoryObjectPicker 라이브러리를 버전 2.3.133에서 3.0.11로 업데이트했습니다.

## 4.6

### 4.6.1 {#4_6_1}

**릴리스 날짜: 2021년 2월 8일**

* <a id="46ki"></a>[Studio Pro 8.0](/releasenotes/studio-pro/8.0/) 이상에서 아직 구성되지 않은 경우 올바른 AdoptOpenJDK 버전을 찾는 알려진 문제를 수정했습니다.
* `Update-MxApp` cmdlet이 더 이상 파일 접근 권한을 적용하지 않도록 변경했습니다. 일반적으로 이 작업은 한 번만 수행하면 되므로, 새 앱을 추가할 때 Mendix Service Console이 이를 수행합니다. 기존 앱에서 이 작업이 필요한 경우 Service Console에서 수동으로 앱을 업데이트하고 **Update App** 양식의 체크박스를 사용하여 사용자 권한을 다시 적용할 수 있습니다. 자세한 내용은 아래 버전 [4.5.1](#451)의 이 체크박스에 대한 릴리스 노트를 참조하세요. (Ticket 67514)
* Mendix Service Console을 처음 시작할 때 파일의 기본 위치를 구성하지 않을 수 있도록 했습니다. 이 경우 애플리케이션이 종료됩니다.
* 서버 배포 파일의 다운로드 또는 추출 중 오류가 표시되지 않는 문제를 수정했습니다.
* 현재 사용 중인 .NET Framework 버전이 기본적으로 서버 TLS 버전을 지원하지 않아 최근 서버 배포 파일 다운로드가 실패하기 시작한 문제를 수정했습니다.
* 서버 배포 파일 추출 프로세스의 진행 표시줄을 보다 현실적으로 개선했습니다.
* Studio Pro 8 이상에서 앱을 시작할 때 Java 버전을 확인합니다.

    * [4.6.1](#46ki)에서 수정되었습니다.

### 4.2.0

**릴리스 날짜: 2014년 1월 16일**

Mendix Service Console을 처음 열면 모든 서비스 사용자 비밀번호와 데이터베이스 비밀번호가 설정 파일에서 암호화된다는 점에 유의하세요. 서비스로 이미 설치된 앱의 데이터베이스 비밀번호만 서비스를 다시 설치할 때까지 변경되지 않습니다.

Start service 버튼은 이제 다른 Start 버튼과 동일한 방식으로 데이터베이스 동기화를 처리할 수 있습니다. 이 기능은 이 버전의 Mendix Service Console로 서비스가 다시 설치된 경우에만 작동합니다.

Service configuration 양식의 변경 사항은 실제 설치된 Windows 서비스에 직접 적용됩니다. 이러한 변경을 위해 서비스를 다시 설치할 필요가 없습니다.

4.2-beta2와 4.2 사이의 변경 사항:

* Mendix 5의 문서 내보내기 기능을 수정했습니다.
* 활성 서버 작업 개요를 표시하는 동안 여러 번 발생하는 예외를 수정했습니다(메뉴 Advanced, Show active server actions).
* Ticket 15817: 이제 배포 패키지와 서버 배포 파일이 디렉토리 탐색 공격에 대해 검사됩니다.
* 런타임 스레드를 표시하는 옵션이 추가되었으며, Advanced 메뉴에서 사용할 수 있습니다.
* Ticket 21020: 서로 다른 앱의 서비스가 동일한 서비스 어셈블리를 사용하는 상황을 수정했습니다.
* Service Console 4.2-beta2 이후 Start service 버튼으로 서비스를 완전히 시작할 권한이 부족한 상황을 수정했습니다.
* Ticket 18676: 이제 Mendix 5 앱이 시작되지 않은 경우에도 라이선스를 설정할 수 있습니다.
* 이제 앱이 처음 서비스로 시작되고 위치가 루트 앱 경로 내에 있는 경우 업로드된 파일 경로와 임시 경로가 자동으로 생성됩니다.
* 이제 구성되지 않은 앱 또는 Mendix 5 앱에 대해 Java 7이 기본값으로 설정됩니다.
* Stop 및 Stop service 버튼의 작동을 개선했습니다.
* Ticket 20737: Service Console 4.2-beta2 이후 의무화되었던 로컬 로그온 및 서비스 로그온 권한이 있는 구성된 사용자 계정 필요 조건을 제거했습니다.
* 여러 사용자 인터페이스 변경 사항이 있습니다.

### 4.2.0 Beta 2

**릴리스 날짜: 2013년 7월 10일**

* Ticket 20737: Start service 버튼의 작동을 개선했습니다. 이제 Start service 버튼을 통해 앱을 시작하더라도 데이터베이스를 동기화할 수 있습니다. 서비스가 설치된 경우 Start 버튼은 기본적으로 보이지 않습니다.

* 이제 서비스 이름이 다른 앱 또는 Windows 서비스 이름 내에서 고유성을 확인합니다.
* 앱을 제거하지만 일부 파일이 사용 중인 경우의 예외 처리를 개선했습니다.
* 이제 로그 라인이 표시되기 전에 시작 상태 메시지가 표시됩니다.

* Active Directory 선택기를 통해 서비스 사용자 계정을 선택하는 기능이 추가되었습니다.
* 이제 도메인 이름/컴퓨터 이름 없이 서비스 사용자를 지정할 수 있습니다. 이 경우 로컬 사용자입니다.
* 사용자 계정 유형 설정이 제거되었습니다. 항상 일반 사용자 계정을 제공해야 합니다. Local System과 같은 시스템 계정의 가능성이 제거되었습니다.
* 이제 새 애플리케이션 상수에 Modeler에서 설정한 기본값이 적용됩니다.
* 이제 애플리케이션 상수가 툴팁에 설명을 표시합니다.
* Common Configuration 패널에 'Uploaded files path'와 'Temporary files path' 설정이 추가되었습니다.
* 이제 프로세스가 시작할 수 없는 경우 시스템 로그 파일 m2ee_log.txt가 즉시 닫힙니다.
* Service Console을 시작하는 동안 이미 실행 중인 서버에 대한 연결이 비동기적으로 수행되므로 양식이 더 빠르게 표시됩니다.
* 이제 서버 또는 서비스가 시작될 때 구성된 모든 경로가 검증됩니다.
* Windows 서비스 예외가 이제 Service Console에 표시됩니다(더 이상 Administrative Tools -> Event Viewer로 이동할 필요가 없습니다).
* 프로젝트 경로의 기본 폴더가 'Project'로 변경되었습니다(이전에는 'Application').
* 기본 폴더가 필요할 때 존재하지 않으면 생성됩니다.
* 이제 Java Virtual Machine에 따라 Mendix 라이브러리 경로에서 올바른 x86 또는 x64 라이브러리가 로드됩니다. 현재 SQL Server 인증 라이브러리에 필요합니다.
* 예외 처리를 개선했습니다.
* PostgreSQL 데이터베이스 유형 옵션의 텍스트를 'PostgreSQL 8.2 and later'에서 'PostgreSQL 8.3 and later'로 변경했습니다.
* 사소한 사용자 인터페이스 변경 사항이 있습니다.
