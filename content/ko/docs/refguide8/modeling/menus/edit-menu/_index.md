## 소개

**Edit** 메뉴를 통해 잘라내기/복사/붙여넣기 또는 특정 문서가 사용되는 위치 검색 등 다양한 작업을 수행할 수 있습니다. 사용자별 설정이 포함된 [Preferences](/refguide8/preferences-dialog/) 대화 상자도 열 수 있습니다.

## 메뉴 항목 개요

**Edit** 메뉴 항목은 아래 표에 설명되어 있습니다:

| 메뉴 항목 (단축키)                                     | 설명                                                  |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| **Undo** (<kbd>Ctrl</kbd> + <kbd>Z</kbd>)                    | 문서 탭에서 마지막 작업을 실행 취소합니다. 실행 취소 및 다시 실행 작업은 무제한입니다. |
| **Redo** (<kbd>Ctrl</kbd> + <kbd>Y</kbd>)                    | 문서 탭에서 마지막으로 실행 취소한 작업을 다시 실행합니다.    |
| **Cut** (<kbd>Ctrl</kbd> + <kbd>X</kbd>)                     | 선택한 요소를 클립보드에 복사하고 삭제합니다.  |
| **Copy** (<kbd>Ctrl</kbd> + <kbd>C</kbd>)                    | 선택한 요소를 클립보드에 복사합니다.                |
| **Paste** (<kbd>Ctrl</kbd> + <kbd>V</kbd>)                   | 현재 편집기에 클립보드의 내용을 붙여넣습니다.  |
| **Delete** (<kbd>Delete</kbd>)                               | 선택한 요소를 삭제합니다.                                |
| **Find** (<kbd>Ctrl</kbd> + <kbd>F</kbd>)                    | 모델에서 텍스트를 검색합니다. 최종 사용자 인터페이스에 나타나는 모든 텍스트(예: 레이블 또는 버튼의 캡션), 문서의 이름과 문서화, Entity, Association, Attribute 이름과 문서화, 액세스 규칙 문서화, 페이지 위젯 이름, Microflow 객체의 캡션과 문서화, Microflow 항목 이름을 검색합니다. |
| **Find Advanced** (<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd>) | 고급 검색 작업을 수행할 수 있는 대화 상자를 엽니다. 예를 들어 모든 문서 유형 검색 및 사용되지 않는 문서 검색이 있습니다. |
| **Find Usages** (<kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd>) | **Find Results** 창을 열고 선택한 객체의 사용 위치를 표시합니다. |
| **Next Find Result** (<kbd>F3</kbd>)                         | **Find Results** 창에서 다음 검색 결과를 강조 표시하고 편집기에서 엽니다. |
| **Previous Find Result** (<kbd>Shift</kbd> + <kbd>F3</kbd>)  | **Find Results** 창에서 이전 검색 결과를 강조 표시하고 편집기에서 엽니다. |
| **Go to** (<kbd>Ctrl</kbd> + <kbd>G</kbd>)                   | 몇 글자를 입력하고 <kbd>Enter</kbd>를 눌러 프로젝트의 모든 문서 또는 Domain Model 요소로 빠르게 이동합니다. |
| **Next Error** (<kbd>F8</kbd>)                               | **Error List** 창에서 다음 오류를 강조 표시하고 편집기에서 엽니다. |
| **Previous Error** (<kbd>Shift</kbd> + <kbd>F8</kbd>)        | **Error List** 창에서 이전 오류 결과를 강조 표시하고 편집기에서 엽니다. |
| **Preferences**                                              | **Preferences** 대화 상자를 열어 일반, 모델 및 고급 편집 환경설정을 지정할 수 있습니다. **Preferences** 대화 상자에 대한 자세한 내용은 [Preferences](/refguide8/preferences-dialog/)를 참조하십시오. |
