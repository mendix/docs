## 설명

표준 로그인 페이지 또는 MxID를 사용하여 클라우드에서 Mendix 애플리케이션에 로그인합니다.

## 사용법

사용자 계정의 이름과 비밀번호를 파라미터로 제공하세요.
선택적으로 MxID를 사용하여 Mendix 애플리케이션에 로그인할 수 있습니다.

## 입력 파라미터

Name | Datatype | Required | Description
--- | --- | --- | ---
User Name | String | yes | 사용자 계정의 이름입니다.
Password | String |yes | 사용자 계정의 비밀번호입니다.
Use MxID | Boolean | no | MxID 사용 여부를 지정합니다.
