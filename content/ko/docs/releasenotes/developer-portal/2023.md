## December 2023

### December 14, 2023

#### New Features

* [Feedback](/developerportal/app-insights/feedback/)에 다음과 같은 새 기능을 추가했습니다:

    * 앱 팀 멤버가 피드백 항목에 우선순위를 지정하고 우선순위별로 피드백 항목을 필터링할 수 있습니다.

    * 이제 피드백 항목의 보고자와 배정된 팀 멤버가 서로 메시지를 보낼 때 이미지를 업로드할 수 있습니다.

#### Improvements

* 앱에 Scrum Master가 없거나 라이선스 앱에 Technical Contact가 없는 경우 Developer Portal의 [Settings](/developerportal/general-settings/) 페이지에 경고 표시를 나타냅니다. 이는 해당 역할을 가진 사람이 "forget me" 요청을 제출한 경우 발생할 수 있습니다.
* [Teams](/developerportal/general/team/) 페이지의 **History** 탭과 **Settings** 페이지의 [History](/developerportal/general-settings/#history) 탭을 하나로 통합하고 히스토리 로그를 다운로드할 수 있도록 했습니다. 이는 곧 구현될 감사 추적 보존 정책을 준비하기 위함입니다.
* 프로젝트를 [Jira](/developerportal/project-management/jira-connector/) 보드에 연결한 경우, 이제 연결을 먼저 비활성화하지 않고도 설정을 변경할 수 있습니다.
* IBM 클라우드 대상에 대한 지원을 중단했습니다. 현재 IBM 클라우드에 배포된 모든 프로젝트는 [Mendix Cloud](/deployment/#mendix-cloud)에 대해 활성화되었습니다.

#### Fixes

* [초대](/developerportal/general/team/#inviting) 마법사에서 초대자에게 초대 대상이 이미 초대되었으나 아직 수락하지 않았다는 피드백을 제공하지 않던 문제를 수정했습니다.

### December 7, 2023

#### Improvements

Portfolio Management의 **Access Management** 페이지에 다음과 같은 개선 사항을 적용했습니다:

* [Members](/developerportal/portfolio-management/access-management/#members) 탭에서 목록의 **Status** 열에 사용자가 활성인지 비활성화되었는지 표시됩니다. 또한 포트폴리오에서 비활성화된 사용자를 한 번에 모두 제거할 수 있습니다.
* 모든 보류 중인 초대가 [Pending Invites](/developerportal/portfolio-management/access-management/#pending-invites) 탭에 표시됩니다.

## November 2023

### November 23, 2023

#### New Features

* [Portfolio Management](/developerportal/portfolio-management/)에서 이제 [이니셔티브에 에픽을 연결](/developerportal/portfolio-management/initiatives-overview/#link-epics)할 수 있습니다.

### November 17, 2023

#### Improvements

* Epics의 [Epics](/developerportal/project-management/epics/epics/) 페이지에 필터를 추가하여 상태에 따라 에픽을 정렬하고 볼 수 있습니다. 또한 필터링 경험에 대한 미니 설문도 추가했으니 의견을 알려주세요!
* Epics의 [Board](/developerportal/project-management/epics/board/) 페이지에서 각 스윔레인의 총 스토리 수를 확인할 수 있습니다. 스윔레인 이름 바로 옆에 표시됩니다.

#### Fixes

* Epics에서 주로 다크 모드와 관련된 여러 버그를 수정했습니다.

### November 16, 2023

#### Improvements

* 피드백을 바탕으로 [Jira Connector](/developerportal/project-management/jira-connector/)를 소폭 조정했습니다. Studio Pro의 Jira 이슈 목록이 이제 Jira rank 속성 대신 스토리 키 기준으로 정렬됩니다. 또한 Jira 연결을 설정할 때 표시되는 설정 팝업 창을 더 명확하게 만들었습니다.

#### Deprecations

* **Company Buzz**를 제거했습니다.

### November 9, 2023

#### New Features

* [Feedback](/developerportal/app-insights/feedback/)에서 **Team Comments** 텍스트 상자와 피드백 보고자 및 팀 멤버가 서로 메시지를 보내는 텍스트 상자에 리치 텍스트 에디터를 구현했습니다.
* [Mini Surveys](/developerportal/app-insights/mini-surveys/)에서 **Responses** 탭 하단의 목록에서 개별 응답을 클릭하면 사이드 패널에서 응답 세부 정보를 확인할 수 있습니다.

#### Fixes

* Feedback에서 태그가 잘못 중복될 수 있던 문제를 수정했습니다.
* Feedback에서 태그 또는 상태를 삭제할 때 오류가 발생하던 문제를 수정했습니다.

### November 2, 2023

#### Improvements

* 회사가 자체 [Identity Provider](/control-center/security/set-up-sso-byoidp/)를 Developer Portal에 연결한 경우, Team Server에 연결하려면 [개인 액세스 토큰](/portal/user-settings/#pat)을 사용해야 합니다. 이를 반영하여 [Team Server](/developerportal/repository/team-server/) 페이지에 다른 URL을 표시합니다.

#### Fixes

* 특정 상황에서 Feedback API에서 일부 속성이 노출되지 않던 문제를 수정했습니다.

## October 2023

### October 26, 2023

#### New Features

* Feedback에서 [태그를 관리](/developerportal/app-insights/feedback/#manage-tags)할 수 있는 기능을 출시했습니다. 이제 태그를 생성, 삭제, 이름 변경하고 태그 색상을 변경할 수 있습니다.

#### Improvements

* 모든 [Feedback](/developerportal/app-insights/feedback/) 알림의 서식을 개선했습니다.

#### Fixes

* Feedback에서 소수의 사용자가 피드백 항목을 스토리로 변환할 때 오류가 발생하던 버그를 수정했습니다.
* 일부 앱의 비활성화가 예기치 않은 오류를 유발하던 문제를 수정했습니다.

### October 19, 2023

#### New Features

* [Epics](/developerportal/project-management/epics/)에 다음 기능을 추가했습니다:
    * [스토리 상세](/developerportal/project-management/epics/board/#story-details) 페이지에 **Audit Trail** 섹션을 추가하여 누가 언제 정보를 업데이트했는지를 포함한 모든 스토리 관련 업데이트 정보를 기록합니다.
    * [Board](/developerportal/project-management/epics/board/) 페이지와 [Planning](/developerportal/project-management/epics/planning/) 페이지 모두에서 필터링을 활성화했습니다. 스토리 제목, 스토리 ID, 에픽 이름 또는 담당자로 스토리를 필터링할 수 있습니다. 태그별로 필터링하고 결과를 결합할 수도 있습니다.

#### Improvements

* Story Archive의 Sprint 필터를 개선하여 텍스트 상자에 Sprint 이름을 입력할 수 있도록 했습니다.

#### Fixes

* [Epics](/developerportal/project-management/epics/)에서 다음 문제를 수정했습니다:
    * Sprint 완료 후 보드에서 스토리가 제거되지 않던 문제를 수정했습니다.
    * 다크 모드에서 화면이 깜빡이던 문제를 수정했습니다.
* API 키가 있는 앱에서 마지막 Scrum Master를 제거할 수 있던 문제를 수정했습니다.
* 새 멤버가 앱 초대를 여러 번 수락할 수 있던 문제를 수정했습니다.

### October 12, 2023

#### New Features

* [Portfolio Management](/developerportal/portfolio-management/)에서 이제 Excel 파일을 사용하여 [이니셔티브를 내보내고 가져올](/developerportal/portfolio-management/export-import-initiatives/) 수 있습니다.

### October 1, 2023

#### Improvements

* Stories에서 Epics로 데이터를 쉽게 이동할 수 있도록 마이그레이션 흐름을 개선했습니다.

#### Deprecations{#stories-deprecation}

* Stories가 공식적으로 은퇴하였으며 Epics가 유일한 공식 Mendix 애자일 계획 도구입니다. 여전히 Stories의 모든 데이터를 Epics로 마이그레이션할 수 있습니다.

## September 2023

### September 28, 2023

#### Fixes

* [Feedback](/developerportal/app-insights/feedback/)에서 다른 피드백 항목이 연결된 피드백 항목을 받은 편지함과 아카이브 간에 이동할 수 없던 문제를 수정했습니다.
* Feedback의 레거시 Feedback 위젯에서 사용자 역할이 너무 많으면 오류가 발생하던 문제를 수정했습니다.
* Feedback에서 잘못 미리 채워진 앱 ID 값으로 인해 Feedback 위젯이 항목을 전송할 수 없던 문제를 수정했습니다.

### September 21, 2023

#### New Features

* [Epics](/developerportal/project-management/epics/)의 새로운 기능을 출시했습니다:
    * [스토리 상세](/developerportal/project-management/epics/board/#story-details) 대화 상자에 스토리의 리비전 기록을 표시하는 **Revisions** 섹션을 추가했습니다. 이 기능은 Git을 버전 관리로 사용하는 앱에서만 사용할 수 있습니다.
    * **Planning** 페이지에서 이제 스토리를 Excel 파일로 [내보낼](/developerportal/project-management/epics/planning/#export-stories) 수 있습니다.
    * **Archive** 페이지에서 [아카이브된 스토리를 내보내면](/developerportal/project-management/epics/archive/#export-archived-stories) Excel 파일에 **Assigned to**와 **Archived by** 두 개의 새로운 열이 포함됩니다.
    * [Planning](/developerportal/project-management/epics/planning/) 페이지에서 검색 바에 *bug* 또는 *feature*를 입력하여 스토리 유형별로 필터링하여 버그 또는 기능만 표시할 수 있습니다. 더 많은 스토리 필터링 방법이 곧 제공됩니다.

#### Deprecations

* Stories 은퇴(2023년 10월 1일)를 위한 모든 준비 작업을 완료했습니다. 해당 날짜 이후에도 Epics에 들어가서 모든 스토리, 댓글, 첨부 파일 등을 마이그레이션할 수 있지만, Stories는 더 이상 어떤 앱에서도 사용할 수 없습니다.

### September 7, 2023

#### Fixes

* Native Template에서 [App Insights](/developerportal/app-insights/)의 [Feedback](/developerportal/app-insights/feedback/)로 피드백 항목이 전송되지 않던 문제를 수정했습니다.
* 피드백 항목을 닫으려고 할 때 오류가 발생하던 문제를 수정했습니다.

#### Deprecations

* App Insights의 [Mini Surveys](/developerportal/app-insights/mini-surveys/)에서 1-10 숫자 평점 질문 옵션을 더 이상 사용하지 않습니다.

## August 2023

### August 24, 2023

#### New Features

* App Insights의 [Feedback](/developerportal/app-insights/feedback/) 및 [Mini Surveys](/developerportal/app-insights/mini-surveys/)에 다음 기능을 추가했습니다:

    * Feedback의 **Inbox** 페이지와 **Archive** 페이지에 "status" 필터를 추가했습니다.
    * Feedback에 이미 처리된 마이그레이션된 피드백 항목에 "Handled" 태그를 도입했습니다. Inbox 페이지에서 이 태그를 사용하여 피드백 항목을 검색할 수 있습니다.
    * **Feedback** 및 [Mini Surveys](/developerportal/app-insights/mini-surveys/) 홈 페이지에 문서 링크를 추가했습니다.

#### Improvements

* App Insights의 Feedback을 다음과 같이 개선했습니다:

    * 피드백 항목을 수동으로 생성할 때 이메일 주소를 남길 수 있습니다.
    * 여러 피드백 항목을 한 번에 아카이브할 수 있습니다.
    * 보고자가 업로드한 피드백 항목의 첨부 파일을 다운로드할 수 있습니다.
    * 적절한 권한이 있는 경우 피드백 항목의 사이드 패널에서 댓글을 삭제할 수 있습니다.

* Scrum 보드에 대한 [Jira 통합](/developerportal/project-management/jira-connector/) 지원을 미세 조정했습니다. Studio Pro의 [Stories pane](/refguide/stories-pane/)에서 이제 보드의 활성 Sprint에 속한 모든 스토리를 표시합니다(이전에는 50개 스토리 제한이 있는 모든 열린 Sprint).

#### Fixes

* URL을 통해 처음으로 Feedback에 접근하려는 새 사용자에게 오류가 표시되던 문제를 수정했습니다.
* 피드백 제출자의 이메일 주소에 특수 문자가 제대로 지원되지 않던 문제를 수정했습니다.
* [설문 상세 페이지](/developerportal/app-insights/mini-surveys/#survey-details)의 **Share Link** 버튼으로 제공된 URL을 사용할 때 오류가 발생하던 문제를 수정했습니다.
* MxDock 내에서 **Developer Portal**을 클릭했을 때 Developer Portal 홈 페이지로 이동하지 않던 문제를 수정했습니다.

### August 12, 2023

#### New Features

* 사용자 입력을 수집, 분석하고 이에 대응하면서 더 빠르게 혁신할 수 있는 새로운 제품군 [App Insights](/developerportal/app-insights/)를 정식 출시했습니다. App Insights에는 [Feedback](/developerportal/app-insights/feedback/)와 [Mini Surveys](/developerportal/app-insights/mini-surveys/) 두 가지 도구가 포함됩니다.

* 새로운 피드백 관리 도구 **Feedback**는 다음을 지원합니다:

    * 피드백 항목에 태그를 추가하여 패턴을 더 쉽게 확인
    * 피드백 항목에 대한 사용자 정의 상태 정의 - 자신만의 워크플로 생성
    * 피드백 항목이 어느 환경(예: 프로덕션 또는 테스트 환경)에서 왔는지 식별
    * 환경, 제출 날짜, 담당자별 필터링으로 더 쉬운 검색
    * 피드백 항목 간 연결 지원 - 여러 사용자가 동일한 버그를 보고하면 모든 피드백을 하나로 처리하고 업데이트
    * 제출자가 Developer Portal에서 자신의 피드백 항목을 보고 업데이트
    * Jira와의 피드백 항목 연결 지원 - 새로운 Jira 커넥터를 활용하는 모든 사용자를 위해

  기존 피드백 데이터는 새 Feedback 도구에서 이미 확인할 수 있습니다. Epics 또는 Jira를 프로젝트 관리 도구로 설정한 경우, Feedback이 이미 연결되어 있습니다. 별도의 조치 없이 바로 사용해 보시고 의견을 알려주세요.

* Feedback를 보완하는 **Mini Surveys**는 짧고 효과적인 설문을 설정하여 다양한 피드백을 수집하고, 데이터 기반 의사결정을 통해 앱과 기능을 개선할 수 있도록 합니다. Mini Surveys는 다음을 지원합니다:

    * 원하는 형식으로 최대 세 개의 질문으로 설문 구성 쉽게 설정
    * 설문 표시 위치, 트리거 타이밍, 대상 사용자 그룹 지정을 위한 설문 설정 맞춤
    * 설문 기간 정의
    * 설문의 화면 배치를 지정하기 위한 토스터 기능 제공
    * 평점 척도, 객관식, 개방형 질문, Net Promoter Score(NPS) 등 선호하는 설문 형식 선택
    * 고객이 전체 설문을 완료하지 않아도 모든 설문 응답 기록
    * 더 넓은 대상에게 설문을 배포하기 전에 실험할 수 있는 테스트 모드 기능
    * 심층 분석을 위한 응답 종합 뷰 제공

### August 10, 2023

#### Fixes

* Jira의 Kanban 보드에서 하위 태스크가 Studio Pro의 **Stories** 패널에 중복 항목을 생성하여 오류가 발생하던 Jira Connector 문제를 수정했습니다.
* 특정 상황에서 앱의 마지막 Scrum Master를 제거할 수 있던 문제를 수정했습니다.

### August 8, 2023

#### Improvements

* [Webhooks API](/apidocs-mxsdk/apidocs/webhooks-api/)를 정식 출시했습니다. 이 API를 사용하여 Mendix 앱에서 수행되는 작업에 대한 Webhook을 관리할 수 있습니다.

## July 2023

### July 27, 2023

#### Improvements
