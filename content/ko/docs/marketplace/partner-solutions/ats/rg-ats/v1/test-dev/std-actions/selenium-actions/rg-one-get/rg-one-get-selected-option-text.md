## 설명

WebElement(예: select)의 현재 선택된 항목의 텍스트를 반환합니다.

## 사용법

현재 선택된 옵션의 텍스트를 가져오려는 상위 WebElement를 전달하세요.

## 입력 파라미터

Name | Datatype | Required | Description
---- | -------- | ------- |---------------
Select Element | WebElement | yes | 상위 WebElement(예: select)입니다.

## 반환 값

Name | Datatype | Description
---- | --------- | ---------------
Selected Option Text | String | 현재 선택된 WebElement의 텍스트입니다.
