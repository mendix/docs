## 소개

Mendix 애플리케이션에서 자체 웹 서비스를 게시할 수 있습니다. 게시된 웹 서비스는 SOAP 1.1을 기반으로 합니다. 이러한 웹 서비스는 오퍼레이션(operation)으로 구성됩니다. 다른 애플리케이션이 이 웹 서비스의 오퍼레이션을 호출하면 결과를 반환할 수 있습니다. 이 결과는 웹 서비스가 호출될 때 실행되는 마이크로플로우(Microflow)를 기반으로 합니다.

웹 서비스를 게시하려면 다음을 참조하세요:

* [Published Web Services](/refguide10/published-web-services/), Studio Pro 가이드의 개요
* [웹 서비스 노출](/howto10/integration/expose-a-web-service/) 단계별 지침

웹 서비스를 사용하려면 다음을 참조하세요:

* [Consumed Web Services](/refguide10/consumed-web-services/), Studio Pro 가이드의 개요
* [Call Web Service](/refguide10/call-web-service-action/), 마이크로플로우 액션 설명
* [간단한 웹 서비스 사용하기](/howto10/integration/consume-a-simple-web-service/) 단계별 지침
* [복잡한 웹 서비스 사용하기](/howto10/integration/consume-a-complex-web-service/) 단계별 지침
