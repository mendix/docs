이 단계별 가이드에서는 Native Mobile 애플리케이션을 위한 로컬 알림을 구축하는 방법을 설명합니다. 로컬 알림은 하나의 모바일 디바이스에 한정된 알림을 예약하고 보낼 수 있습니다. 이러한 알림은 인터넷 연결을 사용하지 않습니다. 로컬 알림의 한 가지 사용 예로는 일정 시간이 경과한 후 알림을 보내는 알람 앱이 있습니다.

이 사용 방법에서는 다음을 수행하는 방법을 설명합니다:

* [파트 1: 로컬 알림](/howto8/mobile/native-local-notifications/) – Mendix 앱의 Microflow에서 네이티브 알림을 트리거하고, 알림 권한을 구성하며, 디바이스에서 알림을 테스트하십시오
* [파트 2: 배지](/howto8/mobile/local-notif-badges/) – 알림이 애플리케이션 아이콘에 배지 표시를 남기도록 설정하십시오
* [파트 3: 액션](/howto8/mobile/local-notif-action/) – 탭한 후 액션을 수행하도록 알림을 구성하십시오(이 경우 페이지 표시)
* [파트 4: 데이터](/howto8/mobile/local-notif-data/) – 알림이 데이터를 전달하고 사용자를 특정 매개변수가 설정된 페이지로 이동시키도록 설정하십시오
* [파트 5: 예약](/howto8/mobile/local-notif-schedule-cancel/) – 특정 시간에 알림이 트리거되도록 하고 취소할 수 있도록 설정하십시오
