## 소개

확장 기능은 여기에서 설명하는 TypeScript 또는 기타 웹 언어로 작성하거나, [C# 개발자를 위한 Extensibility API](/apidocs-mxsdk/apidocs/csharp-extensibility-api-10/)에 문서화된 C# API를 사용하여 작성할 수 있습니다.

웹 API에 대한 자세한 내용은 [Mendix Studio Pro Web Extensibility API 참조 문서](http://apidocs.rnd.mendix.com/10/extensions-api/index.html)를 참조하십시오.

## 전제 조건

Web Extensibility API를 사용하려면 다음이 필요합니다:

* Mendix 플랫폼에 대한 기본적인 이해
* Mendix 모델에 대한 약간의 이해
* TypeScript 개발 경험

## 시작하기

확장 기능 시작 방법에 대한 자세한 내용은 [Web Extensibility API 시작하기](/apidocs-mxsdk/apidocs/web-extensibility-api-10/getting-started/)를 참조하십시오.
