## 소개

Add date 함수 호출은 날짜와 시간에 기간을 추가하고 수정된 값을 반환합니다.

첫 번째 매개변수는 **Date and time** 유형의 Domain Model Entity Attribute, **Date and time** 유형의 변수 또는 [Date Creation](/refguide9/date-creation/) 함수를 사용하여 생성된 **Date and time** 값일 수 있습니다. 두 번째 매개변수는 추가할 기간을 지정합니다.

지정된 날짜에서 기간을 뺄 수도 있습니다. 자세한 내용은 [Subtract Date 함수 호출](/refguide9/subtract-date-function-calls/)을 참조하십시오.

## addMilliseconds

`addMilliseconds` 함수는 날짜에 지정된 밀리초 수를 추가합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                                  | 유형          |
| -------------------------------------- | ------------- |
| 초기 날짜                           | Date and time |
| 추가할 밀리초 수 | Integer       |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형          |
| ------------------------------------------------------------ | ------------- |
| *초기 날짜*와 지정된 *밀리초* 수의 합인 Date and time 값입니다. | Date and time |

### 예제

다음 입력을 사용하는 경우:

```java
addMilliseconds(dateTime(2007, 1, 1, 1, 1, 1), 1400)
```

출력은 다음과 같습니다:

```java
"Mon Jan 01 01:01:02:400 CET 2007"
```

## Long 유형 값 전달

다양한 **Add date 함수** 호출에 Long 유형의 값을 전달할 수 있습니다.

다음 입력을 사용하는 경우:

```java
addSeconds(dateTime(1970, 1, 1, 0, 0, 0), (long)(2147483647 + 100))
```

출력은 다음과 같습니다:

```java
"Tue Jan 19 04:15:47 CET 2038"
```
