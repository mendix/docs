## 소개

Mendix 포털 홈 페이지는 모든 Mendix 온라인 서비스의 진입점입니다.

### 홈 페이지 세부 정보

홈 페이지에는 다음과 같은 사용자 관련 정보가 포함됩니다:

* [Mendix Academy 인증](https://academy.mendix.com/link/certifications)
* Mendix 커뮤니티 [포인트 레벨](/portal/mendix-profile/#level)

### 홈 페이지 작업

홈 페이지에서 수행할 수 있는 작업은 다음과 같습니다:

* 홈 페이지에 표시되는 섹션을 사용자 정의하세요. 두 가지 방법으로 수행할 수 있습니다:

    * **Settings** ({{< icon name="cog" >}})를 클릭한 다음, 표시할 섹션을 선택하거나 숨길 섹션을 선택 해제하세요.
    * 숨기려는 섹션 옆에 있는 점 세 개 아이콘({{% icon name="three-dots-menu-horizontal" %}})을 클릭하세요.
* 앱을 생성하세요.
* Studio Pro를 다운로드하세요.
