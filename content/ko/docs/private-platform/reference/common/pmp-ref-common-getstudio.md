## 소개

**Get Studio Pro** 페이지는 호환 가능한 Studio Pro 버전의 다운로드 페이지입니다.

{{< figure src="/attachments/private-platform/pmp-ref-download-studio.png" class="no-border" >}}

Mendix가 [Mendix Marketplace](https://marketplace.mendix.com/)에 게시한 모든 Studio Pro 버전이 Private Mendix Platform과 호환되는 것은 아닙니다. Private Mendix Platform은 지원되는 Runtime 버전 및 재사용 가능한 컴포넌트(예: Starter App 템플릿)와 연결된 사전 정의된 호환 가능한 Studio Pro 버전을 제공합니다. 회사 관리자는 이러한 지원 버전 중 Private Mendix Platform 최종 사용자가 사용할 수 있는 버전을 지정할 수 있습니다.
