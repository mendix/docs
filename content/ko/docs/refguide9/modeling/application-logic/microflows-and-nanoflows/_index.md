## 소개

Microflow와 Nanoflow를 사용하면 애플리케이션의 로직을 표현할 수 있습니다. 객체 생성 및 업데이트, 페이지 표시, 선택 수행 등의 작업을 수행할 수 있습니다. 이는 전통적으로 텍스트 프로그램 코드로 작성되던 것을 시각적으로 표현하는 방법입니다.

Microflow는 런타임 서버에서 실행되므로 오프라인 앱에서 사용할 수 없지만, Nanoflow는 브라우저/디바이스에서 직접 실행되며 오프라인 앱에서 사용할 수 있습니다. 또한 Nanoflow의 대부분의 Action은 디바이스에서 직접 실행되므로 서버에 접근할 필요가 없는 로직에 대해 속도 이점도 있습니다.
