## 소개

글로벌 내비게이션 상단 바와 메뉴는 Mendix 포털 전체에서 사용할 수 있으며, 모든 포털 서비스에서 동일하게 작동합니다. 

## 글로벌 내비게이션 메뉴 {#global-navigation}

상단 바 왼쪽에서 **Open Global Navigation** ({{% icon name="layout-rounded-1" %}})을 클릭하여 메인 메뉴에 접근하세요.

{{< figure src="/attachments/developerportal/global-nav/navigation-menu.png" width="250" class="no-border" >}}

메뉴 항목을 클릭하여 Mendix 포털의 다른 부분으로 이동하거나, 메뉴 항목 위에 마우스를 올려 섹션을 확장하여 추가로 접근하세요.

## 검색

**Search** 상자에서 포털 내 **Docs**, **Forum** 게시물, 공개 **Marketplace** 콘텐츠 및 **Academy** 콘텐츠를 검색할 수 있습니다.

다양한 필터를 사용하여 검색 결과를 세분화하세요.

{{< figure src="/attachments/mendix-portal/global-nav/portal_search.png" class="no-border" >}}

## 지원 메뉴

**Open Support Menu** ({{% icon name="question-circle" color="color" %}})를 클릭하여 Mendix 플랫폼의 [최신 소식](https://www.mendix.com/releases/)을 확인하고, Mendix 커뮤니티에 [질문하기](/community-tools/mendix-community/#questions-tab), 커뮤니티에 [아이디어 공유하기](/community-tools/mendix-community/#ideas-tab), 더 많은 [Mendix 문서](/), 또는 [Mendix 지원팀](/support/)에 문의하세요.

{{< figure src="/attachments/developerportal/global-nav/help-menu.png" width="300" class="no-border" >}}

{{% alert color="info" %}}
**Get Started with Mendix**가 표시되는 경우, 가입 후 30일 동안 이 메뉴 항목 옆에 빨간 점이 유지됩니다.
{{% /alert %}}

## 알림 메뉴 {#notifications}

**Open Notifications Menu** ({{% icon name="alarm-bell" %}})를 클릭하여 수신한 플랫폼 알림을 확인하세요. 알림 자체를 클릭하면 해당 소스로 이동합니다.

수신할 알림 유형을 구성하려면 **Settings** ({{% icon name="cog" %}})를 클릭하고 열리는 [알림 설정](/portal/user-settings/#notifications) 페이지에서 옵션을 업데이트하세요. 

{{< figure src="/attachments/developerportal/global-nav/notifications.png" width="500" class="no-border" >}}

{{% alert color="info" %}}
특정 앱에 대해 새 피드백이 제출될 때 알림 수신을 중지하려면, 해당 앱의 [Settings](/developerportal/general-settings/) 페이지로 이동하여 **Stop Watching**을 클릭하세요. 한 페이지에서 여러 앱의 알림을 비활성화하려면, [My Apps](/developerportal/#my-apps) 페이지에서 **Stop Watching** 옵션을 사용하세요.
{{% /alert %}}

## 프로필 메뉴

**Open Profile Menu** ({{% icon name="user" %}})를 클릭하여 [Mendix 프로필](/portal/mendix-profile/)에 접근하고, **Dark Mode**를 활성화하며, [계정 설정](/portal/user-settings/#settings)에 접근하세요. 

이 메뉴를 통해 Mendix 포털에서 로그아웃할 수도 있습니다.
