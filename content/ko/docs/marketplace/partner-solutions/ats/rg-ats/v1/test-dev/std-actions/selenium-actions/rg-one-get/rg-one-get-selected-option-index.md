## 설명

WebElement(예: select)의 현재 선택된 항목의 인덱스를 반환합니다.

## 사용법

현재 선택된 옵션의 인덱스를 가져오려는 상위 WebElement를 전달하세요.

## 입력 파라미터

Name | Datatype | Required | Description
---- | -------- | ------- |---------------
Select Element | WebElement | yes | 상위 WebElement(예: select)입니다.

## 반환 값

Name | Datatype | Description
---- | --------- | ---------------
Selected Option Index | Integer | 현재 선택된 WebElement의 인덱스입니다.
