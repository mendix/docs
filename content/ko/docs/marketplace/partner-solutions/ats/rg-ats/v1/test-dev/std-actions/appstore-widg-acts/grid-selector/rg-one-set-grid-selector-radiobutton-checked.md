## 설명

열 및 행 캡션으로 라디오 버튼을 찾고 선택 상태로 설정합니다.

## 지원 Widget

* Grid Selector

## 사용법

찾으려는 라디오 버튼의 Widget 이름, 열 캡션, 행 캡션을 전달하세요.

## 입력 파라미터

Name | Datatype | Required | Description
---- | -------- | -------- | ---------------
Widget Name | String | Yes | Grid Selector Widget의 이름입니다.
Column Caption | String | Yes | 라디오 버튼 셀의 열 캡션입니다.
Row Caption | String | Yes | 라디오 버튼 셀의 행 캡션입니다.
Checked | Boolean | Yes | 설정하려는 체크박스 값입니다 (true 또는 false).
