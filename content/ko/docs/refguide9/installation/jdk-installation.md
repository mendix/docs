## 소개

일부 Studio Pro 버전은 여러 버전의 Java Development Kit(JDK)을 지원합니다.
Studio Pro 설치 중에 하나의 JDK 버전이 다운로드되어 설치됩니다.
Studio Pro 설치 중에 설치된 것과 다른 JDK 버전을 사용하려면 이 문서에 설명된 지침을 따를 수 있습니다.

## JDK 다운로드 및 설치

다음 링크 중 하나를 사용하여 [adoptium.net](https://adoptium.net/) 웹사이트에서 Eclipse Temurin JDK를 다운로드할 수 있습니다:

* [JDK 11](https://adoptium.net/temurin/releases/?version=11)
* [JDK 17](https://adoptium.net/temurin/releases/?version=17)
* [JDK 21](https://adoptium.net/temurin/releases/?version=21)

다운로드한 후 설치 실행 파일을 실행하고 지침을 따르십시오.

## Studio Pro 구성

JDK가 설치된 후 Studio Pro의 [환경 설정](/refguide9/preferences-dialog/#jdk)에서 구성할 수 있습니다.
