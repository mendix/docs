이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.17에 적용된 변경 사항을 다루고 있습니다.

## 1.17.1

### 릴리스 날짜: 2025년 1월 6일

Private Mendix Platform 버전 1.17.1은 패치 릴리스입니다.

#### 수정 사항

다음 수정 사항을 제공합니다:

* (플랫폼) CVE-2024-47554에 대한 알림을 유발하던 라이브러리를 업데이트하였습니다.

{{% alert color="info" %}}
Private Mendix Platform은 해당 취약점의 영향을 받지 않았습니다.
{{% /alert %}}

## 1.17.0

### 릴리스 날짜: 2024년 12월 31일

Private Mendix Platform 버전 1.17.0에서는 다수의 개선 사항 및 버그 수정이 도입되었습니다.

#### 개선 사항

##### Azure DevOps용 앱 가져오기 활성화

**Import Apps** 페이지에서 관리자는 버전 관리 호스트에 있지만 아직 Private Mendix Platform에 등록되지 않은 기존 Mendix 앱을 가져올 수 있습니다. 이전에는 이 기능이 GitHub, GitLab 및 Bitbucket에서만 사용 가능했습니다. 이제 Azure DevOps 호스트에서도 사용할 수 있도록 하였습니다.

##### PCLM 설치 시 Aws-irsa 인증 방법 지원

Private Cloud License Manager를 설치할 때 aws-irsa를 인증 방법으로 선택할 수 있게 되었습니다. 자세한 내용은 [Private Mendix Platform 빠른 시작 가이드: Private Cloud License Manager 설치](/private-mendix-platform/quickstart/#install-pclm)를 참조하십시오.

##### Webhook 개선

Build 또는 Deployment Pipeline에 Webhook 단계를 추가할 때 더 이상 Webhook 유형을 지정할 필요가 없습니다.

##### 엔지니어링 개선

* Azure DevOps가 새로운 *mxbuild* 도구를 사용하도록 업데이트되었습니다.
* SBOM에 대한 성능 개선을 구현하였습니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.31](/releasenotes/studio-pro/9.24/#92431)로 업데이트되었습니다 (프로덕션 지원)
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.18](/releasenotes/studio-pro/10.6/#10618)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)
* Studio Pro 10.12 MTS 최신 패치 버전이 [10.12.10](/releasenotes/studio-pro/10.12/#101210)으로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)

#### 수정 사항

다음 수정 사항을 제공합니다:

* (플랫폼) **Capabilities** 메뉴에서 **Build & Deploy** 기능을 활성화할 수 없던 문제를 수정하였습니다.
* (플랫폼) 사용자 계정이 이미 Private Mendix Platform에 존재하는 경우 SAML을 사용한 SSO 로그인이 실패하던 문제를 수정하였습니다.
* (UI) GitLab 17.5.2-ee에서의 GitLab 페이지네이션 문제를 해결하였습니다.
* (UI) Private Mendix Platform 중국어 번역의 일부 페이지네이션 문제를 해결하였습니다.
