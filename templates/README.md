# Choosing a Template

Go through the questions in order and use the first template that fits. Each template's opening comment says more about when to use it.

1. Is the page an `_index.md` file that introduces a section and lists its child pages? Use `section-index-template.md`.
2. Is the page release notes?
    * Released by version: use `release-notes-version-template.md`.
    * Released by date: use `release-notes-date-template.md`.
3. Does the page guide readers through steps to reach a goal? Use `how-to-template.md`.
4. Does the page document a platform-supported Marketplace component, such as a module, widget, or connector? Use `marketplace-component-page-template.md`. For AWS connectors, use `marketplace-aws-connector-page-template.md`.
5. Does the page document the properties of a Studio Pro element? Use `reference-template.md`.
6. Does none of the above fit? Use `general-page-template.md`. Read sibling pages in the same folder for terminology and level of detail, and choose the other headings to fit the topic.
