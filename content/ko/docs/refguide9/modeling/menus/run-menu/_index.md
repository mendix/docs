## 메뉴 항목 개요

**Run** 메뉴 항목은 아래 표에 설명되어 있습니다:

| 메뉴 항목 | 설명 | 단축키 |
| --- | --- | --- |
| **Run Locally** | 앱을 로컬에서 실행하여 앱을 볼 수 있습니다. | <kbd>F5</kbd> |
| **Stop** | 현재 실행 중인 앱을 중지합니다. | <kbd>Shift</kbd> + <kbd>F5</kbd> |
| **Configuration**               | 구성 레벨을 설정합니다(**Default**).                  |                                                    |
| **Default Log Level** | 앱을 로컬에서 실행하기 전에 기본 로그 레벨을 설정할 수 있습니다. 옵션은 **Trace**, **Debug**, **Info**(기본값), **Warning**, **Error**, **Critical**입니다. |  |
| **Publish** | 앱을 클라우드에 배포합니다. **Console** 창이 활성화되고 앱을 실행하는 서버의 출력을 표시합니다. |  |
| **Run on Cloud Foundry**        | Cloud Foundry에서 앱을 실행할 수 있도록 **Edit Cloud Foundry Settings** 대화 상자를 엽니다. |  |
| **Edit Cloud Foundry Settings** | Cloud Foundry 설정을 편집할 수 있도록 **Edit Cloud Foundry Settings** 대화 상자를 엽니다. 이 대화 상자에 대한 자세한 내용은 [Edit Cloud Foundry Settings](/refguide9/edit-cloud-foundry-settings-dialog/)를 참조하십시오. | |
| **Debug** | [Debugger](/refguide9/view-menu/#debugger)를 연결할 수 있습니다. | |
| **Responsive Web** | 현재 실행 중인 앱의 웹 클라이언트를 브라우저에서 표시합니다. | <kbd>F9</kbd> |
| **Tablet Web** | 현재 실행 중인 앱의 태블릿 모바일 클라이언트를 브라우저에서 표시합니다. | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>F9</kbd> |
| **Phone Web** | 현재 실행 중인 앱의 모바일 클라이언트를 브라우저에서 표시합니다. | <kbd>Ctrl</kbd> + <kbd>F9</kbd> |
| **View on your device** | 앱을 볼 수 있는 링크를 제공합니다. | |
