이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.23에 적용된 변경 사항을 다루고 있습니다.

## 1.23.1

### 릴리스 날짜: 2025년 8월 1일

Private Mendix Platform 버전 1.23.1에서는 다수의 새로운 기능, 개선 사항 및 버그 수정이 도입되었습니다.

#### 새로운 기능

##### AWS Secret Manager를 Secret 스토리지로 사용 가능

Private Mendix Platform의 외부 시크릿 스토리지로 AWS Secret Manager를 사용할 수 있도록 하였습니다. 자세한 내용은 [AWS Secret Manager를 사용한 외부 Secret 관리 구성](/private-mendix-platform/configure-aws-secret-manager/)을 참조하십시오.

##### GitHub Enterprise Cloud를 버전 관리 시스템으로 사용 가능

Private Mendix Platform의 버전 관리 시스템으로 GitHub Enterprise Cloud를 사용할 수 있도록 하였습니다. 자세한 내용은 [Private Mendix Platform의 버전 관리 시스템 구성](/private-mendix-platform/version-control/)을 참조하십시오.

#### 개선 사항

##### 클러스터 관리 개선

수동 프로덕션 배포를 위한 새 클러스터를 등록할 때, MDA 패키지 스토리지 또는 OCI 레지스트리에 대해 다양한 유형 및 인증 방법을 선택할 수 있게 되었습니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.36](/releasenotes/studio-pro/9.24/#92436)으로 업데이트되었습니다 (프로덕션 지원)
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.24](/releasenotes/studio-pro/10.6/#10624)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)
* Studio Pro 10.12 MTS 최신 패치 버전이 [10.12.17](/releasenotes/studio-pro/10.12/#101217)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)
* Studio Pro 10.18 MTS 지원은 호환성 문제로 인해 연기되었습니다

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전 [2.22.0](/releasenotes/developer-portal/mendix-for-private-cloud/#2.22.0)
* Private Cloud License Manager (PCLM) 버전 [0.10.3](/releasenotes/developer-portal/mendix-for-private-cloud/#license-manage-cli-v0103)
* SVIX webhooks 서비스 v.1.65.0

#### 수정 사항

다음 수정 사항을 제공합니다:

* (플랫폼) 사용자가 자신의 계정에 대해 GitLab 자격 증명을 수동으로 등록할 수 없던 문제를 해결하였습니다.
* (플랫폼) Secret 이름을 사용하는 OCI 레지스트리에서 수동 프로덕션 배포가 작동하지 않던 문제를 해결하였습니다.
* (플랫폼) Private Mendix Platform 구성 마법사에서 **Register Cluster** 설정을 제거하였습니다.
* (UI) 기타 사소한 UI 개선 및 수정을 진행하였습니다.

## 1.23.0

### 릴리스 날짜: 2025년 6월 26일

Private Mendix Platform 버전 1.23.0에서는 다수의 새로운 기능, 개선 사항 및 버그 수정이 도입되었습니다.

#### 새로운 기능

##### Vault를 Secret 스토리지로 사용 가능

Private Mendix Platform의 외부 시크릿 스토리지로 Vault를 사용할 수 있도록 하였습니다. 자세한 내용은 [Private Mendix Platform 빠른 시작 가이드](/private-mendix-platform/quickstart/)를 참조하십시오.

##### NIST SP 800-53 개선

이전 버전에서 릴리스된 다양한 기능 및 개선 사항 외에, Private Mendix Platform이 [NIST SP 800-53 사이버보안 프레임워크](https://www.nist.gov/cyberframework)를 준수하도록 다음과 같은 개선을 진행하였습니다:

* AWS GovCloud에서 Private Mendix Platform 실행:

    * Private Mendix Platform이 AWS GovCloud에서 설치 및 실행될 수 있음을 확인하였습니다.
    * AWS GovCloud에서 Private Mendix Platform을 성공적으로 실행하기 위한 격차를 식별하고 문서화하였습니다.
    * Private Mendix Platform이 FIPS 모드로 AWS GovCloud에서 설치 및 실행될 수 있음을 확인하였습니다.
    * FIPS 모드로 AWS GovCloud에서 Private Mendix Platform을 성공적으로 실행하기 위한 격차를 식별하고 문서화하였습니다.
    * AWS GovCloud 호환성을 위한 새로운 Private Mendix Platform 릴리스의 자동 배포 및 테스트를 구현하였습니다.
    * AWS GovCloud에서도 자동화된 E2E 테스트(자동 프로비저닝, 자동 테스트 등)를 구현하였습니다.

* 로그인 화면 개선:

    * 사용자가 계속 진행하기 위해 동의해야 하는 대량의 개인정보 보호 및 보안 알림을 표시할 수 있는 로그인 배너 또는 팝업 구성 지원을 추가하였습니다.

* DevOps 개선:

    * 배포된 모든 앱에 대해 기본 *MxAdmin* 계정을 비활성화하는 토글을 추가하였습니다.

* IAM 및 거버넌스 - 사용자 계정 개선:

    * 구성 가능한 시간 제한 후 비활성 사용자 계정을 비활성화하는 토글을 추가하였습니다.
    * 구성 가능한 세션 기간 후 활성 사용자가 자동으로 로그아웃되도록 세션 만료를 구성할 수 있게 하였습니다.
    * 구성 가능한 비활성 기간 후 유휴 사용자가 자동으로 로그아웃되도록 유휴 세션 타임아웃을 구성할 수 있게 하였습니다.
    * 실패한 로그온 횟수 및 잠금 시간을 구성할 수 있는 로그온 실패 잠금 기능을 추가하였습니다.
    * 구성 가능한 비활성 기간 후 사용자의 화면이 자동으로 잠기도록 세션 잠금 기간 및 타임아웃을 구성할 수 있게 하였습니다.
    * 관리자가 동일한 사용자 계정에 대한 동시 세션 수를 구성할 수 있도록 하였습니다.
    * 관리자가 모든 사용자 또는 특정 사용자를 강제 로그아웃할 수 있는 기능을 제공하였습니다.

* IAM 및 거버넌스 - 로깅 및 감사:

    * 모든 역할의 모든 작업에 대한 로깅을 활성화하였습니다.
    * 감사 로그가 생성되는 시간 단위를 구성할 수 있는 기능을 추가하였습니다.
    * 저장된 타임스탬프의 세분성을 높였습니다.
    * 저장된 타임스탬프를 특정 시간대로 출력할 수 있게 하였습니다.
    * 구성 가능한 기간 만료 후 아카이브 로그를 유지하도록 로깅 설정을 추가하였습니다.
    * 감사 로그를 외부 데이터베이스 대상에 직접 쓸 수 있는 기능을 추가하였습니다.
    * 이벤트의 실시간 로깅을 위한 외부 로깅 대상을 정의하는 설정을 추가하였습니다.
    * 로그 작성을 위한 여러 대상에 대한 연결을 설정하고 테스트할 수 있는 기능을 추가하였습니다.
    * 구성된 경우 활동 로그가 Private Mendix Platform 이메일 알림을 사용하도록 하였습니다.
    * 감사 로깅 실패 시 고객이 구성한 이메일로 알림을 보내는 설정을 추가하였습니다.
    * 사용자 정의 설정으로 주문형 감사를 생성할 수 있는 기능을 추가하였습니다.

#### 개선 사항

##### Pipeline 개선

앱 빌딩 블록을 지원하고 CVE-2025-4949 수정 사항을 반영하도록 Build 및 Deploy Pipeline을 업데이트하였습니다.

##### UI 개선

사용자 경험을 개선하기 위해 **Build Settings** 페이지를 재설계하였습니다.

* Studio Pro 10.18 MTS 지원은 호환성 문제로 인해 연기되었습니다

* (플랫폼) 화면 잠금 해제 후 로그아웃할 수 없던 문제를 수정하였습니다.
* 다음과 관련된 취약점을 수정하였습니다:

    * CVE-2025-48734
    * CVE-2025-4949
    * CVE-2025-27817

* (UI) 기타 사소한 UI 개선 및 수정을 진행하였습니다.
