## 소개

Excel을 사용하여 Mendix 애플리케이션에 대량의 데이터를 가져오고 내보내세요.

이 주제에 대해 제공되는 문서:

* [Excel 문서 가져오기](/refguide10/importing-excel-documents/)

    Excel Importer 모듈을 사용하여 가져오기 템플릿을 설정하고 앱에 데이터를 가져오는 방법을 설명합니다.

* [대용량 Excel 파일 가져오기](/refguide10/import-a-large-excel-file/)

    XML-to-domain 매핑을 사용하여 Excel 시트에서 새 가져오기 엔티티를 만드는 방법을 설명합니다.

* [Excel로 내보내기](/refguide10/using-the-excel-exporter/)

    구성 가능한 템플릿을 기반으로 앱에서 사용자 정의 Excel 문서를 만드는 방법을 설명합니다.
