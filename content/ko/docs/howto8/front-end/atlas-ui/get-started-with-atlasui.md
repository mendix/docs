{{% alert color="info" %}}
Atlas UI Resources 모듈은 더 이상 사용되지 않으며, Atlas 2도 마찬가지입니다. 아직 Atlas 2를 사용하고 있다면, Mendix는 [Atlas 2에서 Atlas 3으로 마이그레이션](/refguide9/moving-from-atlas-2-to-3/)하는 것을 권장합니다.
{{% /alert %}}

## 소개

이 사용 방법 가이드에서는 다음을 배우게 됩니다:

* 앱 템플릿 선택하기
* 페이지 템플릿 선택하기
* 테마 사용자 정의하기

## 사전 요구 사항

이 사용 방법 가이드를 시작하기 전에 다음 사전 요구 사항을 완료했는지 확인하십시오:

* Mendix 계정이 있어야 합니다 ([여기](https://www.mendix.com/try)에서 가입)

## 앱 템플릿 선택하기

[Apps](https://sprintr.home.mendix.com/index.html)에서 **Create App**을 클릭하십시오. **ATLAS UI**로 표시된 여러 앱이 보이며, 이들은 Atlas UI 기반 앱 템플릿입니다. 하나를 선택하여 시작할 수 있습니다.

{{< figure src="/attachments/howto8/front-end/atlas-ui/get-started-with-atlasui/start_choose_your_starter_app.png" alt="App template in Mendix Portal" class="no-border" >}}

Atlas UI에 대한 자세한 내용은 [Atlas UI](/howto8/front-end/atlas-ui/)를 참조하십시오.

## 페이지 템플릿 선택하기

새 페이지를 만들 때 페이지 템플릿을 선택할 수 있습니다.

예를 들어, **Dashboard Action Tiles**, **Dashboard Charts**, **Dashboard Expenses**는 페이지 템플릿입니다.

{{< figure src="/attachments/howto8/front-end/atlas-ui/get-started-with-atlasui/start_choose_a_page_template.png" alt="Page Template" class="no-border" >}}

페이지가 생성되면 사용자 정의할 수 있습니다.

## 테마 사용자 정의하기

**Theme Customizer**를 사용하면 앱을 사용자 정의할 수 있습니다.
