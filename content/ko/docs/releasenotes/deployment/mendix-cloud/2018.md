## December 2018

### December 1, 2018

#### Fixes

* 일부 사용자의 배포가 중단되는 문제를 수정했습니다. (Tickets, 76691,76700)

* 배포 접근 권한이 없는 앱 팀 구성원이 애플리케이션 상수를 볼 수 있었던 보안 문제를 수정했습니다. (Ticket 76171)
* 일부 사용자가 환경에 배포할 수 없었던 문제를 해결하고 수정했습니다. (Tickets 77060, 77122)

## October 2018

### October 30, 2018

#### Improvements

* Cloud v3 PostgreSQL 백업이 이제 `pg_dump` 버전 1.13으로 생성됩니다. 이 버전은 2018년 3월부터 PostgreSQL과 함께 배포되었습니다(PostgreSQL 10.3, 9.6.8, 9.5.12, 9.4.17, 9.3.22). 부작용으로 1.13 미만의 `pg_restore` 버전으로는 이러한 PostgreSQL 백업을 복원할 수 없습니다. 발생하는 오류는 `pg_restore: [archiver] unsupported version (1.13) in file header`입니다. 이 문제를 해결하려면 PostgreSQL 클라이언트 소프트웨어를 최신 버전의 `pg_dump` 및 `pg_restore`가 포함된 버전으로 업그레이드하세요.

### October 17, 2018

#### Improvements

* Mendix Cloud v4 애플리케이션에 대한 백업 다운로드를 일시 중지하고 재개할 수 있게 되었습니다.
* 스케일링 사용자 인터페이스를 더 직관적으로 개편했습니다. (Ticket 67557)
* 라이브 로깅이 때때로 멈추는 문제를 해결했습니다. 이 수정은 Internet Explorer를 제외한 모든 주요 브라우저에서 확인되었으며, Internet Explorer는 아직 조사 중입니다. (Ticket 66418)

#### Fixes

* 샌드박스 환경에서 서브도메인 유효성 검사 오류가 발생하던 문제를 수정했습니다. (Ticket 56574)

## August 2018

### August 21, 2018

#### Fixes

* 일부 Mendix Cloud v4 사용자가 환경 권한 설정을 변경한 후 알림 목록에서 구독 취소되던 버그를 수정했습니다.
* 일부 Mendix Cloud v4 사용자가 전날의 아카이브 로그를 볼 수 없었던 문제를 해결했습니다.

### August 13, 2018

#### Fixes

* 시작 실패 시 피드백 메시지를 개선했습니다.
* 알림 이메일의 상태 페이지 링크가 이제 Developer Portal의 해당 알림 페이지로 리다이렉트됩니다.
* 백업 생성 중 빈 오류 메시지가 발생하던 문제를 해결했습니다.

#### Improvements

* Mendix Cloud v4 애플리케이션의 로그에 접근하기 위한 새로운 API 호출을 사용할 수 있습니다. 자세한 정보는 [Deploy API](/apidocs-mxsdk/apidocs/deploy-api/)에서 확인하실 수 있습니다.
* Developer Portal에서 사용자 정의 환경 변수를 추가하여 Datadog 및 Telegraph로 애플리케이션 메트릭을 설정할 수 있습니다.
* Developer Portal의 모든 로그 수준(INFO, ERROR, TRACE, DEBUG, WARNING, CRITICAL)을 이제 Datadog에서도 사용할 수 있습니다.
* Developer Portal에서 활성화한 후 Postgres 데이터베이스 크기도 Datadog에서 확인할 수 있습니다.
* **Deploy** > **Environments** > 환경의 **Environments** 브레드크럼이 이제 **Environments** 페이지로 리다이렉트하는 링크입니다.

### August 9, 2018

#### Improvements

* Mendix Cloud v3 앱 또는 데이터베이스의 시스템 메모리가 부족할 때 알림이 전송됩니다.

### August 8, 2018

#### Improvements

지난 몇 달 동안 Mendix Cloud v4 애플리케이션의 알림 스택에 여러 가지 개선 사항을 적용하여 알림의 적시성을 향상시켰습니다. 그 결과, 런타임 하트비트 타임아웃을 15분에서 3분으로 줄이고 있습니다. 이는 실수로 알림을 놓치지 않도록 하기 위함입니다. 오탐(false positive)이 발생하는지 애플리케이션을 모니터링할 것입니다.

일부 경우에 런타임 하트비트 알림에 대한 오탐이 여전히 발생할 수 있습니다. 이 경우 앱을 전송한 다음 재시작하면 문제를 해결할 수 있습니다.

## March 2018

### March 21, 2018

#### Improvements

* Mendix Cloud v3에서 248일 이상 실행된 애플리케이션이 Mendix Runtime, JVM 또는 이들의 조합에서 알 수 없는 버그로 인해 100% CPU를 사용하기 시작했습니다. 대부분의 애플리케이션은 훨씬 더 자주 업데이트되고 모든 배포가 애플리케이션을 다시 시작하므로 매우 적은 수의 애플리케이션만 영향을 받았습니다. 그러나 이 문제는 영향을 받는 애플리케이션과 인프라 모두에 성능 문제를 일으키고 있었습니다. 해결 방법으로, 247일 동안 연속 실행된 앱을 클라우드 리전의 현지 시간 01:00에서 07:00 사이에 자동으로 재시작합니다. 이 경우 애플리케이션 로그에서 메시지를 확인하실 수 있습니다.

### March 20, 2018

#### Improvements

* Mendix Cloud v4 로드 밸런서에 대해 ICMP(ping) 패킷을 활성화했습니다. 이제 ping, traceroute, mtr과 같은 도구를 사용하여 현재 위치에서 Mendix Cloud v4 애플리케이션까지의 연결 문제를 디버깅할 수 있습니다. 패킷은 실제 애플리케이션이 아닌 로드 밸런서에만 도달합니다. 로드 밸런서와 애플리케이션 사이의 지연 시간은 낮은 한 자릿수 밀리초를 예상하실 수 있습니다.

### March 16, 2018

#### Fixes

* Mendix Cloud v4 애플리케이션 사용자는 이제 환경 정리가 제대로 되지 않은 경우 알림을 받게 됩니다.
* 새로 생성된 Mendix Cloud v4 애플리케이션의 상태가 빨간 십자 표시로 반영되던 문제가 수정되었습니다.

#### Improvements

* Mendix Cloud v4 애플리케이션의 데이터베이스 저장 공간 알림을 개선했습니다. 앱 알림을 구독한 경우, 앱 데이터베이스의 디스크 공간이 25% 미만일 때 경고 알림을, 10% 미만일 때 위험 알림을 받게 됩니다. 이 알림을 활성화하려면 앱을 다시 배포해야 합니다.
* Mendix Cloud v4 애플리케이션의 라이브 로깅이 출시되었습니다! 이제 실시간으로 로그를 깔끔하게 확인할 수 있습니다.

### March 13, 2018

#### Improvements

* Mendix Cloud에서 *.mendixcloud.com*, *.mxapps.io*, *.mendix.com*에 대한 SSL/TLS 인증서를 갱신했습니다.

### March 1, 2018

#### Fixes

* Mendix Cloud v3 앱의 **Metrics** 메뉴에서 환경 전환 문제가 수정되었습니다.
* Mendix Cloud v3 사용자가 최신 야간 백업을 볼 수 없던 동기화 문제를 수정했습니다.

## February 2018

### February 27, 2018

#### Fixes

* Mendix Cloud v3에서 백업 업로드 시 **Restore** 버튼을 더블클릭하면 UI가 중단되던 문제가 수정되었습니다.

### February 23, 2018

#### Improvements

* Mendix Cloud v4에서 애플리케이션의 네이티브 메모리 사용량이 매우 높았습니다. 이로 인해 특히 1GB 메모리의 컨테이너에서 충돌 및 자동 재시작이 발생했습니다. glibc에 대한 고급 메모리 제한 설정(`MALLOC_ARENA_MAX`)을 활성화하여 이 동작을 방지합니다. 이 수정은 오늘부터 전송 및 재시작되는 모든 앱에 자동 적용됩니다.

### February 22, 2018

#### Improvements

* 인기 있는 피드백 항목을 구현했습니다 – 이제 플랫폼이 화면 전환 시 선택한 환경을 기억합니다.
* 이제 Mendix Cloud v4 애플리케이션의 **DB Plan Space**, **Plan Cores**, **Plan Memory**와 같은 데이터베이스 세부 정보를 확인할 수 있습니다.
* Mendix 7 앱의 스케일링이 간소화되고 빨라졌습니다.

#### Fixes

* 백업 생성이 활동 피드에서 백업 복원 작업으로 보고되던 문제가 수정되었습니다.
* 백업 페이지를 볼 때마다 백업 활동 항목이 추가되던 문제를 해결했습니다.
* 일부 사용자에게 환경 세부 정보 목록이 느리게 로드되던 문제가 수정되었습니다.

### February 19, 2018

#### Improvements

* Mendix Cloud v4에서 느린 데이터베이스 쿼리 로깅을 활성화했습니다. 이것은 사용자 정의 런타임 설정 `LogMinDurationQuery`이며, 애플리케이션의 성능 병목 현상을 찾는 데 유용합니다. 값은 기본값 10,000ms로 설정되어 있으며, 이는 Mendix Cloud v3에서도 사용되던 값입니다. **Environments** 아래 환경 세부 정보 화면의 **Runtime** 탭을 사용하여 이 설정을 사용자 정의할 수 있습니다. Mendix Cloud 환경에서 이 기능을 사용하려면 배포 패키지를 전송하고 앱을 재시작하세요.

## January 2018

### January 25, 2018

#### Fixes

* **Environments** 섹션에서 Free App의 대상 클라우드가 이제 올바르게 표시됩니다.
