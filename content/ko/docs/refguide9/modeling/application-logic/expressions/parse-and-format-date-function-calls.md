## 소개 

이 문서에서는 지정된 패턴을 사용하여 문자열에서 Date and time 값을 파싱하거나 Date and time 값에서 문자열을 생성하는 데 사용되는 함수를 설명합니다.

다음 패턴 문자를 사용하여 Date and time 값을 파싱하고 포맷할 수 있습니다:

| 문자 | 날짜 또는 시간 구성 요소                    | 예제               |
| ------ | ----------------------------------------- | ---------------------- |
| M      | 연도 내 월 (문맥 감지)         | November; Nov; 11      |
| L      | 연도 내 월 (독립형)                | November; Nov; 11      |
| y      | 연도                                      | 2001; 01               |
| G      | 시대 표시자                            | AD                     |
| E      | 요일 이름                          | Tuesday; Tue           |
| u      | 요일 (1 = 월요일, ..., 7 = 일요일) | 5                      |
| Y      | 주 연도                                 | 2009; 09               |
| w      | 연도 내 주                              | 11                     |
| W      | 월 내 주                             | 2                      |
| D      | 연도 내 일                               | 133                    |
| d      | 월 내 일                              | 7                      |
| F      | 월 내 요일                      | 1                      |
| a      | 오전/오후 표시자                              | PM                     |
| H      | 일 내 시간 (0-23)                        | 0                      |
| k      | 일 내 시간 (1-24)                        | 24                     |
| K      | 오전/오후 내 시간 (0-11)                      | 0                      |
| h      | 오전/오후 내 시간 (1-12)                      | 12                     |
| m      | 시간 내 분                            | 24                     |
| s      | 분 내 초                          | 50                     |
| S      | 밀리초                               | 201                    |

{{% alert color="info" %}}
Microflow에서는 패턴 문자 `M`과 `L`이 모두 지원되며 예상대로 완전히 작동합니다.

그러나 Nanoflow에서는 현재 패턴 문자 `M`이 제대로 지원되지 않으므로 일반적으로 사용하지 않아야 합니다. 한 가지 예외는 `MM`을 사용할 수 있다는 것인데, 이는 월 이름의 숫자 표현을 제공하기 때문입니다.

Nanoflow에서 패턴 문자 `L`은 문맥에 따라 월 이름이 변경되는 일부 언어(격변화가 있는 언어)를 제외하고는 제대로 작동합니다. 이러한 언어의 경우 더 많은 문자(예: `LLL` 또는 `LLLL`)를 사용하면 패턴 문자 `L`이 제대로 작동하지 않을 수 있으므로 문자 제한은 `LL`로 하는 것이 좋습니다. 예를 들어, `LLL`은 러시아어에서는 작동하지만 카탈로니아어에서는 작동하지 않습니다. `LLLL`은 이러한 언어에 권장되지 않습니다.

다음은 Studio Pro에서 사용 가능한 해당 언어의 전체 목록입니다: 아르메니아어, 벨라루스어, 카탈로니아어, 크로아티아어, 체코어, 핀란드어, 그리스어, 리투아니아어, 폴란드어, 러시아어, 슬로바키아어, 우크라이나어.
{{% /alert %}}

다음 패턴 문자는 Microflow에서만 사용할 수 있습니다:

| 문자 | 날짜 또는 시간 구성 요소                    | 예제                              |
| ------ | ----------------------------------------- | ------------------------------------- |
| z      | 시간대                                 | Pacific Standard Time; PST; GMT-08:00 |
| Z      | 시간대                                 | -0800                                 |
| X      | 시간대                                 | -08; -0800; -08:00                    |

## parseDateTime[UTC] {#parsedatetime-utc}

문자열을 받아 파싱합니다. 실패하고 기본값이 지정된 경우 기본값을 반환합니다. 그렇지 않으면 오류가 발생합니다. `parseDateTime` 함수는 사용자의 시간대를 사용하고 `parseDateTimeUTC`는 UTC 캘린더를 사용합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                        | 유형                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| 날짜                         | 날짜의 텍스트 표현이 포함된 문자열 — 예: `dd/MM/yyyy` 또는 `MM/dd/yyyy` |
| 형식                       | String                                                       |
| 기본값 (**선택 사항**) | Date and time                                                |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형          |
| ------------------------------------------------------------ | ------------- |
| 파싱된 날짜 또는 날짜를 파싱할 수 없는 경우 기본값입니다. | Date and time |

{{% alert color="info" %}}
`Date` 문자열이 날짜와 유사하지만 유효한 날짜가 아닌 경우, 함수는 이를 파싱하고 유효한 `Date and time` 값을 반환할 수 있습니다.

예를 들어 `parseDateTime('35-11-2015', 'dd-MM-yyyy', dateTime(2015))`는 `05 December 2015 12:00 AM`을 반환합니다.
{{% /alert %}}

### 예제

아래 예제는 Expression이 반환하는 값을 보여줍니다:

* 다음 입력을 사용하는 경우:

    ```java
    parseDateTime('2022-04-30T22:00:00.000', 'yyyy-MM-dd''T''HH:mm:ss.SSS')
    ```

    출력은 다음과 같습니다:

    ```java
    Apr 30 2022 22:00:00
    ```

    시간이 지정되지 않으면 00:00이 됩니다.
    
* 다음 입력을 사용하는 경우:

    ```java
    parseDateTime('noDateTime', 'dd-MM-yyyy', dateTime(2007))
    ```

    출력은 다음과 같습니다:

    ```java
    Mon Jan 01 00:00:00 CET 2007
    ```

## formatDateTime[UTC]{#format-datetime-utc}

Date and time 값을 형식 매개변수에 따라 포맷된 문자열로 변환합니다. 형식 매개변수가 없으면 [Java 버전](/refguide/java-version-migration/#date-locale-dutch) 및 사용자 로케일에 따라 달라지는 표준 형식이 사용됩니다. `formatDateTime` 함수는 사용자의 캘린더를 사용하고 `formatDateTimeUTC`는 UTC 캘린더를 사용합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                 | 유형          |
| --------------------- | ------------- |
| 날짜                  | Date and time |
| 형식 (**선택 사항**) | String        |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                       | 유형   |
| ------------------------------------------- | ------ |
| Date and time 값의 포맷된 표현입니다. | String |

### 예제

다음 입력을 사용하는 경우:

```java
formatDateTime($object/Date1,'EEE, d MMM yyyy HH:mm:ss Z')
```

출력은 다음과 같습니다:

```java
'Sun, 8 Jun 2008 10:12:01 +0200'
```

`'2008-06-08T10:12:01'`과 같은 형식을 얻으려면 두 개의 formatDateTime[UTC] 함수를 연결해야 합니다:

```java
formatDateTime($object/Date1,'yyyy-MM-dd') + 'T' + formatDateTime($object/Date1,'HH:mm:ss')
```

## formatTime[UTC]

Date and time 값의 시간 부분을 Java 버전 및 사용자 로케일에 따라 달라지는 표준 형식의 문자열로 변환합니다. `formatTime`은 사용자의 캘린더를 사용하고 `formatTimeUTC`는 UTC 캘린더를 사용합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값 | 유형          |
| ----- | ------------- |
| 날짜  | Date and time |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형   |
| ------------------------------------------------------------ | ------ |
| Date and time 값의 시간 부분의 포맷된 표현입니다. | String |

### 예제

다음 입력을 사용하는 경우:

```java
formatTime(dateTime(1974, 7, 2, 9, 50, 10))
```

출력은 다음과 같습니다:

```java
'9:50 AM'
```

## dateTimeToEpoch

1970년 1월 1일 00:00:00 GMT부터 해당 날짜까지의 밀리초 수를 반환합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값 | 유형          |
| ----- | ------------- |
| 날짜  | Date and time |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형   |
| ------------------------------------------------------------ | ------ |
| 1970년 1월 1일 00:00:00 GMT부터 해당 날짜까지의 밀리초 수입니다. | Integer/Long |

### 예제

다음 입력을 사용하는 경우:

```java
dateTimeToEpoch(dateTime(1974, 7, 2, 9, 50, 10))
```

출력은 다음과 같습니다:

```java
141990610000
```

## epochToDateTime

1970년 1월 1일 00:00:00 GMT 이후 지정된 밀리초 수를 나타내는 Date and time을 생성합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값 | 유형          |
| ----- | ------------- |
| Epoch | Integer/Long |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형   |
| ------------------------------------------------------------ | ------ |
| 1970년 1월 1일 00:00:00 GMT 이후 지정된 밀리초 수를 나타내는 Date and time입니다. | Date and time |

### 예제

다음 입력을 사용하는 경우:

```java
epochToDateTime(141990610000)
```

출력은 다음과 같습니다:

```java
dateTime(1974, 7, 2, 9, 50, 10)
```
