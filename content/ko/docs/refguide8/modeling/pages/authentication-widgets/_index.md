## 소개

인증 위젯은 사용자를 로그인시키고 로그아웃하는 데 사용됩니다.

[내비게이션 프로필 설정](/refguide8/navigation/#authentication)을 사용하여 사용자를 올바른 인증 페이지로 안내하세요.

**인증 위젯** 카테고리에는 다음 위젯이 포함되어 있습니다:

* [Login ID 텍스트 박스](/refguide8/login-id-text-box/) – 사용자가 인증을 위한 로그인 ID를 제공할 수 있습니다

    {{< figure src="/attachments/refguide8/modeling/pages/authentication-widgets/logid-id-example.png" alt="Login ID Text Box Example" class="no-border" >}}

* [Password 텍스트 박스](/refguide8/password-text-box/) – 사용자가 인증을 위한 비밀번호를 제공할 수 있습니다

    {{< figure src="/attachments/refguide8/modeling/pages/authentication-widgets/password-text-box-example.png" alt="Password Text Box Example" class="no-border" >}}

* [Sign-in 버튼](/refguide8/sign-in-button/) – 사용자의 로그인 ID와 비밀번호를 서버로 전송하여 인증합니다
    {{< figure src="/attachments/refguide8/modeling/pages/authentication-widgets/sign-in-button-example.png" alt="Sign-In Button Example" class="no-border" >}}

* **Sign-out 버튼** – 현재 로그인한 사용자를 로그아웃합니다. Sign-out 버튼은 클릭 이벤트가 **Sign out**으로 설정된 버튼입니다. 클릭 이벤트에 대한 자세한 내용은 [클릭 이벤트 및 이벤트 섹션](/refguide8/on-click-event/)을 참조하세요. 버튼 속성에 대한 자세한 내용은 [버튼 속성](/refguide8/button-properties/)을 참조하세요.

* [유효성 검사 메시지](/refguide8/validation-message/) – 인증 실패가 있을 경우 사용자에게 알립니다

    {{< figure src="/attachments/refguide8/modeling/pages/authentication-widgets/validation-message-example.png" alt="Validation Message Example" class="no-border" >}}
