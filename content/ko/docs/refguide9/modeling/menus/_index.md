## 소개

Studio Pro의 상단 바에는 다음과 같은 메뉴가 포함되어 있습니다:

{{< figure src="/attachments/refguide9/modeling/menus/menu-bar.png" alt="Menu-bar" class="no-border" >}}

* [Global Navigation Menu](#global-navigation-menu) – 플랫폼의 다른 부분으로 이동할 수 있습니다
* [File](#file) – 문서와 앱을 관리할 수 있습니다
* [Edit](#edit) – Studio Pro 내에서 검색 또는 복사와 같은 편집 기능을 수행할 수 있습니다
* [View](#view) – Studio Pro와 Studio Pro 내의 도킹 가능한 창의 표시 방식을 선택할 수 있습니다
* [App](#app) – 앱 전체 설정이 포함되어 있습니다
* [Run](#run) – 앱 배포 및 모니터링을 위한 작업이 포함되어 있습니다
* [Version Control](#version-control) – 버전 관리 설정이 포함되어 있습니다
* [Language](#language) – 언어 및 번역 설정이 포함되어 있습니다
* [Help](#help) – 문서를 보거나, [Mendix Community](https://community.mendix.com/p/questions)에 접속하거나, 로그 파일 디렉토리를 열거나, Studio Pro의 현재 정보를 확인할 수 있습니다

## Global Navigation Menu {#global-navigation-menu}

**Global Navigation Menu** 메뉴는 Studio Pro의 좌측 상단에 위치하며 9개의 점 아이콘으로 표시됩니다. 새 브라우저 창에서 열리는 플랫폼의 다양한 부분에 대한 링크가 포함되어 있습니다. **Global Navigation Menu** 메뉴에 대한 자세한 내용은 [Global Navigation](/portal/global-navigation/)을 참조하십시오.

## File 메뉴 {#file}

**File** 메뉴를 통해 문서와 앱을 관리할 수 있습니다. **File** 메뉴에 대한 자세한 내용은 [File Menu](/refguide9/file-menu/)를 참조하십시오.

## Edit 메뉴 {#edit}

**Edit** 메뉴에서는 잘라내기/복사/붙여넣기 등의 편집 기능을 수행할 수 있습니다. 이 메뉴를 통해 [환경 설정](/refguide9/preferences-dialog/)도 지정할 수 있습니다. **Edit** 메뉴에 대한 자세한 내용은 [Edit Menu](/refguide9/edit-menu/)를 참조하십시오.

## View 메뉴 {#view}

**View** 메뉴에서는 도킹 가능한 창을 확인하고, 전체 화면 모드를 활성화하며, 앱 레이아웃을 초기화할 수 있습니다. **View** 메뉴와 해당 항목에 대한 자세한 내용은 [View Menu](/refguide9/view-menu/)를 참조하십시오.

## App 메뉴 {#app}

**App** 메뉴에서는 앱 및 배포와 관련된 설정을 확인하거나 조작할 수 있습니다. **App** 메뉴에 대한 자세한 내용은 [App Menu](/refguide9/app-menu/)를 참조하십시오.

## Run 메뉴 {#run}

**Run** 메뉴에는 **Publish**, **Run Locally**, **Debugger** 등 앱 배포 및 모니터링을 위한 작업이 포함되어 있습니다. **Run** 메뉴에 대한 자세한 내용은 [Run Menu](/refguide9/run-menu/)를 참조하십시오.

## Version Control 메뉴 {#version-control}

**Version Control** 메뉴에서는 버전 관리 관련 설정을 확인하거나 조작할 수 있습니다. **Version Control** 메뉴에 대한 자세한 내용은 [Version Control Menu](/refguide9/version-control-menu/)를 참조하십시오.

## Language 메뉴 {#language}

**Language** 메뉴에서는 최종 사용자가 원하는 언어로 앱을 볼 수 있도록 대체 언어를 추가할 수 있습니다. 하나의 언어로만 작업하는 경우에도 동일한 텍스트를 일괄 변경할 수 있습니다. **Language** 메뉴에 대한 자세한 내용은 [Language Menu](/refguide9/translatable-texts/)를 참조하십시오.

## Help 메뉴 {#help}

| 메뉴 항목                   | 설명                                                                                                                                             | 단축키  |
|-----------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------|---------------|
| **Help**                    | 현재 선택된 요소에 대한 문서 페이지를 엽니다. 예를 들어 Entity가 선택되어 있으면 Entity에 대한 문서가 표시됩니다. | <kbd>F1</kbd> |
| **Help Contents**           | 기본 웹 브라우저에서 문서 홈 페이지를 엽니다.                                                                                    |               |
| **Ask a Question**          | 기본 웹 브라우저에서 Mendix Community를 엽니다.                                                                                                  |               |
| **Submit Feedback...**      | [Help us improve](/refguide9/feedback-survey/) 대화 상자를 열어 Mendix Studio Pro 사용 경험에 대한 피드백을 수집합니다.                             |               |
| **Open Log File Directory** | 로컬에서 앱의 로그 파일을 엽니다.                                                                                                               |               |
| **About Mendix Studio Pro** | 현재 Mendix Studio Pro 버전에 대한 정보를 표시합니다.                                                                                       |               |
