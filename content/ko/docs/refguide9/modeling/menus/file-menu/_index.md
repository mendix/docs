## 소개

**File** 메뉴에서는 문서와 앱을 관리할 수 있습니다. 예를 들어 새 앱을 생성하거나 변경 사항을 저장할 수 있습니다:

{{< figure src="/attachments/refguide9/modeling/menus/file-menu/file-menu.png" alt="File Menu" class="no-border" >}}

## 메뉴 항목 개요 {#overview}

**File** 메뉴 항목은 아래 표에 설명되어 있습니다:

| 메뉴 항목                  | 설명                                                  | 단축키                                      |
| -------------------------- | ------------------------------------------------------------ | ------------------------------------------------- |
| **New Document**           | 현재 열려 있는 앱 내에 새 문서를 생성합니다. 문서의 이름, 위치 및 유형을 선택할 수 있습니다. 문서 유형에 대한 자세한 내용은 [Modules](/refguide9/modules/)를 참조하십시오. | <kbd>Ctrl</kbd> + <kbd>N</kbd>                    |
| **New App**            | 새 단일 개발자 앱을 생성합니다. 단일 개발자 앱은 로컬 파일 시스템에 저장되는 파일(확장자 *.mpr*)입니다. 자세한 내용은 [New App](/refguide9/new-app/)을 참조하십시오. | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd> |
| **Open App**           | 기존 단일 개발자 앱(*.mpr*) 또는 앱 패키지(*.mpk*)를 엽니다. 단일 개발자 앱에 대한 정보는 위의 **New App**을 참조하십시오. 자세한 내용은 [Open App](/refguide9/open-app-dialog/)을 참조하십시오. | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> |
| **Recent Apps**        | 빠르게 열 수 있도록 최근에 열린 앱 목록을 표시합니다.  |                                                   |
| **Save**                   | 현재 활성 문서 탭의 변경 사항을 저장합니다.      | <kbd>Ctrl</kbd> + <kbd>S</kbd>                    |
| **Save All**               | 열려 있는 모든 문서의 변경 사항을 저장합니다.            | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> |
| **Close**                  | 현재 문서를 닫습니다. 필요한 경우 변경 사항을 저장하거나 취소하라는 메시지가 표시됩니다. | <kbd>Ctrl</kbd> + <kbd>W</kbd>                    |
| **Close All**              | 모든 문서 탭을 닫습니다. 필요한 경우 변경 사항을 저장하거나 취소하라는 메시지가 표시됩니다. | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> |
| **Close App**          | 현재 열려 있는 앱을 닫고 홈 페이지로 돌아갑니다. |                                                   |
| **Export as Image**        | 현재 문서를 *.png* 형식의 이미지로 내보냅니다. Domain Model, Workflow, Microflow, Nanoflow, 규칙 및 문서 템플릿 유형의 문서를 이미지로 내보낼 수 있습니다. |                                                   |
| **Export App Package** | 현재 앱을 패키지(*.mpk*) 파일로 내보냅니다. 예를 들어 다른 사람에게 전체 앱을 제공하거나 티켓을 제출할 때 테스트 앱을 제공해야 할 때 유용합니다. 자세한 내용은 [Export App Package](/refguide9/export-app-package-dialog/)를 참조하십시오. |                                                   |
| **Import App Package** | **Export App Package** 메뉴 항목으로 생성된 패키지를 가져옵니다. 자세한 내용은 [Import App Package](/refguide9/import-app-package-dialog/)를 참조하십시오. |                                                   |
| **Exit**                   | Studio Pro를 종료합니다                                            |                                                   |
