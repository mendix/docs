## December 2024

### December 12, 2024

#### Improvements

* Alerts 페이지의 레이아웃과 표시를 개선했습니다. 새 레이아웃은 심각도와 날짜를 기반으로 알림을 정렬하고 필터링할 수 있으며 자유 텍스트 검색도 가능합니다. 
* 이제 설정 탭에서 알림 이메일을 구독할 수 있습니다. 자세한 내용은 [Alerts](/developerportal/operate/monitoring-application-health/)를 참조하세요.

### December 5, 2024

#### Improvements

* 클라우드 리소스 팩 구매를 위한 cloud token을 도입했습니다! 이제부터 클라우드 리소스 구매를 완료하기 위해 cloud credit 대신 [cloud tokens](/control-center/cloud-tokens/#cloud-tokens)를 사용합니다. Cloud credit에서 cloud token으로의 전환을 통해, Mendix는 Mendix Cloud 제품의 구매 및 전환에 대해 보다 간소화되고 유연한 접근 방식의 기반을 마련하고 있습니다.

### December 1, 2024

#### API Retirement

* Team Server API를 폐지했습니다. 이제 [App Repository API](/apidocs-mxsdk/apidocs/app-repository-api/)를 대신 사용해야 합니다.

## November 2024

### November 29, 2024

#### New Features

* Software Composition을 향상시켜 마켓플레이스 관련 메타데이터를 포함하도록 했습니다. 이제 [All Components](/developerportal/deploy/software-composition/#all-components) 탭과 [Deployed Package Details](/developerportal/deploy/software-composition/#deployed-package-details) 페이지 모두에서 이 추가 정보를 확인하여 컴포넌트에 대한 보다 포괄적인 개요를 볼 수 있습니다.

### November 17, 2024

#### Deployment Portal Fixes

* [레거시 UI의 Permissions 탭](/developerportal/deploy/environments/#permissions-tab)에서 애플리케이션의 Technical Contact를 변경하면 빈 페이지가 되는 버그를 수정했습니다.
* [새 UI](/developerportal/deploy/environments/)에서 확장 불가능한 환경에 **scalable** 태그가 표시되는 버그를 수정했습니다.
* 다크 모드 관련 기타 여러 버그를 수정했습니다.

### November 6, 2024

#### New Features

* Cloud 권한이 이제 프로젝트 역할에 포함됩니다.
* 회사 수준 역할 사용으로 전환한 경우 이제 회사 수준에서 모든 프로젝트 역할을 중앙에서 관리할 수 있습니다.

#### Improvements

* [권한 탭](/developerportal/deploy/node-permissions/#permissions-tab)을 개선했습니다. **Receive alerts** 권한도 권한 탭에서 제거되었습니다. **Alerts** 페이지의 **Email Alerts** 옵션을 사용하여 알림을 구독할 수 있습니다.

## October 2024

### October 17, 2024

#### Improvements

* [Software Composition](/developerportal/deploy/software-composition/)의 성능을 개선했습니다. 배포 패키지 생성 시 자동으로 생성되는 Software Bills of Materials(SBOM)가 이제 몇 분 내에 **Software Composition** 페이지에 표시됩니다.

## September 2024

### September 5, 2024

#### New Features

* [Software Composition](/developerportal/deploy/software-composition/) 페이지에 고유 식별 및 간편한 공유를 위한 딥 링크를 추가했습니다.

### September 3, 2024

#### Improvements

* 최근 배포 패키지 생성 중 발생하는 Software Bill of Materials(SBOM) 생성 프로세스에서 성능 문제가 확인되었습니다. Mendix는 이 문제를 해결하여 SBOM 생성 및 관련 Software Composition 기능이 이제 다음 Studio Pro 버전과 완전히 호환됩니다: 9.24.26 이상, 10.6.12 이상, 10.12.3 이상.
  
    이전에 지원되던 Studio Pro 버전(9.24.22~9.24.25, 10.6.9~10.6.11, 10.10.0~10.12.2, 10.13)에서는 더 이상 SBOM 생성 및 [Software Composition](/developerportal/deploy/software-composition/)에서의 가시성이 제공되지 않습니다. Software Composition을 계속 사용하려면 호환되는 Studio Pro 버전으로 업그레이드하세요. Software Composition 내의 모든 기록 데이터는 업그레이드 여부와 관계없이 접근 가능합니다.

## July 2024

### July 16, 2024

#### Improvements

* 다음 클라우드 리소스 팩에 대한 [Database Freeable Memory 알림 임계값](/developerportal/operate/monitoring-application-health/#dbase-freeable-memory)을 변경했습니다:
    * XS21: 위험 알림 임계값이 10%에서 5% freeable memory로 변경되었습니다.
    * XS20 (Legacy): 위험 알림 임계값이 10%에서 5% freeable memory로 변경되었습니다.
    * S (Legacy): 위험 알림 임계값이 10%에서 5% freeable memory로 변경되었습니다.
    * Strato (Legacy): 위험 알림 임계값이 10%에서 5% freeable memory로 변경되었습니다.

## May 2024

### May 14, 2024

#### New Features

* Mendix Public Cloud의 모든 플랜에서 새 환경의 데이터베이스에 최고의 성능을 위해 Arm 기반 AWS Graviton 2 프로세서를 사용합니다. Graviton 2 프로세서는 이전 세대 인스턴스에 비해 상당한 성능 향상을 제공할 수 있습니다. 데이터베이스 작업의 경우 쿼리 처리 속도가 빨라지고 동시 요청 처리가 개선됩니다.

    기존 환경은 자동으로 Graviton 2 프로세서를 사용하지 않습니다. Graviton 2 프로세서는 새 환경 및 지워지거나, 축소되거나, 크기가 조정된 환경에 사용됩니다.

## April 2024

### April 25, 2024

#### Metrics Improvements

* 이전에 **Metrics** 페이지는 처음 열 때 **Day** 기간과 **Application** 메트릭 그룹을 표시했습니다. 이제 사용자가 마지막으로 선택한 메트릭 기간(**Day**, **Week**, **Month**, **Quarter**)과 그룹(**Application**, **Database**, **All**)으로 페이지가 열립니다. 표시는 환경이나 앱 이력이 아닌 사용자 이력에 따라 달라집니다. 이전과 마찬가지로 **Metrics** 페이지의 **Period** 및 **Group** 드롭다운 메뉴를 통해 메트릭 기간과 그룹을 전환할 수 있습니다.
* **Metrics** 페이지에서 전체 페이지를 한 번에 로드하는 대신 각 그래프를 비동기적으로 로드합니다. 이를 통해 페이지 로딩 시간이 단축되어 사용자 경험이 개선됩니다.
* **Metrics** 페이지 상단으로 빠르게 스크롤할 수 있는 방법을 추가했습니다. 각 그래프 옆에 **Scroll to top** 버튼({{% icon name="arrow-circle-up" %}})이 있어 클릭하면 페이지 상단으로 바로 이동합니다.

### Deprecations

* *Application Container CPU Percentage* 알림은 너무 자주 트리거되어 유용하지 않아 지원을 중단했습니다. CPU 사용 데이터는 여전히 **Metrics** 페이지에서 확인할 수 있습니다.

## March 2024

### March 26, 2024

#### Improvements

* Mendix Cloud의 적격 플랜에 있는 모든 환경의 데이터베이스가 gp3 스토리지 인스턴스로 마이그레이션되었습니다(아래 표 참조). gp2에 비해 gp3는 더 높은 기본 스토리지 성능을 제공합니다. 자세한 내용은 *Metrics* 문서의 [Database IOPS Burst Balance](/developerportal/operate/metrics/#Trends-dbmxdatabaseburstbalance)를 참조하세요.

    | Storage Size           | Storage Instance Type | Baseline Storage Performance      | Provisioned IOPS Range | Provisioned Throughput Range |
    | ---------------------- | --------------------- | --------------------------------- | ---------------------- | ---------------------------- |
    | Less than 20 GiB       | gp2                   | 100 IOPS (3000 Burst) / 125 MiB/s | 100 - 1197 IOPS        | 128-250 MiB/s                |
    | Between 20 and 400 GiB | gp3                   | 3000 IOPS / 125 MiB/s             | N/A                    | N/A                          |
    | 400 GiB and higher     | gp3                   | 12000 IOPS / 500 MiB/s            | 12000 - 64000 IOPS     | 500 - 4000 MiB/s             |

### March 7, 2024

#### Bug Fixes

* **Metrics** 그래프의 일부 렌더링 문제를 수정했습니다: 
    * 일부 데이터 포인트가 누락되면 모든 기존 데이터 포인트가 그래프 왼쪽으로 이동했습니다. 이제 모든 데이터 포인트가 올바른 위치에 표시됩니다.
    * 누락된 데이터 포인트가 있을 때 그래프의 스케일이 변경되었습니다. 이제 스케일이 고정되었습니다.

#### Improvements

* 필요할 때 2단계 인증 설정을 더 쉽게 재설정할 수 있도록 **Logs** 및 **Metrics** 페이지에 해당 설정으로의 링크를 추가했습니다. 이 링크는 2FA가 필요한 페이지에 접근하려고 할 때 표시됩니다.

## February 2024 

### February 19, 2024

#### Bug Fixes

* **Metrics** 페이지의 [JVM object heap 그래프](/developerportal/operate/metrics/#Trends-appmxruntimejvmheap)에서 레이블 중 하나를 수정했습니다. 네이티브 메모리가 아닌 survivor space를 표시합니다.

### February 8, 2024

#### Bug Fixes

* **Logs** 페이지에서 빈 줄을 제거했습니다. 
* **Metrics** 페이지에서 애플리케이션과 데이터베이스 메트릭을 함께 볼 때, 이제 함께 표시되는 대신 분리되어 표시됩니다. **Logs** 페이지에서 이제 모든 애플리케이션 메트릭 그래프가 먼저 표시되고, 그 다음에 데이터베이스 메트릭 그래프가 표시됩니다.
* **Environments** 드롭다운 목록이 Developer Portal의 **Environments** 페이지와 동일한 정렬 순서를 유지합니다.

## January 2024 

### January 31, 2024 

#### Improvements

* Mendix Cloud 아시아 태평양에 새로운 배포 대상으로 AWS Osaka, Seoul, Jakarta 리전을 추가했습니다.
* 일본(도쿄 및 오사카)에서의 regional fallback 지원을 추가했습니다.

### January 18, 2024

#### Bug Fixes

* **Metrics** 및 **Logs** 페이지에서 2단계 인증(2FA) 관련 문제를 수정했습니다. 2FA는 이제 계정 수준이 아닌 세션 기반입니다.
* 메모리 관련 메트릭 그래프가 이제 기가바이트(GB)가 아닌 기비바이트(GiB)로 표시됩니다.
