이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.9에 적용된 변경 사항을 다루고 있습니다.

## 1.9.0

### 릴리스 날짜: 2024년 5월 10일

Private Mendix Platform 버전 1.9.0에서는 플랫폼 및 개발자 경험을 개선하는 다수의 새로운 기능, 엔지니어링 개선 사항 및 기능 확장이 도입되었습니다.

#### 새로운 기능

##### 향상된 오류 처리

오류가 이제 심각도에 따라 등급이 매겨지고 보다 적절한 UX가 제공됩니다. 오류 메시지는 더 상세하고 설명적이며, 더 쉬운 문제 해결을 위해 로그 메시지를 추적하는 데 사용할 수 있는 고유한 오류 코드를 포함합니다.

##### Container Image 지원

Kubernetes CI 옵션은 이제 빌드 프로세스의 결과로 Docker Container Image(OCI)를 출력하는 것도 지원합니다. 이를 통해 배포 오케스트레이션을 위해 Container Image를 표준화하는 엔터프라이즈 고객이 Private Mendix Platform 프로젝트를 해당 워크플로에 원활하게 통합할 수 있습니다.

##### 사용자 사전 프로비저닝을 위한 SCIM

이제 SCIM 표준을 사용하여 플랫폼에 사용자를 사전 프로비저닝할 수 있습니다. 최초 SSO 로그인을 기다리는 대신, 관리자는 IdP에서 선택한 사용자로 Private Mendix Platform을 미리 채울 수 있습니다. 이는 SCIM 표준을 따릅니다.

#### 개선 사항

##### 확장된 알림

Private Mendix Platform 버전 1.9.0에서는 플랫폼 전반에 걸쳐 알림이 대폭 확장되었습니다. 더 많은 이벤트가 이제 알림을 트리거하여 개발자에게 보다 풍부하고 인터랙티브한 경험을 제공합니다.

##### Build Image 간소화

이전 버전에서는 빌드 이미지가 다양한 소스에서 Container Image를 가져와 빌드 프로세스 중에 결합해야 했습니다. 에어갭 인스턴스에서는 모든 외부 이미지를 개별적으로 로컬에 미러링해야 했습니다. 앞으로 이러한 이미지는 간소화되어 하나로 결합되고, Mendix의 이미지 레지스트리에 호스팅되며, 로컬 저장소로 쉽게 마이그레이션할 수 있습니다.

##### 엔지니어링 개선

###### Private Mendix Platform을 Mendix 버전 10.6으로 업그레이드

Private Mendix Platform 포털에서 사용하는 기본 Mendix 애플리케이션이 Mendix Runtime 버전 10.6(MTS)으로 업그레이드되어 보안이 향상되었으며, 새로운 Mendix 10 기능으로 제품을 지속적으로 개선할 수 있게 되었습니다.

###### 이메일 고유성 적용

관리자는 더 이상 동일한 이메일로 여러 사용자를 생성할 수 없습니다 - 하나의 이메일은 하나의 사용자에게만 사용할 수 있습니다. 고유한 이메일은 플랫폼에서 사용자를 더 잘 식별하는 데 도움이 됩니다.

##### 기타 개선 사항

###### 일반 개선 사항

* GitLab 서비스 자격 증명은 API 토큰만 필요합니다.
* Kubernetes CI Pipeline이 `git curl aws` 및 `oci`에 대한 자체 서명 인증서를 지원합니다.
* Svix가 버전 1.21.0으로 업그레이드되었습니다.
* Mendix Operator가 버전 2.15.1로 업그레이드되었습니다.

###### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.20](/releasenotes/studio-pro/9.24/#92420)으로 업데이트되었습니다
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.7](/releasenotes/studio-pro/10.6/#1067)로 업데이트되었습니다

#### 수정 사항

다음 수정 사항을 제공합니다:

* (Admin) Runtime 버전 10.6.3에서 플랫폼 통계 차트의 표시 문제를 수정하였습니다.
* (Developer) 그룹과 앱을 공유할 때 빈 설명 필드에 플레이스홀더 텍스트가 나타나던 문제를 수정하였습니다.
* (Marketplace) 사용자가 동일한 버튼을 다시 클릭하여 저장된 항목 목록에서 컴포넌트를 제거한 후에도 **Save and get notified** 옵션이 계속 알림을 생성하던 문제를 수정하였습니다.
* (Marketplace) 그룹이 할당되지 않은 비공개 공유 컴포넌트의 **Details** 페이지를 볼 수 없던 문제를 수정하였습니다. 비공개 공유 컴포넌트에 대해 그룹 지정이 이제 필수입니다.
* (Marketplace) 콘텐츠 업로드 과정에서 사용자가 이미 제거된 그룹에 비공개 공유 컴포넌트를 할당할 수 있던 문제를 수정하였습니다.
* (Marketplace) 새로운 Marketplace 컴포넌트를 업로드하는 사용자가 *.mpk* 파일 업로드를 방해하는 오류 메시지를 받던 문제를 수정하였습니다.
* (Marketplace) 새 앱을 생성할 때 **Blank Web App** 템플릿 버전이 표시되지 않던 문제를 수정하였습니다.
