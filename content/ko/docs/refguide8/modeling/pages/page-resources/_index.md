## 소개

페이지와 페이지 리소스의 주요 차이점은 페이지는 독립적인 문서인 반면, 페이지 리소스는 단독으로 기능할 수 없는 보조 문서라는 것입니다. 예를 들어, 레이아웃은 단독으로 기능할 수 없지만, 페이지에 구조를 제공합니다.

다음 페이지 리소스를 추가할 수 있습니다:

* [이미지 컬렉션](/refguide8/image-collection/)
* [레이아웃](/refguide8/layout/)
* [페이지 템플릿](/refguide8/page-templates/)
* [Snippet](/refguide8/snippet/)
* [Building Block](/refguide8/building-block/)
* [메뉴](/refguide8/menu/)

## 페이지 리소스 추가

리소스 문서를 추가하려면 다음을 수행하세요:

1. [프로젝트 탐색기](/refguide8/project-explorer/)에서 리소스를 추가하려는 모듈 또는 폴더를 마우스 오른쪽 버튼으로 클릭하고 **Add other**를 선택하세요:
