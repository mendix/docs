## 소개

UI Kit로 디자인을 시작하려면 [Atlas UI Kit for Figma](https://www.figma.com/community/file/1291681319513425134)를 다운로드해야 합니다. 최신 [Atlas 프레임워크](https://atlasdesignsystem.mendixcloud.com/p/dashboard)와 최신 상태인 모든 컴포넌트를 사용하여 디자인할 수 있습니다.

Kit 내에서 다음을 찾을 수 있습니다:

* 라이브러리로 사용하거나 복사/붙여넣기할 수 있는 컴포넌트
* Widget 및 레이아웃

## 사전 준비 사항

Figma용 Atlas UI Kit를 최대한 활용하려면 다음이 필요합니다:

* Figma 구독 (Kit의 파일을 라이브러리로 사용하는 데 필요)
* Figma 데스크톱 앱 (Figma의 최고 기능을 활용하기 위해 다운로드)

## 기본 사항

Figma 데스크톱 앱을 설치하려면 [Figma 웹사이트](https://www.figma.com/)에서 앱을 다운로드하고 설치하세요.

## 권장 사례

다음 사례를 권장합니다:

1. 앱에서 라이브러리와 기본 요소를 사용하세요.
1. 컴포넌트의 색상을 변경하려면 글로벌 로컬 변수를 사용하세요.
1. 이 Kit의 컴포넌트는 이미 Atlas와 Studio Pro에서 지원되므로 우선적으로 디자인하세요.
1. Atlas에서 지원하고 Figma용 Atlas UI Kit에 있는 타이포그래피를 사용하세요.

다음 사례는 권장하지 *않습니다*:

1. 컴포넌트 이름을 변경하지 마세요 (변경하면 라이브러리에서 연결이 해제됩니다).
1. 컴포넌트 레이어 이름을 변경하지 마세요.
