## 소개

메뉴 위젯은 [내비게이션](/refguide8/navigation/) 또는 [메뉴](/refguide8/menu/)에서 구성된 메뉴 항목을 표시합니다.

* [Menu Bar](/refguide8/menu-bar/) – [내비게이션 프로필](/refguide8/navigation/#profiles) 또는 [메뉴](/refguide8/menu/) 문서의 메뉴 항목을 가로 막대 형태로 표시합니다

    {{< figure src="/attachments/refguide8/modeling/pages/menu-widgets/menu-bar-example.png" alt="Menu Bar Example" class="no-border" >}}

* [Navigation Tree](/refguide8/navigation-tree/) – [내비게이션 프로필](/refguide8/navigation/#profiles) 또는 [메뉴](/refguide8/menu/) 문서의 메뉴 항목을 트리 형태로 표시합니다

    {{< figure src="/attachments/refguide8/modeling/pages/menu-widgets/navigation-tree-example.png" alt="Navigation Tree Example" class="no-border" >}}

* [Simple Menu Bar](/refguide8/simple-menu-bar/) – [내비게이션 프로필](/refguide8/navigation/#profiles) 또는 [메뉴](/refguide8/menu/) 문서의 메뉴 항목을 가로 또는 세로 막대 형태로 표시합니다

    {{< figure src="/attachments/refguide8/modeling/pages/menu-widgets/simple-menu-bar-example.png" alt="Simple Menu Bar Example" class="no-border" >}}
