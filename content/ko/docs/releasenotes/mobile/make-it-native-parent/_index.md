## 소개

앱이 개발된 Mendix 버전과 실행하려는 기기에 따라 다른 Make It Native 앱이 필요합니다. 올바른 버전을 다운로드하는 방법에 대한 자세한 내용은 *네이티브 앱 사전 요구 사항 및 문제 해결*의 [Make It Native 앱 다운로드](/refguide/mobile/getting-started-with-mobile/prerequisites/#get-min-app) 섹션을 참조하세요.

## Make It Native 버전

현재 3가지 다른 버전의 Make It Native 앱을 제공합니다. 다음은 각 버전의 릴리스 노트입니다:

1. [Make It Native](/releasenotes/mobile/make-it-native/)
1. [Make It Native 9](/releasenotes/mobile/make-it-native-9/)
1. [Make It Native 8](/releasenotes/mobile/make-it-native-app/)
