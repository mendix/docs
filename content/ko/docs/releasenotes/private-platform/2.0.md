이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 2.0에 적용된 변경 사항을 다루고 있습니다.

## 2.0

### 릴리스 날짜: 2025년 12월 7일

Private Mendix Platform 버전 2.0에서는 다수의 새로운 기능, 업데이트 및 수정 사항이 도입되었습니다.

#### 새로운 기능

##### Azure Key Vault를 통한 Secret 관리

Private Mendix Platform은 이제 기존 데이터베이스 저장 옵션과 함께 외부 시크릿 관리 솔루션으로 [Azure Key Vault](https://azure.microsoft.com/en-us/products/key-vault)를 지원합니다. 자세한 내용은 [Azure Key Vault를 사용한 외부 Secret 관리 구성](/private-mendix-platform/configure-azure-key-vault/)을 참조하십시오.

##### Hashicorp Vault를 통한 Secret 관리

Private Mendix Platform은 이제 기존 데이터베이스 저장 옵션과 함께 외부 시크릿 관리 솔루션으로 [Hashicorp Vault](https://www.hashicorp.com/en/products/vault)를 지원합니다. 자세한 내용은 [HashiCorp Vault를 사용한 외부 Secret 관리 구성](/private-mendix-platform/configure-hashicorp-vault/)을 참조하십시오.

##### 동적 역할 관리

이제 Single Sign-On(SSO) 역할을 Private Mendix Platform에서 설정한 사용자 정의 역할과 연결할 수 있습니다. 관리자는 세분화된 권한 관리를 통해 보다 유연하고 자동화된 방식으로 역할 할당을 관리할 수 있습니다.

##### Software Composition Insights

Private Mendix Platform은 이제 Software Composition Insights를 지원합니다. 자세한 내용은 [Software Composition](/developerportal/deploy/software-composition/)을 참조하십시오.

##### Pipeline 개선

Jenkins 및 Azure DevOps Pipelines CI/CD 도구에 Pipeline을 프로비저닝하는 템플릿을 업데이트하여 SBOM 생성 기능을 포함하고, [Software Composition](/developerportal/deploy/software-composition/) 분석을 위해 MDA와 동일한 폴더에 파일을 저장하도록 하였습니다.

#### 개선 사항

##### UX 개선

Private Mendix Platform의 다음 기능에 대한 UX를 개선하였습니다:

* 로그인
* 초기 설정 구성
* 백업 복원
* 사용자 관리
* 앱 관리
* Private Mendix Platform Marketplace에 컴포넌트 게시
* Private Mendix Platform Marketplace에서 컴포넌트 관리

#### 지원 종료

##### CI/CD용 Tekton 지원 종료

Private Mendix Platform은 더 이상 Tekton을 CI/CD 도구로 지원하지 않습니다. Build 및 Deploy Pipeline의 빌드 유틸리티에서 Tekton이 제거되었습니다.

#### 알려진 문제

##### 상속된 역할로 Studio Pro에서 앱 열기

그룹에서 상속된 역할을 가진 멤버는 **My Group Apps**에서 해당 앱을 Studio Pro로 열 수 없습니다.

###### 해결 방법

임시 해결 방법으로, 앱 소유자에게 직접 앱에 추가해 달라고 요청하십시오. 이 문제는 향후 릴리스에서 해결될 예정입니다.

##### 그룹 멤버가 있는 앱의 아카이브 및 삭제

상속된 그룹 역할을 통해 연결된 멤버가 있는 경우 앱의 아카이브 또는 삭제가 작동하지 않습니다.

###### 해결 방법

Company Admin에게 **App Management** 페이지에서 앱을 아카이브하거나 삭제해 달라고 요청하십시오. 이 문제는 향후 릴리스에서 해결될 예정입니다.

##### 콘텐츠 공유 및 이전 문제

콘텐츠가 그룹과 공유된 경우, 그룹 멤버는 **Group Contents** 페이지에서 해당 콘텐츠를 볼 수 없습니다. 콘텐츠를 그룹으로 이전할 수 없습니다.

###### 해결 방법

이 문제는 향후 릴리스에서 해결될 예정입니다.

##### Admin 패널에서 Marketplace 콘텐츠 누락

Marketplace 관련 콘텐츠가 Admin 패널의 **Group Resources** 섹션에 표시되지 않습니다.

###### 해결 방법

이 문제는 향후 릴리스에서 해결될 예정입니다.
