## 설명

두 값이 같은지 검증합니다.

## 사용법

비교하려는 두 값을 전달하고 동일한지 검증하세요.

## 입력 파라미터

Name | Datatype | Required | Description
---- | -------- | ------- |---------------
Assert Value 1 | any | yes | value 2와 비교할 value 1
Assert Value 2 | any | yes | value 1과 비교할 value 2
