## 소개

**My Content** 페이지는 사용자가 소유한 모든 콘텐츠 목록을 표시합니다.

{{< figure src="/attachments/private-platform/pmp-refguide-mycontent.png" class="no-border" >}}

**Add Content**를 클릭하여 새 콘텐츠 항목을 추가할 수 있습니다. 자세한 내용은 [Marketplace 콘텐츠 공유](/private-mendix-platform/user-guide/#sharing)를 참조하십시오.

콘텐츠 항목을 클릭하여 세부 정보를 보거나 편집할 수도 있습니다.

{{< figure src="/attachments/private-platform/pmp-content-details.png" class="no-border" >}}
