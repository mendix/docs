## 2.8.1

### Release date: September 25, 2026

Version 2.8.1 of Private Mendix Platform introduces a number of new features, updates, and fixes.

#### New Features

##### Centralized Private Mendix Platform Registry

To support fully automating the installation of Private Mendix Platform using Helm, we now provide a centralized download registry. Private Mendix Platform and all its components, as well as the Helm charts required to install them, are offered from a central registry and repositories, enabling users to pull images and charts in an automated manner.

##### Cluster Manager API

We have provided a new Cluster Manager API, consisting of API endpoints that allow automating the registration of new clusters, namespaces and resource plans. For more information, see [Cluster Manager API](/apidocs-mxsdk/apidocs/private-platform-cluster-manager-api/).

#### Improvements

##### Build and Deploy Pipeline Improvements

To allow for non-disruptive testing of pipelines, you can now create multiple [Build](/private-mendix-platform/reference-guide/admin/system/#build-steps) and [Deploy](/private-mendix-platform/reference-guide/admin/system/#deployment) pipelines, and mark them as either Main or Draft. Pipelines designated as Main are used as the default, except for projects where you select a Draft pipeline as default.

##### Metrics Enhancements

We have made the following improvements to the **Metrics** page:

* You can now filter the results by time span.
* You can combine the metrics for all pods together instead of viewing them by pod.

##### Logs & Events Enhancements

We have made the following improvements to the **Logs & Events** page:

* You can now filter the results by time span and by keywords.
* You can search and download consolidated app logs.

##### Software Composition Enhancements

The **Overview** tab of the [Software Composition](/private-mendix-platform/reference-guide/admin/company/#software-composition) page now shows a warning if an app uses an unsupported version of the Mendix Runtime.

##### API Enhancements

To support the new features of Private Mendix Platform, we have updated the following APIs:

* Build - `revisionId` and `branchName` can now be used as filters in retrieving a package.
* Deploy - We have added a new `isKvValue` flag to support Azure Key Vault integration.

For more information, refer to [APIs for Private Mendix Platform](/apidocs-mxsdk/apidocs/private-platform/).

##### UI and UX Improvements

We have improved the UI and UX for the following functionalities:

* Commit history
* **Package Detail** page
* Constants
* PAT creation

#### Known Issues

##### Error when Updating a widget through a Private Marketplace Bundle

When a widget is updated to a newer version through a Private Marketplace bundle, and the project already contains an earlier version of that widget, Studio Pro may fail to overwrite it. Instead of replacing the existing widget, the new version is added as a separate file, which can trigger an import error in Studio Pro.

As a workaround, manually remove the older widget version from the project before importing the updated bundle.

We are aware of this limitation and are working on a fix.

## 2.8.0

### Release date: August 19, 2026

Version 2.8.0 of Private Mendix Platform introduces a number of new features, updates, and fixes.

#### New Features

##### Manage Platform Ops as Code

You can now use Helm and Helmfile in order to automate the declarative installation of Private Mendix Platform and its components through GitOps and CI/CD pipelines. For more information, refer to the [Private Mendix Platform Quickstart Guide](/private-mendix-platform/helmfile-installation/).

#### Improvements

##### Improved Support for Maia Make

We have significantly updated the functionality of [Maia Make](/refguide/maia-make/), and provided a new LLM Gateway component to help you configure Maia for Studio Pro 11.12 LTS. For more information, refer to the [Private Mendix Platform Quickstart Guide](/private-mendix-platform/interactive-installation/#maia).

##### Interactor-Agent Mode Enhancements

To support deployments in Interactor-Agent mode, we have provided the following enhancements:

* You can now configure custom HTTP headers in the **Network and TLS** tab of the **Environment Details** page.
* You can configure constants and schedule events by importing and exporting a yaml file on the *Model Options** tab of the **Environment Details** page.
* Private Mendix Platform now supports runtime leaderless mode for connected environments, which allows nodes to dynamically choose a leader.
