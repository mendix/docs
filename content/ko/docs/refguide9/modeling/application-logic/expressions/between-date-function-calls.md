## 소개

Between date 함수 호출은 두 날짜 사이의 절대 차이를 계산합니다. 차이는 항상 0 또는 양수입니다.

## millisecondsBetween

`millisecondsBetween` 함수는 입력 값 사이의 절대 차이를 밀리초 단위로 계산합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값       | 유형          |
| ----------- | ------------- |
| 첫 번째 날짜  | Date and time |
| 두 번째 날짜 | Date and time |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형    |
| ------------------------------------------------------------ | ------- |
| 밀리초 단위로 측정된 두 날짜 사이의 절대 차이 | Decimal |

### 예제

다음 입력을 사용하는 경우:

```java
millisecondsBetween(dateTime(2007, 1, 1, 1, 1, 1), dateTime(2007,1,1,1,1,3))
```

출력은 다음과 같습니다:

```java
2000
```

```java

```

## calendarMonthsBetween

`calendarMonthsBetween` 함수는 입력 값 사이의 절대 차이를 월 단위로 계산합니다. 시간은 무시됩니다. 날짜는 최종 사용자의 현지 시간대에 있는 것으로 간주됩니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값       | 유형          |
| ----------- | ------------- |
| 첫 번째 날짜  | Date and time |
| 두 번째 날짜 | Date and time |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                    | 유형            |
| -------------------------------------------------------- | --------------- |
| 월 단위로 측정된 두 날짜 사이의 절대 차이 | Integer/Long    |

### 예제

다음 입력을 사용하는 경우:

```java
calendarMonthsBetween(dateTime(2007, 1, 1, 10, 1, 1), dateTime(2007, 8, 1, 1, 1, 1))
```

출력은 두 날짜 사이의 월 수입니다:

```java
7
```
