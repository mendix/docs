### Fixes

* Upgraded to Studio Pro 10.24.8
* Updated Java dependencies to remove unused JAR files and to resolve vulnerabilities
* Implemented dependencies using managed dependencies (**vendorlib**)

### Breaking Changes

* Before updating this module, remove all old *.jar* files of the previous version of the Teamcenter Connector from the **userlib** folder.

## 2406.3.0

**Release date:** September 13, 2024

{{% button color="info" href="https://marketplace.mendix.com/link/component/111627" text="Go to Marketplace" title="Download the Teamcenter Connector from the Marketplace" %}}

**Requirements:** Studio Pro 10.0.0 or above

The following is the list of improvements and fixes in Teamcenter Connector version Tc2406.0003.0.

### Fixes

* Upgraded TcSS JARs and modified `SSORedirectRequestHandler.processCallback` to allow creating an SSO app session using the JSON type. The XML type is no longer supported.
* Added access rules for the `TcConnector.Image` and `TcConnector.ImanFile` entities.
* The Mendix Teamcenter Connector can now upload Dataset named references defined with `*`.
* Changed the length of `POM_application_object.object_string` and `BOMLine.object_string` to 4000 to match the Teamcenter data model.
* Cleaned up the **userlib** folder by removing unnecessary JARs.
* Set the timeout for the `SendService` microflow to 300 seconds.
