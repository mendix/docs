## Introduction

The initial login screen is the same for all users, whether or not they have administrator access rights. The following login methods are available:

* A local user login with a username and password
* Optionally, an SSO login which redirects to an SSO provider

{{< figure src="/attachments/private-platform/pmp-ref-signin.png" class="no-border" >}}

After signing in, all users regardless of their role are initially directed to the **Home** page. Users with the administrator role can switch to admin view by clicking the user icon in the top right corner, and then selecting **Admin Mode** from the **User Mode** drop-down.

## Home Page

The **Home** page is the landing page of Private Mendix Platform.

{{< figure src="/attachments/private-platform/pmp-homepage.png" class="no-border" >}}

It shows an overview of your applications and groups. You can use it to perform the following tasks:

* See the number of your apps total and your deployed apps.
* [Download Studio Pro](/private-mendix-platform/apps/#install-studio-pro).
* [Create a new app](/private-mendix-platform/apps/#create-app).
* Access specific apps.
* View the groups to which you belong.
* Add or remove members to groups where you have the Group Admin role.

## Top Navigation Bar

The top navigation bar displays your location within the Platform (for example, *Apps* or *Marketplace*). The branding of the bar, such as the logo and title, can be customized by a Company Admin.

From the navigation bar, you can access the following items:

* [Platform Navigation](#navigation) (({{% icon name="layout-1-filled" %}}))
* [Notifications](#notifications) (({{% icon name="alarm-bell" %}}))
* [Account Menu](#account)

### Platform Navigation {#navigation}

The navigation menu contains the options that you need to make or manage your apps.

{{< figure src="/attachments/private-platform/pmp-navigation-menu.png" class="no-border" >}}

It consists of the following sections:

* **Home** - Click this option to go to the Home page.
* **Apps > Direct Access** - Click this option to go to the **Direct Access** section of the [My Apps](/private-mendix-platform/reference-guide/common/my-apps/) page.
* **Apps > Access via Groups** - Click this option to go to the **Access via groups** section of the [My Apps](/private-mendix-platform/reference-guide/common/my-apps/) page.
* **Groups** - Click this option to go to the [My Group](/private-mendix-platform/reference-guide/common/manage-group/) page.
* **Marketplace > Company Content** - Click this option to go to the [Company Content](/private-mendix-platform/reference-guide/common/company-content/) page.
* **Marketplace > Group Content** - Click this option to go to the [Group Content](/private-mendix-platform/reference-guide/common/group-content/) page.
* **Marketplace > My Content** - Click this option to go to the [My Content](/private-mendix-platform/reference-guide/common/my-content/) page.
* **Create App** - Click this option to [start creating your application](/private-mendix-platform/apps/) page.
* **Download Studio Pro** - Click this option to go to the [Get Studio Pro](/private-mendix-platform/reference-guide/common/get-studio/) page.

### Notifications {#notifications}

The **Notifications** center shows notifications for the following events:

* **Alerts** - Notifications about events that require attention, for example, app availability and status
* **Following** - Notifications about comments and reactions to your stories, posts, or projects
* **Recommendation** - Notifications about new Private Mendix Platform releases
* **Requests/Approvals** - Notifications about status changes for your requests, for example, the publication of a Marketplace content item

You can click a notification to view the related page or link. You can also mark a notification as read or unread by clicking the status dot on the left. To set your notification preferences, go to [Manage My Account > Notifications](/private-mendix-platform/user-profile/#notifications).

### Manage My Account {#account}

The **Manage My Account** menu contains the options that you need to make or manage your account. For more information, see [Configuring Your User Profile and Settings](/private-mendix-platform/user-profile/).
