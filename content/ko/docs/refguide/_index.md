## 소개

*Mendix Studio Pro 11 가이드*는 [Studio Pro](/refguide/modeling/), [Mendix Runtime](/refguide/runtime/), 그리고 Mendix Platform의 기타 구성 요소와 관련된 중요한 주제를 다룹니다.

Studio Pro는 Windows와 macOS에서 모두 실행됩니다. Studio Pro 11을 설치하기 전에 [시스템 요구 사항](/refguide/system-requirements/)을 확인하세요. Studio Pro 설치 방법에 대한 자세한 내용은 [Mendix Studio Pro 설치하기](/refguide/install/)를 참조하세요.

Studio Pro 버전 10을 사용해 오셨다면, [Mendix Studio Pro 10에서 11로 업그레이드하기](/refguide/upgrading-from-10-to-11/)를 읽어보시는 것을 권장합니다.

첫 번째 앱을 만들고 싶으시다면, [빠른 시작](/quickstarts/)을 확인하세요.

다양한 Mendix 작업에 대한 단계별 가이드를 찾고 계신다면, [Studio Pro 11 How-to](/howto/)를 참조하세요.

## Studio Pro 기능

Studio Pro를 사용하면 앱을 만들고, 테스트하고, 실행할 수 있습니다.

### 모델링

앱 모델링은 앱을 만드는 과정으로, 페이지 생성, 로직 추가, 보안 구성 등을 포함합니다. 앱 모델링에 사용할 수 있는 기능에 대한 자세한 내용은 [앱 모델링](/refguide/modeling/)을 참조하세요.

### 테스트

애플리케이션 테스트와 관련하여, 먼저 무엇을 테스트할지 결정해야 합니다: 외부 서비스와의 통합, 앱 로직(Microflow) 등. 애플리케이션을 테스트하는 방법에 대한 자세한 내용은 [테스트](/howto/testing/)를 참조하세요.

### 배포

Studio Pro를 사용하면 앱을 로컬에서 또는 기본 환경에서 실행하고 확인할 수 있습니다.

앱 배포 옵션에 대한 자세한 내용은 [앱 배포](/deployment/)를 참조하세요.

## Version Control

[Version Control](/refguide/version-control/)을 사용하면 앱 개발을 관리하고 여러 개발 라인에서 작업할 수 있습니다. Studio Pro가 앱의 버전 관리를 어떻게 처리하는지에 대한 자세한 내용은 *Studio Pro에서 Version Control 사용하기*의 [클라우드에 배포된 앱 버전 관리](/refguide/using-version-control-in-studio-pro/#versioning-app) 섹션을 참조하세요.

## Mendix Runtime

[Mendix Runtime](/refguide/runtime/)은 Studio Pro에서 생성된 애플리케이션 모델을 실행합니다. 동일한 버전 번호를 사용하므로 Studio Pro 11 가이드에 포함되어 있습니다.

## 모바일

모바일 앱 개발을 통해 네이티브 모바일 및 프로그레시브 웹 앱을 만들 수 있습니다. 자세한 내용은 [모바일](/refguide/mobile/)을 참조하세요.
