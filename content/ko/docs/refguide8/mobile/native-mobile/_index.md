## 소개

{{% alert color="warning" %}}
2025년 10월부터 Mendix 8은 네이티브 모바일 애플리케이션 실행을 더 이상 지원하지 않습니다. 최신 [MTS 또는 LTS 버전](/releasenotes/studio-pro/lts-mts/)의 Mendix로 업그레이드하십시오. 오래된 앱은 최신 OS 버전에서 예상대로 작동하지 않을 수 있습니다. 자세한 내용은 [이 블로그 게시물](https://www.mendix.com/blog/empowering-mobile-innovation/)을 참조하십시오.
{{% /alert %}}

Mendix 8부터 완전한 네이티브 모바일 앱을 구축할 수 있습니다. 네이티브 모바일 앱은 웹 뷰 내에서 렌더링되지 않는다는 점에서 하이브리드 앱과 다릅니다. 대신 네이티브 UI 요소를 사용합니다. 이를 통해 빠른 성능, 부드러운 애니메이션, 스와이프 제스처, 그리고 모든 네이티브 디바이스 기능에 대한 향상된 접근이 가능합니다.
