Studio Pro 11용으로 현재 활발히 개발 중인 Native Template 버전은 다음과 같습니다:

* Native Template [15](/releasenotes/mobile/nt-15-rn/) 버전은 다음 Studio Pro 버전으로 빌드된 앱과 호환됩니다:
    * Studio Pro 11.0 이상.
* Native Template [16](/releasenotes/mobile/nt-16-rn/) 버전은 다음 Studio Pro 버전으로 빌드된 앱과 호환됩니다:
    * Studio Pro 11.5 이상.
* Native Template [17](/releasenotes/mobile/nt-17-rn/) 버전은 다음 Studio Pro 버전으로 빌드된 앱과 호환됩니다:
    * Studio Pro 11.6 이상.
