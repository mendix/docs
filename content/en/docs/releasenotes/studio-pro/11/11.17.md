## 11.17.0 {#11170}

**Release date: November 24, 2026**

### New Features

#### Maia New Features

* Maia Make now uses Claude Sonnet 5.5 by default. For more information, see the [Maia Third-Party Services](/refguide/mendix-ai-assistance/#maia-third-party-services) section in *Mendix AI Assistance (Maia)*.
* Configuring a custom AI provider for Maia is now generally available. For more information, see the [Configuring a Custom AI Provider](/refguide/maia-make/#custom-provider) section in *Maia Make Capabilities*.
* You can now sign in with Microsoft Entra ID to an OpenAI-compatible custom AI provider that Microsoft Entra ID protects, such as Azure AI Foundry. You do not need an API key. For more information, see the [Signing In with Microsoft Entra ID](/refguide/maia-make/#openai-entra-id) section in *Maia Make Capabilities*.
* You can now test the connection to your custom AI provider before you save the settings. For more information, see the [Testing the Connection](/refguide/maia-make/#test-connection) section in *Maia Make Capabilities*.
* Maia can now work with XML schema documents, and you can attach XSD files to your Maia chat messages.
