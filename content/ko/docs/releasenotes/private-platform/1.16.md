이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.16에 적용된 변경 사항을 다루고 있습니다.

## 1.16.0

### 릴리스 날짜: 2024년 11월 29일

Private Mendix Platform 버전 1.16.0에서는 다수의 새로운 기능, 개선 사항 및 버그 수정이 도입되었습니다.

#### 새로운 기능

##### 구성 가능한 Deploy Pipeline

변경 유형을 고려하도록 Deploy Pipeline을 구성할 수 있게 되었습니다. 관리자 **Settings** > **Integrations** > **Deployment** 섹션에 새로운 체크박스가 추가되어, 앱 환경(앱 상수 또는 레플리카 수 등)에 대한 변경만 있는 경우 배포 단계를 건너뛰고 앱을 단순히 재시작할 수 있습니다.

##### 구성 가능한 로그인 배너

사용자가 앱의 로그인 페이지 이전, 도중 또는 이후에 표시되는 배너를 구성할 수 있게 되었습니다. 예를 들어 사용자에게 전달하고 싶은 개인정보 보호 또는 보안 관련 정보를 표시할 수 있습니다. 관리자는 관리자 메뉴의 **Settings** > **Preferences** > **General** > **Branding** > **Access Banner** 섹션에서 이 설정을 활성화하거나 비활성화할 수 있습니다.

##### Private Mendix Platform 추가 언어 지원

Private Mendix Platform을 이제 중국어, 일본어, 한국어로 사용할 수 있습니다.

#### 개선 사항

##### AWS ECR을 OCI 레지스트리로 지원

Private Mendix Platform은 이제 빌드 입력을 위한 OCI 레지스트리로 Amazon Elastic Container Registry(ECR)를 지원합니다. 자세한 내용은 [Kubernetes에서 CI/CD 구성](/private-mendix-platform/configure-k8s/)을 참조하십시오.

##### 엔지니어링 개선

###### 관리자가 모든 사용자를 강제 로그아웃 가능

관리자는 이제 개별 사용자 또는 로그인된 모든 사용자를 동시에 로그아웃시킬 수 있습니다. 이 옵션은 관리자 메뉴의 **Manage** > **Users** > **User Management** > **Actions** 및 **Users** 섹션에서 사용할 수 있습니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.29](/releasenotes/studio-pro/9.24/#92429)로 업데이트되었습니다 (프로덕션 지원)
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.17](/releasenotes/studio-pro/10.6/#10617)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)
* Studio Pro 10.12 MTS는 [10.12.9](/releasenotes/studio-pro/10.12/#10129) 버전부터 호환됩니다 (이노베이션 트랙, 제한적 지원)

#### 수정 사항

다음 수정 사항을 제공합니다:

* (플랫폼) Build API의 409 충돌 문제를 해결하였습니다.
* (플랫폼) Azure에 대해 자동 생성된 Git 서버 URL의 형식 문제를 수정하였습니다.
* (UI) 다른 그룹에서 이미 사용된 이름으로 그룹을 생성하려 할 때 오류가 표시되지 않던 문제를 해결하였습니다.
* (UI) 이미 모든 가용 앱이 가져온 경우 앱 가져오기 중 오류 메시지가 잘못 표시되던 문제를 수정하였습니다.
* (UI) Studio Pro 9.24.3에서 사용자 프로필 이미지가 표시되지 않던 문제를 해결하였습니다.
