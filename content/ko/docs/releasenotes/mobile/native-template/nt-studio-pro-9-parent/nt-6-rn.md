### Native Mobile Resources 모듈 업데이트

{{% alert color="warning" %}}
라이브러리 업데이트로 인해 Native Template이 Native Mobile Resources와 정렬되어야 하며, 그렇지 않으면 빌드가 실패합니다. Marketplace에서 최신 버전의 Native Mobile Resources 모듈을 사용하고 있는지 확인하세요(현재 [버전 3.13.0](https://marketplace.mendix.com/link/component/109513)).
{{% /alert %}}

App Center에 이미 프로젝트가 있는 경우, 호환성을 보장하기 위해 다음 환경 변수를 추가해야 합니다:

1. App Center에서 프로젝트를 열고 **Build** 메뉴 항목으로 이동하세요.
1. **모든 브랜치**에서 렌치 아이콘({{% icon name="wrench" %}})을 클릭하세요.
1. **Environment Variable**에서 다음 **Name**과 **Value**를 추가하세요(이 옵션이 활성화되어 있지 않으면 활성화하세요):
    1. Name: **JAVA_HOME**.
    1. Value: **$(JAVA_HOME_11_X64)**.

## 6.2.9 {#6.2.9}

**릴리스 날짜: 2021년 11월 29일**

* Mendix Studio Pro 9.8에서 도입된 새로운 네이티브 모바일 암호화 기능에 대한 지원을 추가했습니다.

    * Native Template v6.2.9 이상의 Android에서 모든 새로운 앱별 쿠키는 Studio Pro 9 마이너 버전과 관계없이 자동으로 암호화됩니다.

### 수정 사항

## 6.2.0 {#620}

**릴리스 날짜: 2021년 7월 20일**

### 개선 사항

* `appCenterOTA` 기능에 대한 구현을 추가하여 기능 구성을 개선했습니다. 이로 인해 Native Mobile App Builder를 통해 OTA 지원이 활성화되지 않은 경우에도 모든 애플리케이션에 `Codepush`를 번들로 포함해야 하는 이전의 필요성이 제거되었습니다.
* Android 11 기기에 대한 지원을 구현했습니다.
* 이전 버전의 보안 문제로 인해 `react-native-codepush` 종속성을 `6.4.1`로 업데이트했습니다.

### 호환성을 깨뜨리는 변경 사항

* `react-native-image` 내부 종속성을 버전 `4.0.3`으로 업데이트하고 `react-native-permissions` 종속성을 도입했습니다. 개발자는 예기치 않은 동작을 피하기 위해 [Native Mobile Resources](https://marketplace.mendix.com/link/component/109513) 모듈을 최신 버전으로 업데이트해야 합니다. 이 변경으로 인해 이전에 OTA 업데이트에 의존하던 개발자는 앱 스토어에 새 애플리케이션을 릴리스해야 합니다.

**릴리스 날짜: 2021년 6월 11일**

### 개선 사항

### 호환성을 깨뜨리는 변경 사항

iOS에서 이제 `AppDelegate.m.`의 두 가지 구현이 있습니다: 하나는 릴리스 앱용이고, 다른 하나는 개발자 앱용입니다. 더 많은 기능을 추가할수록 커스텀 개발자 앱의 더 복잡한 요구 사항을 지원하기 위해 더 많은 보일러플레이트를 추가해야 했습니다. 구현을 분리함으로써 릴리스 앱은 이제 깔끔하고 간단한 구현을 받고, 더 복잡한 구현은 추상화됩니다. 

이를 통해 종속성의 문서를 따르기만 하면 커스텀 코드를 쉽게 추가할 수 있습니다. 

{{% alert color="warning" %}}
앱에 타사 종속성 등으로 인해 커스텀 초기화가 필요하고 커스텀 개발자 앱을 사용하여 구현을 테스트할 계획인 경우, 이 버전 이상부터 해당 커스텀 작업을 AppDelegate(`Dev/AppDelegate.m`에 위치)에 **반드시 복제해야** 합니다.
{{% /alert %}}
