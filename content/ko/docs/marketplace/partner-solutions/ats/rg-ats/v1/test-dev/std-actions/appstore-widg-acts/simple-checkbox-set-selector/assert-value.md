## 설명

지정된 값으로 찾은 체크박스가 선택 또는 해제되었는지 검증합니다.

## 지원 Widget

* Simple Checkbox Set Selector

## 사용법

Widget의 이름, 체크박스에 연결된 값, 그리고 체크박스가 선택 또는 해제되어야 하는지를 전달하세요.

## 입력 파라미터

Name | Datatype | Required | Description
---- | -------- | ------- |---------------
Widget Name | String | Yes | Widget의 이름입니다.
Value | String | Yes | 체크박스에 연결된 값입니다.
Checked | Boolean | Yes | 체크박스가 선택 또는 해제되었는지 검증합니다.
