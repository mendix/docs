## December 2020

### December 23, 2020

#### Improvements

* **Stories** > **Project History** 페이지의 스타일을 조정했습니다.
* 스토리를 다른 앱으로 이동하는 과정을 더 직관적으로 개선했습니다.
* 앱 생성 시작 방법에 대한 팁이 포함된 Model 페이지를 제거했습니다.

#### Fixes

* Buzz 알림에 대한 답장이 [앱 Buzz](/developerportal/general/overview/) 페이지의 댓글로 올바르게 처리되지 않던 문제를 수정했습니다. (Ticket 111076)

### December 2, 2020

#### Improvements

* Developer Portal의 홈 페이지를 [My Apps](/developerportal/#my-apps)로 변경했습니다.

## November 2020

### November 4, 2020

#### Fixes

* 회사명 변경이 플랫폼 전체에 제대로 반영되지 않던 버그를 수정했습니다.
* 스토리 상세 페이지에서 드롭다운 메뉴가 잘리던 버그를 수정했습니다.

## October 2020

### October 9, 2020

#### Fixes

* [Team](/developerportal/general/team/) 개요에서 팀 멤버가 표시되지 않던 문제를 수정했습니다.

### October 4, 2020

#### Improvements

* 스토리 상세 페이지를 재설계하여 베타 사용이 가능하도록 했습니다. 새 UI가 활성화된 경우 새 디자인을 사용할 수 있습니다. 현재 새 UI에서는 라벨 추가 또는 관리가 불가능하며, 이 기능은 향후 릴리스될 예정입니다.
* 앱 모델의 커밋에 태스크를 추가하면 스토리 상세의 리비전 개요에 해당 리비전이 표시됩니다. 태스크를 클릭하면 해당 태스크가 속한 스토리 상세 페이지로 이동합니다.
* **Company** 페이지의 **Company Settings** 탭에서 거의 사용되지 않는 일부 속성을 제거하여 단순화했습니다.

#### Fixes

* 리비전을 커밋한 팀 멤버의 기본 아바타가 스토리 상세의 리비전 개요에 제대로 표시되지 않던 문제를 수정했습니다.
* Company Admin이 팀 멤버가 아닌 앱의 [Settings](/developerportal/general-settings/)를 열 수 없던 문제를 수정했습니다.
* [App User Management](/developerportal/general-settings/#managing-app-users) 페이지의 깨진 문서 링크를 수정했습니다.

## August 2020

### August 25, 2020

#### Improvements

* 사용자 스토리 개요에 대한 읽기 전용 권한을 다시 도입했습니다.

#### Fixes

* 특정 상황에서 스토리 댓글 업데이트에 대한 이메일 알림이 전송되지 않던 문제를 수정했습니다.

### August 11, 2020

#### Improvements

* 소규모 성능 개선을 적용했습니다.

#### Fixes

* Developer Portal에서 호스팅하는 파일에 사용 중단 경고를 추가했습니다. 이 파일은 이전 버전의 [Mendix Feedback](/appstore/modules/mendix-feedback/) 위젯에서 사용됩니다. 2020년 10월 1일부로 Mendix Feedback 위젯 버전 5 이하에 대한 지원을 종료합니다. 최상의 사용자 경험을 보장하기 위해 Feedback 위젯을 항상 최신 상태로 유지하세요.
* Sprint를 지정하지 않고 사용자 스토리를 다른 Sprint로 이동할 수 있던 문제를 수정했습니다.

## July 2020

### July 28, 2020

#### Fixes

* 특정 상황에서 [피드백](/developerportal/app-insights/feedback/) 항목에 대한 이메일 알림이 전송되지 않던 문제를 수정했습니다.

### July 13, 2020

#### Improvements

* Buzz 페이지 열기 성능을 향상시켰습니다.
* 사용자 프로필의 기본 아바타를 Mendix 로고에서 업계 표준 사용자 아이콘으로 변경했습니다.

#### Fixes

* 특정 상황에서 "View App" 버튼이 활성화되어야 함에도 비활성화되던 버그를 수정했습니다.

## June 2020

### June 28, 2020

#### Improvements

* 기본 **End-user** 팀 역할의 이름을 [Guest](/developerportal/general/app-roles/#team-roles)로 변경하는 두 번째 단계를 구현했습니다.

#### Fixes

* 종료된 Sprint의 종료 날짜를 변경할 수 있던 문제를 수정했습니다.

### June 15, 2020

#### Improvements

* 새로운 Stories UI가 다양한 섹션으로 개선되었습니다. 기존 Stories UI는 곧 사용할 수 없게 됩니다. 기존 Stories UI에서 아직 남아있는 태스크를 기존 UI에 접근할 수 없게 되기 전에 새 스토리로 전환하시기 바랍니다.
* 삭제된 항목이 많은 대규모 앱에서 드래그 앤 드롭 및 상태 변경과 같은 스토리 관련 작업의 성능을 개선했습니다.
* 기본 **End-User** 팀 역할의 이름을 [Guest](/developerportal/general/app-roles/#team-roles)로 변경하여 팀 역할과 앱 사용자 역할을 더 잘 구분할 수 있도록 했습니다.
* [My Company's Apps](/developerportal/#my-company-apps) 페이지의 리스트 형태 표시를 제거했습니다.

#### Fixes

* 모바일 브라우저에서 배경이 제대로 표시되지 않던 버그를 수정했습니다.
* **Cancel**을 클릭했을 때 스토리 제목이나 설명의 변경 사항이 저장되던 버그를 수정했습니다.

## May 2020

### May 27, 2020

#### Improvements

* **Stories** 페이지에서 스토리 또는 태스크를 삭제하면 시스템에서 영구적으로 제거됩니다.
* 앱 히스토리에서 스토리 관련 변경 사항을 되돌리는 기능을 제거했습니다.
* **Stories** 페이지에서 여러 스토리를 한 번에 삭제하는 기능을 제거했습니다.
* 중첩 태스크를 방지하여 스토리 관리를 단순화했습니다.
* 업계 표준에 맞추기 위해 스토리 보드의 읽기 전용 권한을 제거했습니다.
* Developer Portal의 디자인을 소규모로 개선했습니다.

#### Fixes

* 날짜/시간 입력 필드의 달력 아이콘({{% icon name="calendar" %}})이 제대로 표시되지 않던 버그를 수정했습니다.
* [즐겨찾기 앱](/developerportal/#my-apps)의 별 아이콘({{% icon name="star" %}})이 제대로 표시되지 않던 버그를 수정했습니다.

### May 22, 2020

#### Improvements

* Stories 템플릿 기능이 새 UI 옵션(베타)의 **Clone** 기능으로 대체되었습니다.

### May 7, 2020

#### Improvements

* 새 베타 UI에 **Clone**이라는 새 스토리 액션을 추가했습니다. 자세한 내용은 *Stories*의 New UI Option (beta) 섹션을 참조하세요.

## February 2020

### February 21, 2020

#### Improvements

* 삭제된 후에도 [즐겨찾기 앱](/developerportal/#my-apps)이 [My Apps](/developerportal/#my-apps) 페이지의 즐겨찾기 보기에 계속 표시되던 문제를 수정했습니다.
* **My Apps** 페이지의 성능을 개선했습니다.
* 새 스토리 생성 시 설명 필드가 제대로 확장되지 않던 문제를 수정했습니다.

### February 6, 2020

#### Improvements

* [앱 생성](/developerportal/) 흐름에 새로운 디자인을 적용했습니다.
* 새 앱을 만들 때 기능 데모, 아카데미 교육 앱, 즉시 사용 가능한 앱 등의 템플릿을 검색할 수 있습니다.
* 앱 템플릿을 선택한 후 앱에 적절한 아이콘을 선택할 수 있습니다.
