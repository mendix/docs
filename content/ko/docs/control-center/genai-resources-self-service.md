## 소개

**GenAI 리소스** 섹션은 회사 내에서 사용 가능한 모든 Mendix GenAI 리소스에 대한 자세한 개요를 제공하여 Mendix 관리자가 필요에 따라 GenAI 리소스를 원활하게 프로비저닝 및 디프로비저닝할 수 있도록 합니다. 이 기능을 통해 Mendix 관리자는 셀프 서비스 기능을 통해 [Control Center](https://controlcenter.mendix.com/index.html) 내에서 직접 모든 GenAI 리소스를 효율적으로 관리하여 운영을 간소화하고 거버넌스를 개선할 수 있습니다. 자세한 내용은 [GenAI 리소스 접근](/appstore/modules/genai/mx-cloud-genai/resource-packs/#accessing-genai-resources)을 참조하십시오.

## 전제 조건

Mendix Cloud 토큰을 사용한 GenAI 리소스의 셀프 서비스 프로비저닝은 다음 조건을 충족하는 사용자에게만 사용할 수 있습니다:

1. 충분한 토큰 권한 – GenAI 리소스 프로비저닝에 할당할 수 있는 충분한 Mendix Cloud 토큰이 있어야 합니다.
2. 유효한 구독 플랜 – 사용자의 Mendix 구독은 FY21 가격표 이상을 기반으로 해야 합니다. 이전 구독 플랜은 프로비저닝에 적합하지 않습니다.
3. 단일 계정 소유 – 사용자는 단일 계정을 가지고 있어야 합니다. 여러 계정 소유는 셀프 서비스 GenAI 프로비저닝에 지원되지 않습니다.
4. 엔터프라이즈 플랫폼 구독 – 사용자는 단일 활성 엔터프라이즈 플랫폼 구독이 있어야 합니다. 활성 구독이 없는 경우 시스템은 다음 텍스트와 함께 경고 메시지를 표시합니다: "사용 가능한 토큰에 접근하고 리소스를 생성하는 데 필요한 올바른 플랫폼 계정을 검색할 수 없습니다. 도움이 필요하면 Mendix 지원팀에 문의하십시오."

## 배포된 리소스 개요

개요 페이지는 텍스트 생성 리소스, 임베딩 생성 리소스, 지식 베이스 리소스를 포함한 모든 배포된 GenAI 리소스의 중앙 집중식 뷰를 제공합니다. 이 페이지에서 각 배포된 리소스의 상태, 기본 정보 및 사용 세부 정보를 쉽게 확인할 수 있습니다. 다음 목록은 GenAI 리소스에 대한 자세한 정보를 보여줍니다.

* **상태** – 리소스의 현재 상태입니다.
* **이름** – 리소스의 이름입니다.
* **모델** – 사용되는 모델, 예: Anthropic Claude Sonnet 4.0.
* **플랜** – 리소스에 사용되는 구독 플랜, 예: small, medium, large.
* **생성 대상** – 누구를 위해 생성되었는지.

## GenAI 리소스 프로비저닝

셀프 서비스 기능을 사용하여 Control Center 내에서 직접 GenAI 리소스를 프로비저닝할 수 있습니다.
이를 수행하려면 적절한 리소스 유형을 선택하고 **리소스 프로비저닝**을 클릭하십시오.

{{% alert color="info" %}}
프로비저닝하기 전에 올바른 리소스 탭에 있는지 확인하십시오. 예를 들어, 새 텍스트 생성 리소스를 만들려면 먼저 **텍스트 생성 리소스** 탭을 선택하십시오.
{{% /alert %}}

새 리소스를 프로비저닝할 때 다음 정보를 입력하십시오:

* **표시 이름** – 리소스의 이름입니다.
* **환경** – 리소스가 생성되는 환경, 예: Test, Acceptance, Production.
* **Mendix Cloud 리전** – 리소스가 호스팅되는 클라우드 리전입니다.
* **교차 리전 추론** – 선택한 모델이 교차 리전 추론을 지원하는지 여부를 지정합니다. 자세한 내용은 *Mendix Cloud GenAI 포털 탐색*의 [설정](/appstore/modules/genai/mx-cloud-genai/Navigate-MxGenAI/#settings) 섹션을 참조하십시오.
* **사용 가능한 텍스트 생성 모델** – 선택할 수 있는 지원되는 모델 목록, 예: Anthropic Claude Sonnet V4.
* **크기** – 리소스에 사용되는 토큰이 포함된 구독 플랜입니다.
* **사용자** – 프로비저닝이 처음 생성된 사용자의 이름입니다.
* **이메일** – 사용자의 이메일 주소입니다.

필수 필드를 입력한 후 **리소스 사양**에서 입력된 모든 세부 정보를 검토할 수 있습니다. 자세한 내용은 [Mendix Cloud GenAI Resource Packs](/appstore/modules/genai/mx-cloud-genai/resource-packs/)를 참조하십시오.

**리소스 프로비저닝**을 클릭하여 프로세스를 완료하십시오. **GenAI 리소스** 페이지로 돌아가며 새로 생성된 리소스가 목록에 표시됩니다. 새로 프로비저닝된 리소스를 선택하면 새 탭에서 Mendix Cloud GenAI Portal에서 직접 세부 정보가 열립니다.

## GenAI 리소스 디프로비저닝

리소스를 디프로비저닝하려면 선택한 리소스 옆의 점 세 개 아이콘({{% icon name="three-dots-menu-horizontal" %}})을 클릭하고 **리소스 디프로비저닝**을 선택하십시오.
아래 예시와 같이 메시지와 선택한 리소스의 세부 정보를 표시하는 확인 팝업이 나타납니다.

{{< figure src="/attachments/control-center/genai-resources/deprovisioning.png" >}}

**디프로비저닝**을 클릭하여 진행하십시오. 확인 후 **GenAI 리소스** 페이지에서 리소스 상태가 디프로비저닝이 예약되었음을 반영하도록 업데이트됩니다.

{{% alert color="info" %}}
구독 플랜은 월간 번들 주기로 운영됩니다. 리소스를 디프로비저닝하면 실제 디프로비저닝은 현재 구독 월의 끝에 발생합니다. 해당 날짜까지 리소스를 계속 사용할 수 있으며, 예약된 디프로비저닝 날짜가 리소스의 **상태**에 표시됩니다.
{{% /alert %}}

## GenAI 리소스 플랜 크기 조정

이미 프로비저닝된 GenAI 리소스(텍스트 또는 임베딩 모델)의 플랜 크기를 실제 토큰 수요에 더 잘 맞도록 변경할 수 있습니다. Control Center의 셀프 서비스 기능을 통해 GenAI 리소스 플랜 크기를 조정할 수 있습니다.

리소스 플랜 크기를 조정하려면 다음을 수행하십시오:

1. 회사 관리자로 Control Center에 로그인하십시오.
2. **GenAI 리소스** 페이지에서 선택한 리소스 옆의 점 세 개({{% icon name="three-dots-menu-horizontal-filled" %}}) 아이콘을 클릭하고 **플랜 크기 조정**을 선택하십시오.
3. 원하는 플랜을 선택하고 **플랜 크기 조정 GenAI 리소스** 페이지에서 **리소스 사양**을 검토하십시오. **플랜 조정**을 클릭하여 변경 사항을 제출하십시오.

{{< figure src="/attachments/control-center/genai-resources/adjust-plan-size.png" >}}

### GenAI 리소스 플랜 크기 업그레이드

업그레이드하려면 예상 수요에 맞는 더 큰 플랜을 선택하십시오. 업그레이드는 즉시 적용됩니다. 새 플랜에 필요한 추가 토큰을 충당할 수 있는 충분한 미사용 클라우드 토큰이 계정에 있어야 합니다. 예를 들어 30토큰(Small) 플랜에서 60토큰(Medium) 플랜으로 업그레이드하려면 계정에 최소 30개의 미사용 클라우드 토큰이 필요합니다. 계정에 필요한 토큰이 없으면 오류 메시지가 표시되고 업그레이드가 방지됩니다.

### GenAI 리소스 플랜 크기 다운그레이드

다운그레이드하려면 더 작은 플랜을 선택하십시오. 다운그레이드는 즉시 적용되지 않습니다. 현재 플랜은 현재 구독 월의 끝까지 활성 상태로 유지되며, 다운그레이드는 다음 구독 월의 시작에 적용됩니다. 예를 들어 Medium 플랜이 2월 12일에 시작되었고 2월 20일에 Small로 다운그레이드를 예약하면 실제 다운그레이드는 3월 12일에 발생합니다. 다운그레이드 결과로 계정에 반환되는 클라우드 토큰은 예약된 다운그레이드가 적용된 후에만 사용할 수 있습니다.

#### 예약된 다운그레이드 취소

적용되기 전에 언제든지 예약된 다운그레이드를 취소할 수 있습니다. 다운그레이드가 예약되면 리소스 상태가 **PLAN DOWNGRADE SCHEDULED**로 변경됩니다. 취소하려면 선택한 리소스 옆의 점 세 개({{% icon name="three-dots-menu-horizontal-filled" %}}) 아이콘을 클릭하고 **플랜 다운그레이드 취소**를 선택하십시오. 작업은 즉시 적용되어 예약된 다운그레이드를 취소합니다.
