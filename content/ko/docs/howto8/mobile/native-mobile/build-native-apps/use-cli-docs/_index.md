대부분의 앱 빌드에서 Mendix는 Mendix Studio Pro 8.15 이상에 포함된 Native Builder UI 도구를 사용하는 것을 권장합니다. 그러나 특정 사용 사례에서는 Native Builder CLI 도구를 사용해야 합니다. 

이 단계별 가이드에서는 Native Builder CLI를 사용하여 Native Mobile 애플리케이션을 빌드하는 방법을 설명합니다:

* [Native Builder CLI를 사용하여 첫 번째 Mendix Native Mobile App 배포하는 방법](/howto8/mobile/deploying-native-app-cli/) – 빈 상태에서 디바이스에서 실행되는 앱까지 만들어 보십시오.
* [Native Builder CLI를 사용하여 사용자 정의 Developer App 만드는 방법](/howto8/mobile/how-to-devapps-cli/) – 네이티브 Widget이나 폰트와 같은 사용자 정의 종속성을 수용하는 Make It Native 앱의 대체물인 사용자 정의 Developer App을 만드십시오.
* [CLI를 사용하여 App Center의 CodePush로 Over the Air 업데이트 릴리스](/howto8/mobile/how-to-ota-cli/) - App Center의 CodePush 서비스와 Native Builder CLI를 사용하여 Over the Air 업데이트가 가능하도록 설정하십시오.
