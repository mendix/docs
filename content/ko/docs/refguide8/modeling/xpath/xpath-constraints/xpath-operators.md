## XPath 쿼리 제약 조건용

다음 연산자를 Studio Pro와 Java 코드 모두에서 XPath 쿼리 제약 조건에 사용할 수 있습니다:

| 연산자 | 설명 | 예제 | 반환 값 |
| --- | --- | --- | --- |
| `=` | 같음 | `price = 9.80` | 가격이 9.80이면 true, 가격이 9.90이면 false |
| `!=` | 같지 않음 | `price != 9.80` | 가격이 9.90이면 true, 가격이 9.80이면 false |
| `<` | 보다 작음 | `price < 9.80` | 가격이 9.70이면 true, 가격이 9.80이면 false |
| `<=` | 보다 작거나 같음 | `price <= 9.80` | 가격이 9.80이면 true, 가격이 9.90이면 false |
| `>` | 보다 큼 | `price > 9.80` | 가격이 9.90이면 true, 가격이 9.80이면 false |
| `>=` | 보다 크거나 같음 | `price >= 9.80` | 가격이 9.80이면 true, 가격이 9.70이면 false |
| `or` | 또는 | `price = 9.80 or price = 9.70` | 가격이 9.80이면 true, 가격이 9.60이면 false |
| `and` | 그리고 | `price = 9.80 and amount = 1` | 가격이 9.80이고 수량이 1이면 true, 가격이 9.70이고 수량이 1이면 false, 가격이 9.80이고 수량이 2이면 false, 가격이 9.70이고 수량이 2이면 false |

## Java 코드 전용

추가로 다음 연산자는 Java 코드에서만 지원됩니다:

| 연산자 | 설명 | 예제 | 반환 값 |
| --- | --- | --- | --- |
| `+` | 덧셈 | `6 + 4` | 10 |
| `-` | 뺄셈 | `6 - 4` | 2 |
| `*` | 곱셈 | `6 * 4` | 24 |
| `div` | 나눗셈 | `8 div 4` | 2 |

## 연산자 동작

연산자의 동작은 Mendix 애플리케이션에 사용되는 데이터베이스 유형에 따라 다를 수 있습니다. Mendix Runtime은 구성한 XPath에 대한 SQL 쿼리를 생성합니다. 이 쿼리는 서로 다른 데이터베이스 유형에 의해 다르게 해석될 수 있습니다. 예를 들어, HSQLDB는 = 연산자를 사용할 때 후행 공백을 무시하지만, PostgreSQL은 이를 고려합니다.
