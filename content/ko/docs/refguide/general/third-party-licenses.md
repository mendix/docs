## 소개

Mendix는 자체 라이선스를 가진 다양한 서드파티 라이브러리를 사용합니다. 모든 라이선스는 [Mendix Studio Pro](https://marketplace.mendix.com/link/studiopro/)를 다운로드할 때 확인할 수 있습니다. 아래에 설명된 **Mendix** 설치 폴더의 다양한 하위 폴더에서 찾을 수 있습니다:

| 라이브러리 및 라이선스   | 위치                                                     |
| ------------------------ | ------------------------------------------------------------ |
| Runtime Server 라이브러리 | `runtime\bundles`                                         |
| Studio Pro 라이브러리     | `modeler\Licenses`                                         |
| Client 라이선스          | Client 라이선스는 다음 위치에서 찾을 수 있습니다: <ul><li>`modeler\tools\node\licenses.csv<`/li><li>Dojo 및 기타 모든 client 종속성 라이선스: `runtime\mxclientsystem\licenses.txt`</li></ul>|
