이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.5에 적용된 변경 사항을 다루고 있습니다:

## 1.5.3

### 릴리스 날짜: 2023년 12월 28일

이 릴리스는 향후 MTS 릴리스에 대비하여 플랫폼의 안정성을 더욱 향상시키는 데 중점을 두고 있습니다.

#### 새로운 기능

#### Azure DevOps CI/CD

* 개발자를 위해 사전 구성된 Azure DevOps CI/CD Pipeline을 통해 애플리케이션을 빌드하고 배포하는 옵션을 추가하였습니다.
* Company Admin은 이제 Azure DevOps Pipelines와의 통합을 구성하고 설정할 수 있습니다. Private Mendix Platform은 이제 Azure DevOps Pipelines 호스트와 통합하고 빌드 및 배포를 위한 사전 구성된 Pipeline을 설정할 수 있습니다. 선택 및 구성되면 앱을 빌드하고 배포하는 모든 개발자가 백그라운드에서 이 서비스 통합을 자동으로 활용합니다.

#### 개선 사항

##### Download Portal 개선

###### 체크섬 추가

Private Mendix Platform 설치 프로그램의 무결성과 보안을 보장하기 위해 Download Portal에 체크섬을 추가하였습니다. 새 릴리스는 SHA-256 체크섬으로 서명되며, 다운로드한 아티팩트의 무결성을 확인하기 위해 복사하거나 다운로드할 수 있습니다.

#### 수정 사항

다음 수정 사항을 제공합니다:

* 아카이브된 플랫폼 로그에서 생성된 PDF의 정렬 문제를 수정하였습니다.
* Marketplace 템플릿이 로드되지 않은 에어갭 시나리오에서 새 앱을 생성할 때 발생하던 문제를 해결하였습니다.
* 특정 설정 조합에서 앱 이름을 변경할 때 발생하던 문제를 해결하였습니다.
* 웹 UI 및 IDE 내 Marketplace **Item** 보기에서 날짜 형식을 수정하였습니다.
* 일부 위치에서 변경되지 않은 로케일 날짜 및 시간 기본 설정을 수정하였습니다.
* **General Settings** 페이지의 사소한 레이아웃 수정을 진행하였습니다.
* **Help** 페이지의 버튼 스타일링 문제를 수정하였습니다.
* Download Portal에 대한 다양한 수정을 진행하였습니다.

#### 알려진 문제

* 최신 Studio Pro 9.24 LTS 패치 버전은 Private Mendix Platform에서 일시적으로 지원할 수 없습니다. 이 문제가 Studio Pro의 게시된 릴리스에서 해결될 때까지 Private Mendix Platform은 Studio Pro 9.24.3과만 호환됩니다.

## 1.5.2

### 릴리스 날짜: 2023년 11월 30일

이 릴리스에서는 도움말 관련, 수동 배포 프로세스 지원 및 다수의 수정 사항과 사소한 개선 사항이 포함된 추가 기능이 제공됩니다.

#### 새로운 기능

##### Help 버튼

* 개발자를 위해 Developer Portal에 **Help** 버튼과 **Help** 페이지를 추가하여 상황별 정보 번들을 다운로드할 수 있도록 하였습니다. 이 번들을 Certified Partner에게 공유하거나, 조직이 인증된 경우 플랫폼 지원팀에 **Help** 페이지에 표시된 안내에 따라 공유하십시오. 이를 통해 문제 해결을 위한 기술 정보(로그, 이벤트 등)를 간소화하여 제공할 수 있습니다.
* Company Admin은 **Settings** > **General** > **Support** 탭에서 Rich Text 입력 필드를 사용하여 적절한 지원 프로세스를 입력하여 지원 프로세스를 표준화할 수 있습니다.

##### 수동 배포 지원

* 개발자를 위해 클러스터 옵션 중 하나로 **Manual Deployment** 대상을 선택할 수 있게 되었습니다. 이러한 대상에 배포하면 빌드 아티팩트가 사전 정의된 스토리지 버킷 또는 아티팩트 레지스트리로 전송되어, Ops 팀이 이후 격리된 프로덕션 인프라에 배포할 수 있습니다. 선택적으로 Webhooks 호출을 구성하여 해당 측의 자동화 Pipeline을 시작할 수도 있습니다.
* 클러스터 관리자를 위해, 조직에 수동 Ops 개입이 필요한 격리된 프로덕션 클러스터가 있는 경우, Cluster Manager(**Settings** > **DevOps** > **CI/CD** > **Cluster Manager**)에서 **Manual Deployment** 대상을 사전 정의할 수 있습니다. 이는 빌드된 애플리케이션 패키지가 후속 수동 단계를 위해 스테이징되는 스토리지 버킷 또는 아티팩트 레지스트리입니다. 새 클러스터를 추가하는 것과 동일한 방식으로 추가하되, Manual Deployment 유형을 선택하고 스토리지 버킷에 쓰기 위한 필요한 인증을 입력하면 됩니다. 선택적으로 플랫폼 수준의 Webhook 자동화를 추가하여 해당 측의 Ops 프로세스를 자동으로 시작할 수도 있습니다.

#### 개선 사항

##### 일반 설정 및 로케일 기본 설정

* **General Settings** 페이지(관리자 접근 가능)에 **General** 탭을 추가하여 고객 및 Certified Partner 정보를 저장할 수 있도록 하였습니다.
* General 섹션에는 로케일 기본 설정도 포함됩니다. 국가를 변경하면 숫자, 날짜 및 시간, 통화 등의 로케일 종속 형식이 선택한 국가의 기본 형식으로 설정됩니다. 이 설정은 Private Mendix Platform(예: Marketplace 또는 Developer Portal)에 적용됩니다. 앱의 날짜 및 시간 또는 로케일 설정에는 영향을 미치지 않습니다.

##### 설치 프로그램의 Helm Charts

Private Mendix Platform 설치 프로그램이 이제 설치 프로그램 자체 코드의 일부였던 하드코딩된 것 대신, 파일 및 폴더 트리에서 볼 수 있는 명시적으로 정의된 Helm 차트를 사용합니다.

#### 수정 사항

다음 문제를 해결하였습니다:

* DevOps 페이지 상단에 Webhook과 관련된 무관한 오류 팝업이 나타나던 문제를 해결하였습니다.
* 숨겨진 Marketplace 항목 버전이 Studio Pro에서 볼 때 여전히 표시되던 문제를 해결하였습니다.
* Studio Pro 웹 로그인 비밀번호 가시성 아이콘이 깜빡이며 사라지던 문제를 해결하였습니다.
* 앱 이름 변경 시 앱 설정에 유효성 검사가 추가되던 문제를 해결하였습니다.
* 패키지 빌드 중 Azure DevOps를 버전 관리 시스템으로 사용할 때 발생하던 페이지네이션 문제를 해결하였습니다.
* 잘못된 Azure DevOps 자격 증명을 추가할 때 표시기가 영구적으로 회전하던 문제를 해결하였습니다.
* 소유권을 다른 사용자에게 이전할 때 이전 소유자를 제거하지 않고 새 소유자가 추가되던 오류를 해결하였습니다.
* Azure DevOps로 새 사용자 로그인 시 온보딩 중 오류가 발생하던 문제를 해결하였습니다.
* 팀 개요에서 버전 관리 호스트 간 Git 사용자 ID 표시가 달라지던 문제를 해결하였습니다.
* 일부 경우 Studio Pro에서 Azure DevOps 앱 생성 중 오류가 발생하던 문제를 해결하였습니다.
* 관리자가 **MxDock** 링크를 클릭하면 오류가 발생하던 문제를 해결하였습니다.

#### 알려진 문제

* 새로운 설치 프로그램 Helm 차트가 스크립트 배포에 영향을 미칠 수 있습니다. 플랫폼 배포를 자동화하는 Certified Partner인 경우, 자동화가 올바르게 작동하는지 확인하십시오.
* Studio Pro에서 새 브랜치에 대한 다른 복제 및 복사 메커니즘이 도입됨에 따라, 이 문제가 해결될 때까지 최신 Studio Pro 9.24 LTS 패치 버전을 일시적으로 지원할 수 없습니다. 이 문제는 향후 릴리스에서 해결될 예정입니다.

## Private Mendix Platform 릴리스

### 릴리스 날짜: 2023년 11월 15일

Private Mendix Platform은 자체 프라이빗 인프라에서 엔드투엔드 Mendix 개발자 경험을 제공합니다. 최고 수준의 데이터 보안 및 컴플라이언스를 보장하기 위해 자체 엔터프라이즈 보안 경계 내에서 애플리케이션을 개발하고 배포할 수 있는 환경을 제공합니다. Private Mendix Platform을 기존 IT 인프라와 통합하고 특정 비즈니스 요구 사항에 맞게 조정할 수 있습니다. 자세한 내용은 [Private Mendix Platform](/private-mendix-platform/)을 참조하십시오.

Private Mendix Platform은 다음 기능을 제공합니다.

{{% alert color="info" %}}
정확한 기능 지원은 선택한 구성에 따라 다릅니다. 자세한 내용은 기능별 문서를 참조하십시오.
{{% /alert %}}

* 공용 인터넷에 접근할 수 없는 환경에서도 Mendix Studio Pro 통합 및 원클릭 앱 배포
* 모든 가상 프라이빗 클라우드 내에서 완전히 호스팅되는 Mendix 개발자 경험
* 자체 ID 제공자(IdP)를 통한 Private Mendix Platform 및 Studio Pro의 SSO 인증 지원
* 브라우저 내 및 Studio Pro에서 직접 접근 가능한 프라이빗 버전의 Mendix Marketplace(모든 콘텐츠가 Private Mendix Platform 내에 완전히 호스팅됨)
* GitLab, GitHub, Bitbucket 및 Azure DevOps에 대한 SCM 저장소 지원(프로젝트의 소스 코드 저장소로 사용)
* 기본 제공 CI/CD 기능과 Jenkins 및 Tekton과의 통합 추가 지원; 사전 정의된 템플릿을 활용하거나 자체 사용자 정의 템플릿 구현 가능
* Loki 및 Grafana와의 통합을 통한 기본 로그 브라우징 및 메트릭 등의 운영 기능
* 애플리케이션 환경 관리, Marketplace 관리, 사용자 그룹 관리와 다양한 개발자 플랫폼 기능 설정 및 활동 로그 등의 거버넌스 기능
