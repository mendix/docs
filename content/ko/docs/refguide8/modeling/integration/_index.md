## 소개

다른 애플리케이션(Mendix 외)과의 통합은 REST 또는 SOAP/Web Service를 사용하여 수행할 수 있습니다. Mendix는 XML 및 JSON에서 데이터를 가져오고 내보낼 수 있습니다.

Mendix 애플리케이션 간의 통합은 REST 서비스로 수행하는 것이 가장 좋습니다(자세한 내용은 [Published REST Service](/refguide8/published-rest-services/) 및 [Call REST Service](/refguide8/call-rest-action/)를 참조하십시오). 가장 자주 사용되는 용어 중 일부는 아래에 설명되어 있습니다.

{{% alert color="info" %}}
[Call REST Service](/refguide8/call-rest-action/) 액티비티 및 [Mapping Document](/refguide8/mapping-documents/)의 JSON 지원에 대해서는 [Consumed REST Service](/refguide8/consumed-rest-services/)를 참조하십시오.
{{% /alert %}}{{% alert color="info" %}}
[Call Web Service](/refguide8/call-web-service-action/) 액티비티 및 SOAP 웹 서비스/XML 지원에 대해서는 [Consumed Web Service](/refguide8/consumed-web-services/)를 참조하십시오.
{{% /alert %}}
