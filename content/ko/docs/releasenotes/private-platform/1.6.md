이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.6에 적용된 변경 사항을 다루고 있습니다.

## 1.6.2

### 릴리스 날짜: 2024년 7월 17일

Private Mendix Platform 버전 1.6.2는 여러 버그 수정 및 안정성 개선을 포함하는 패치 릴리스입니다.

#### 개선 사항

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전을 9.24.20으로 업데이트하였습니다
* Studio Pro 10.6 MTS 최신 패치 버전을 10.6.7로 업데이트하였습니다

#### 수정 사항

다음 수정 사항을 제공합니다:

* 여러 취약점을 수정하였습니다.
* 상수 이름에 큰따옴표를 지원하도록 하였습니다.

## 1.6.1

### 릴리스 날짜: 2024년 3월 6일

Private Mendix Platform 버전 1.6.1은 여러 버그 수정 및 안정성 개선을 포함하는 패치 릴리스입니다.

#### 개선 사항

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전을 9.24.14로 업데이트하였습니다
* Studio Pro 10.6 MTS 최신 패치 버전을 10.6.1로 업데이트하였습니다

#### 수정 사항

다음 수정 사항을 제공합니다:

* SSO로 로그인을 시도할 때 오류가 발생하던 문제를 수정하였습니다.

## 1.6.0

### 릴리스 날짜: 2024년 1월 31일

Private Mendix Platform 버전 1.6.0은 MTS 릴리스로, Private Mendix Platform에 Mendix 10을 도입합니다. 이 릴리스는 장기 안정성, 성숙화 및 자동화에 중점을 두고 있으며, 최신 Mendix 주요 버전의 많은 새로운 기능과 특성을 프라이빗 개발 환경의 고객에게 소개합니다.

#### 새로운 기능

#### Mendix 10 지원

이 릴리스를 통해 Private Mendix Platform은 이제 Mendix 10을 지원하며, Studio Pro 10.6.1이 Private Platform과 함께 번들되어 패치 적용이 가능합니다. Studio Pro 10.6을 포함한 Mendix 10에는 다음과 같은 많은 개선 사항이 포함되어 있습니다:

* Studio Fusion 프로그램의 일환으로 이전 Studio 웹 모델러의 최고 기능들이 포함된 대폭 향상된 개발자 경험
* 보다 편안하고 개인화된 작업 경험을 위한 Light 및 Dark 모드
* 관리자 권한 없이도 설치 가능
* 복잡한 워크플로 구축을 더 쉽게 만드는 개선된 UI 및 확장된 기능
* IDE를 통해 접근 가능한 업계 최초의 AI 및 Machine Learning 도구와 Marketplace에서 찾을 수 있는 커넥터 및 모듈
* AI/ML 모델을 애플리케이션에 쉽게 드래그 앤 드롭하고, Mendix 런타임에 임베드하며, Microflow를 통해 상호 작용할 수 있는 기능

Mendix 10의 전체 개요는 [새로운 기능](https://www.mendix.com/whats-new/) 및 [Studio Pro 릴리스 문서](/releasenotes/studio-pro/10.6/)를 참조하십시오.

#### 개선 사항

##### 배포 개선

###### Deployment Details UX 개선

애플리케이션이 배포된 후 **Deployment Details** 페이지의 **URL field**가 이제 편집 불가능한 입력 필드가 아닌 하이퍼링크로 변경되어 앱의 URL에 쉽게 접근할 수 있습니다.

##### 엔지니어링 개선

###### 플랫폼 시작 시간 개선

제품의 엔지니어링 작업 및 코드베이스를 간소화하기 위한 노력의 일환으로, 포털의 시작 시간이 크게 개선되어 시작 중 문제가 발생할 가능성이 현저히 낮아지고 애플리케이션 시작 시간이 단축되었습니다.

##### 기타 개선 사항

###### 설치 프로그램에서 Helm Charts 사용

설치 프로그램이 이제 설치 프로그램 자체 코드의 일부였던 하드코딩된 것 대신, 폴더 트리에서 볼 수 있는 명시적으로 정의된 Helm 차트를 사용합니다. 설치 프로그램이 명시적으로 정의된 Helm 차트를 사용하는 방식이 이번 릴리스에서 더욱 개선되었으며 이제 일반적으로 접근 가능합니다.

###### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.14](/releasenotes/studio-pro/9.24/#92414)로 업데이트되었습니다
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.1](/releasenotes/studio-pro/10.6/#1061)로 업데이트되었습니다

#### 수정 사항

다음 수정 사항을 제공합니다:

* Git 브랜칭 URL 관련 Studio Pro 알려진 비호환성 문제를 수정하였습니다. 이 수정 덕분에 이번 릴리스에는 Studio Pro 9.24.14 및 10.6.1의 최신 패치 버전이 포함되어 있습니다.
* **Publish** 버튼이 플랫폼 측에서 빌드 프로세스를 트리거하지 않는 드문 문제를 해결하였습니다.
* **View app** 버튼을 클릭하면 현재 환경이 아닌 이전 환경의 URL이 열리던 문제를 해결하였습니다.
* Marketplace 탭이 포커스가 전환될 때마다 반복적으로 연결 및 재로드되던 문제를 수정하였습니다.
* 일부 상황에서 **App Buzz** 페이지의 항목이 *Created build for: null*로 표시되던 문제를 수정하였습니다.
* 최신 구성 옵션으로 First-time Configuration Wizard를 업데이트하였습니다.
* Bitbucket이 앱의 Git 서버 페이지에서 브랜치 정보를 가져올 수 없던 문제를 수정하였습니다.
