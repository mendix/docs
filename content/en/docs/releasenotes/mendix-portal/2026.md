## November 2026

### November 24, 2026

#### Improvements

* If you use Studio Pro in a [Private Mendix Platform](/private-mendix-platform/) environment, a **PMP** badge is now displayed next to your profile picture, and the user profile menu displays the name of your Private Mendix Platform portal. For more information, refer to [Mendix Profile](/portal/mendix-profile/).
