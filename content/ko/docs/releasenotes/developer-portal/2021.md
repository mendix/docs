## December 2021

## November 2021

### November 18, 2021

#### Improvements

* [Git 지원](/refguide9/branch-line-manager-dialog/#byo-server-app)의 도입으로 새로운 버전의 [Platform SDK](/apidocs-mxsdk/mxsdk/)가 필요하게 되었습니다. 이 새 버전을 수용하기 위해 Developer Portal에 일부 변경을 적용했으며, 현재 테스트 중이고 곧 게시될 예정입니다.
* 곧 Marketplace에 출시될 차세대 [Feedback 위젯](/appstore/modules/mendix-feedback/)에서 사용할 새 버전의 Feedback API를 도입했습니다.
* 이전에는 라이선스 환경이든 Free App의 샌드박스이든 관계없이 환경에 배포된 앱을 삭제하거나 비활성화할 수 없었습니다. 이제 라이선스 환경 여부만 확인하도록 동작을 변경했습니다. 이에 따라 [My Apps](/developerportal/#my-apps) 페이지의 앱 타일에 클라우드 아이콘은 라이선스 노드에 배포된 앱에만 표시됩니다.

## October 2021

### October 21, 2021

#### Improvements

* 앱 [Team](/developerportal/general/team/#managing) 개요에 비활성화된 사용자가 표시됩니다. 이 사용자들은 더 이상 Mendix Platform에 로그인하거나 앱에 기여할 수 없으며, 이전에는 보기에서 숨겨져 있었습니다. 비활성화된 사용자를 표시함으로써 앱 관리자가 해당 사용자를 앱 팀에서 제거할 수 있습니다.
* 지속적인 모니터링 중에 피크 시간대에 앱을 생성하면 성능 문제와 때때로 시간 초과가 발생하는 것을 확인했습니다. 앱 생성 프로세스를 재구성하여 이 문제를 완화했습니다.

#### Fixes

* [10월 14일](#oct-fourteen) 릴리스에서 실수로 도입된 [피드백 항목 상세 페이지](/developerportal/app-insights/feedback/#feedback-details)에 댓글을 게시할 수 없던 문제를 수정했습니다. (Tickets 132892, 132959, 132983, 133075)

### October 14, 2021 {#oct-fourteen}

#### Improvements

* **API Keys** 개요가 정확한 정보를 표시하지 않는 것을 확인하고 이에 따라 변경했습니다. API 키는 사용자 프로비저닝 시스템에 의해 캐시되기 때문에 API 키를 취소해도 플랫폼 전체에 반영되기까지 일정 시간이 소요됩니다. 이를 알려주는 새로운 확인 메시지를 추가했습니다.
* Git 지원 앱을 위한 [Team Server 리비전 기록](/developerportal/repository/team-server/#revision-history) 개요 페이지를 추가했습니다. 이를 통해 앱의 최근 40개 커밋 개요를 확인할 수 있습니다. 브랜치별로 개요를 필터링할 수 있습니다. 리비전이 사용자 스토리에 연결된 경우, Team Server 페이지에서 스토리 상세 페이지로 이동할 수 있습니다.

#### Fixes

* 태스크 중 하나의 제목이 200자를 초과하는 경우 스토리 상세를 볼 수 없던 문제를 수정했습니다.

#### Improvements

* **Stories Overview** 페이지(새 UI 및 기존 UI 모두)의 드래그 앤 드롭 동작을 단순화하여 더 안정적으로 개선했습니다.

* Developer Portal의 내부 통신 방식을 현대화하는 1년간의 프로젝트를 완료했습니다. 오래 사용된 내부 플랫폼 앱을 제거하고 Kafka 기반의 비즈니스 이벤트로 대체했습니다.

## March 2021

### March 30, 2021

#### Improvements

* 다음과 같은 주요 기능이 포함된 새로운 [플랫폼 네비게이션](/developerportal/) 솔루션을 출시했습니다:
    * 상단 바 왼쪽의 **Switch to** 메뉴를 통해 Mendix Platform의 다른 부분에 접근할 수 있습니다.
    * 상단 바에 하위 네비게이션 항목(예: **Company Buzz**)이 포함됩니다.
    * 상단 바 오른쪽의 **+** 버튼을 클릭하면 플랫폼 어디에서나 새 앱을 생성할 수 있습니다.
    * 상단 바 오른쪽의 아바타 아래에 새 네비게이션을 끄는 옵션이 있으며, 제한된 기간 동안 사용할 수 있습니다.
* 검색 경험을 개선하고 검색 드롭다운 메뉴 하단의 **View Search Results Page**를 클릭하거나 검색어 입력 후 <kbd>Enter</kbd>를 눌러 접근할 수 있는 전체 페이지 검색 결과를 추가했습니다.
* [My Apps](/developerportal/#my-apps) 페이지를 변경하고 즐겨찾기 앱을 **Pinned** 탭으로 이동했습니다. 이 탭이 이 페이지의 기본 탭이 되어 가장 중요한 앱에 빠르게 접근할 수 있습니다.
* 요청에 따라 Stories의 라벨에 새 라벨 색상을 추가했습니다. 이제 접근성을 고려하여 특별히 선택된 15가지 색상 중에서 선택할 수 있습니다.
* Developer Portal의 디자인에 대규모 변경을 적용했습니다:
    * 리서치 인사이트를 기반으로 [App Buzz](/developerportal/general/overview/)의 네비게이션 항목을 더 논리적인 순서로 재배치했습니다. 이제 **Collaborate**와 **Deploy** 두 개의 주요 섹션이 있습니다.
    * 다양한 네비게이션 항목(**Feedback**, **Planning**, **Team Server**, **General**)의 디자인을 새 디자인으로 업데이트했습니다.
    * 모든 페이지에서 흰색 카드 콘텐츠가 있는 회색 배경을 제거했습니다.
    * 프로젝트 네비게이션 왼쪽 상단의 브레드크럼을 앱 이름과 아이콘으로 대체했습니다.

#### Fixes

* Studio Pro에서 피드백을 보내면 오류가 발생하던 문제를 수정했습니다. (Tickets 113634, 115031)
