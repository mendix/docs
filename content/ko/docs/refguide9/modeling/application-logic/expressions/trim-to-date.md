## 소개

날짜를 다양한 시간 단위로 반올림하는 함수입니다.

## trimToSeconds

이 함수는 날짜를 초 단위로 자르고, 모든 밀리초를 0으로 반올림하는 데 사용됩니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                            | 유형          |
| -------------------------------- | ------------- |
| 자를 날짜입니다. | Date and time |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                       | 유형          |
| ------------------------------------------- | ------------- |
| 동일한 날짜이지만 초 단위로 내림된 값입니다. | Date and time |

### 예제

예를 들어, '08-06-2008 10:12:51.387'을 나타내는 변수 `$myDate`가 있습니다:

```java
trimToSeconds($myDate)
```

출력은 다음과 같습니다:

```java
'Sun Jun 08 10:12:51 CEST 2008'
```
