## 3.3.0

**릴리스 날짜: 2017년 4월 13일**

* Modeler 버전 7.2.0 지원을 추가하였습니다.

## 3.2.0

**릴리스 날짜: 2017년 3월 17일**

* `pages.NewButton` 엘리먼트의 `pageSettings` 속성이 더 이상 선택 사항이 아닙니다.
* Modeler 버전 7.1.0 지원을 추가하였습니다.

## 3.1.1

* Modeler 버전 7.0.2 지원을 수정하였습니다.

## 3.1.0

* Modeler 버전 6.10.4 지원을 추가하였습니다.
* Modeler 버전 7.0.2 지원을 추가하였습니다.

## 3.0.3

내부 속성이 타이핑에 실수로 포함되는 문제를 수정하였습니다.

## 3.0.2

Modeler 버전 7.0.1 Beta 2 지원을 추가하였습니다.

## 3.0.1

| 영향도 | 설명 |
| --- | --- |
| 낮음 | 목록 파트 속성에서의 멱등 스플라이스가 인식되어 아무 작업도 수행하지 않습니다(모델을 잠재적으로 손상시키는 대신). |
| 없음 | 해결되지 않은 이름 참조가 이제 유닛에서 검사를 실행할 때 보고됩니다. |
| 낮음 | `deploy` 작업이 더 이상 사용되지 않으며 `startAppUpdate` 및 `getAppUpdateStatus`로 대체되었습니다. 마찬가지로 `getDeploymentStatus`는 `getAppEnvironmentStatus`로 대체되었습니다(SDK로 생성된 프로젝트에는 배포를 사용할 수 없으므로 영향이 낮습니다). |

참고: 영향도 = 낮음은 "일부 코드가 이제 작동할 수 있음"을 의미합니다.

## 3.0.0

| 영향도 | 설명 |
| --- | --- |
| 높음 | **호환성 변경!** `(I)ModelUnit` 타입에서 `moduleName` 메서드가 제거되었습니다. 대신 `(I)AbstractElement`의 `qualifiedName`을 사용하세요. |
| 낮음 | 컨테이너 간에 엘리먼트를 이동할 때 발생하는 여러 문제를 수정하였습니다. |
| 낮음 | 해결할 수 없는 이름 참조를 수정할 수 없는 문제를 수정하였습니다. |
| 낮음 | 모든 NPM 의존성이 이제 캐럿 버전 범위를 가지므로, 다운스트림의 피어 의존성으로 함께 작동할 수 있습니다. |
| 없음 | Modeler 버전 7.0.0 지원을 추가하였습니다. |
| 없음 | 여러 구조를 포함하는 속성(예: `pages.VerticalFlow.widgets`)에 `move(from, to)` 메서드를 추가하였습니다. |
| 없음 | 모델 유닛(예: Pages) 삭제 가능성을 추가하였습니다. |
| 없음 | Model API에 대한 불필요한 트래픽 문제를 수정하였습니다. |
| 없음 | 원시 배포에서의 성공/오류 처리에 대한 내부 개선을 수행하였습니다. |
| 없음 | WM 릴리스를 위한 검사를 추가하였습니다. |

참고: 영향도 = 낮음은 "일부 코드가 이제 작동할 수 있음"을 의미합니다.

"모델 유닛 삭제" 추가: 모델 유닛의 컨테이너에서 `splice`를 사용하여 수행합니다. 예를 들어:

```text
const deleteIndex = page.container.documents.indexOf(page);
page.container.documents.splice(deleteIndex, 1);
```
