## Client API

Client API는 React 클라이언트와 Dojo 클라이언트 모두와 호환됩니다. 이 공식 문서 사이트에는 예제, 모듈 등이 포함되어 있습니다:

* [Mendix 11 Client API 문서](https://apidocs.rnd.mendix.com/11/client-mx-api/index.html)

{{% alert color="warning" %}}
Client API는 위젯에서 지원되지 않습니다. 위젯 개발에는 [Pluggable Widgets API](/apidocs-mxsdk/apidocs/pluggable-widgets/)를 사용하십시오.
{{% /alert %}}
