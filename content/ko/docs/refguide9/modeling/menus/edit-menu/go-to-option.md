## 소개

Navigation, 페이지 또는 Microflow 편집기와 같은 Studio Pro 편집기에서 항목을 마우스 오른쪽 버튼으로 클릭하면 유용한 메뉴에 접근할 수 있습니다. **Go to** 옵션은 앱 내에서 경로를 찾는 데 일반적으로 사용됩니다. 한 요소에서 다른 요소로 이동할 수 있습니다: 예를 들어 버튼의 대상으로 이동하거나 Data Grid의 소스로 이동할 수 있습니다.

## Go to 옵션

**Go to** 옵션의 사용 예시는 아래에 설명되어 있습니다:

* **메뉴 항목의 대상 열기** – **App** > **Navigation**에서 메뉴 항목을 마우스 오른쪽 버튼으로 클릭하고 **Go to target**을 선택할 수 있습니다. Studio Pro가 메뉴 항목의 해당 대상(예: 페이지)을 엽니다.

    {{< figure src="/attachments/refguide9/modeling/menus/edit-menu/go-to-option/go-to-target.png" alt="Go to Target" class="no-border" >}}

* **요소의 데이터 소스 열기** – 페이지에서 Widget의 데이터 소스로 이동할 수 있습니다. 예를 들어 Data Grid의 버튼을 마우스 오른쪽 버튼으로 클릭하고 **Go to microflow**를 선택할 수 있습니다. Mendix Studio Pro가 해당 Microflow를 엽니다:

    {{< figure src="/attachments/refguide9/modeling/menus/edit-menu/go-to-option/go-to-microflow.png" alt="Go to Microflow" class="no-border" >}}

* **Microflow에서 Entity 열기** – Microflow에서 Activity를 마우스 오른쪽 버튼으로 클릭하고 **Go to entity**를 선택하면 Domain Model의 Entity로 이동할 수 있습니다. Mendix Studio Pro가 해당 Domain Model을 엽니다:

    {{< figure src="/attachments/refguide9/modeling/menus/edit-menu/go-to-option/go-to-entity.png" alt="Go to Entity" class="no-border" >}}
