## 소개

Subtract date 함수 호출은 날짜와 시간에서 기간을 빼고 수정된 값을 반환합니다.

첫 번째 매개변수는 **Date and time** 유형의 Domain Model Entity Attribute, **Date and time** 유형의 변수 또는 [Date Creation](/refguide9/date-creation/) 함수를 사용하여 생성된 **Date and time** 값일 수 있습니다. 두 번째 매개변수는 뺄 기간을 지정합니다. 다양한 **Subtract date 함수** 호출에 Long 유형의 값을 전달할 수도 있습니다.

지정된 날짜에 기간을 추가할 수도 있습니다. 자세한 내용은 [Add Date 함수 호출](/refguide9/add-date-function-calls/)을 참조하십시오.

## subtractMilliseconds

`subtractMilliseconds` 함수는 날짜에서 지정된 밀리초 수를 뺍니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                                       | 유형          |
| ------------------------------------------- | ------------- |
| 초기 날짜                                | Date and time |
| 뺄 밀리초 수 | Integer       |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형          |
| ------------------------------------------------------------ | ------------- |
| *초기 날짜*에서 지정된 *밀리초* 수를 뺀 결과인 date and time 값입니다. | Date and time |

### 예제

다음 입력을 사용하는 경우:

```java
subtractMilliseconds(dateTime(2007, 1, 1, 1, 1, 1), 1000)
```

출력은 다음과 같습니다:

```java
Mon Jan 01 01:01:00 CET 2007
```
