## Introduction

  The **Module overview** gives you a single view of all the modules in your app, together with some basic information about each one.

  You can open **Module overview** in the following ways:

  * In the **App Explorer**, double-click **Module overview**.                                            
  * In MxDock, go to **App** > **Tools** > **Module Overview**.

## Toolbar 

### View in Marketplace

  Select a module and click **View in Marketplace** to open the module's page in the Marketplace pane within Studio Pro. This option is only available for Marketplace modules. 

### Update 

  Click **Update** and choose **From file** to update the selected module. This works the same way as updating a module from the **App Explorer**.

## Module List

  The module list shows every module in your app, including protected modules, with the following columns:

  | Column | Description |
  | --- | --- |
  | **Local name** | The name with which the module is displayed in the **App Explorer**. |                                                          
  | **Local version** | The version of the installed module. |
