## February 2026

### February 1, 2026

#### General Availability Release

* [Version Pinning](/developerportal/deploy/version-pinning/)이 이제 일반 출시(GA)되었으며, 모든 Mendix Cloud(Kubernetes) 사용자에게 기본적으로 활성화됩니다. 회사 수준의 활성화가 더 이상 필요하지 않습니다.

#### New Features

* Technical Contact는 이제 Control Center의 [Certificate Management](/control-center/certificate-management/) 페이지에서 Mendix Admin이 생성한 [중앙 집중식 인증서](/developerportal/deploy/certificates/centralized-certificates/)를 사용하여 애플리케이션 수준에서 [사용자 정의 도메인을 구성](/developerportal/deploy/custom-domains/#Configuring)할 수 있습니다.

#### Bug Fixes

* 데이터베이스 버전이 표시되지 않던 문제를 수정했습니다. (Tickets #257091, #260360, #262575)
* 잘린 상수 값의 표시 문제를 수정했습니다. 값이 이제 있는 그대로 표시됩니다. (Ticket #262456)
* 배포 팝업에서 잘못된 **Mendix Pipelines** 링크 문제를 수정했습니다.

## January 2026

### January 18, 2026

#### New Features

* 중앙 집중식 인증서 관리 지원을 추가했습니다. **Cloud Settings** 페이지의 업데이트된 [Custom Domains](/developerportal/deploy/environments/#custom-domains) 탭을 통해, Technical Contact는 이제 애플리케이션 수준뿐만 아니라 사용자 정의 도메인 인증서를 중앙에서 관리할 수 있습니다. 인증서가 앱 수준에서 로컬로 관리되는지 중앙에서 관리되는지도 확인할 수 있습니다.

### January 16, 2026

#### New Features

* [Splunk Cloud Platform 통합](/developerportal/operate/splunk-metrics/)에 메트릭 지원을 추가했습니다.

### January 11, 2026

#### Improvements

* [배포 패키지 생성](/developerportal/deploy/environments/#create-package-wizard) 시 **Options** 탭의 **App highest tag** 및 **Branch highest tag**를 각각 **App latest tag** 및 **Branch latest tag**로 이름을 변경하여 다른 Mendix 애플리케이션과의 일관성을 보장합니다.
* [Plan Change Requests 상태](/developerportal/deploy/change-plan/#plan-change-status)에 새로운 **Ineligible** 상태가 추가되었습니다.
* APM 도구가 이제 완전히 지원되므로, Kubernetes 애플리케이션에 대한 사용자 정의 환경 변수 구성 대화 상자에서 APM 도구에 관한 경고 배너가 제거되었습니다.

#### Bug Fixes

* [Permissions 탭](/developerportal/deploy/environments/#permissions-tab)에서 환경 선택 드롭다운이 선택된 환경 이름을 올바르게 표시하지 않던 문제를 수정했습니다. (Ticket 264653)
* 무료 앱 배포가 차단될 때 표시되는 배너가 이제 올바른 **Control Center** 페이지로 링크되도록 수정했습니다.

### January 5, 2026

#### New Features

* **Environment Details** 페이지의 **Connectivity** 탭에 Technical Contact가 [Mendix Cloud Private Connectivity](/control-center/private-connectivity/)를 통해 [Mendix 애플리케이션을 외부 리소스에 안전하게 연결](/developerportal/deploy/connecting-to-external-resource/)할 수 있는 새 기능을 추가했습니다.
    * **Connectivity** 탭의 [Connections](/developerportal/deploy/environments-details/#connections) 섹션에서 Technical Contact는 이제 새로운 프라이빗 연결을 요청하고, 대기 중인 연결 요청의 상태를 추적하고, 외부 리소스에 연결하고, 기존 연결을 삭제할 수 있습니다.
