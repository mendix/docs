## November 2019

### November 14, 2019

#### 개선 사항

Mendix Marketplace 콘텐츠를 유지 관리하여 필요한 위젯과 모듈을 더 쉽게 찾고 사용할 수 있도록 투자하고 있습니다. 이를 위해 Mendix 지원이 더 이상 불가능한 이전 App Store 콘텐츠를 정리하고 지원 레벨을 **Platform support**에서 **Community support**로 변경했습니다.

이러한 지원 레벨에 대한 자세한 내용은 *Marketplace Overview*의 [Marketplace Content Support](/appstore/marketplace-content-support/) 섹션을 참조하세요.

### November 6, 2019

#### 개선 사항

* 즐겨찾는 App Store 콘텐츠의 새 버전이 게시될 때 이메일을 받을 수 있도록 구독할 수 있습니다.

## October 2019

### October 23, 2019

#### 새로운 기능

이제 회사에 대한 [사용자 그룹](/appstore/home-page/#content-groups)을 생성하고 회사의 App Store 콘텐츠를 다른 그룹에 할당할 수 있습니다. 사용자 그룹 콘텐츠의 관리는 그룹 멤버로만 제한됩니다. 이러한 그룹에 [게스트](/appstore/home-page/#guests) 사용자를 추가하고 선택한 비공개 회사 콘텐츠를 다운로드할 수 있도록 허용할 수도 있습니다.

이전 App Store **Content Managers** 및 **External Downloaders** 그룹이 제거되었습니다. 이 그룹의 멤버들은 **Migrated Data**라는 새로운 임시 사용자 그룹으로 마이그레이션되었습니다. 이전 "콘텐츠 관리자"는 사용자 그룹 [멤버](/appstore/home-page/#members)로, 이전 "외부 다운로더"는 [게스트](/appstore/home-page/#guests)로 추가되었습니다.

**Protected**로 표시된 콘텐츠와 **Shared with Others**로 표시된 콘텐츠가 Migrated Data 사용자 그룹의 [Content](/appstore/home-page/#group-content) 탭으로 마이그레이션되었습니다. 이를 통해 모든 "외부 공유" 콘텐츠가 해당 사용자 그룹에 대해 보호됩니다.

## August 2019

### August 30, 2019

#### 개선 사항

일관성을 위해 App Store의 모든 SAP 관련 커넥터 및 앱 템플릿의 이름을 변경했습니다. 변경 사항은 다음과 같습니다:

| Type | Old Name | New Name |
| ----- | ----- | -----|
| Connector | SAP Cloud Platform XSUAA Connector | XSUAA Connector for SAP Business Technology Platform |
| Connector | SAP Fiori UI Package | UI Package for SAP Fiori themed apps |
| Connector | SAP Leonardo Machine Learning Foundation Connector | Connector for SAP Leonardo Machine Learning Foundation |
| Connector | SAP OData Connector | OData Connector for SAP solutions |
| Connector | SAP OData Model Creator | OData Model Creator for SAP solutions |
| App Template | Fiori Blank | Blank App for SAP Fiori themed apps |
| App Template | SAP Northwind OData | Northwind OData Service Master-Detail App for SAP solutions |
| App Template | SAP Purchase Order Approval Tutorial | Purchase Order Approval Tutorial for SAP solutions |

### August 26, 2019

#### 개선 사항

* **SAP OData Connector**를 업데이트하여 **Edm.Int64** 데이터 타입을 지원합니다. (Ticket 87284)

#### 수정 사항

* OData 서비스 엔드포인트에 큰 요청을 보낼 때 발생하는 *java.net.SocketException: Broken pipe (Write failed)* 예외도 수정했습니다. (Ticket 86680)

## July 2019

### July 31, 2019  

#### 개선 사항 

* 새로운 App Store 콘텐츠를 만들 때 Documentation 섹션의 서식 옵션을 간소화했습니다.
* Documentation 편집기에 이미지를 업로드할 수 있게 했습니다 - 파일 탐색기에서 편집기로 이미지를 끌어다 놓거나 URL을 통해 이미지에 연결할 수 있습니다(브라우저 불일치로 인해 복사 + 붙여넣기는 작동하지 *않습니다*).
* GitHub를 소스로 사용하여 새 콘텐츠를 만들 때 일부 사용자 변경 및 개선을 수행했습니다. 예를 들어, 리포지토리를 선택할 때 더 쉽게 사용할 수 있는 선택 화면을 제공합니다.  
* 기타 사소한 버그 수정도 수행했습니다. 

### July 5, 2019

#### 개선 사항

* **SAP Logging Connector**를 업데이트하여 열거형 대신 상수를 통해 로그 레벨을 설정할 수 있도록 했습니다. 이를 통해 앱을 완전히 재배포할 필요 없이 재시작 시 로그 레벨을 변경할 수 있습니다.
* SAP Logging Connector가 Community Commons 모듈과 충돌하는 문제를 해결했습니다.

## April 2019

### April 29, 2019

#### 개선 사항

* 새로운 App Store 메뉴 구조를 만들어 생성된 콘텐츠를 더 쉽게 탐색할 수 있습니다. 특정 권한을 가진 Mendix Admin인 경우 비공개 및 공개 회사 콘텐츠를 관리하는 데 도움이 되는 추가 메뉴 항목이 표시됩니다.
* App Store 관리자의 경우, 이제 보호된 콘텐츠로 표시하여 회사 콘텐츠를 관리할 수 있는 콘텐츠 관리자를 설정할 수 있습니다.
* 이제 비공개 App Store 콘텐츠를 다른 회사의 외부 다운로더와 공유할 수 있습니다.

## February 2019

### February 15, 2019

#### 개선 사항 

* Destination이 존재하지 않거나 앱이 로컬로 실행 중인 경우 Microflow에서 잡을 수 있는 오류를 발생시킵니다. 이전에는 오류를 잡을 수 없었습니다.
* Oracle DB를 데이터베이스로 사용하는 Mendix 앱에 대한 OData Connector 지원을 제공합니다.
* OData Connector 액션의 일부 오타를 수정했습니다.

## January 2019

### January 21, 2019

#### 수정 사항

[App Store 메인 페이지](https://marketplace.mendix.com/) 하단의 **Reviews** 섹션은 최근 게시된 사용자 리뷰를 표시합니다. 사용자 이름을 클릭하여 프로필을 볼 때 내부 서버 오류가 발생하는 문제를 수정했습니다. 이제 예상되는 사용자로 리디렉션됩니다.
