Pluggable Web Widget은 React 기반의 Mendix 사용자 정의 Widget입니다. 이 UI 라이브러리를 사용하면 Widget을 쉽고 적은 오류로 맞춤 제작할 수 있습니다. Pluggable Web Widget에 대한 자세한 내용은 [Pluggable Widgets API](/apidocs-mxsdk/apidocs/pluggable-widgets/), [Pluggable Widget에서 사용 가능한 Client API](/apidocs-mxsdk/apidocs/pluggable-widgets-client-apis/) 및 [Pluggable Widget 속성 유형](/apidocs-mxsdk/apidocs/pluggable-widgets-property-types/)을 참조하세요. 이 사용 방법 시리즈는 Pluggable Web Widget의 강력한 기능을 단계별로 알려드립니다:

* [Pluggable Web Widget 빌드: 파트 2 (고급)](/howto10/extensibility/create-a-pluggable-widget-two/)
