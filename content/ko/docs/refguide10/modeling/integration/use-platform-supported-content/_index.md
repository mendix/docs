## 소개

Mendix Studio Pro에서 플랫폼 지원 콘텐츠를 사용하여 외부 소스에 연결하고 정보를 수신하세요.

이 주제에 대해 제공되는 문서:

* [Business Event Services](/refguide10/business-event-services/)

* [Data Importer 사용하기](/refguide10/use-the-data-importer/)

   Data Importer를 사용하여 대표 파일(Excel 및 CSV)에서 데이터를 가져오고 도메인 모델에 비영속(non-persistable) 엔티티를 만드는 방법에 대한 개요입니다.

* [외부 데이터베이스에 연결](/refguide10/external-database-connection/)

   External Database Connection 문서를 구성하는 방법에 대한 개요입니다.

* [외부 데이터 쿼리 및 통합](/refguide10/query-and-integrate-external-data/)

   External Database Connector를 사용하여 외부 데이터베이스를 쿼리하고 데이터를 Mendix 애플리케이션에 통합하는 방법을 자세히 설명합니다.

* [외부 데이터베이스에서 SQL 문 실행](/refguide10/execute-an-sql-statement-on-an-external-database/)

   Database Connector를 사용하여 관계형 외부 데이터베이스에서 SQL 문을 실행하는 방법을 설명합니다.
