## 9.0.3 {#902}

**릴리스 날짜: 2024년 10월 2일**

### 개선 사항

* Android SDK 버전을 35로 업그레이드했습니다.
* `react-native-permissions`를 버전 4.1.5로 업그레이드했습니다.
 
## 9.0.1 {#901}

**릴리스 날짜: 2024년 9월 3일**

### 개선 사항

* `react-native-video`를 6.4.5로 업그레이드했습니다.

### 수정 사항

* iOS 18에서의 OTA 업데이트 호환성 문제를 수정했습니다.

## 9.0.0 {#900}

**릴리스 날짜: 2024년 7월 30일**

### 개선 사항

* React Native 버전을 0.73.8로 업그레이드했습니다. 이 중요한 업데이트는 성능을 개선하고 React Native의 최신 기능과의 호환성을 높입니다.
