## 소개

이 섹션에서는 Mendix Marketplace 안팎에서 판매할 수 있는 Solution을 개발하는 방법에 대한 정보와 지침을 제공합니다.

## Solution이란?

Solution은 여러 다양한 고객에게 판매하기에 적합한 모든 Mendix 앱입니다. 이는 앱이 더 넓은 범위의 고객의 요구와 기대에 맞게 구축되었으며, 런타임에 구성 가능하여 고객의 요구에 더 잘 대응할 수 있음을 의미합니다. 이 경우 일반적인 Mendix 개발 [모범 사례](/refguide/dev-best-practices/)가 적용되며, Mendix Platform에서 사용 가능한 모든 템플릿으로 Solution 구축을 시작할 수 있습니다.

고객은 종종 Solution이 기본적으로 지원하는 것 이상을 요구합니다. 고객의 IT 환경에 있는 기존 시스템과의 통합, 고객의 프로세스에 더 잘 맞도록 하는 변경, 또는 단순히 고객의 브랜드에 더 잘 맞도록 UI를 조정하는 것이든, 이러한 조정에는 규범적인 SaaS(Software-as-a-Service) 솔루션 이상이 필요합니다. 이는 고객의 특정 요구에 맞게 Solution을 조정할 수 있도록 해야 함을 의미합니다.

기본 로직과 고객 맞춤화를 결합하는 방법에 대한 자세한 내용은 [적응 가능한 Solution 소개](/appstore/creating-content/sol-adapt/)를 참조하십시오.

## 더 읽어보기

* 프리미엄 컴포넌트를 게시하려는 경우 [Mendix Component Partner Program](/appstore/partner-program/)의 세부 정보를 참조하십시오.

* 상업적 Solution을 구축하고 마케팅하려는 경우 [Mendix Commercial Solution Partner Program](/appstore/creating-content/comm-sol-partner-program/)을 참조하십시오.

* 그런 다음, Mendix Platform에서 Marketplace에서 판매할 준비가 된 Solution을 개발하기 위한 원칙과 모범 사례를 제시하는 [적응 가능한 Solution 소개](/appstore/creating-content/sol-adapt/)로 진행하십시오.

* 이 페이지들을 읽은 후, [앱을 만들고](https://new.mendix.com/) 시작하십시오!
