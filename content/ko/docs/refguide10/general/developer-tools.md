개발을 좀 더 쉽게 하기 위해, 앱 개발 작업을 가속화할 유용한 서드파티 도구 목록을 소개합니다:

* [Linux m2ee scripts](https://github.com/mendix/m2ee-tools) – GNU/Linux용 Mendix Runtime 도우미 도구 (설치에 대한 자세한 내용은 [GNU/Linux에 Mendix 설치하기](https://github.com/mendix/m2ee-tools/blob/master/doc/README.md)를 참조하세요)
* [Firefox DevTools](https://www.mozilla.org/en-US/firefox/developer/?utm_source=firebug&utm_medium=lp&utm_campaign=switch&utm_content=landingpage) – 더 이상 지원되지 않는 [Firebug](https://getfirebug.com/)를 대체하는 개발자 도구
* [Selenium](https://www.seleniumhq.org/) – 웹 브라우저 자동화 도구
* [Eclipse](https://www.eclipse.org/downloads/) – Java Action 작성 및 디버깅 도구 (자세한 정보는 [Eclipse 사용하기](/refguide10/using-eclipse/)를 참조하세요)
* [SOAP UI](https://www.soapui.org/) – REST 및 SOAP 테스트 도구 (자세한 정보는 [SoapUI를 사용하여 웹 서비스 테스트하기](/howto10/testing/testing-web-services-using-soapui/)를 참조하세요)
* [Visual Studio Code](https://code.visualstudio.com/) – 강력한 코드 편집기 (특히 테마 유지 관리에 유용)
