## 소개

개발 작업을 좀 더 쉽게 만들기 위해, 앱 개발 작업을 가속화할 유용한 서드파티 도구 목록을 소개합니다:

* [Linux m2ee 스크립트](https://github.com/mendix/m2ee-tools) – GNU/Linux용 Mendix Runtime 헬퍼 도구(설치에 대한 자세한 내용은 [GNU/Linux에 Mendix 설치](https://github.com/mendix/m2ee-tools/blob/master/doc/README.md)를 참조하십시오)
* [Firefox DevTools](https://www.mozilla.org/en-US/firefox/developer/?utm_source=firebug&utm_medium=lp&utm_campaign=switch&utm_content=landingpage) – 이 개발자 도구는 더 이상 지원되지 않는 [Firebug](https://getfirebug.com/)를 대체합니다
* [Selenium](https://www.seleniumhq.org/) – 웹 브라우저 자동화 도구
* [Eclipse](https://www.eclipse.org/downloads/) – Java Action 작성 및 디버깅 도구(자세한 내용은 [Eclipse 사용](/refguide8/using-eclipse/)을 참조하십시오)
* [SOAP UI](https://www.soapui.org/) – REST 및 SOAP 테스트 도구(자세한 내용은 [SoapUI를 사용한 웹 서비스 테스트 방법](/howto8/integration/testing-web-services-using-soapui/)을 참조하십시오)
* [Visual Studio Code](https://code.visualstudio.com/) – 강력한 코드 편집기(특히 테마 유지관리에 유용합니다)
