## 소개

[Catalog](https://catalog.mendix.com)를 사용하여 다양한 소스의 데이터를 빌드, 업데이트 및 공유하세요.

이 주제에 대해 제공되는 문서:

* [앱 간 데이터 공유](/refguide10/share-data/)

    Studio Pro에서 간단한 데이터 자산을 Catalog에 게시 및 등록하고, 이 자산을 사용하는 새 앱을 만드는 방법을 설명합니다.

* [다른 앱에 데이터 쓰기](/refguide10/write-data/)

    Mendix Studio Pro에서 OData 서비스에 어노테이션을 추가하고, Catalog에서 이러한 기능이 포함된 외부 엔티티(Entity)를 확인하며, 이를 사용하여 앱을 구축하는 방법을 설명합니다.
