## 소개

[Menditect Test Automation (MTA)](https://marketplace.mendix.com/link/component/120116)는 자동화된 회귀 테스트를 위한 도구입니다. MTA는 단위, 컴포넌트, 프로세스, 사용자 인터페이스(UI) 및 API 테스트를 애플리케이션 라이프사이클에 포함시킬 수 있는 노코드 시각적 자동화 테스트 도구 모음을 제공합니다. 자세한 내용은 [Menditect](https://menditect.com/) 웹사이트를 참조하십시오.

{{% alert color="info" %}}
MTA 구매에 대한 자세한 내용은 Customer Success Manager(CSM)에게 문의하거나 [문의 양식](https://www.mendix.com/contact-us/#contactform)을 작성하십시오.
{{% /alert %}}

## Mendix에서 MTA 사용하기

Mendix를 통해 구매한 경우, MTA는 아래 요구 사항에 따라 모든 Mendix 클라우드 호스팅 옵션에서 사용할 수 있습니다:

* 테스트 대상 애플리케이션 모델은 Mendix Team Server 저장소에 저장되어 있어야 합니다.
* MTA 애플리케이션과 테스트 대상 애플리케이션은 Mendix Team Server 및 Project API를 포함한 Mendix 플랫폼 API와 네트워크 연결을 설정할 수 있어야 합니다.

UI 테스트의 경우, MTA는 Playwright가 필요합니다. 지원되는 옵션은 자체 호스팅 Playwright 또는 BrowserStack SaaS 인스턴스입니다.

현재 MTA는 온프레미스 Git 저장소를 사용하거나 완전한 에어갭 시나리오에서 실행되는 앱에는 사용할 수 없습니다.

{{% alert color="info" %}}
MTA는 Mendix 구독과 별도의 유료 애드온으로 제공됩니다. Mendix 기반 애플리케이션이므로 별도로 획득해야 하는 Mendix 라이선스와 클라우드 리소스가 필요합니다.
{{% /alert %}}
