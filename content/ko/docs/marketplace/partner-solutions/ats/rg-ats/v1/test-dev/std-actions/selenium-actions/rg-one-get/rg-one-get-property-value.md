## 설명

웹 요소에서 속성 값을 반환합니다.
(Dojo Widget 속성에는 액세스할 수 없습니다)

## 사용법

텍스트 값을 가져오려는 WebElement를 전달하세요.

## 입력 파라미터

Name | Datatype | Required | Description
---- | -------- | ------- |---------------
Element | WebElement | yes | 속성 값을 가져오려는 WebElement입니다.
Property Name | String | yes | 속성의 이름입니다.

## 반환 값

Name | Datatype | Description
---- | --------- | ---------------
Property Value | String | WebElement 속성의 현재 값입니다.
