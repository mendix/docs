## 소개

**My Apps** 페이지는 Private Mendix Platform의 랜딩 페이지입니다.

{{< figure src="/attachments/private-platform/pmp-homepage.png" class="no-border" >}}

다음 요소가 포함되어 있습니다:

### 온보딩 {#onboarding}

**My Apps** 페이지의 상단 섹션에는 새 사용자가 Private Mendix Platform을 시작하는 데 도움이 되는 요소가 포함되어 있습니다. 다음 블록으로 구성됩니다:

* **Download & Install Studio Pro** - 이 블록을 클릭하면 Private Mendix Platform에서 사용 가능한 최신 버전의 Studio Pro를 다운로드합니다.
* **Patch Studio Pro** - 이 블록을 클릭하면 Studio Pro에 필요한 패치 파일을 다운로드합니다.
* **Create a New App Project** - 이 블록을 클릭하면 새 앱을 만듭니다. 자세한 내용은 [새 앱 만들기](/private-mendix-platform/user-guide/#create-app)를 참조하십시오.

**온보딩** 섹션을 숨기려면 **Hide onboarding**을 클릭하십시오.

### 내 앱 개요

**My Apps** 페이지의 하단 섹션에는 활성 및 보관된 애플리케이션의 개요가 포함되어 있습니다. 다음 요소가 포함되어 있습니다:

* 검색 바 - 검색 바를 사용하여 이름 또는 설명으로 앱을 검색하십시오.
* **Active** 탭 - 현재 활성 상태인 모든 앱을 표시합니다. 각 타일에는 앱의 현재 멤버 수와 보관 또는 삭제할 수 있는 하위 메뉴가 표시됩니다. 앱에 대한 자세한 내용을 보려면 해당 타일을 클릭하십시오. 자세한 내용은 [앱 관리](/private-mendix-platform/user-guide/#manage-app)를 참조하십시오.
* **Archived** 탭 - 보관된 모든 앱을 표시합니다. 보관된 프로젝트를 다시 활성화하려면 해당 타일을 클릭하십시오. 멤버가 두 명 이상인 앱은 보관할 수 없습니다.
