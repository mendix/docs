## 소개

수학 함수 호출에는 최대값 반환 또는 숫자 올림과 같은 숫자에 대한 제한된 수의 수학 연산이 포함됩니다.

더 정교한 함수(예: 제곱근, sin, cos, tan, numberOfPermutations, factorial 또는 fibonacciNumber)가 필요한 경우 Mendix Marketplace에서 제공되는 커뮤니티 지원 [Math](https://marketplace.mendix.com/link/component/112522/) 모듈 사용을 고려하십시오.

## max

지정된 인수에서 가장 큰 값을 반환합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값              | 유형                                   |
| ------------------ | -------------------------------------- |
| 두 개 이상의 값 | 모두 숫자 유형(Integer/Long 또는 Decimal) 또는 모두 Date and time                          |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                           | 유형                                                         |
| ----------------------------------------------- | ------------------------------------------------------------ |
| 지정된 인수에서 가장 큰 값입니다. | 인수가 Date and time 유형인 경우 결과도 Date and time 유형입니다. <br />인수가 숫자인 경우 결과는 가장 정밀한 유형이 됩니다. <br />예를 들어, Integer/Long과 Decimal 인수가 모두 지정된 경우 결과는 Decimal 유형이 됩니다. |

### 예제

다음 입력을 사용하는 경우:

```java
max(5, 1, 5, 6.7)
```

출력은 decimal입니다:

```java
6.7
```

## round

숫자를 특정 정밀도로 반올림합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값                  | 유형                  |
| ---------------------- | --------------------- |
| 숫자               | Integer/Long, Decimal |
| 정밀도 (선택 사항) | Integer/Long          |

### 출력

[앱 설정](/refguide9/app-settings/)에서 **숫자 반올림** 옵션을 설정할 수 있으며, 이는 반수(0.5)가 처리되는 방식을 결정합니다:

* **0에서 먼 방향으로 반올림** 옵션("상업적 반올림"이라고도 함)의 경우, +2.5는 +3이 되고 -1.5는 -2가 됩니다
* **가장 가까운 짝수로 반올림** 옵션("은행가 반올림"이라고도 함)은 [IEEE 754](https://en.wikipedia.org/wiki/IEEE_floating_point "IEEE floating point") 컴퓨팅 함수 및 연산자에서 사용되는 기본 반올림 모드입니다. 예를 들어, +23.5는 +24가 되고, +24.5도 마찬가지입니다. -22.5는 -22가 되고, -21.5도 마찬가지입니다

두 번째 선택적 매개변수는 반올림의 정밀도를 결정합니다. 기본값은 0입니다. 결과는 가능한 한 가장 정밀한 유형이 됩니다. 정밀도가 0이면 결과는 integer/long 유형이 되고, 다른 모든 정밀도 값의 경우 결과는 decimal 유형이 됩니다.

### 예제

다음 입력을 사용하는 경우:

```java
round(3.5)
```

출력은 Integer/Long 유형입니다:

```java
4
```

다른 입력 예제는 다음과 같습니다:

```java
round(88.725,2)
```

출력은 decimal입니다:

```java
88.72
```

| 값                                                  | 유형    |

## pow {#pow}

숫자를 특정 거듭제곱으로 올립니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값    | 유형                  |
| -------- | --------------------- |
| 숫자 | Integer/Long, Decimal |
| 거듭제곱  | Integer/Long, Decimal |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                | 유형    |
| ------------------------------------ | ------- |
| 거듭제곱 결과, 즉 n^p입니다. | Decimal |

### 예제

다음 입력을 사용하는 경우:

```java
pow(2, 3)
```

출력은 다음과 같습니다:

```java
8
```

다른 입력 예제는 다음과 같습니다:

```java
pow(2.5, 3)
```

출력은 다음과 같습니다:

```java
15.625
```

{{% alert color="info" %}}
decimal 거듭제곱으로 `pow`를 계산하면 정확도가 떨어질 수 있습니다. 표준 Java/JavaScript 라이브러리가 이러한 계산을 높은 정밀도로 지원하지 않기 때문입니다. 이 경우 높은 정밀도가 필요하면 사용자 정의 Java/JavaScript Action에서 전문 라이브러리를 사용하십시오.
{{% /alert %}}

## abs

숫자의 절대값(음이 아닌 값)을 계산합니다.

### 입력 매개변수

입력 매개변수는 아래 표에 설명되어 있습니다:

| 값    | 유형                  |
| -------- | --------------------- |
| 숫자 | Integer/Long, Decimal |

### 출력

출력은 아래 표에 설명되어 있습니다:

| 값                                                        | 유형                    |
| ------------------------------------------------------------ | ----------------------- |
| 절대값으로, 항상 음이 아닙니다. 제곱한 후 양의 제곱근을 취하는 것에 해당합니다. | Integer/Long 또는 Decimal |

### 예제

음수 값을 입력으로 사용하는 경우:

```java
abs(-5)
```

또는 양수 값을 입력으로 사용하는 경우:

```java
abs(5)
```

두 경우 모두 출력은 다음과 같습니다:

```java
5
```
