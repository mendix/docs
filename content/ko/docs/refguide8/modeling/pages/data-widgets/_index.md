## 소개

데이터 위젯은 하나의 객체 또는 객체 목록의 내용을 표시합니다.

데이터 위젯 카테고리에는 다음 위젯이 포함되어 있습니다:

* [Data View](/refguide8/data-view/) – 이 위젯은 정확히 하나의 객체의 내용을 표시합니다. 예를 들어, 단일 프로그램 항목의 세부 정보를 표시하려면 Data View를 사용합니다:

    {{< figure src="/attachments/refguide8/modeling/pages/data-widgets/data-view-example.png"   width="500"  class="no-border" >}}

* [Data Grid](/refguide8/data-grid/) – 이 위젯은 객체 목록을 테이블 형식으로 표시합니다. 예를 들어, Data Grid는 고객이 주문한 모든 주문을 표시할 수 있습니다. Data Grid에서 제공하는 컨트롤을 사용하여 해당 객체를 찾아보고, 검색하고, 편집할 수 있습니다.

    {{< figure src="/attachments/refguide8/modeling/pages/data-widgets/data-grid-example.png"   width="450"  class="no-border" >}}

* [Template Grid](/refguide8/template-grid/) – 이 위젯은 객체 목록을 타일 보기로 표시합니다. 예를 들어, Template Grid는 프로필 사진이 포함된 직원 목록을 표시할 수 있습니다. Template Grid에서 제공하는 컨트롤을 사용하여 해당 객체를 찾아보고, 검색하고, 조작할 수 있습니다.

    {{< figure src="/attachments/refguide8/modeling/pages/data-widgets/template-grid-example.png"   width="450"  class="no-border" >}}

* [List View](/refguide8/list-view/) – 이 위젯은 객체 목록을 표시합니다. 예를 들어, List View를 사용하여 모든 프로필 목록을 표시할 수 있습니다.

    {{< figure src="/attachments/refguide8/modeling/pages/data-widgets/list-view-example.png"   width="450"  class="no-border" >}}
