## 설명

Mendix 전용 설정으로 브라우저에서 [Application URL]의 Mendix 애플리케이션을 엽니다.

## 사용법

열려는 애플리케이션의 URL을 전달하세요. 전역 상수 **Application URL**을 사용할 수도 있습니다.

## 입력 파라미터

Name | Datatype | Required | Description
--- | --- | --- | ---
Application URL | String | yes | 열려는 애플리케이션의 URL입니다.
