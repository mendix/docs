## 소개

**File** 메뉴를 통해 문서와 프로젝트를 관리할 수 있습니다. 예를 들어, 새 프로젝트를 생성하거나 변경 사항을 저장할 수 있습니다:

{{< figure src="/attachments/refguide8/modeling/menus/file-menu/file-menu.png" alt="File Menu"   width="300"  class="no-border" >}}

## 메뉴 항목 개요 {#overview}

**File** 메뉴 항목은 아래 표에 설명되어 있습니다:

| 메뉴 항목                  | 설명                                                  | 단축키                                      |
| -------------------------- | ------------------------------------------------------------ | ------------------------------------------------- |
| **New Document**           | 현재 열려 있는 앱 내에서 새 문서를 생성합니다. 이름, 위치, 문서 유형을 선택할 수 있습니다. | <kbd>Ctrl</kbd> + <kbd>N</kbd>                    |
| **New Project**            | 새 단일 개발자 프로젝트를 생성합니다. 단일 개발자 프로젝트는 로컬 파일 시스템에 저장되는 파일(확장자 *.mpr*, "Mendix project"의 약자)입니다. **New Project** 메뉴 항목과 설정에 대한 자세한 내용은 [New Project](/refguide8/new-project/)를 참조하십시오. | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd> |
| **Open Project**           | 기존 단일 개발자 프로젝트(*.mpr*) 또는 프로젝트 패키지(*.mpk*)를 엽니다. 단일 개발자 프로젝트에 대한 정보는 위의 **New Project**를 참조하십시오. **Open Project** 메뉴 항목에 대한 자세한 내용은 [Open Project](/refguide8/open-app-dialog/)를 참조하십시오. | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> |
| **Recent Projects**        | 빠른 열기를 위해 최근에 열었던 프로젝트 목록을 표시합니다.  |                                                   |
| **Save**                   | 현재 활성 문서 탭의 변경 사항을 저장합니다.      | <kbd>Ctrl</kbd> + <kbd>S</kbd>                    |
| **Save All**               | 열려 있는 모든 문서의 변경 사항을 저장합니다.            | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> |
| **Close**                  | 현재 문서를 닫습니다. 필요한 경우 변경 사항을 저장하거나 취소할지 묻습니다. | <kbd>Ctrl</kbd> + <kbd>W</kbd>                    |
| **Close All**              | 모든 문서 탭을 닫습니다. 필요한 경우 변경 사항을 저장하거나 취소할지 묻습니다. | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> |
| **Close Project**          | 현재 열려 있는 프로젝트를 닫고 홈 페이지로 돌아갑니다. |                                                   |
| **Export as Image**        | 현재 문서를 *.png* 형식의 이미지로 내보냅니다. Microflow, Nanoflow, Domain Model, 문서 템플릿, 규칙 문서 유형을 이미지로 내보낼 수 있습니다. |                                                   |
| **Export Project Package** | 현재 앱을 프로젝트 패키지(*.mpk*) 파일로 내보냅니다. 예를 들어 다른 사람에게 전체 앱을 전달하거나 티켓 제출 시 테스트 앱을 제공해야 할 때 유용합니다. 프로젝트 패키지 내보내기에 대한 자세한 내용은 [Export Project Package](/refguide8/export-project-package-dialog/)를 참조하십시오. |                                                   |
| **Import Project Package** | **Export Project Package** 메뉴 항목으로 생성된 프로젝트 패키지를 가져옵니다. 프로젝트 패키지 가져오기에 대한 자세한 내용은 [Import Project Package](/refguide8/import-project-package-dialog/)를 참조하십시오. |                                                   |
| **Exit**                   | Studio Pro를 닫습니다                                            |                                                   |
