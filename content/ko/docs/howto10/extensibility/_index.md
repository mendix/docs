## 소개

Mendix의 강점 중 하나는 Mendix 애플리케이션을 다른 시스템에 쉽게 연결할 수 있다는 것입니다. [Mendix Marketplace](https://marketplace.mendix.com/)에는 다양한 종류의 커넥터와 어댑터가 준비되어 있습니다. 또한 Widget을 사용하고 생성하여 앱을 확장할 수도 있습니다.

관련하여 Studio Pro의 강점 중 하나는 커스터마이즈 가능성입니다. Studio Pro에 첫 번째 사용자 정의 확장을 추가하는 방법에 대한 자세한 내용은 API 문서의 [Create a Menu Extension](/apidocs-mxsdk/apidocs/csharp-extensibility-api-10/create-menu-extension/)을 참조하십시오.
