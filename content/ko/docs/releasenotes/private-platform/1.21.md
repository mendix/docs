이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.21에 적용된 변경 사항을 다루고 있습니다.

## 1.21.0

### 릴리스 날짜: 2025년 4월 30일

Private Mendix Platform 버전 1.21.0에서는 다수의 새로운 기능, 개선 사항 및 버그 수정이 도입되었습니다.

#### 새로운 기능

##### CI/CD 리소스에 대한 인증 지원

이미지 레지스트리, 버킷 및 파일 서버의 모든 설정을 일관된 방식으로 인증을 지원하도록 업데이트하였습니다. 여기에는 다음 설정이 포함됩니다:

* Build Images 설정:

    * Build Image 레지스트리
    * Build Package Path 파일 서버
    * MxBuild Image 레지스트리
    * Runtime Base Image 레지스트리
    * 출력을 저장하는 OCI 레지스트리

* Marketplace 가져오기:

    * Import Bundle 파일 서버

또한 Build Pipeline에서 이미지 레지스트리 업로드 시 인증이 필요한지 여부를 지정하는 옵션을 추가하였습니다.

##### 사용자 관리 페이지에서 SSO 사용자 시각적 식별

**Manage** > **User Management** 페이지에서 사용자가 로컬 사용자인지 SSO를 통해 활성화된 사용자인지 표시됩니다. SSO 사용자는 페이지에서 **SSO** 아이콘으로 식별됩니다.

#### 개선 사항

##### Pipeline 호출 개선

이제 REST API를 사용하여 완료된 Pipeline을 호출할 수 있습니다.

##### 엔지니어링 개선

Private Mendix Platform 코드를 SP 10.18.5로 업데이트하였습니다.

#### 업데이트

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.34](/releasenotes/studio-pro/9.24/#92434)로 업데이트되었습니다 (프로덕션 지원)
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.22](/releasenotes/studio-pro/10.6/#10621)로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)
* Studio Pro 10.12 MTS 최신 패치 버전이 [10.12.16](/releasenotes/studio-pro/10.12/#101216)으로 업데이트되었습니다 (이노베이션 트랙, 제한적 지원)
* Studio Pro 10.18 MTS 지원은 호환성 문제로 인해 연기되었습니다

##### 기타 플랫폼 구성 요소

* Mendix on Kubernetes Operator 버전 [2.21.2](/releasenotes/developer-portal/mendix-for-private-cloud/#2.21.2)
* Private Cloud License Manager (PCLM) 버전 [0.10.2](/releasenotes/developer-portal/mendix-for-private-cloud/#license-manager-cli-v0102)
* SVIX webhooks 서비스 v.1.42.0

#### 수정 사항

다음 수정 사항을 제공합니다:

* (플랫폼) 기존 Bitbucket 계정과 동일한 사용자 이름 또는 이메일로 Private Platform 계정을 생성하는 것을 방지하기 위한 추가 유효성 검사를 추가하였습니다.
* (플랫폼) 화면 잠금과 관련된 여러 문제를 해결하였습니다.
* (플랫폼) 사용자 정의 속성 매핑을 사용한 OIDC 로그인 시 발생하던 문제를 수정하였습니다.
* (UI) 로그아웃 후 다시 로그인했을 때 프로젝트 삭제에 대한 메시지가 표시되던 문제를 수정하였습니다.
* (UI) 딥 링크와 관련된 여러 문제를 해결하였습니다.
* (UI) 기타 사소한 UI 개선 및 수정을 진행하였습니다.
