## 소개

*Mendix Studio Pro 10 가이드*는 [Studio Pro](/refguide10/modeling/), [Mendix Runtime](/refguide10/runtime/) 및 Mendix Platform의 기타 구성 요소에 관한 중요한 주제를 다룹니다.

Studio Pro는 Windows와 macOS 모두에서 실행됩니다. Studio Pro 10을 설치하기 전에 [시스템 요구 사항](/refguide10/system-requirements/)을 확인하십시오. Studio Pro 설치 방법에 대한 정보는 [Mendix Studio Pro 설치하기](/refguide10/install/)를 참조하세요.

Studio Pro 버전 9를 사용해 왔다면 [Mendix Studio Pro 9에서 10으로 업그레이드](/refguide10/upgrading-from-9-to-10/)를 읽어보시기 바랍니다.

첫 번째 앱을 빌드하려면 [빠른 시작](/quickstarts/)을 확인하세요.

다양한 Mendix 작업을 수행하는 단계별 가이드를 찾고 있다면 [Studio Pro 10 사용 방법](/howto10/)을 참조하세요.

## Studio Pro 기능

Studio Pro를 사용하면 앱을 생성, 테스트 및 실행할 수 있습니다.

### 모델링

앱 모델링은 앱을 생성하는 과정으로, 페이지 작성, 로직 추가, 보안 구성 등을 포함합니다. 앱 모델링에 사용할 수 있는 기능에 대한 자세한 정보는 [앱 모델링](/refguide10/modeling/)을 참조하세요.

### 테스트

애플리케이션 테스트와 관련하여 먼저 외부 서비스와의 통합, 앱 로직(Microflow) 등 무엇을 테스트할지 결정해야 합니다. 애플리케이션 테스트 방법에 대한 자세한 정보는 [테스트](/howto10/testing/)를 참조하세요.

### 배포

Studio Pro를 사용하면 앱을 로컬로 또는 기본 환경에서 실행하고 볼 수 있습니다.

앱 배포 옵션에 대한 자세한 정보는 [앱 배포](/deployment/)를 참조하세요.

## Version Control

[Version Control](/refguide10/version-control/)을 통해 앱 개발을 관리하고 여러 개발 라인에서 작업할 수 있습니다. Studio Pro가 앱 버전 관리를 처리하는 방법에 대한 정보는 *Studio Pro에서 Version Control 사용하기*의 [클라우드에 배포된 앱 버전 관리](/refguide10/using-version-control-in-studio-pro/#versioning-app) 섹션을 참조하세요.

## Mendix Runtime

[Mendix Runtime](/refguide10/runtime/)은 Studio Pro에서 생성된 애플리케이션 모델을 실행합니다. 동일한 버전 번호를 사용하므로 Studio Pro 10 가이드에 포함되어 있습니다.

## 모바일

모바일 앱 개발을 통해 네이티브 모바일 및 프로그레시브 웹 앱을 만들 수 있습니다. 자세한 정보는 [모바일](/refguide10/mobile/)을 참조하세요.
