## December 2018

### December 17, 2018

#### 개선 사항

App Store에서 검색할 때(**Search Mendix** 검색 바 사용) 사용자들이 **Mendix**, **Modeler**, **Desktop**, **Download**와 같은 키워드와 다양한 Desktop Modeler 버전을 자주 사용하는 것을 확인했습니다. 이러한 키워드를 기반으로 검색 결과가 예상되는 결과를 제공하지 않았습니다(즉, Modeler 다운로드 페이지를 표시하지 않음). 이번 업데이트로 **Search Mendix** 검색 바에서 Modeler 및 모든 버전을 검색할 수 있게 되었으며, Mendix Marketplace의 [Desktop Modeler 페이지](https://marketplace.mendix.com/link/studiopro/)로 리디렉션됩니다.

## October 2018

### October 1, 2018

#### SAP OData Connector 4.0

 이 버전의 [SAP OData Connector](https://marketplace.mendix.com/link/component/74525/)를 사용하면 SAP Cloud Platform의 Destination 서비스를 사용할 수 있습니다. 이를 통해 SAP Cloud Platform에서 실행되는 애플리케이션을 SAP 백엔드 서비스와 통합할 때 구성, 인증 및 엔드포인트 관리가 간소화됩니다. [SAP Destination Service](/developerportal/deploy/sap-cloud-platform/sap-destination-service/)를 참조하세요.

현재 SAP Destination Services에서 지원되는 인증 유형은 다음과 같습니다:

* PrincipalPropagation 인증 및 ProxyType 온프레미스 (Connectivity Service/Cloud Connector/온프레미스 백엔드)
* Oauth2SALMAssertion 인증 (Neo Platform 앱용)
* 공개 백엔드를 위한 Basic 및 None 인증

#### SAP Leonardo Machine Learning Foundation Connector Version 1.0.0

이 새로운 커넥터를 사용하면 Mendix 모델에 Activity를 추가하여 API Business Hub 및 SAP Cloud Platform에서 Leonardo Machine Learning 서비스를 사용할 수 있습니다.

SAP Leonardo Machine Learning Foundation Connector는 App Store에서 제공됩니다: https://marketplace.mendix.com/link/component/107221/.

#### SAP Fiori 스타일링

기존 SAP Blank 앱 템플릿이 새로운 Fiori Blank 앱 템플릿으로 교체되었습니다. 이 새로운 Fiori Blank 앱 템플릿에는 새로운 Fiori UI Package가 포함되어 있습니다. 이는 Atlas UI를 기반으로 하므로, Web Modeler 또는 Desktop Modeler를 사용하여 SAP Fiori UI 경험을 제공하는 애플리케이션을 구축할 수 있습니다.

#### 호환성 변경 사항

새로운 **SAP OData Connector**는 SAP Cloud Connector를 사용하는 기존 프로젝트를 손상시킬 수 있습니다. SAP OData Connector는 더 이상 "Use Cloud Connector" 속성을 지원하지 않습니다. 이는 이제 Destination 서비스 구성에 포함되어 있습니다. 자세한 내용은 [SAP Destination Service](/developerportal/deploy/sap-cloud-platform/sap-destination-service/)를 참조하세요.
