## Introduction

A bubble chart shows one or more series as bubbles. The size of each bubble is set by an attribute.

For the properties that all series-based charts share, such as the **Series** list, **Dimensions**, and **Advanced** settings, see [Common Chart Properties](/appstore/widgets/charts/#common-properties). This page describes the properties that are specific to the bubble chart.

## Edit Series Dialog Box – General Tab

In addition to the [common series properties](/appstore/widgets/charts/#series-general), the **General** tab has these properties:

* **Bubble size attribute** – The attribute whose value determines the size of the bubble.
* **Auto scale** – If set to **Yes**, bubble sizes are scaled automatically. If set to **No**, the **Scale factor** is used.
* **Scale factor** – The number used to calculate the rendered bubble size. The value of the **Bubble size attribute** is multiplied by this factor. This property is visible only when **Auto scale** is set to **No**. The default value is **10**.

## Edit Series Dialog Box – Appearance Tab

* **Marker color** – The color of the bubbles for this series.
