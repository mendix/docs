## 7.0.25 {#725}

**릴리스 날짜: 2025년 1월 30일**

* Node.js 버전을 v20으로 업그레이드했습니다.
* Java 8 이후 MaxPermSize를 사용할 수 없으므로 Android에서 MaxPermSize JVM 매개변수를 MaxMetaspaceSize로 교체했습니다.

## 7.0.24 {#724}

**릴리스 날짜: 2025년 1월 15일**

* 커스텀 빌드된 Mendix Native Developer App에서 원격 JavaScript 디버깅이 실패하여 "Remote JS Debugging"을 활성화할 때 충돌이 발생하는 문제를 해결했습니다. 이 문제는 빌드 과정에서 Firebase 서비스가 올바르게 초기화되지 않아 발생했습니다. 이제 Firebase 종속성은 애플리케이션에서 명시적으로 필요한 경우에만 포함됩니다.

## 7.0.23 {#723}

**릴리스 날짜: 2025년 1월 7일**

* App Center의 Xcode 버전을 15.4로 업데이트했습니다.

## 7.0.22 {#722}

**릴리스 날짜: 2025년 1월 3일**

* Android SDK 34 이상에 맞게 **registerReceiver** 메서드의 구현을 업데이트했습니다.

## 7.0.20 {#720}

**릴리스 날짜: 2024년 12월 23일**

* Android에서 minSDK를 23으로 업데이트했습니다.

## 7.0.19 {#719}

**릴리스 날짜: 2024년 10월 1일**

### 개선 사항

* `react-native-permissions`를 버전 3.6.1로 업그레이드했습니다.

## 7.0.17 {#717}

**릴리스 날짜: 2024년 9월 3일**

### 수정 사항

* iOS 18에서의 OTA 업데이트 호환성 문제를 수정했습니다.

## 7.0.16 {#716}

**릴리스 날짜: 2024년 8월 29일**

### 수정 사항

* Xcode 15.3에서 Flipper 관련 빌드 오류를 해결했습니다.

## 7.0.15 {#715}

**릴리스 날짜: 2024년 8월 5일**

### 개선 사항

* Android의 `buildToolsVersion`, `compileSdkVersion`, `targetSdkVersion`을 34로 업그레이드했습니다.

## 7.0.14 {#714}

**릴리스 날짜: 2024년 6월 28일**

### 수정 사항

* <a id="fix-cookie-encryption"></a> `@mendix/native` 종속성을 업데이트하여 [알려진 쿠키 암호화 문제](#kis-713)를 수정했습니다. 이 버전으로 앱을 업데이트한 후에도 문제가 계속되는 사용자는 앱의 캐시를 지우고 앱을 다시 로드하세요.

## 7.0.13 {#713}

**릴리스 날짜: 2024년 6월 5일**

### 개선 사항

* Android에서 암호화된 파일 동기화를 개선했습니다.

### 알려진 문제 {#kis-713}

* 기존 메커니즘과 호환되지 않는 것으로 판명된 쿠키 암호화 문제를 해결했습니다. 이로 인해 앱 로드 시 다음 예외가 발생합니다: `java.security.InvalidAlgorithmParameterException Unsupported IV length: 16 bytes. Only 12 bytes long IV supported`
    * [Native Template 7.0.14](#fix-cookie-encryption)에서 수정되었습니다. 

## 7.0.12 {#712}

**릴리스 날짜: 2024년 5월 27일**

### 개선 사항

* Android 14에서 [로컬 알림](/refguide/mobile/using-mobile-capabilities/local-notifications/) 예약 지원을 추가했습니다.

## 7.0.11 {#711}

**릴리스 날짜: 2024년 5월 13일**

## 7.0.10 {#710}

**릴리스 날짜: 2024년 3월 15일**

### 개선 사항

## 7.0.9 {#709}

**릴리스 날짜: 2023년 10월 13일**

### 수정 사항

* 최근 Xcode 15 업데이트로 인한 빌드 오류를 수정했습니다.

## 7.0.8 {#708}

**릴리스 날짜: 2023년 9월 25일**

### 수정 사항

* Android에서 파일 암호화를 개선했습니다.

## 7.0.7 {#707}

**릴리스 날짜: 2023년 9월 22일**

### 수정 사항

* 필요한 데이터만 지우도록 `clearKeychain` 메서드를 업데이트했습니다.

## 7.0.6 {#706}

**릴리스 날짜: 2023년 9월 15일**

### 추가 사항

* Android 매니페스트 파일에 `com.google.android.gms.permission.AD_ID` 권한을 추가했습니다. 이 권한은 광고 ID에 대한 접근을 관리하여 앱의 광고 서비스 내에서 보다 효과적인 타겟팅과 개인화를 지원합니다.
    * 현재 이 권한은 `tools:node="remove"` 속성으로 비활성화되어 있습니다.

## 7.0.5 {#705}

**릴리스 날짜: 2023년 8월 24일**

### 개선 사항

* Android SDK 버전을 33으로 업그레이드했습니다.

## 7.0.3 {#703}

**릴리스 날짜: 2023년 8월 8일**

### 수정 사항

## 7.0.2 {#702}

**릴리스 날짜: 2023년 8월 1일**

* 커스텀 개발자 앱의 iOS 버전에서 QR 코드 스캐너가 작동하지 않는 문제를 수정했습니다.

## 7.0.1 {#701}

**릴리스 날짜: 2023년 4월 13일**

### 수정 사항

* AppCenter 및 로컬 모두에서 빌드 단계 중 중복 심볼이 발생하는 iOS 빌드 문제를 수정했습니다.
* Android 기기의 쿠키에 영향을 미치는 문제를 수정했습니다. (티켓 178853, 178053)
* Android에서 `mailto` 스키마에 영향을 미치는 문제를 수정했습니다. (티켓 180301)

## 7.0.0 {#700}

### 개선 사항

* Studio Pro [9.24](/releasenotes/studio-pro/9.24/)와 호환되도록 특정 라이브러리를 업데이트했습니다.
