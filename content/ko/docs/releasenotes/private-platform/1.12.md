이 릴리스 노트는 [Private Mendix Platform](/private-mendix-platform/) 버전 1.12에 적용된 변경 사항을 다루고 있습니다.

## 1.12.0

### 릴리스 날짜: 2024년 8월 8일

Private Mendix Platform 버전 1.12.0에서는 다수의 버그 수정, 새로운 기능 및 엔지니어링 개선 사항이 도입되었습니다.

#### 새로운 기능

##### API Endpoint를 통한 MDA 다운로드

이제 Project API의 새로운 엔드포인트를 사용하여 *.mda* 앱 패키지를 다운로드할 수 있습니다. 또한 API를 사용하여 특정 프로젝트에 사용 가능한 패키지 목록을 얻을 수 있습니다. 자세한 내용은 [Private Mendix Platform Project API](/apidocs-mxsdk/apidocs/private-platform-project-api/)를 참조하십시오.

#### 개선 사항

##### Pipeline 개선

Build 및 Deploy Pipeline에서 일부 단계는 이제 사전 설정된 시간 간격 후 자동으로 타임아웃됩니다. Manual Approve 및 Waiting for Rest Call 단계에 대해 타임아웃까지의 시간을 설정할 수 있습니다. Manual Approve 단계의 경우 프로젝트 소유자와 수동 승인 권한이 있는 프로젝트 멤버에게 알림 메시지가 전송됩니다.

##### Webhook 개선

Webhook은 이제 Pipeline에서의 위치에 따라 유형별로 자동 분류됩니다. 사용되지 않는 Webhook 등록도 자동으로 제거됩니다.

#### 엔지니어링 개선

* Private Mendix Platform은 이제 Java 버전 11, 17, 21을 지원합니다.
* Mendix Operator 버전을 2.18.1로 업그레이드하였습니다.
* svix 버전을 1.25로 업그레이드하였습니다.
* PCLM 버전을 0.7.1로 업그레이드하였습니다.

##### Studio Pro 업데이트

* Studio Pro 9.24 LTS 최신 패치 버전이 [9.24.24](/releasenotes/studio-pro/9.24/#92424)로 업데이트되었습니다
* Studio Pro 10.6 MTS 최신 패치 버전이 [10.6.11](/releasenotes/studio-pro/10.6/#10611)로 업데이트되었습니다

#### 수정 사항

다음 수정 사항을 제공합니다:

* (Marketplace) 시스템 관리자가 Marketplace 콘텐츠 가져오기를 비활성화할 수 없던 문제를 해결하였습니다.
* (Marketplace) Marketplace 번들을 업로드하고 Private Mendix Platform으로 가져올 수 없던 문제를 수정하였습니다
* (플랫폼) Company Admin이 **Platform Statistics** 페이지에 접근할 수 없던 문제를 해결하였습니다.
* (플랫폼) 접근 권한이 취소된 후에도 사용자가 로그 및 메트릭을 볼 수 있던 문제를 해결하였습니다.
* (플랫폼) 취약점을 수정하였습니다.
* (UI) 다수의 UI 관련 문제를 수정하였습니다.

#### 알려진 문제

##### Studio Pro 10.12 MTS와의 비호환성

이번 릴리스에서는 Studio Pro 10.12 MTS를 아직 사용할 수 없습니다.

###### 원인

호환성 문제입니다.

###### 해결 방법

이 문제는 향후 릴리스에서 해결될 예정입니다.

##### 플랫폼 버전 1.12.0으로 업데이트 후 Build OCI Image 실패

Private Mendix Platform을 버전 1.12.0으로 업그레이드한 후 Build OCI Image가 실패합니다.

###### 원인

새 버전에서 Runtime Base Image의 기본값이 변경되었지만 인스턴스에서 이전 값을 사용하고 있기 때문입니다.

###### 해결 방법

**Setting** > **Build** > **Build Images Setting**에서 **Runtime Base Image** 값을 `private-cloud.registry.mendix.com/app-building-blocks`로 설정하십시오.
