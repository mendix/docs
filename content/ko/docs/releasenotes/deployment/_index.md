배포 릴리스 노트는 배포 대상별로 분류되어 있어, 선택하신 배포 방식에 해당하는 노트를 함께 확인하실 수 있습니다.

아래 표의 링크를 클릭하여 원하시는 릴리스 노트를 확인하세요:

| 배포 유형 | 최종 업데이트 |
| --- | --- |
| [Mendix Cloud](/releasenotes/developer-portal/mendix-cloud/) | 2026년 2월 1일 |
| [Mendix on Kubernetes](/releasenotes/developer-portal/mendix-for-private-cloud/) | 2026년 1월 29일 |
| [Mendix on Azure](/releasenotes/developer-portal/mendix-on-azure/) | 2026년 1월 29일 |
| [SAP Business Technology Platform (SAP BTP)](/releasenotes/developer-portal/sap-cloud-platform/) | 2025년 9월 28일 |
| [기타 배포 옵션](/releasenotes/developer-portal/on-premises/) | 2023년 9월 15일 |

빌드팩에 대한 릴리스 노트는 각각의 GitHub 저장소에서 확인하실 수 있습니다:

* [Mendix Cloud Foundry Buildpack – cf-mendix-buildpack](https://github.com/mendix/cf-mendix-buildpack/releases)
* [Mendix Buildpack for Docker – docker-mendix-buildpack](https://github.com/mendix/docker-mendix-buildpack/releases)

Mendix Cloud 및 Mendix on Kubernetes의 현재 상태를 확인하려면 [Mendix Status](https://status.mendix.com/)를 참조하세요. 여기에서 계획된 유지보수 및 과거 인시던트도 확인하실 수 있습니다.
