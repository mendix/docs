네이티브 모바일 앱 개발에 대한 자세한 내용은 [native-template](https://github.com/mendix/native-template/) 리포지토리와 [앱 빌드, 테스트 및 배포](/refguide/mobile/distributing-mobile-apps/) 가이드를 참조하세요. 아래에서 현재 활발히 개발 중인 버전과 해당하는 Mendix Studio Pro 버전을 확인할 수 있습니다.

Studio Pro 11과 호환:

* Native Template [17](/releasenotes/mobile/nt-17-rn/) 버전은 Studio Pro [11.6](/releasenotes/studio-pro/11.6/) 이상으로 빌드된 앱과 호환됩니다.
* Native Template [16](/releasenotes/mobile/nt-16-rn/) 버전은 Studio Pro [11.5](/releasenotes/studio-pro/11.5/) 이상으로 빌드된 앱과 호환됩니다.
* Native Template [15](/releasenotes/mobile/nt-15-rn/) 버전은 Studio Pro [11.0](/releasenotes/studio-pro/11.0/) 이상으로 빌드된 앱과 호환됩니다.

Studio Pro 10과 호환:

* Native Template [13](/releasenotes/mobile/nt-13-rn/) 버전은 Studio Pro [10.21](/releasenotes/studio-pro/10.21/) 이상으로 빌드된 앱과 호환됩니다.
* Native Template [12](/releasenotes/mobile/nt-12-rn/) 버전은 Studio Pro [10.19](/releasenotes/studio-pro/10.19/) 이상으로 빌드된 앱과 호환됩니다.
* Native Template [11](/releasenotes/mobile/nt-11-rn/) 버전은 Studio Pro [10.18](/releasenotes/studio-pro/10.18/) 이상으로 빌드된 앱과 호환됩니다.
* Native Template [10](/releasenotes/mobile/nt-10-rn/) 버전은 Studio Pro [10.17](/releasenotes/studio-pro/10.17/) 이상으로 빌드된 앱과 호환됩니다.
* Native Template [9](/releasenotes/mobile/nt-9-rn/) 버전은 Studio Pro [10.13](/releasenotes/studio-pro/10.13/)-[10.16](/releasenotes/studio-pro/10.16/)으로 빌드된 앱과 호환됩니다.
