Microsoft SQL Server 플랫폼을 사용하여 Mendix를 온프레미스에 배포할 때 Mendix 데이터베이스의 양호한 상태를 유지하기 위해 여러 가이드라인을 준수해야 합니다. 이 웹사이트의 사용 방법 섹션에는 균일한 유지 관리 및 백업 계획 세트를 구성하여 DBMS를 Mendix 표준에 맞게 설정하는 방법에 대한 단계별 가이드가 포함되어 있습니다. 모범 사례는 다음과 같은 요구 사항을 제시합니다:

* 전담 SQL 서버 운영자를 지정하십시오. 이 운영자가 (유지 관리) 알림 및 상태 메시지를 수신합니다
* Mendix 데이터베이스에 대한 예상 부하를 파악하십시오. 많이 사용되는 데이터베이스는 가벼운 요청 부하를 가진 데이터베이스와 다른 유지 관리 간격이 필요합니다.
* 데이터베이스의 예상 사용량을 기반으로 무결성 검사 및 인덱스 재빌드를 수행해야 하는 빈도를 정의하십시오.
* 조직의 요구 사항에 맞는 백업 계획을 수립하십시오. 조직의 요구와 스토리지 환경의 기술 사양 사이에서 균형을 찾으십시오. 예를 들어, 테이프 백업과의 중복에 유의하고 백업 보관을 고려하십시오.

자세한 내용은 [Mendix SQL 유지 관리 계획 구성 방법](/developerportal/deploy/mendix-sql-maintenance-plans/)을 참조하십시오.
