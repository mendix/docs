## 설명

지정된 값에 연결된 체크박스를 찾아 선택하거나 해제합니다.

## 지원 Widget

* Simple Checkbox Set Selector

## 사용법

Widget의 이름, 체크박스에 연결된 값, 그리고 체크박스를 선택할지 해제할지를 전달하세요.

## 입력 파라미터

Name | Datatype | Required | Description
---- | -------- | -------- | ---------------
Widget Name | String | Yes | Simple Checkbox Set Selector Widget의 이름입니다.
Value | String | Yes | 체크박스에 연결된 값입니다.
Checked | Boolean | Yes | 체크박스를 선택하거나 해제합니다.
