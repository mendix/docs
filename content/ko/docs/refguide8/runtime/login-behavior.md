## 기본 로그인 동작

사용자는 로그인 시도 사이의 시간에 관계없이 연속 3회 잘못된 로그인 시도 후 차단됩니다. 실패한 로그인 횟수는 로그인 성공 후 또는 차단된 사용자가 차단 해제될 때 재설정됩니다. 사용자 차단은 프로젝트 보안 레벨이 'Production'으로 설정된 경우에만 발생합니다.

사용자는 클러스터 관리자가 실행될 때마다 차단이 해제되며, 그 시점에서 실패한 로그인 횟수도 0으로 재설정됩니다. 기본적으로 클러스터 관리자는 5분마다 실행됩니다. 이 간격은 [Runtime 사용자 정의](/refguide8/custom-settings/)의 `ClusterManagerActionInterval` 설정을 사용하여 변경할 수 있습니다.

{{% alert color="warning" %}}
클러스터 관리자는 사용자 차단 해제 외에도 더 많은 작업을 수행합니다. 예를 들어, 만료된 세션을 제거합니다. 따라서 이 간격을 변경하면 더 광범위한 영향이 있습니다.
{{% /alert %}}

{{% alert color="info" %}}
클러스터 관리자가 차단된 모든 사용자의 차단을 해제하기 시작하기 불과 1초 전에 사용자가 차단된 경우, 1초 후에 잠금이 해제됩니다.
{{% /alert %}}

## 로그인 동작 사용자 정의

커스텀 Java Action을 구현하고 기본 로그인 작업 대신 사용하도록 등록하여 로그인 동작을 사용자 정의할 수 있습니다.

클러스터 관리자 동작은 현재 변경할 수 없습니다.
