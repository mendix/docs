{{% alert color="warning" %}}**Login ID 텍스트 박스** 위젯은 네이티브 모바일 페이지에서 지원되지 않습니다.{{% /alert %}}

## 소개

**Login ID 텍스트 박스**는 인증을 위한 로그인 ID를 제공하는 데 사용할 수 있는 위젯입니다. 로그인 ID는 사용자의 고유 식별자로, 예를 들어 사용자 이름이나 이메일 주소입니다:

{{< figure src="/attachments/refguide8/modeling/pages/authentication-widgets/login-id-text-box/login-id.png" alt="Login ID Text Box" class="no-border" >}}

**Login ID 텍스트 박스**는 [Password 텍스트 박스](/refguide8/password-text-box/) 및 [Sign-in 버튼](/refguide8/sign-in-button/)과 함께 페이지에 배치해야 합니다.

#### Placeholder

**Placeholder**는 최종 사용자가 아직 텍스트를 입력하지 않았을 때 표시되는 텍스트입니다. 필드에 어떤 정보를 입력해야 하는지 최종 사용자에게 힌트를 제공하는 데 사용할 수 있습니다.
