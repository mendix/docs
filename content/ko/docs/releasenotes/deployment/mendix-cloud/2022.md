## November 2022

### November 14, 2022

#### Improvements

* Mendix Cloud v4의 발신 IP 주소에 대한 역방향 DNS를 구성했습니다. 역방향 DNS 조회는 이메일 서비스에서 스팸을 필터링하는 데 일반적으로 사용됩니다.

### November 10, 2022

#### Improvements

* **Virtual Machine Out of Memory** 및 **Virtual Machine Error** 알림을 업데이트하여 애플리케이션 동작에 대한 더 많은 명확성과 가시성을 제공합니다. 이 변경 사항은 앱을 다시 배포한 후 사용할 수 있습니다.
* 지원되지 않는 사용자 정의 런타임 설정을 설정하려고 하면 경고를 표시합니다. 이러한 설정은 주로 스토리지 옵션과 관련되며 Mendix Cloud 배포에 의해 제어되므로 Mendix Cloud에 배포된 앱에 대해 사용자 정의할 수 없습니다.

### November 1, 2022

#### Improvements

* 모든 `*.mendixcloud.com` 도메인에 대해 DNSSEC를 활성화했습니다.

### March 30, 2022{#waf}

#### Improvements

* Mendix Cloud에 배포된 Free App을 위한 Web Application Firewall(WAF) 서비스를 구현했습니다.

    Web Application Firewall(WAF)은 애플리케이션 코드를 수정하지 않고 악의적이고 원치 않는 인터넷 트래픽으로부터 애플리케이션을 보호하는 보안 서비스입니다. Free App용 WAF는 [OWASP Top 10](https://owasp.org/www-project-top-ten/)과 같은 OWASP 출판물에 설명된 다수의 고위험 및 일반적으로 발생하는 취약점을 포함한 다양한 공격 범주를 해결합니다. 여기에는 다음이 포함됩니다:

    * Cross-site scripting
    * HTTP protocol violations
    * Bots, crawlers, and scanners
    * HTTP Denial of Service
    * Server-side request forgery
    * Local File Inclusion
    * Log4j remote code execution
